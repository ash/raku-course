## Problema

Scribe grammaticam quae `bool` analysat, qui aut verbum `true` aut verbum `false` est. Utere **tessera proto** cum duabus variantibus `:sym<…>`. Analysa `'true'`, `'false'`, et etiam `'unknown'` (qui neuter est), imprimens utrum unaquaeque successerit.

## Exemplum

Programma imprimit:

```
True
True
False
```
