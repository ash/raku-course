Quid haec programma imprimit?

```raku
say 'a_1 b' ~~ /\W/;
```

{:.quiz}
0 | ｢a｣
0 | ｢_｣
0 | ｢1｣

{% include quiz.html %}

<div class="extended-explanation">

Classis `\W` primum characterem congruit qui littera, cifra vel lineola infima **non** est. Characteres `a`, `_` et `1` omnes characteres verbi sunt, itaque primus character non verbi spatium est.
