## Codex

```raku
say so '3 apples' ~~ /^ \d /;
```

🦋 Inveni codicem fontem in archivo [starts-with.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/anchors/starts-with.raku).

## Exitus

```
True
```

## Commentarii

1. Ancora `^` congruentiam ab initio catenae incipere cogit, et `\d` deinde postulat illum primum characterem cifram esse.

1. Sine `^` exemplar etiam pro cifra alicubi posterius in catena apparente succederet, qualis `'apples 3'`.
