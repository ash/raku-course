Ecce solutio possibilis huius exercitationis.

## Codex

```raku
say so 'hello' ~~ /^ <[a..z]>+ $/;
```

🦋 Inveni codicem fontem in archivo [whole-string.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/anchors/whole-string.raku).

## Exitus

```
True
```

## Commentarii

1. Ancorae `^` et `$` exemplar ad initium et finem catenae adfigunt.

1. Inter eas `<[a..z]>+` omnem characterem explicare debet, itaque catena cum littera maiuscula vel spatio, qualis `Hello there`, deficeret.
