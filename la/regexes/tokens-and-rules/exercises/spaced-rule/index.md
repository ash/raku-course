## Problema

Scribe grammaticam cuius `TOP` est **regula** quae tria verba spatiis separata congruit. Unumquodque verbum est tessera unius vel plurium characterum verbi. Analysa `'the quick fox'` et imprime utrum successerit (simplex `True` vel `False`).

## Exemplum

Programma imprimit:

```
True
```
