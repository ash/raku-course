Quod argumentum facit ut `IO::Socket::INET` coniunctiones advenientes exspectet pro eo quod ad servitorem vocat?

{:.quiz}
1 | `:listen`
0 | `:host`
0 | `:server`
0 | `:accept`

{% include quiz.html %}

<div class="extended-explanation">

`:listen` foramen in modum servitoris ponit, in inscriptione et portu locali exspectans. Deinde `.accept` vocas ut unamquamque coniunctionem advenientem capias. (`.accept` methodus est, non argumentum constructoris.)

</div>
