## Problema

Fac ut servitor opus verum cum ingressu clientis agat, pro eo quod catenam fixam reddit. Scribe servitorem qui, in **anulo** (ut in pagina priore), unamquamque petitionem legit, **viam** petitam capit, eamque **maiusculis scriptam** remittit — ita ut petitio pro `/hello` `HELLO` respondeat. Via est secundum verbum primae lineae petitionis (`GET /hello HTTP/1.0`); abice `/` praecedens antequam eam in maiusculas vertas. Petitioni post petitionem servire pergit; siste eum per Ctrl-C.

## Exemplum

Viam per `curl` poscere eam maiusculis reddit:

```console
$ curl http://127.0.0.1:8080/hello
HELLO
```
