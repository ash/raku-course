## Problema

Amplifica servitium salutationis via **secunda**: via `GET` pro semita `bye` quae textum simplicem `Goodbye!` reddit. Serva viam originalem `hello` quoque.

> Haec exercitatio Cro installato eget (`zef install cro`).

## Exemplum

Petitio ad `/bye` reddit:

```
Goodbye!
```
