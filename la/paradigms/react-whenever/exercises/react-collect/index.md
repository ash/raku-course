## Problema

Bloco `react` utens, divide unum fluxum in duas collectiones. Specta supply ex `4, 42, 7, 100, 15` aedificatum et, intra corpus `whenever`, immitte omnem valorem maiorem quam `10` in `@big` et ceteros in `@small`. Imprime utrumque ordinem postquam blocus react finivit.

## Exemplum

Programma imprimit:

```
[4 7]
[42 100 15]
```
