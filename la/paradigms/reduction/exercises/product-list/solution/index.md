## Codex

```raku

```

## Exitus

```
720
```

## Commentarii

1. `[*]` `*` inter omnia intervalli elementa inserit, ea omnia multiplicans.

1. `1 * 2 * 3 * 4 * 5 * 6` est `720` — idem quod factorialis numeri `6`.
