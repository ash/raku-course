Ecce solutio possibilis huius exercitationis.

## Codex

```raku
say [~] '2', '0', '2', '5';
```

🦋 Inveni codicem fontem in archivo [join-strings.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/join-strings.raku).

## Exitus

```
2025
```

## Commentarii

1. `[~]` operatorem concatenationis `~` inter catenas inserit.

1. `'2' ~ '0' ~ '2' ~ '5'` unam catenam `2025` producit.
