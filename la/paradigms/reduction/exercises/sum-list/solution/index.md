Ecce solutio possibilis huius exercitationis.

## Codex

```raku
say [+] 10, 20, 30, 40;
```

🦋 Inveni codicem fontem in archivo [sum-list.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/sum-list.raku).

## Exitus

```
100
```

## Commentarii

1. `[+]` operatorem `+` inter omnia indicis elementa inserit.

1. Summa `10 + 20 + 30 + 40` est `100`.
