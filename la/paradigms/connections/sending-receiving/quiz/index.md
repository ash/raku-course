In petitione HTTP per foramen missa, quid finem capitum petitionis notat?

{:.quiz}
0 | Punctum
1 | Linea vacua (`\r\n` superfluum)
0 | Verbum `END`
0 | Foramen claudere

{% include quiz.html %}

<div class="extended-explanation">

HTTP capita a corpore separat — et «nulla capita amplius» significat — per lineam vacuam, ut `\r\n` superfluum scriptam. Sine ea, servitor reliquum petitionis exspectare pergit.
