## Problema

Numerus triangularis _n_-us est summa `n + (n - 1) + … + 1`, numero triangulari nullo `0` existente. Scribe subprogramma recursivum `tri` quod illum computat, sed illud **duobus candidatis `multi`** potius quam condicione intra unum corpus exprime: uno candidato pro casu fundamentali, uno pro gradu recursivo. Imprime `tri(5)`.

## Exemplum

Programma imprimit:

```
15
```
