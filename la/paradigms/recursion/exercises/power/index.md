## Problema

Scribe subprogramma recursivum `power($base, $exp)` quod `$base` ad potentiam `$exp` multiplicando elevat — sine operatore `**`. Casus fundamentalis est `$exp == 0`, qui `1` dat; aliter responsum est `$base` per `power($base, $exp - 1)`. Imprime `power(2, 10)`.

## Exemplum

Programma imprimit:

```
1024
```
