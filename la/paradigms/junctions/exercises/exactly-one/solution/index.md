Ecce solutio possibilis huius exercitationis.

## Codex

```raku
say so one(1, 2, 3) == 2;
```

🦋 Inveni codicem fontem in archivo [exactly-one.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/junctions/exactly-one.raku).

## Exitus

```
True
```

## Commentarii

1. Iunctura `one` vera est solum cum **exacte unus** valor comparationi congruit.

1. Exacte unus ex `1, 2, 3` `2` aequat, itaque effectus est `True`. Si duo congruerent (vel nullus), `False` esset. `so` iuncturam in simplicem Booleanam contrahit.
