## Codex

```raku
say so none(3, 7, 2) < 0;
```

🦋 Inveni codicem fontem in archivo [none-negative.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/junctions/none-negative.raku).

## Exitus

```
True
```

## Commentarii

1. Iunctura `none` vera est cum **nullus** valor comparationi congruit.

1. Nullus ex `3, 7, 2` infra nihil est, itaque effectus est `True`. Unus valor negativus illud `False` faceret.
