## Problema

Datis tribus longitudinibus laterum, decerne utrum triangulum aequilaterum, isosceles an
scalenum efficiant — an nullum triangulum omnino cum latus longissimum nimis longum est.
Distingue `(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)` et `(1, 2, 10)`.

## Exemplum

Programma imprimit:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
