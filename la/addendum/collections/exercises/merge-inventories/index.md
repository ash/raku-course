## Problema

Duae tabernae copias suas in tabulis servant:
`apples => 3, pears => 2` et `apples => 4, plums => 5`. Compone eas in unam,
quantitates pro clavibus quae in utraque apparent addens. Imprime effectum secundum
clavem ordinatum, ut paria `key: total` commatibus iuncta.

## Exemplum

Programma imprimit:

```
apples: 7, pears: 2, plums: 5
```
