## Problema

Datis numeris venditionum `apples => 5, pears => 3, plums => 8`, imprime simplex
diagramma virgarum: unumquodque nomen, deinde tabulationem, deinde virgam signorum `#` tam longam quam valor eius,
secundum nomen ordinatam.

## Exemplum

Programma imprimit:

```
apples	#####
pears	###
plums	########
```
