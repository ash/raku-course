## Problema

*Radix digitalis* numeri est id quod accipis cifras eius iterum atque iterum addendo
donec una cifra restet. Pro `987654`: `9+8+7+6+5+4 = 39`, deinde
`3+9 = 12`, deinde `1+2 = 3`. Computa et imprime radicem digitalem ipsius `987654`.

## Exemplum

Programma imprimit:

```
3
```
