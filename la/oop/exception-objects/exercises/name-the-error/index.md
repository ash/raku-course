## Problema

Scribe subprogramma `risky` quod `die 'sub failed'` agit. Deinde voca illud ex clausula quae fasim `CATCH` habet. `CATCH` nomen generis exceptionis (per `.^name`) et deinde nuntium eius (per `.message`) imprimere debet. Hoc ostendit `CATCH` exceptiones tractare quas codex a clausula *vocatus* iacit, non solum eas quas `die` in clausula directe scriptum iacit.

## Exemplum

Programma imprimit:

```
X::AdHoc
sub failed
```
