## Problema

Curre imperatum quod consulto deficit — exempli gratia `sh -c 'exit 4'` — et `Proc` quod reddit serva. Imprime codicem exeundi imperati, et deinde imprime `success` vel `failure` prout imperatum successerit necne.

## Exemplum

Programma imprimit:

```
4
failure
```
