## Problema

Utere `run` ut `echo` cum duobus separatis argumentis lancies: `home:` et `$HOME`. Sine exitum eius in screen ire. Animadverte `$HOME` litteraliter apparere, et directoriam domesticam **non** imprimi — quia `run` nullum interpretem adhibet, nulla est variabilium expansio.

## Exemplum

Programma imprimit:

```
home: $HOME
```
