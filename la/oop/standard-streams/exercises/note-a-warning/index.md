## Problema

Programma valorem tractat qui negativus esse apparet. Utere `note` ut monitum ad errorem vulgarem mittas cum valor infra nihil est, et `say` ut verum effectum — valorem absolutum eius — ad exitum vulgarem mittas. Utere valore `-3`.

## Exemplum

Utraque linea in screen apparet:

```
Warning: the value is negative
3
```

Si error vulgaris abicitur, solus effectus manet:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
