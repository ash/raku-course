## Problema

Define duas classes vacuas, `Cat` et `Dog`. Deinde percurre quattuor valores `Cat`, `Dog`, `Cat.new` et `Dog.new`, imprimens utrum unusquisque definitus sit. Animadverte duo obiecta generis indefinita esse et duo exemplaria definita — nulla habita ratione classis ad quam pertinent.

## Exemplum

Programma imprimit:

```
False
False
True
True
```
