## Problema

Define duas classes vacuas, `Cat` et `Dog`, et fac exemplar `Cat` nomine `$felix`. Imprime genus `$felix` per `WHAT`. Deinde, duabus lineis amplius, imprime utrum illud genus idem sit ac `Cat`, et utrum idem sit ac `Dog`, operatore `===` utens.

## Exemplum

Programma imprimit:

```
(Cat)
True
False
```
