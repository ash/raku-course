## Problema

Define partem `Sized` cum methodo `describe` quae chordam `size is <size>` reddit, `self.size` utens.

Deinde define classem `Box` quae partem `Sized` facit et attributum `size` habet. Crea arcam magnitudine `10`, imprime effectum vocationis `describe` in ea, et deinde, altera linea, imprime utrum arca `~~ Sized` sit — id est, utrum ut partem faciens agnoscatur.

## Exemplum

Programma imprimit:

```
size is 10
True
```
