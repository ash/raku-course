## Problema

Data tabula `a => 1, b => 2, c => 3`, adverbio subscripti utere ut introitum `b` deleas, deinde imprime quot introitus tabula reliquos habeat ut demonstres unum remotum esse.

## Exemplum

Programma imprimit:

```
2
```
