## Codex

```raku
my %h = x => 10, y => 20;
say %h<x>:kv;
```

🦋 Inveni codicem fontem in archivo [key-and-value.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/subscript-adverbs/key-and-value.raku).

## Exitus

```
(x 10)
```

## Commentarii

1. Adverbium `:kv` et clavem et valorem ut listam reddit.

1. In tabula, clavis est nomen quo subscriptis, ergo `%h<x>:kv` listam `(x 10)` dat.
