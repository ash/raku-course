Hic est possibilis solutio huius muneris.

## Codex

```raku
my %h = a => 1, b => 2;
say %h<z>:exists;
```

🦋 Inveni codicem fontem in archivo [check-exists.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/subscript-adverbs/check-exists.raku).

## Exitus

```
False
```

## Commentarii

1. Adverbium `:exists` reddit num clavis praesens sit, sine valore obtento.

1. Tabula nullam clavem `z` habet, ergo `False` reddit — et, dissimiliter quaestioni ordinariae, clavem ut effectum lateralem non creat.
