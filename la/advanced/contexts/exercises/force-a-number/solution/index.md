## Codex

```raku
my @a = 1, 2, 3;
say +@a;
```

🦋 Inveni codicem fontem in archivo [force-a-number.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/contexts/force-a-number.raku).

## Exitus

```
3
```

## Commentarii

1. Praefixum `+` contextum numericum cogit.

1. In contextu numerico, ordo fit numerus elementorum suorum, itaque resultatum est `3`.
