## Problema

Data est variabilis cum typo definito:

```raku
my Str $lang = 'Raku';
```

Imprime tria facta de ea, unumquodque in propria linea:

1. typum valoris eius;
2. typum receptaculi eius;
3. nomen eius, sigillum includens.

## Exemplum

Programma imprimit:

```
Str
Scalar
$lang
```
