## Problema

Receptaculum valorem praedefinitum ferre potest, tropo `is default` constitutum. Donec quidquam assignas, lectio variabilis illud praedefinitum reddit, et `.VAR.default` id refert.

Declara scalarem `$count` cum praedefinito `0`. Sine ulla assignatione, imprime variabilem ipsam, deinde imprime praedefinitum receptaculi eius. Ambae lineae `0` ostendere debent.

## Exemplum

Programma imprimit:

```
0
0
```
