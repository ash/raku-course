## Problema

Phaser `NEXT` currit in *fine* cuiusque iterationis ansae, quod est bonum momentum ad progressum referendum.

Tene totalem currentem in `$sum`, incipiens ab `0`. Per `1..3` itera; in quoque transitu, primum adde numerum currentem ad `$sum`. Utere phasere `NEXT` ad imprimendum `sum so far: $sum` post quamque iterationem.

Attende ordinem: phaser `NEXT` post corpus currit, ergo totalem *includentem* numerum currentem refert.

## Exemplum

Programma imprimit:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
