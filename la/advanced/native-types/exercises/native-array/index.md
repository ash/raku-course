## Problema

Usus naturalis typi nativi dimensi est index compactus bytorum. Declara indicem `uint8` qui valores `100`, `200`, et `255` continet — quisque in unum byte capit — et summam elementorum eius imprime.

Nota quod elementa intra `0..255` manent, sed summa eorum non debet: `.sum` ordinarium `Int` reddit.

## Exemplum

Hoc programma imprimit:

```
555
```
