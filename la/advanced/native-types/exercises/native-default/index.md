## Problema

Regula quod variabilis nativa numquam indefinita esse potest ad omnem typum nativum pertinet, non solum ad `int`. Declara nativum `num` non assignatum et nativum `str` non assignatum. Numerum imprime, deinde chordam intra parentheses quadratas imprime ut eius vacuitas visibilis sit.

## Exemplum

Hoc programma imprimit:

```
0
[]
```
