## Problema

Scribe subprogramma `describe` quod nomen positionale necessarium accipit et deinde quotlibet argumenta nominata in mappam sorbentem (`*%opts`) colligit. Reddere debet chordam formae `nomen: clavis=valor, clavis=valor, ...`, omnes optiones clavibus ordine alphabetico enumerans.

Voca illud ut `describe('Anna', colour => 'red', size => 5)` et effectum imprime.

## Exemplum

Programma imprimit:

```
Anna: colour=red, size=5
```
