## Problema

Scribe programma quod medium (medium arithmeticum) ordinis numerorum imprimit. Utere meta-operatore reductionis ad valores addendos.

Data introitus in programmate fixata sunt, exempli gratia:

```raku
my @data = 10, 20, 30, 40;
```

## Exemplum

Programma medium elementorum `@data` imprimit:

```
25
```
