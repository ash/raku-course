Quis trait subroutinae permittit **variabilem vocantis mutare** per parametrum?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | nullus — parametra ex defectu scribilia sunt

{% include quiz.html %}

<div class="extended-explanation">

Parametrum ex defectu tantum-lectu est, itaque simplex parametrum assignari non potest. `is rw` parametrum variabili propria vocantis ligat, ita ut mutatio intra routinam facta foris visibilis sit. `is copy` potius *copiam* mutabilem daret, vocantem intactum relinquens.

</div>
