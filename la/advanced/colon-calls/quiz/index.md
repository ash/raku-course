Quid sequens programma imprimit?

```raku
say 'programming'.substr: 0, 3;
```

{:.quiz}
1 | pro
0 | program
0 | ing

{% include quiz.html %}

<div class="extended-explanation">

Colon totum reliquum enuntiati ut indicem argumentorum consumit, itaque `substr: 0, 3` idem est ac `substr(0, 3)` — ambo argumenta traduntur. Ab indice `0` incipiens et `3` litteras capiens dat `pro`.
