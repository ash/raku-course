## Problema

Declara duas variabiles scalares iuxta positas: `$untyped` sine typo et `$typed` typi `Int`. Ambas cum `dd` exscribe dum adhuc vacuae sunt, deinde `42` cuique assigna et ambas iterum exscribe. Attente inspice quomodo `dd` duos continentes diverse describat.

## Exemplum

Programma imprimit (ad errorem normalem):

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
