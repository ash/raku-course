## Problema

`do` etiam ante sententias fluxus controllandi operatur, eas in expressiones quae valorem producunt convertens. Utere `do if 7 > 5 { 'big' } else { 'small' }` ad etiketam eligendam, eam ad `$label` assigna, et imprime.

## Exemplum

Programma imprimit:

```
big
```
