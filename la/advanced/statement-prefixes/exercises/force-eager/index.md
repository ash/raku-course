## Problema

Praefixum `eager` contrarium `lazy` facit: indicem cogit plene produci, ita ut non iam piger sit. Contrastum cum `.is-lazy` ostende.

Imprime utrum intervallum infinitum `1 .. Inf` pigrum sit, deinde utrum `eager 1..3` pigrum sit, et denique utrum `lazy 1..3` pigrum sit. Resultata debent esse `True`, `False`, `True`.

## Exemplum

Programma imprimit:

```
True
False
True
```
