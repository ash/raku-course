Hic est possibilis solutio.

## Codex

```raku
my %h = a => 1;
say %h<a>;
```

🦋 Inveni codicem fontem in archivo [subscript-a-hash.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operator-types/subscript-a-hash.raku).

## Exitus

```
1
```

## Commentarii

1. Subscriptio `< >` operator postcircumfixus est: terminum (hash) sequitur et clavem circumdat.

1. `%h<a>` valorem sub clave `a` repositum reddit, qui est `1`.
