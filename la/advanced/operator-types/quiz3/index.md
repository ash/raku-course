Operator `x` filum repetit, itaque `'ab' x 3` dat `'ababab'`. Inter duos operandos suos sedens, ad quam categoriam `x` pertinet?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Quod interest est positio, non utrum operator symbolum sit an verbum. `x` *inter* duos operandos sedet, ergo operator **infixus** est — sicut `+` vel `~`, tantum ut littera scriptus.

</div>
