## Problema

`index` tibi dicit *ubi* character sit; `substr` deinde permittit chordam eo loco secare. Eas coniunge.

Dato inscriptione electronica `user@example.com`, positionem signi `@` inveni et omnia quae post id sequuntur imprime — partem dominii.

## Exemplum

Hoc programma imprimit:

```
example.com
```
