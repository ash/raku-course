Jen ebla solvo de la tasko.

## Kodo

```raku
say so none(3, 7, 2) < 0;
```

🦋 Vi povas trovi la fontkodon en la dosiero [none-negative.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/junctions/none-negative.raku).

## Eligo

```
True
```

## Komentoj

1. `none`-kunligo estas vera, kiam **neniu** valoro kongruas kun la komparo.

1. Neniu el `3, 7, 2` estas sub nulo, do la rezulto estas `True`. Unu sola negativa valoro farus ĝin `False`.
