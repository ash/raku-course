Jen ebla solvo de la tasko.

## Kodo

```raku
say so one(1, 2, 3) == 2;
```

🦋 Vi povas trovi la fontkodon en la dosiero [exactly-one.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/junctions/exactly-one.raku).

## Eligo

```
True
```

## Komentoj

1. `one`-kunligo estas vera nur kiam **precize unu** valoro kongruas kun la komparo.

1. Precize unu el `1, 2, 3` egalas `2`, do la rezulto estas `True`. Se du el ili kongruus (aŭ neniu), ĝi estus `False`. La `so` kolapsigas la kunligon al simpla bulea valoro.
