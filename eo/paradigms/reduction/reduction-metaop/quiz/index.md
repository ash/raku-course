Kion presas la jena programo?

```raku
say [min] 8, 3, 5, 1;
```

{:.quiz}
0 | 17
1 | 1
0 | 8
0 | 3

{% include quiz.html %}

<div class="extended-explanation">

`[min]` reduktas la liston per la operatoro `min`, komparante la elementojn duope kaj konservante la plej malgrandan. La plej malgranda el `8, 3, 5, 1` estas `1`.

</div>
