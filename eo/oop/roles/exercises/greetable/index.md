## Problemo

Difinu rolon `Sized` kun metodo `describe`, kiu redonas la ĉenon `size is <size>`, uzante `self.size`.

Poste difinu klason `Box`, kiu faras la rolon `Sized` kaj havas atributon `size`. Kreu skatolon kun grandeco `10`, presu la rezulton de voki `describe` sur ĝi, kaj poste, en dua linio, presu, ĉu la skatolo `~~ Sized` — tio estas, ĉu ĝi estas rekonata kiel faranta la rolon.

## Ekzemplo

La programo presas:

```
size is 10
True
```
