## Problemo

Malfermu dosieron nomatan `out.txt` por skribado. Tenante la tenilon malfermita, skribu la nombrojn `1`, `2` kaj `3` en ĝin, ĉiun en sia propra linio, uzante buklon. Poste fermu la tenilon, relegu la dosieron, kaj presu ĝian enhavon.

## Ekzemplo

La programo presas:

```
1
2
3
```
