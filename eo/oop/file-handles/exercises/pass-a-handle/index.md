## Problemo

Dosiertenilo estas ordinara valoro, do vi povas transdoni ĝin al funkcio kiel ĉiun alian argumenton. Skribu subrutinon `log-line`, kiu prenas tenilon kaj mesaĝon, kaj skribas la mesaĝon al la tenilo en sia propra linio.

Malfermu `log.txt` por skribado, voku `log-line` trifoje por registri `started`, `working` kaj `done`, poste fermu la tenilon, relegu la dosieron, kaj presu ĝian enhavon.

## Ekzemplo

La programo presas:

```
started
working
done
```
