## Problemo

Rulu komandon, kiu malsukcesas intence — ekzemple `sh -c 'exit 4'` — kaj tenu la `Proc`, kiun ĝi redonas. Presu la elirkodon de la komando, kaj poste presu `success` aŭ `failure` depende de tio, ĉu la komando sukcesis.

## Ekzemplo

La programo presas:

```
4
failure
```
