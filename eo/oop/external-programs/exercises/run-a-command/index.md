## Problemo

Uzu `run` por lanĉi `echo` kun du apartaj argumentoj: `home:` kaj `$HOME`. Lasu ĝian eligon iri al la ekrano. Rimarku, ke `$HOME` aperas laŭvorte, kaj la hejma dosierujo **ne** estas presata — ĉar `run` ne implikas ŝelon, ne estas variabla ekspansio.

## Ekzemplo

La programo presas:

```
home: $HOME
```
