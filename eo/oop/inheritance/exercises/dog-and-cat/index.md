## Problemo

Difinu bazan klason `Employee` kun atributo `name`, metodo `role`, kiu redonas `'staff'`, kaj metodo `badge`, kiu redonas la ĉenon `<name> - <role>` (uzante sian propran `role`).

Poste difinu du idajn klasojn, `Manager` kaj `Intern`, kiuj heredas de `Employee` kaj superregas `role` por redoni `'manager'` kaj `'intern'` respektive.

Presu la insignon de manaĝero nomata `Anna` kaj staĝanto nomata `Bob`.

## Ekzemplo

La programo presas:

```
Anna - manager
Bob - intern
```
