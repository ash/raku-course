## Problemo

Skribu subrutinon `get`, kiu redonas sian argumenton, sed vokas `fail` kun la mesaĝo `bad`, kiam la argumento estas `0`.

Uzante la operatoron `//` por provizi retiriĝon de `default`, presu la rezulton de `get(5)` kaj poste de `get(0)`.

## Ekzemplo

La programo presas:

```
5
default
```
