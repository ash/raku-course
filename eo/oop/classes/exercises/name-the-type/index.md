## Problemo

Difinu du malplenajn klasojn, `Cat` kaj `Dog`, kaj faru ekzempleron de `Cat` nomatan `$felix`. Presu la tipon de `$felix` per `WHAT`. Poste, en du pliaj linioj, presu, ĉu tiu tipo estas la sama kiel `Cat`, kaj ĉu ĝi estas la sama kiel `Dog`, uzante la operatoron `===`.

## Ekzemplo

La programo presas:

```
(Cat)
True
False
```
