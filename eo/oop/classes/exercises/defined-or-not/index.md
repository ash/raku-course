## Problemo

Difinu du malplenajn klasojn, `Cat` kaj `Dog`. Poste iru tra la kvar valoroj `Cat`, `Dog`, `Cat.new` kaj `Dog.new`, presante, ĉu ĉiu el ili estas difinita. Rimarku, ke la du tipobjektoj estas nedifinitaj kaj la du ekzempleroj estas difinitaj — sendepende de tio, al kiu klaso ili apartenas.

## Ekzemplo

La programo presas:

```
False
False
True
True
```
