Kion presas la jena programo? Notu la `$` ĉe la fino de la ŝablono.

```raku
say so 'hello world' ~~ / world $/;
```

{:.quiz}
1 | True
0 | False
0 | ｢world｣
0 | Nil

{% include quiz.html %}

<div class="extended-explanation">

La ankro `$` postulas, ke la kongruo finiĝu ĉe la tute fino de la ĉeno. La ĉeno `hello world` ja finiĝas per `world`, do la ankrita ŝablono sukcesas kaj `so` redonas `True`.

</div>
