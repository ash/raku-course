Kion presas la jena programo?

```raku
say 'a_1 b' ~~ /\W/;
```

{:.quiz}
0 | ｢a｣
0 | ｢_｣

{% include quiz.html %}

<div class="extended-explanation">

La klaso `\W` kongruas kun la unua signo, kiu **ne** estas litero, cifero aŭ substreko. La signoj `a`, `_` kaj `1` ĉiuj estas vortaj signoj, do la unua nevorta signo estas la spaco.

</div>
