Kion presas la jena programo?

```raku
say 'goodbye' ~~ / [ hello | good ] bye /;
```

{:.quiz}
1 | ｢goodbye｣
0 | ｢good｣
0 | ｢bye｣
0 | False

{% include quiz.html %}

<div class="extended-explanation">

La rektaj krampoj grupigas la alternativon `hello | good` sen kapti, do la ŝablono signifas «`hello` aŭ `good`, poste `bye`». En `goodbye` la alternativo `good` kongruas kaj estas sekvata de `bye`, donante `｢goodbye｣`.

</div>
