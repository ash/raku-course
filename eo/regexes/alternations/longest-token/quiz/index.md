Kion presas la jena programo? Notu la unuoblan strekon `|`.

```raku
say 'download' ~~ / down | download /;
```

{:.quiz}
1 | ｢download｣
0 | ｢down｣
0 | ｢load｣
0 | False

{% include quiz.html %}

<div class="extended-explanation">

La unuobla streko `|` uzas kongruigon laŭ plej longa ĵetono: kiam pli ol unu alternativo kongruas ĉe la sama loko, la plej longa venkas. Kvankam `down` estas skribita unue kaj kongruus, `|` preferas la pli longan `download`. Kun `||` anstataŭe, `down` estus venkinta.

</div>
