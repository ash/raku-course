## Problemo

Skribu gramatikon, kiu analizas `bool`, kiu estas aŭ la vorto `true` aŭ la vorto `false`. Uzu **proto-ĵetonon** kun du variantoj `:sym<…>`. Analizu `'true'`, `'false'`, kaj ankaŭ `'unknown'` (kiu estas nek unu nek la alia), presante, ĉu ĉiu sukcesis.

## Ekzemplo

La programo presas:

```
True
True
False
```
