Kion presas la jena programo? Notu, ke ĉi-foje ne estas `so`, kaj la kongruo uzas la formon `m/.../`.

```raku
say 'the cat sat' ~~ m/sat/;
```

{:.quiz}
0 | True
0 | False
1 | ｢sat｣
0 | Nil

{% include quiz.html %}

<div class="extended-explanation">

`m/sat/` kongruas same, kiel `/sat/` farus. Sen `so` por devigi ĝin al Boolea valoro, la sagaca kongruigo redonas la kongruan objekton mem, kiun `say` presas inter angulaj krampoj kiel `｢sat｣`.

</div>
