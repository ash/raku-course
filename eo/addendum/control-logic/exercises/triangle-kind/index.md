## Problemo

Donite tri laterajn longojn, decidu, ĉu ili formas egallateran, egalkruran aŭ
neregulan triangulon — aŭ tute neniun triangulon, kiam la plej longa latero estas
tro longa. Klasifiku `(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)` kaj `(1, 2, 10)`.

## Ekzemplo

La programo presas:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
