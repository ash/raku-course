## Problemo

Jaro estas superjaro, se ĝi estas dividebla per 4, escepte ke jarcentaj jaroj
estas superjaroj nur kiam ili estas divideblaj per 400. Por la jaroj `2000`,
`1900`, `2024` kaj `2023`, presu, ĉu ĉiu estas superjaro aŭ ordinara jaro.

## Ekzemplo

La programo presas:

```
2000: leap
1900: common
2024: leap
2023: common
```
