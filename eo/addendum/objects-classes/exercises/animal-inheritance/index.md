## Problemo

Faru bazan klason `Animal` kun `name` kaj metodo `greet`, kiu diras, kion la besto
diras. La subklasoj `Dog` kaj `Cat` ĉiu difinas sian propran sonon. Igu `Dog`
nomatan `Rex` kaj `Cat` nomatan `Tom` saluti.

## Ekzemplo

La programo presas:

```
Rex says Woof
Tom says Meow
```
