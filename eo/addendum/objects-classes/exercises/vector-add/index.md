## Problemo

Verku klason `Vector` kun `x` kaj `y` kaj metodo `add`, kiu redonas *novan*
vektoron — la sumon de du. Donu al ĝi metodon `Str`, por ke ĝi presiĝu kiel
`(x, y)`. Adiciu `(1, 2)` kaj `(3, 4)` kaj presu la rezulton.

## Ekzemplo

La programo presas:

```
(4, 6)
```
