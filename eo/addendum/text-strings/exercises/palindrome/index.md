## Problemo

Palindromo legiĝas same antaŭen kaj malantaŭen. Por ĉiu el la vortoj
`level`, `hello` kaj `racecar`, presu la vorton sekvatan de `yes` aŭ `no`
laŭ tio, ĉu ĝi estas palindromo.

## Ekzemplo

La programo presas:

```
level: yes
hello: no
racecar: yes
```
