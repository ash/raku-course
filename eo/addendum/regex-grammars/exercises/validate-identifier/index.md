## Problemo

En multaj programlingvoj, valida identigilo komenciĝas per litero aŭ
substreko kaj daŭras per literoj, ciferoj aŭ substrekoj. Por `count`,
`total2`, `2fast`, `my-var` kaj `_hidden`, presu, ĉu ĉiu estas valida
identigilo laŭ tiu klasika regulo.

(Raku mem estas pli malavara: `my-var` estas tute valida identigilo de Raku.
Kontrolu ankaŭ tiun varianton sur la solvopaĝo.)

## Ekzemplo

La programo presas:

```
count: valid
total2: valid
2fast: invalid
my-var: invalid
_hidden: valid
```
