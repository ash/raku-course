## Problemo

La prefikso `eager` faras la malon de `lazy`: ĝi devigas liston esti plene produktita, tiel ke ĝi ne plu estas maldiligenta. Montru la kontraston per `.is-lazy`.

Presu ĉu la senfina intervalo `1 .. Inf` estas maldiligenta, poste ĉu `eager 1..3` estas maldiligenta, kaj fine ĉu `lazy 1..3` estas maldiligenta. La rezultoj devus esti `True`, `False`, `True`.

## Ekzemplo

La programo presas:

```
True
False
True
```
