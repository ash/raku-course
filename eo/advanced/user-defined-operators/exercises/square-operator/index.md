## Problemo

La simbolo de operatoro povas esti ajna signo, inkluzive de Unikoda. Difinu **postfiksan** operatoron `²`, kiu kvadratigas sian operandon, tiel ke `5²` signifu `5 ** 2`. Poste presu `5²`.

## Ekzemplo

La programo presas:

```
25
```
