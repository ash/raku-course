## Problemo

Skribu testodosieron, kiu uzas `plan` (ne `done-testing`) por anticipe deklari, ke ĝi enhavas ĝuste du kontrolojn. Faru tiujn kontrolojn:

1. Per `is-deeply`, ke ordigo de la listo `3, 1, 2` donas `[1, 2, 3]`.
1. Per `is`, ke `10 % 3` egalas `1`.

Donu al ĉiu kontrolo mallongan priskribon laŭ via elekto.

## Ekzemplo

Kun la priskriboj `sorted` kaj `remainder`, la programo presas:

```
1..2
ok 1 - sorted
ok 2 - remainder
```
