En la modulo `Test`, kiu funkcio sukcesas kiam bulea kondiĉo estas vera?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` akceptas kondiĉon kaj sukcesas kiam ĝi estas vera. `is` komparas realan valoron kun atendata, `plan` indikas kiom da testoj estas atendataj, kaj `done-testing` finas la dosieron kaj eligas la planon.

</div>
