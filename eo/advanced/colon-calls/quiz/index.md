Kion presas la jena programo?

```raku
say 'programming'.substr: 0, 3;
```

{:.quiz}
1 | pro
0 | program
0 | ing
0 | (0 3)

{% include quiz.html %}

<div class="extended-explanation">

La dupunkto konsumas la *tutan* reston de la deklaro kiel la argumentan liston, do `substr: 0, 3` estas same kiel `substr(0, 3)` — ambau argumentoj estas transdonitaj. Komencante che indekso `0` kaj prenante `3` signojn donas `pro`.

</div>
