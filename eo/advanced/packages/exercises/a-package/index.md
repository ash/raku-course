## Problemo

Kreu pakon `Temperature`, kiu grupigas du aferojn: `our`-variablon `$freezing` metitan al `0`, kaj `our`-subrutinon `fahrenheit`, kiu konvertas valoron laŭ Celsio al Fahrenheit (multipliku per 9/5 kaj aldonu 32). De ekster la pako, presu la frostopunkton, poste presu la Fahrenheit-valoron de `100` gradoj laŭ Celsio.

## Ekzemplo

La programo presas:

```
0
212
```
