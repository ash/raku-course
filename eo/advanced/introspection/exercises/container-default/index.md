## Problemo

Ujo povas porti defaultan valoron, difinitan per la trajto `is default`. Ghis vi atribuas ion ajn, legado de la variablo redonas tiun defaulton, kaj `.VAR.default` raportas ghin.

Deklaru skalaron `$count` kun defaulto de `0`. Sen atribui ion ajn al ghi, presu la variablon mem, kaj poste presu la defaulton de ghia ujo. Ambau linioj devus montri `0`.

## Ekzemplo

La programo presas:

```
0
0
```
