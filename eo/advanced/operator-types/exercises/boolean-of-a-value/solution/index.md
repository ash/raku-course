Jen ebla solvo de la tasko.

## Kodo

```raku
say ?0;
say ?5;
```

🦋 Vi povas trovi la fontkodon en la dosiero [boolean-of-a-value.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operator-types/boolean-of-a-value.raku).

## Eligo

```
False
True
```

## Komentoj

1. `?` estas prefiksa operatoro: ĝi venas antaŭ sia operando kaj redonas la Boolean valoron de la operando.

1. `0` estas malvera kaj `5` estas vera, do la programo presas `False` kaj `True`.
