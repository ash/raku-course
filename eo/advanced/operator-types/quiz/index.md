En la esprimo `@a[0]`, al kiu kategorio apartenas la subskribo `[0]`?

{:.quiz}
0 | postfix
1 | postcircumfix
0 | circumfix
0 | infix

{% include quiz.html %}

<div class="extended-explanation">

Subskribo ĉirkaŭas sian enhavon per krampoj *kaj* sekvas terminon (ĉi tie `@a`), kio faras ĝin post-ĉirkaŭfiksa operatoro. Simpla postfikso (kiel `++`) prenas neniujn ĉirkaŭajn krampojn, kaj ĉirkaŭfikso (kiel la tabela konstruilo `[1, 2, 3]`) ĉirkaŭas sed ne sekvas terminon.

</div>
