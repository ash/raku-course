Kion presas la jena programo?

```raku
enum Colour <red green blue>;
say green + blue;
```

{:.quiz}
1 | 3
0 | greenblue
0 | (green blue)
0 | eraron

{% include quiz.html %}

<div class="extended-explanation">

Ĉiu konstanto reprezentas nombron, atribuitan ekde nulo laŭ la listigita ordo: `red` estas `0`, `green` estas `1`, `blue` estas `2`. En aritmetika kunteksto la konstantoj agas kiel tiuj nombroj, do `green + blue` estas `1 + 2`, kio estas `3`.

</div>
