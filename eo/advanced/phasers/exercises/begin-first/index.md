## Problemo

`BEGIN`-phaser estas pli ol bloko, kiu ruliĝas frue — ĝi estas ankaŭ *esprimo*, kies valoro estas kalkulita unufoje, dum kompilotempo, kaj poste frostigita en la programon.

Uzu `BEGIN { 2 + 3 }` por pravalorigi variablon `$compiled`, kaj presu ĝin. La `2 + 3` estas taksata dum la programo ankoraŭ kompilas, sed la konservita valoro estas tute uzebla dum rultempo.

## Ekzemplo

La programo presas:

```
5
```
