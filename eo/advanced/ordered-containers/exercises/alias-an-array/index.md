## Problemo

Estas donita al vi tabelo:

```raku
my @original = 10, 20, 30;
```

Kreu duan nomon, `@alias`, kiu referencas la _saman_ tabelon (ne kopiu ĝin). Ĉi-foje, `push` novan elementon sur `@original`, kaj poste presu `@alias` por montri, ke la aliaso vidas ne nur valorajn ŝanĝojn sed ankaŭ strukturajn.

## Ekzemplo

La programo presas:

```
[10 20 30 40]
```
