**Diese Übersetzung stammt von einer Maschine.** Die deutsche Fassung des Kurses wurde von einem Sprachmodell aus dem englischen Original übersetzt, ohne anschließendes Lektorat durch einen Muttersprachler. Inhalt, Codebeispiele und Programmausgaben sind unverändert, doch die Formulierung kann stellenweise holprig und ein Begriff nicht der geläufigste sein.

Wirkt eine Stelle unklar, ziehen Sie das [englische Original](/) heran — es bleibt stets die maßgebliche Quelle.

Code wird nie übersetzt. Raku-Schlüsselwörter, Namen von Typen, Methoden und Subroutinen sowie Programmausgaben (`True`, `False`, `Nil` und dergleichen) bleiben unverändert — genau so, wie der Compiler sie sieht.

Einen Fehler oder eine unglückliche Übersetzung entdeckt? Melden Sie sie [auf GitHub](https://github.com/ash/raku-course) — das ist der beste Weg, den Text zu verbessern.
