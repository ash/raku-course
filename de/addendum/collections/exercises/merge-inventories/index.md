## Aufgabe

Zwei Läden führen ihren Bestand in Hashes:
`apples => 3, pears => 2` und `apples => 4, plums => 5`. Führen Sie sie zu einem
zusammen und addieren Sie dabei die Mengen für Schlüssel, die in beiden vorkommen. Geben
Sie das Ergebnis nach Schlüssel sortiert aus, als `schlüssel: summe`-Paare, mit Kommas
verbunden.

## Beispiel

Das Programm gibt aus:

```
apples: 7, pears: 2, plums: 5
```
