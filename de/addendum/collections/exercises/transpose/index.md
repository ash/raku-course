## Aufgabe

Behandeln Sie die verschachtelte Liste `[1, 2, 3], [4, 5, 6]` als 2×3-Matrix und
transponieren Sie sie zu einer 3×2-Matrix, sodass aus den Zeilen Spalten werden. Geben
Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
((1 4) (2 5) (3 6))
```
