## Aufgabe

Schreiben Sie mit mehrfacher Verteilung eine Subroutine `describe`, die auf eine
Ganzzahl, eine Zeichenkette und eine Liste jeweils verschieden reagiert. Rufen Sie sie
mit `42`, `'hi'` und `[1, 2, 3]` auf.

## Beispiel

Das Programm gibt aus:

```
integer 42
string hi
list of 3
```
