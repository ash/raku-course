## Aufgabe

Schreiben Sie eine Subroutine, die einen Sammler bei einem gegebenen Wert beginnen lässt
und eine Funktion liefert, die bei jedem Aufruf zur laufenden Summe addiert und die neue
Summe zurückgibt. Beginnen Sie bei `100`, addieren Sie dann `10`, `25` und `-5` und geben
Sie jedes Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
110
135
130
```
