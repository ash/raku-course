## Aufgabe

Nehmen Sie in einer einzigen Pipeline die Zahlen `1` bis `10`, behalten Sie die geraden,
quadrieren Sie sie und addieren Sie die Ergebnisse. Geben Sie die Summe aus.

## Beispiel

Das Programm gibt aus:

