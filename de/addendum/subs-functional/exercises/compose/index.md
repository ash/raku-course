## Aufgabe

Schreiben Sie eine Subroutine `compose`, die zwei Funktionen entgegennimmt und eine neue
Funktion liefert, die sie nacheinander anwendet — zuerst die zweite, dann die erste.
Verketten Sie „verdoppeln“ mit „eins addieren“ und rufen Sie das Ergebnis dann auf `5`
auf (was `12` ergibt).

## Beispiel

Das Programm gibt aus:

```
12
```
