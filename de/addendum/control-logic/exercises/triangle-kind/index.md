## Aufgabe

Entscheiden Sie bei drei gegebenen Seitenlängen, ob sie ein gleichseitiges,
gleichschenkliges oder ungleichseitiges Dreieck bilden — oder überhaupt kein Dreieck,
wenn die längste Seite zu lang ist. Ordnen Sie `(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)`
und `(1, 2, 10)` ein.

## Beispiel

Das Programm gibt aus:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
