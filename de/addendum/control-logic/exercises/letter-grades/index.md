## Aufgabe

Wandeln Sie jede der Punktzahlen `95`, `82`, `71` und `58` in einen Notenbuchstaben um:
`A` für 90 und darüber, `B` für 80–89, `C` für 70–79, `D` für 60–69 und `F` darunter.
Geben Sie jede Punktzahl mit ihrer Note aus.

## Beispiel

Das Programm gibt aus:

```
95 -> A
82 -> B
71 -> C
58 -> F
```
