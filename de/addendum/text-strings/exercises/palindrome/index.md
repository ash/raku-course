## Aufgabe

Ein Palindrom liest sich vorwärts wie rückwärts. Geben Sie für jedes der Wörter
`level`, `hello` und `racecar` das Wort aus, gefolgt von `yes` oder `no`, je nachdem,
ob es ein Palindrom ist.

## Beispiel

Das Programm gibt aus:

```
level: yes
hello: no
racecar: yes
```
