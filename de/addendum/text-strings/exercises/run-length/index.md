## Aufgabe

Komprimieren Sie die Zeichenkette `aaabbbbcc`, indem Sie jeden Lauf gleicher Buchstaben
durch den Buchstaben gefolgt von der Länge des Laufs ersetzen, was `a3b4c2` ergibt. Geben
Sie die komprimierte Zeichenkette aus.

## Beispiel

Das Programm gibt aus:

```
a3b4c2
```
