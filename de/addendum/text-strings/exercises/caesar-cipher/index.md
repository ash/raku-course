## Aufgabe

Verschlüsseln Sie das großgeschriebene Wort `HELLO` mit einer Caesar-Verschlüsselung,
die jeden Buchstaben um drei Stellen im Alphabet vorwärts verschiebt und dabei `X`, `Y`,
`Z` auf `A`, `B`, `C` umlaufen lässt. Geben Sie das verschlüsselte Wort aus.

## Beispiel

Das Programm gibt aus:

```
KHOOR
```
