## Aufgabe

Geben Sie zu den Verkaufszahlen `apples => 5, pears => 3, plums => 8` ein einfaches
Balkendiagramm aus: jede Beschriftung, dann einen Tabulator, dann einen Balken aus
`#`-Zeichen, so lang wie ihr Wert, nach Beschriftung geordnet.

## Beispiel

Das Programm gibt aus:

```
apples	#####
pears	###
plums	########
```
