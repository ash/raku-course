## Aufgabe

Gruppieren Sie die Wörter `<listen silent enlist cat act dog>` so, dass Anagramme (Wörter
aus denselben Buchstaben) beieinander landen. Geben Sie jede Gruppe in einer eigenen Zeile
aus, die Wörter in alphabetischer Reihenfolge, die Gruppen nach ihren gemeinsamen
Buchstaben geordnet.

## Beispiel

Das Programm gibt aus:

```
act cat
dog
enlist listen silent
```
