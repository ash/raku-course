## Aufgabe

Räumen Sie die folgende Zeichenkette so auf, dass führende und abschließende Leerzeichen
verschwinden und jede Lücke im Inneren ein einzelnes Leerzeichen ist. Geben Sie das
Ergebnis aus.

```raku
my $messy = '  too    many     spaces   ';
```

## Beispiel

Das Programm gibt aus:

```
too many spaces
```
