## Aufgabe

Schreiben Sie eine Klasse `Point`, die `x` und `y` hält, mit einer Methode, die meldet, in
welchem Quadranten der Punkt liegt — `first`, `second`, `third` oder `fourth` — oder dass
er auf einer Achse sitzt. Melden Sie die Punkte `(3, 4)`, `(-2, 5)`, `(-1, -6)` und
`(0, 3)`.

## Beispiel

Das Programm gibt aus:

```
(3, 4): first
(-2, 5): second
(-1, -6): third
(0, 3): on an axis
```
