## Aufgabe

Schreiben Sie eine Klasse `Vector` mit `x` und `y` und einer Methode `add`, die einen
*neuen* Vektor liefert — die Summe zweier. Geben Sie ihr eine Methode `Str`, damit sie
sich als `(x, y)` ausgibt. Addieren Sie `(1, 2)` und `(3, 4)` und geben Sie das Ergebnis
aus.

## Beispiel

Das Programm gibt aus:

```
(4, 6)
```
