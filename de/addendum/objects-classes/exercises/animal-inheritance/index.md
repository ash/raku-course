## Aufgabe

Bauen Sie eine Basisklasse `Animal` mit einem `name` und einer Methode `greet`, die sagt,
was das Tier sagt. Die Unterklassen `Dog` und `Cat` bestimmen jeweils ihren eigenen Laut.
Lassen Sie einen `Dog` namens `Rex` und eine `Cat` namens `Tom` grüßen.

## Beispiel

Das Programm gibt aus:

```
Rex says Woof
Tom says Meow
```
