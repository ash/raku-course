## Aufgabe

Schreiben Sie eine Klasse `Account` mit einem `balance`, der bei `0` beginnt, einer
Methode `deposit` und einer Methode `withdraw`, die sich (mit einer Meldung) weigert,
wenn nicht genug Geld da ist. Zahlen Sie `100` ein, heben Sie `30` ab, versuchen Sie,
`200` abzuheben, und geben Sie dann den Kontostand aus.

## Beispiel

Das Programm gibt aus:

```
declined: insufficient funds
70
```
