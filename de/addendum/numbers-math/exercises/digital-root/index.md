## Aufgabe

Die *Quersummenwurzel* einer Zahl ist das, was man erhält, wenn man ihre Ziffern
wiederholt addiert, bis eine einzelne Ziffer übrig bleibt. Für `987654`:
`9+8+7+6+5+4 = 39`, dann `3+9 = 12`, dann `1+2 = 3`. Berechnen Sie die Quersummenwurzel
von `987654` und geben Sie sie aus.

## Beispiel

Das Programm gibt aus:

```
3
```
