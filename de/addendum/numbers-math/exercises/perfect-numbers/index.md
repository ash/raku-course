## Aufgabe

Eine *vollkommene Zahl* ist gleich der Summe ihrer echten Teiler (aller Teiler außer der
Zahl selbst). Zum Beispiel `6 = 1 + 2 + 3`. Finden Sie alle vollkommenen Zahlen von `1`
bis `30` und geben Sie sie aus.

## Beispiel

Das Programm gibt aus:

```
[6 28]
```
