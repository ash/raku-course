## Aufgabe

Von einer Zahl ausgehend halbiert das Collatz-Verfahren sie, wenn sie gerade ist, und
ersetzt sie durch `3n + 1`, wenn sie ungerade ist, und wiederholt das, bis es `1`
erreicht. Zählen Sie, wie viele Schritte es braucht, um `27` auf `1` herunterzubringen,
und geben Sie diese Anzahl aus.

## Beispiel

Das Programm gibt aus:

```
111
```
