## Aufgabe

Zerlegen Sie die Zahl `360` in ihre Primfaktoren und geben Sie diese als Liste aus, wobei
wiederholte Faktoren so oft erscheinen, wie sie vorkommen (aus `12` würde also `2 2 3`).

## Beispiel

Das Programm gibt aus:

```
[2 2 2 3 3 5]
```
