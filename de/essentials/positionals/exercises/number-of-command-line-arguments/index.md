## Aufgabe

Schreiben Sie ein Programm, das in einem vollständigen Satz meldet, wie viele Argumente es aus der Befehlszeile erhalten hat. Achten Sie auf die richtige Grammatik: Verwenden Sie das Wort `argument`, wenn genau eines übergeben wurde, und `arguments` in allen anderen Fällen.

## Beispiel

So soll das Programm reagieren:

```console
$ raku number-of-command-line-arguments.raku make them count us now
You passed 5 arguments.

$ raku number-of-command-line-arguments.raku solo
You passed 1 argument.
```
