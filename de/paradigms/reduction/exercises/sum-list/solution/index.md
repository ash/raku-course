Hier ist eine mögliche Lösung der Aufgabe.

## Code

```raku
say [+] 10, 20, 30, 40;
```

🦋 Du findest den Quellcode in der Datei [sum-list.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/sum-list.raku).

## Ausgabe

```
100
```

## Kommentare

1. `[+]` setzt `+` zwischen jedes Element der Liste.

1. Die Summe `10 + 20 + 30 + 40` ist `100`.
