## Aufgabe

Finden Sie mit der **Methode** `reduce` und einem Block die längste Zeichenkette in der Liste `'cat', 'elephant', 'dog', 'fox'` — die mit den meisten Zeichen — und geben Sie sie aus. Ein Metaoperator hilft hier nicht: Der Block muss die beiden Kandidaten selbst vergleichen.

## Beispiel

Das Programm gibt aus:

```
elephant
```
