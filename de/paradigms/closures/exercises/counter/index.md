## Aufgabe

Schreiben Sie eine Subroutine `make-counter($step)`, die eine Closure zurückgibt. Jedes Mal, wenn die Closure aufgerufen wird, rückt sie eine laufende Summe um `$step` vor und liefert sie. Die Closure muss sich sowohl die Schrittweite als auch die Summe merken. Erzeugen Sie einen Zähler mit einer Schrittweite von `10` und geben Sie seine ersten drei Werte aus.

## Beispiel

Das Programm gibt aus:

```
10
20
30
```
