## Aufgabe

Schreiben Sie eine Subroutine `make-accumulator`, die eine Closure zurückgibt, die eine laufende Summe führt. Jeder Aufruf addiert sein Argument zur Summe und liefert die neue Summe. Addieren Sie `10`, dann `5`, und geben Sie das Ergebnis des zweiten Aufrufs aus.

## Beispiel

Das Programm gibt aus:

```
15
```
