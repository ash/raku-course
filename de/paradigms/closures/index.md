Ein _Lambda_ ist eine kleine, namenlose Funktion, die man inline schreibt — genau die Pointy Blocks und Whatever-Ausdrücke, die Sie an `map` und Verwandte übergeben haben. Eine _Closure_ ist ein Lambda (oder eine beliebige Subroutine), das sich Variablen von der Stelle merkt, an der es erzeugt wurde.

Closures machen zurückgegebene Subroutinen so nützlich: Sie tragen ein kleines Stück eigenen Zustand mit sich. Dieser Abschnitt betrachtet beide Gedanken.
