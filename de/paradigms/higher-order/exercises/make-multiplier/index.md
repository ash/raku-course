## Aufgabe

Schreiben Sie eine Subroutine `multiplier`, die eine Zahl `$n` aufnimmt und eine Subroutine **zurückgibt**, die ihr Argument mit `$n` multipliziert. Bauen Sie damit zwei Funktionen — einen „Verdoppler“ und einen „Verdreifacher“ — und rufen Sie jede mit `7` auf.

## Beispiel

Das Programm gibt aus:

```
14
21
```
