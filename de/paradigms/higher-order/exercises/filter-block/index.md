## Aufgabe

`grep` ist eine Funktion höherer Ordnung: Sie nimmt einen Block auf und behält die Elemente, für die der Block wahr ist. Zählen Sie mit `grep`, wie viele Zahlen im Bereich `1..10` größer als `5` sind, und geben Sie die Anzahl aus.

## Beispiel

Das Programm gibt aus:

```
5
```
