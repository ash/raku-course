## Aufgabe

Öffnen Sie einen Socket zu `example.com` auf Port `80`, senden Sie eine minimale HTTP-**HEAD**-Anfrage (die nur nach den Headern fragt, nicht nach dem Seitenrumpf), empfangen Sie die Antwort und geben Sie ihre erste Zeile aus (die Statuszeile).

> Diese Übung braucht eine funktionierende Netzverbindung, um zu laufen.

## Beispiel

Beim Ausführen gibt das Programm eine Zeile wie diese aus:

```
HTTP/1.1 200 OK
```
