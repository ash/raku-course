## Aufgabe

Teilen Sie mit einem `react`-Block einen Strom in zwei Sammlungen. Beobachten Sie ein Supply, das aus `4, 42, 7, 100, 15` gebaut ist, und legen Sie im `whenever`-Rumpf jeden Wert größer als `10` in `@big` und den Rest in `@small`. Geben Sie beide Arrays aus, nachdem der react-Block fertig ist.

## Beispiel

Das Programm gibt aus:

```
[4 7]
[42 100 15]
```
