## Aufgabe

Verfolgen Sie einen Kontostand, der von zwei Strömen mit **entgegengesetzten Rollen** gespeist wird. Erzeugen Sie zwei benannte Supplies — Einzahlungen aus `100, 50, 200` und Abhebungen aus `30, 120` — und **addieren** Sie in einem `react`-Block mit zwei `whenever`-Blöcken jede Einzahlung zum Kontostand und **ziehen** Sie jede Abhebung davon **ab**. Geben Sie den Endstand aus.

## Beispiel

Das Programm gibt aus:

```
200
```
