## Aufgabe

Erzeugen Sie ein Supply aus den Zeichenketten `'red'`, `'green'` und `'blue'` und zapfen Sie es so an, dass jeder Wert in einer eigenen Zeile ausgegeben wird.

## Beispiel

Das Programm gibt aus:

```
red
green
blue
```
