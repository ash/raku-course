## Aufgabe

Die _n_-te Dreieckszahl ist die Summe `n + (n - 1) + … + 1`, wobei die nullte Dreieckszahl `0` ist. Schreiben Sie eine rekursive Subroutine `tri`, die sie berechnet, drücken Sie sie aber mit **zwei `multi`-Kandidaten** aus statt mit einer Bedingung in einem Rumpf: ein Kandidat für den Grundfall, einer für den rekursiven Schritt. Geben Sie `tri(5)` aus.

## Beispiel

Das Programm gibt aus:

```
15
```
