## Aufgabe

Schreiben Sie eine rekursive Subroutine `sum-digits`, die die Summe der Dezimalziffern einer nichtnegativen ganzen Zahl liefert. Für eine Zahl unter `10` ist die Antwort die Zahl selbst; andernfalls addieren Sie die letzte Ziffer (`$n % 10`) zur Quersumme des Rests (`$n div 10`).

Geben Sie `sum-digits(1234)` aus.

## Beispiel

Das Programm gibt aus:

```
10
```
