## Aufgabe

Schreiben Sie eine rekursive Subroutine `countup`, die die Zahlen von `1` bis `$n` ausgibt, jede in einer eigenen Zeile. Der Kniff: **zuerst** rekursiv aufrufen, dann ausgeben — damit die Zahlen in aufsteigender Reihenfolge herauskommen, obwohl jeder Aufruf die größte Zahl bearbeitet. Rufen Sie `countup(3)` auf.

## Beispiel

Das Programm gibt aus:

```
1
2
3
```
