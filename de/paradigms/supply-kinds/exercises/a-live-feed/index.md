## Aufgabe

Zeigen Sie, dass ein Live-Supply sich nicht an die Vergangenheit erinnert. Erzeugen Sie einen `Supplier`, senden Sie `1` **vor** dem Anzapfen aus, zapfen Sie ihn dann an, um Werte in einem Array zu sammeln, und senden Sie schließlich `2` und `3` aus. Geben Sie das Array aus — der vor der Zapfstelle ausgesandte Wert soll fehlen.

## Beispiel

Das Programm gibt aus:

```
[2 3]
```
