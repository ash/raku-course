## Aufgabe

Erweitern Sie den Begrüßungsdienst um eine **zweite** Route: eine `GET`-Route für den Pfad `bye`, die den reinen Text `Goodbye!` liefert. Behalten Sie auch die ursprüngliche Route `hello`.

> Diese Übung braucht Cro installiert (`zef install cro`).

## Beispiel

Eine Anfrage nach `/bye` liefert:

```
Goodbye!
```
