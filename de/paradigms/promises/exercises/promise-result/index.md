## Aufgabe

Starten Sie ein Promise, das die Zeichenkette `'raku'` erzeugt. Hängen Sie mit `.then` einen Nachfolger an, der sie **großschreibt** (lesen Sie den Wert mit `.result`), und hängen Sie dann ein **zweites** `.then` an, das ein Ausrufezeichen anfügt. Warten Sie das letzte Promise ab und geben Sie seinen Wert aus.

## Beispiel

Das Programm gibt aus:

```
RAKU!
```
