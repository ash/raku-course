## Aufgabe

Addieren Sie die Zahlen in der Liste `3, 7, 5`, indem Sie unmittelbar einen **Iterator** antreiben: Holen Sie sich einen mit `.iterator` und rufen Sie `pull-one` in einer Schleife auf, bis er `IterationEnd` liefert. Verwenden Sie keine `for`-Schleife, kein `sum` und keine Reduktion. Geben Sie die Summe aus.

## Beispiel

Das Programm gibt aus:

```
15
```
