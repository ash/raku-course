## Aufgabe

Die Zeichenkette `'5 and $9'` enthält zwei Zahlen: eine blanke `5` und einen Preis `$9`. Schreiben Sie mit einem **verneinenden Lookbehind** ein Muster, das eine Zahl nur dann trifft, wenn ihr **nicht** unmittelbar ein `$` vorausgeht. Geben Sie den Treffer aus.

## Beispiel

Das Programm gibt aus:

```
｢5｣
```
