## Aufgabe

Schreiben Sie eine Grammatik, deren `TOP` eine **rule** ist, die `Schlüssel = Wert` trifft, wobei Schlüssel und Wert Tokens aus einem oder mehreren Wortzeichen sind und um das `=` Leerzeichen stehen dürfen. Zerlegen Sie `'x = 5'` und geben Sie aus, ob es gelungen ist (ein schlichtes `True` oder `False`).

## Beispiel

Das Programm gibt aus:

```
True
```
