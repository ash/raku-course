## Aufgabe

Schreiben Sie eine Grammatik, deren `TOP` eine **rule** ist, die drei durch Leerzeichen getrennte Wörter trifft. Jedes Wort ist ein Token aus einem oder mehreren Wortzeichen. Zerlegen Sie `'the quick fox'` und geben Sie aus, ob es gelungen ist (ein schlichtes `True` oder `False`).

## Beispiel

Das Programm gibt aus:

```
True
```
