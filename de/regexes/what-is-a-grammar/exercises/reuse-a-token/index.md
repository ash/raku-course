## Aufgabe

Deklarieren Sie einen benannten Regex `word`, der ein oder mehrere Wortzeichen trifft. Verwenden Sie ihn **zweimal** in einem Muster, um zwei durch ein Leerzeichen getrennte Wörter zu treffen, wie in `'cat dog'`. Geben Sie beide gecapturten Wörter aus, jedes in einer eigenen Zeile.

## Beispiel

Das Programm gibt aus:

```
｢cat｣
｢dog｣
```
