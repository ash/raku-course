## Aufgabe

Deklarieren Sie einen benannten Regex namens `word`, der ein oder mehrere Wortzeichen trifft. Verwenden Sie ihn dann (als `<word>`), um die Zeichenkette `'hello world'` zu treffen, und geben Sie das gecapturte Wort aus.

## Beispiel

Das Programm gibt aus:

```
｢hello｣
```
