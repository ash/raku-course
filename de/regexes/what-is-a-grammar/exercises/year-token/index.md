## Aufgabe

Deklarieren Sie zwei benannte Regexes: `year`, der genau vier Ziffern trifft, und `month`, der genau zwei Ziffern trifft. Verwenden Sie beide in einem Muster, um eine Zeichenkette wie `'2025-06'` zu treffen, in der ein Jahr und ein Monat durch einen Bindestrich getrennt sind. Geben Sie das gecapturte Jahr und den gecapturten Monat aus, jedes in einer eigenen Zeile.

## Beispiel

Das Programm gibt aus:

```
｢2025｣
｢06｣
```
