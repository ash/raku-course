## Aufgabe

Eine einzelne Zeichenklasse kann mehr als einen Bereich verbinden. Schreiben Sie eine Klasse, die ein Zeichen trifft, das entweder ein Kleinbuchstabe **oder** eine Ziffer ist, und finden Sie damit das erste solche Zeichen in der Zeichenkette `'  @x7'` (die mit Leerzeichen und einem `@` beginnt). Geben Sie den Treffer aus.

Verwenden Sie keine vordefinierte Klasse wie `\w` — schreiben Sie die Bereiche selbst.

## Beispiel

Das Programm gibt aus:

```
｢x｣
```
