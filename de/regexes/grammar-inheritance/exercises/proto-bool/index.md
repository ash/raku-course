## Aufgabe

Schreiben Sie eine Grammatik, die einen `bool` zerlegt, der entweder das Wort `true` oder das Wort `false` ist. Verwenden Sie ein **Prototoken** mit zwei `:sym<…>`-Spielarten. Zerlegen Sie `'true'`, `'false'` und außerdem `'unknown'` (das keines von beiden ist) und geben Sie für jedes aus, ob es gelungen ist.

## Beispiel

Das Programm gibt aus:

```
True
True
False
```
