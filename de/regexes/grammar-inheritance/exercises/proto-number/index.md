## Aufgabe

Schreiben Sie eine Grammatik, die eine `number` zerlegt, die entweder eine dezimale ganze Zahl (eine oder mehrere Ziffern) oder ein hexadezimales Literal (`0x` gefolgt von Hexziffern `0`–`9`, `a`–`f`) sein darf. Verwenden Sie ein **Prototoken** mit zwei `:sym<…>`-Spielarten, `dec` und `hex`. Zerlegen Sie `'0xff'` und geben Sie aus, ob es gelungen ist.

## Beispiel

Das Programm gibt aus:

```
True
```
