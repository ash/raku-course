## Aufgabe

Alternativen in einer Alternation müssen keine wörtlichen Wörter sein — sie können beliebige Teilmuster sein. Schreiben Sie ein Muster, das entweder das wörtliche Wort `cat` **oder** eine einzelne Ziffer (`\d`) trifft. Prüfen Sie es an der Zeichenkette `'item 5'` und geben Sie den Treffer aus.

## Beispiel

Das Programm gibt aus:

```
｢5｣
```
