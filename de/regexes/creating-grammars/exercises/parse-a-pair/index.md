## Aufgabe

Schreiben Sie eine Grammatik, die einen vollständigen Namen der Form `Vorname Nachname` zerlegt, wobei Vor- und Nachname jeweils eine Folge von Wortzeichen sind, getrennt durch ein Leerzeichen. Zerlegen Sie damit `'Grace Hopper'` und geben Sie den gecapturten Nachnamen aus.

## Beispiel

Das Programm gibt aus:

```
｢Hopper｣
```
