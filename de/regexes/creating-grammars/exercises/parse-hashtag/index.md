## Aufgabe

Schreiben Sie eine Grammatik, die einen Hashtag der Form `#tag` zerlegt, wobei der Tag eine Folge von Wortzeichen hinter einem wörtlichen `#` ist. Zerlegen Sie damit `'#raku'` und geben Sie den gecapturten Tag aus.

## Beispiel

Das Programm gibt aus:

```
｢raku｣
```
