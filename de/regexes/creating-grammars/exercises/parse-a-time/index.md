## Aufgabe

Schreiben Sie eine Grammatik, die eine Uhrzeit der Form `Stunde:Minute:Sekunde` zerlegt, wobei jeder der drei Teile eine Ziffernfolge ist. Zerlegen Sie damit `'09:30:45'` und geben Sie die gecapturte Sekunde aus.

## Beispiel

Das Programm gibt aus:

```
｢45｣
```
