## Aufgabe

Eine Grammatik kann aus den Werten, die ihre Teile gemacht haben, einen Wert `make`-n. Zerlegen Sie eine Wortgruppe — Wörter aus Wortzeichen, getrennt durch einzelne Leerzeichen, ohne weitere Satzzeichen — und erzeugen Sie die Wortgruppe mit **jedem Wort umgedreht**.

Lassen Sie jedes Token `word` seinen eigenen Text umgedreht `make`-n (mit `flip`) und lassen Sie `TOP` diese zur endgültigen Wortgruppe verbinden. Zerlegen Sie `'hello world'` und geben Sie `.made` aus.

## Beispiel

Das Programm gibt aus:

```
olleh dlrow
```
