## Aufgabe

Schreiben Sie eine Grammatik, die ein Gewicht wie `'5kg'` trifft — eine `number` (eine oder mehrere Ziffern) gefolgt von der wörtlichen Einheit `kg`. Hängen Sie mit einem inline stehenden `make` **nur den Zahlenwert** als echte ganze Zahl an, ohne die Einheit. Zerlegen Sie `'5kg'` und geben Sie das Ergebnis von `.made` aus.

## Beispiel

Das Programm gibt aus:

```
5
```
