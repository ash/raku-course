## Aufgabe

Treffen Sie den wörtlichen Text `base` in der Zeichenkette `'database'`. Weisen Sie das Ergebnis keiner Variablen zu; lesen Sie den Treffer stattdessen aus der selbsttätigen Match-Variablen `$/` und geben Sie **nur den getroffenen Text** als schlichte Zeichenkette aus (nicht zwischen Eckklammern).

## Beispiel

Das Programm gibt aus:

```
base
```
