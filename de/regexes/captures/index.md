Das Treffen sagt Ihnen, _ob_ ein Muster vorhanden ist. Ein _Capture_ geht weiter: Es merkt sich ein bestimmtes Stück des Treffers, damit Sie es hinterher verwenden können. So ziehen Sie ein Jahr aus einem Datum, einen Namen aus einem Datensatz oder die Teile jeder strukturierten Zeichenkette heraus.

Raku hat zwei Arten von Captures: _positionale_, ab null nummeriert, und _benannte_, die Sie selbst beschriften. Beide erreichen Sie über das Match-Objekt.
