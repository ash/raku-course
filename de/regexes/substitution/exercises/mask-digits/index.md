## Aufgabe

Nehmen Sie die Zeichenkette `'PIN 1234'` und erzeugen Sie eine **Kopie**, in der jede Ziffer durch ein `#` ersetzt ist, und verwenden Sie dafür den Operator `S///`, damit das Original unverändert bleibt. Geben Sie die maskierte Kopie aus und danach das Original, um zu zeigen, dass es nicht verändert wurde.

## Beispiel

Das Programm gibt aus:

```
PIN ####
PIN 1234
```
