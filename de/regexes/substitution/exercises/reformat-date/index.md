## Aufgabe

Die Zeichenkette `'2025-06-15'` ist ein Datum in der Reihenfolge `Jahr-Monat-Tag`. Schreiben Sie es mit Captures in einer Ersetzung in die Reihenfolge `Tag/Monat/Jahr` um: `15/06/2025`. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
15/06/2025
```
