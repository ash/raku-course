## Aufgabe

Die Zeichenkette `'say "hi" and "bye"'` enthält zwei angeführte Stücke. Schreiben Sie ein Muster, das **nur das erste** angeführte Stück trifft — vom ersten `"` bis zum nächstgelegenen `"` —, und verwenden Sie dafür einen sparsamen Quantor. Geben Sie den Treffer aus.

## Beispiel

Das Programm gibt aus:

