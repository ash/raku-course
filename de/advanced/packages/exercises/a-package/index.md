## Problem

Erstelle ein Package `Temperature`, das zwei Dinge zusammenfasst: eine `our`-Variable `$freezing` mit dem Wert `0` und eine `our`-Subroutine `fahrenheit`, die einen Celsius-Wert in Fahrenheit umrechnet (multipliziere mit 9/5 und addiere 32). Gib von außerhalb des Packages den Gefrierpunkt aus und dann den Fahrenheit-Wert von `100` Grad Celsius.

## Beispiel

Das Programm gibt aus:

```
0
212
```
