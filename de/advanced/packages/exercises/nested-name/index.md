## Problem

Verschachtle ein Modul `Inner` innerhalb eines Moduls `Outer`. Deklariere in `Inner` eine `our`-Variable `$base` mit dem Wert `10` und eine `our sub doubled`, die `$base` multipliziert mit zwei zurückgibt. Greife von außerhalb beider Module über den vollständigen verschachtelten Namen auf die Variable zu und rufe die Subroutine über ihren vollständigen verschachtelten Namen auf. Gib beide Ergebnisse aus.

## Beispiel

Das Programm gibt aus:

```
10
20
```
