## Aufgabe

`WHAT` beschreibt nicht nur einen Typ — es gibt das Typ-Objekt selbst zurück, das du mit dem `===`-Operator vergleichen kannst.

Deklariere zwei Variablen: `$a` mit der Ganzzahl `42` und `$b` mit dem String `'x'`. Gib für jede aus, ob ihr `WHAT` der `Int`-Typ ist.

## Beispiel

Das Programm gibt aus:

```
True
False
```
