## Aufgabe

Ein Container kann einen Standardwert tragen, der mit dem `is default`-Trait gesetzt wird. Solange du nichts zuweist, gibt das Lesen der Variable diesen Standardwert zurück, und `.VAR.default` meldet ihn.

Deklariere einen Skalar `$count` mit einem Standardwert von `0`. Gib, ohne ihm etwas zuzuweisen, die Variable selbst aus und dann den Standardwert ihres Containers. Beide Zeilen sollten `0` zeigen.

## Beispiel

Das Programm gibt aus:

```
0
0
```
