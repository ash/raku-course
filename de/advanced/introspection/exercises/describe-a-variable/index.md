## Aufgabe

Dir ist eine typisierte Variable gegeben:

```raku
my Str $lang = 'Raku';
```

Gib drei Fakten darüber aus, jeweils in einer eigenen Zeile:

1. den Typ ihres Wertes;
2. den Typ ihres Containers;
3. ihren Namen, einschließlich des Sigils.

## Beispiel

Das Programm gibt aus:

```
Str
Scalar
$lang
```
