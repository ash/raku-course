## Problem

Gehe von der nicht-interpolierenden `q`-Form aus und schalte nur das Closure-Adverb ein. Bei einer Variablen `$x` mit dem Wert `10`, gib eine Zeile aus, die die eingebettete Berechnung `{$x ** 2}` enthält *und* ein wörtliches, nicht-interpoliertes `$x`. Dies zeigt, dass das Closure-Adverb Code in geschweiften Klammern auswertet, während einfache `$`-Variablen unberührt bleiben.

## Beispiel

Das Programm gibt aus:

```
$x squared is 100
```
