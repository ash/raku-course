## Problem

Erstelle ein Modul namens `Maths` in einer Datei `Maths.rakumod`, das eine Subroutine `square` exportiert, die das Quadrat ihres Arguments zurückgibt.

Schreibe dann ein separates Programm, das das Modul verwendet, um `square(6)` auszugeben.

## Beispiel

Mit dem Modul im Suchpfad ausgeführt, gibt das Programm aus:

```console
$ raku -I. maths.raku
36
```
