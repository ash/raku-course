## Problem

Erstelle ein Modul namens `Shouter` in einer Datei `Shouter.rakumod`, das eine Subroutine `shout` exportiert, die ihr Argument in Großbuchstaben zurückgibt.

Schreibe dann ein separates Programm, das das Modul verwendet, um `shout('hi')` auszugeben.

## Beispiel

Mit dem Modul im Suchpfad ausgeführt, gibt das Programm aus:

```console
$ raku -I. shout.raku
HI
```
