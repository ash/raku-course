---
title: Verständnis von Raku-Containern
---

{% include menu.html %}

Container in der Programmiersprache Raku dienen dazu, Daten aufzubewahren, aber ihre Rolle und Bedeutung sind tiefgreifender und umfassender als nur eine Variable zu sein. Dieser Abschnitt gibt einen Überblick über die verschiedenen Containertypen, die einem Raku-Entwickler zur Verfügung stehen.

Es ist wichtig, das Konzept der Container zu verstehen. Ohne dieses Verständnis kann es überraschend erscheinen, dass ein Programm in manchen Fällen einen Skalar zu verwenden scheint, wo man ein Array erwartet hätte, oder umgekehrt.

Verschiedene Container können Daten unterschiedlicher Natur, unterschiedlicher Größe oder sogar einer unterschiedlichen Anzahl von Datenelementen aufnehmen. Entsprechend hat jeder Containertyp seine eigenen Methoden, um die darin enthaltenen Daten zu manipulieren.
