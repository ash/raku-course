## Problem

Eine anonyme Subroutine muss nicht erst gespeichert werden — man kann sie direkt an eine andere Routine übergeben. Übergeben Sie mit der `sub`-Form (nicht einem Pointy Block) eine anonyme „Quadrat"-Subroutine direkt an `map` über die Liste `1, 2, 3`, und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
(1 4 9)
```
