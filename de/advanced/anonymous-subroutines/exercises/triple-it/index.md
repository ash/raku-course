## Problem

Eine anonyme Subroutine ist eine Closure: Sie merkt sich die Variablen aus dem Gültigkeitsbereich, in dem sie geschrieben wurde. Deklarieren Sie eine Variable `$factor` mit dem Wert `3`. Speichern Sie dann einen Pointy Block in `$scale`, der sein Argument mit `$factor` multipliziert (nicht mit einer fest codierten `3`). Rufen Sie `$scale(7)` auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
21
```
