## Problem

Ein Pointy Block kann mehr als einen Parameter entgegennehmen, und das `&`-Sigil ermöglicht es, das Ergebnis über einen Namen aufzurufen. Speichern Sie einen Pointy Block mit zwei Parametern, der seine Argumente addiert, in einer Variablen `&add`, die mit dem `&`-Sigil deklariert ist. Rufen Sie ihn dann als `add(2, 3)` — ohne Sigil — auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
5
```
