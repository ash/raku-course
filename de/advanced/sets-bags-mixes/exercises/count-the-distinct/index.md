## Aufgabe

Du hast eine Liste von Zahlen, von denen sich einige wiederholen:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Gib aus, wie viele _verschiedene_ Werte sie enthält. Verwende dafür ein Set.

## Beispiel

Das Programm gibt aus:

```
7
```
