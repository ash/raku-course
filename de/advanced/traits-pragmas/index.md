Zwei Funktionen ermöglichen es Ihnen, die **Kompilierung** von Code zu beeinflussen, noch bevor er ausgeführt wird. Ein _Trait_ ist ein Modifikator, der an eine Deklaration angehängt wird — eine Variable oder eine Routine — und mit `is` geschrieben wird. Ein _Pragma_ ist eine modulähnliche Direktive, die mit `use` aktiviert (oder mit `no` deaktiviert) wird und eine Regel für den Rest des lexikalischen Gültigkeitsbereichs ändert.

Sie haben bereits ein Trait wie `is default` im Vorbeigehen verwendet. Dieser Abschnitt betrachtet Traits als eigenständige Funktion, zeigt, wie Sie Ihre eigenen schreiben können, und führt Pragmas ein.
