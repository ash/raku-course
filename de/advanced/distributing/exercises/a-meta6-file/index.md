## Problem

Schreibe eine `META6.json` für eine Distribution namens `Greet::Simple`, Version `0.0.1`, die das Modul `Greet::Simple` aus der Datei `lib/Greet/Simple.rakumod` bereitstellt. Anders als bei dem leeren `depends` im Theorie-Beispiel **hängt** diese Distribution von einer anderen Distribution ab, `JSON::Fast` — liste sie im `depends`-Array auf.

> Diese Aufgabe erzeugt eine Datei, keine Programmausgabe.
