## Problem

Jedes `*` in einem Whatever-Ausdruck ist ein eigenes Argument, sodass ein Ausdruck mit zwei Sternen eine Funktion mit zwei Argumenten erzeugt. Schreibe eine solche Funktion, die ihre beiden Argumente mit einem Bindestrich dazwischen verbindet — `* ~ '-' ~ *` — speichere sie in einer Variablen, rufe sie dann mit `'a'` und `'b'` auf und gib das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
a-b
```
