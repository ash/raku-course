## Aufgabe

Die natürliche Verwendung eines nativen Typs mit fester Größe ist ein kompaktes Array von Bytes. Deklariere ein `uint8`-Array mit den Werten `100`, `200` und `255` — jeder passt in ein einzelnes Byte — und gib die Summe seiner Elemente aus.

Beachte, dass die Elemente innerhalb von `0..255` bleiben, ihre Summe aber nicht: `.sum` gibt einen gewöhnlichen `Int` zurück.

## Beispiel

Das Programm gibt aus:

```
555
```
