## Aufgabe

Die Regel, dass eine native Variable niemals undefiniert sein kann, gilt für jeden nativen Typ, nicht nur für `int`. Deklariere eine nicht zugewiesene native `num` und eine nicht zugewiesene native `str`. Gib die Zahl aus und dann den String in eckigen Klammern, damit seine Leere sichtbar ist.

## Beispiel

Das Programm gibt aus:

```
0
[]
```
