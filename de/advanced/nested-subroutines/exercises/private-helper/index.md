## Problem

Schreiben Sie eine Unterroutine `stats`, die eine **verschachtelte** Hilfsunterroutine `double` definiert, die das Doppelte ihres Arguments zurückgibt. Verwenden Sie innerhalb von `stats` den Helfer, um den Wert von `double(3) + double(5)` auszugeben.

Rufen Sie dann `stats` auf.

## Beispiel

Das Programm gibt aus:

```
16
```
