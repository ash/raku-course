## Aufgabe

Eine URL wurde in Teile zerlegt und in einem Array gespeichert. Fügen Sie die Teile mit einem Reduktions-Meta-Operator wieder zu einer einzigen Zeichenkette zusammen, geben Sie die resultierende URL aus, und drucken Sie in der nächsten Zeile, wie viele Zeichen lang sie ist.

## Beispiel

Für das Eingabe-Array:

```raku
my @parts = <http :// example .com>;
```

gibt das Programm aus:

```
http://example.com
18
```
