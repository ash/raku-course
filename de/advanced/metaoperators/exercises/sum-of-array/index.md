## Aufgabe

Schreiben Sie ein Programm, das den Durchschnitt (das arithmetische Mittel) eines Arrays von Zahlen ausgibt. Verwenden Sie einen Reduktions-Meta-Operator, um die Werte aufzuaddieren.

Die Eingabedaten sind fest im Programm codiert, zum Beispiel:

```raku
my @data = 10, 20, 30, 40;
```

## Beispiel

Das Programm gibt das Mittel der Elemente von `@data` aus:

```
25
```
