Ein _Meta-Operator_ ist kein eigenständiger Operator — er ist eine Hülle, die einen gewöhnlichen Operator in einen neuen verwandelt. Mit einem Meta-Operator können Sie beispielsweise denselben Operator auf eine ganze Liste von Werten auf einmal anwenden, anstatt ihn zwischen jedem Paar einzeln auszuschreiben.

Raku verfügt über mehrere Meta-Operatoren. Dieser Abschnitt behandelt die nützlichsten Familien: _Reduktion_, die eine Liste zu einem einzelnen Wert zusammenfasst; _Zip_, das zwei Listen elementweise kombiniert; und — auf der letzten Seite — die _Kreuz-_, _Hyper-_ und _negierten_ Operatoren.
