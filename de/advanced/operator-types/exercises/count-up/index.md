## Problem

Beginnen Sie mit `my $n = 9;`. Der Postfix-Operator `++` hat eine subtile Eigenschaft: Als Ausdruck gibt er den Wert zurück, den die Variable *vor* der Inkrementierung hatte, und erhöht dann die Variable.

Geben Sie in einem einzelnen `say` das Ergebnis von `$n++` aus, und in der nächsten Zeile `$n` selbst, damit der Unterschied sichtbar wird.

## Beispiel

Das Programm gibt aus:

```
9
10
```
