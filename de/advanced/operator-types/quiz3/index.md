Der Operator `x` wiederholt einen String, sodass `'ab' x 3` das Ergebnis `'ababab'` liefert. Da er zwischen seinen beiden Operanden steht, welcher Kategorie gehört `x` an?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Entscheidend ist die Position, nicht ob der Operator ein Symbol oder ein Wort ist. `x` steht *zwischen* zwei Operanden und ist daher ein **Infix**-Operator — genau wie `+` oder `~`, nur als Buchstabe geschrieben.

</div>
