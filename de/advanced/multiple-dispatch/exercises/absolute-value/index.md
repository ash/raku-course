## Problem

Schreiben Sie zwei Multi-Subroutinen mit dem Namen `abs-value`, die eine ganze Zahl entgegennehmen und ihren Absolutwert zurückgeben. Verwenden Sie eine `where`-Klausel, um den negativen Fall separat zu behandeln — verwenden Sie kein `if` innerhalb der Subroutinen und nicht das eingebaute `abs`.

Geben Sie das Ergebnis für `-7` und für `4` aus.

## Beispiel

Das Programm gibt aus:

```
7
4
```
