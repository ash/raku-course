## Problem

Die Doppelpunkt-Form muss der *letzte* Aufruf in einer Kette sein, aber die Aufrufe davor können gewöhnliche mit Klammern sein. Beginne mit den Wörtern `a`, `b`, `c`, kehre sie mit `.reverse` um und verbinde dann das Ergebnis mit einem Bindestrich unter Verwendung der **Doppelpunkt**-Form. Gib es aus.

## Beispiel

Das Programm gibt aus:

```
c-b-a
```
