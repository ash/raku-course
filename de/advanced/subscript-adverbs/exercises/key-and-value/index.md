## Aufgabe

Gegeben ist der Hash `x => 10, y => 20`. Verwende ein Subscript-Adverb, um sowohl den Schlüssel `x` als auch den darunter gespeicherten Wert zusammen auszugeben.

## Beispiel

Das Programm gibt aus:

```
(x 10)
```
