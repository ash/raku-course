## Aufgabe

Gegeben ist der Hash `a => 1, b => 2, c => 3`. Verwende ein Subscript-Adverb, um den Eintrag `b` zu löschen, und gib dann aus, wie viele Einträge der Hash noch hat, um zu zeigen, dass einer entfernt wurde.

## Beispiel

Das Programm gibt aus:

```
2
```
