## Aufgabe

`do` funktioniert auch vor Kontrollfluss-Anweisungen und verwandelt sie in Ausdrücke, die einen Wert liefern. Verwende `do if 7 > 5 { 'big' } else { 'small' }`, um ein Label auszuwählen, weise es `$label` zu und gib es aus.

## Beispiel

Das Programm gibt aus:

```
big
```
