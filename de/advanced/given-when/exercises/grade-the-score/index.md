## Problem

Gib mit `given`/`when` die Lebensphase für ein fest eingetragenes Alter nach folgenden Bereichen aus:

* `child` für 0--12,
* `teenager` für 13--19,
* `adult` für 20--64,
* `senior` für 65 und älter.

Ein negatives Alter ergibt keinen Sinn, daher gib `invalid` für jede Zahl unter null aus. Stelle sicher, dass dieser Fall vor den Bereichsprüfungen behandelt wird.

## Beispiel

Für das Alter `30` gibt das Programm aus:

```
adult
```
