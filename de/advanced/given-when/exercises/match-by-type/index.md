## Problem

Ein `when` kann gegen einen *Typ* matchen, nicht nur gegen einen Wert. Verwende bei der in einer Variable gespeicherten Zahl `3.14` `given`/`when`, um zu berichten, um welche Art von Wert es sich handelt: Gib `integer` für einen `Int`, `rational` für einen `Rat` und `string` für einen `Str` aus.

## Beispiel

Das Programm gibt aus:

```
rational
```
