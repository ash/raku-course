## Problem

Ein `BEGIN`-Phaser ist mehr als nur ein Block, der früh ausgeführt wird — er ist auch ein *Ausdruck*, dessen Wert einmal zur Kompilierzeit berechnet und dann im Programm eingefroren wird.

Verwende `BEGIN { 2 + 3 }`, um eine Variable `$compiled` zu initialisieren, und gib sie aus. Die Berechnung `2 + 3` wird ausgewertet, während das Programm noch kompiliert wird, aber der gespeicherte Wert ist zur Laufzeit problemlos verwendbar.

## Beispiel

Das Programm gibt aus:

```
5
```
