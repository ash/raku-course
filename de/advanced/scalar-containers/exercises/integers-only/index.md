## Aufgabe

Deklariere einen Container `$cars`, der nur Ganzzahlen aufnehmen darf.

Du hast einen Wert, der durch Verkehrsmodellierungsberechnungen ermittelt wurde: `250.7`. Speichere ihn in `$cars`, wobei du ihn in eine Ganzzahl umwandelst, damit die Zuweisung akzeptiert wird. Gib dann den Wert und seinen Typ aus.

## Beispiel

Das Programm gibt aus:

```
250
(Int)
```
