## Aufgabe

Nimm das Array `1, 2, 3` und packe es mit dem **Element**-Kontextualisierer in einen Skalar `$x`, sodass `$x` das gesamte Array als einzelnen Wert enthält. Verwende dann den **Listen**-Kontextualisierer, um eine `for`-Schleife über `$x` laufen zu lassen und die Iterationen zu zählen. Da der Listenkontext das gepackte Array zurück in seine Elemente ausbreitet, läuft die Schleife dreimal. Gib die Anzahl aus.

## Beispiel

Das Programm gibt aus:

```
3
```
