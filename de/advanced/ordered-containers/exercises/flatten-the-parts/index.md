## Aufgabe

Du hast zwei Arrays:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Kombiniere sie zu einem einzigen _flachen_ Array (kein verschachteltes). Gib das Array und dann die Anzahl seiner Elemente aus.

## Beispiel

Das Programm gibt aus:

```
[1 2 3 4 5]
5
```
