title: Geordnete Container
---

{% include menu.html %}

Geordnete Container speichern mehrere Elemente und bewahren deren Reihenfolge, sodass jedes Element über seine Position erreichbar ist. (In Sonderfällen können sie auch nur ein einzelnes Element oder gar keines enthalten.) Die gebräuchlichsten geordneten Container sind _Arrays_ und _Listen_.

Das Sigil `@` zeigt an, dass eine Variable dafür vorgesehen ist, viele Elemente aufzunehmen. Eine Variable mit dem Sigil `@` unterstützt Indizierung, sodass du ein Element über seinen Index lesen kannst, wie du es bereits im Grundlagenteil gesehen hast.

In diesem Abschnitt schauen wir uns genauer an, wie sich Arrays und Listen _als Container_ unterscheiden: Welche davon du ändern kannst, was passiert, wenn du einen Container in einen anderen steckst, und wie _Binding_ einem Container einen Namen gibt, ohne etwas zu kopieren.
