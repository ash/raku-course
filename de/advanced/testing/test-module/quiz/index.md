Welche Funktion im `Test`-Modul wird bestanden, wenn eine boolesche Bedingung wahr ist?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` nimmt eine Bedingung entgegen und wird bestanden, wenn sie wahr ist. `is` vergleicht einen tatsächlichen Wert mit einem erwarteten, `plan` gibt an, wie viele Tests erwartet werden, und `done-testing` beendet die Datei und gibt den Plan aus.

</div>
