{% include menu.html %}

Tests überprüfen, ob dein Code das tut, was er soll — und es auch weiterhin tut, wenn du ihn änderst. Raku wird mit einem Testmodul, `Test`, und den Konventionen geliefert, um ganze Testsuiten auf einmal auszuführen. Tests zu schreiben ist ein wesentlicher Bestandteil der Entwicklung von echten Raku-Programmen und -Modulen.

Dieser Abschnitt behandelt die Grundbausteine des `Test`-Moduls, die verschiedenen Vergleichsarten, die es bietet, und wie Tests ausgeführt werden.
