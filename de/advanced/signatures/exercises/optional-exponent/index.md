## Problem

Schreiben Sie eine Subroutine `power` mit einem erforderlichen Parameter `$base` und einem **optionalen** Parameter `$exp`. Wenn der Exponent angegeben wird, erheben Sie die Basis auf diesen Wert; wenn er weggelassen wird, quadrieren Sie standardmäßig (verwenden Sie den Defined-or-Operator `//`, um `2` als Ersatzwert anzugeben).

Rufen Sie die Funktion einmal nur mit einer Basis und einmal mit einer Basis und einem Exponenten auf.

## Beispiel

Das Programm gibt aus:

```
25
125
```
