## Problem

Definiere einen Infix-Operator `percent-of`, sodass der Ausdruck `$p percent-of $whole` `$p` Prozent von `$whole` zurückgibt. Zum Beispiel ergibt `20 percent-of 150` den Wert `30`.

Verwende den Operator, um `20 percent-of 150` auszugeben.

## Beispiel

Das Programm gibt aus:

```
30
```
