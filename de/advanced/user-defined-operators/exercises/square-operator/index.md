## Problem

Das Symbol eines Operators kann ein beliebiges Zeichen sein, auch ein Unicode-Zeichen. Definiere einen **Postfix**-Operator `²`, der seinen Operanden quadriert, sodass `5²` bedeutet `5 ** 2`. Gib dann `5²` aus.

## Beispiel

Das Programm gibt aus:

```
25
```
