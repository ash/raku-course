## Aufgabe

Definieren Sie zwei leere Klassen, `Cat` und `Dog`. Laufen Sie dann über die vier Werte `Cat`, `Dog`, `Cat.new` und `Dog.new` und geben Sie für jeden aus, ob er definiert ist. Beachten Sie, dass die beiden Typobjekte undefiniert und die beiden Instanzen definiert sind — unabhängig davon, zu welcher Klasse sie gehören.

## Beispiel

Das Programm gibt aus:

```
False
False
True
True
```
