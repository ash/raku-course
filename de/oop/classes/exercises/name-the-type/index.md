## Aufgabe

Definieren Sie zwei leere Klassen, `Cat` und `Dog`, und erzeugen Sie eine `Cat`-Instanz namens `$felix`. Geben Sie den Typ von `$felix` mit `WHAT` aus. Geben Sie dann in zwei weiteren Zeilen aus, ob dieser Typ derselbe wie `Cat` und ob er derselbe wie `Dog` ist, und verwenden Sie dafür den Operator `===`.

## Beispiel

Das Programm gibt aus:

```
(Cat)
True
False
```
