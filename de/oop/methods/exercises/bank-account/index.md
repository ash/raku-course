## Aufgabe

Definieren Sie eine Klasse `Robot` mit einem veränderbaren Attribut `position`, das standardmäßig `0` ist, und einer Methode `move`, die die Position um eine gegebene Anzahl von Schritten vorrückt. Lassen Sie die Anzahl der Schritte standardmäßig `1` sein, sodass ein Aufruf von `move` ohne Argument den Roboter einen Schritt bewegt.

Erzeugen Sie einen Roboter, bewegen Sie ihn `5` Schritte, dann ohne Argument, dann weitere `2` Schritte, und geben Sie seine Endposition aus.

## Beispiel

Das Programm gibt aus:

```
8
```
