## Aufgabe

Definieren Sie eine Klasse `Word` mit einem Attribut `text` und einer Methode `reversed`, die den Text des Wortes rückwärts geschrieben liefert (die Methode `flip` dreht eine Zeichenkette um).

Erzeugen Sie ein Wort mit dem Inhalt `Raku` und geben Sie seine Umkehrung aus.

## Beispiel

Das Programm gibt aus:

```
ukaR
```
