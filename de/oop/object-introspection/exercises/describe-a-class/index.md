## Aufgabe

Definieren Sie eine Basisklasse `Animal` und eine Klasse `Dog`, die von ihr erbt. Geben Sie dann den Namen der Klasse `Dog` aus und in der nächsten Zeile die Anzahl der Typen in ihrer Vererbungskette (verwenden Sie `.^mro` und zählen Sie deren Elemente). Geben Sie schließlich in einer dritten Zeile aus, ob irgendwo in dieser Kette eine Klasse namens `Cat` vorkommt.

## Beispiel

Das Programm gibt aus:

```
Dog
4
False
```
