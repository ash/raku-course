## Aufgabe

Definieren Sie eine Klasse `Converter` mit einer Klassenmethode `km-to-miles`, die eine Anzahl Kilometer aufnimmt und die Strecke in Meilen liefert (multiplizieren Sie mit `0.621`).

Rufen Sie die Methode auf der Klasse für `10` Kilometer auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
6.21
```
