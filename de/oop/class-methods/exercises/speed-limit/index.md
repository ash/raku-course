## Aufgabe

Eine Klassenmethode kann Parameter aufnehmen, genau wie jede andere Methode. Definieren Sie eine Klasse `Geometry` mit einer Klassenmethode `circle-area`, die einen Radius aufnimmt und die Fläche eines Kreises liefert (verwenden Sie `π` oder `pi`), gerundet auf eine ganze Zahl. Die Formel gehört zur Klasse als Ganzem — es ist kein einzelnes Kreisobjekt beteiligt. Rufen Sie die Methode auf der Klasse mit einem Radius von `10` auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
314
```
