## Aufgabe

Lösen Sie nun dieselbe Aufgabe als **Methode**. Definieren Sie eine Klasse `Number` mit einem Attribut `n` und einer Methode `triple`, die das Dreifache von `n` liefert. Erzeugen Sie ein `Number` mit `n` gleich `7` und geben Sie das Ergebnis des Aufrufs von `triple` darauf aus.

## Beispiel

Das Programm gibt aus:

```
21
```
