## Aufgabe

Definieren Sie eine Klasse `Label` mit einem einzigen Attribut `text`, das geändert werden kann (`is rw`). Erzeugen Sie ein Etikett mit dem Text `draft` und **hängen** Sie dann über den Accessor ` (revised)` an seinen Text an — ohne das Objekt neu zu erzeugen — und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
draft (revised)
```
