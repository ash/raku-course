## Aufgabe

Definieren Sie eine Klasse `Counter` mit einem einzigen Attribut `count`, das veränderbar ist (`is rw`) und standardmäßig `0` ist.

Erzeugen Sie einen Zähler und geben Sie zuerst sein `count` aus, um zu bestätigen, dass er beim Standardwert beginnt. Erhöhen Sie ihn dann in einer Schleife fünfmal und geben Sie den Endwert aus.

## Beispiel

Das Programm gibt aus:

```
0
5
```
