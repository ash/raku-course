## Aufgabe

Bauen Sie eine kleine Protokolldatei auf, indem Sie wiederholt an sie anhängen. Schreiben Sie die Zeile `start` in eine Datei namens `log.txt` und hängen Sie dann in einer Schleife drei weitere Zeilen an — `entry 1`, `entry 2` und `entry 3` —, ohne zu löschen, was schon dort steht. Lesen Sie schließlich die ganze Datei und geben Sie sie aus.

## Beispiel

Das Programm gibt aus:

```
start
entry 1
entry 2
entry 3
```
