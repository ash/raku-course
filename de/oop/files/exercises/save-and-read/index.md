## Aufgabe

Sichern Sie eine Zahl in einer Datei und laden Sie sie wieder. Schreiben Sie die Zahl `42` (gefolgt von einem Zeilenumbruch) in eine Datei namens `number.txt`. Lesen Sie die Datei dann zurück, machen Sie aus ihrem Inhalt eine ganze Zahl und geben Sie diese Zahl mal zwei aus.

## Beispiel

Das Programm gibt aus:

```
84
```
