## Aufgabe

Öffnen Sie eine Datei namens `out.txt` zum Schreiben. Schreiben Sie mit offenem Handle die Zahlen `1`, `2` und `3` hinein, jede in einer eigenen Zeile, und verwenden Sie dafür eine Schleife. Schließen Sie dann den Handle, lesen Sie die Datei zurück und geben Sie ihren Inhalt aus.

## Beispiel

Das Programm gibt aus:

```
1
2
3
```
