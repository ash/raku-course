## Aufgabe

Schreiben Sie die drei Wörter `apple`, `banana` und `cherry`, jedes in einer eigenen Zeile, in eine Datei namens `words.txt`. Lesen Sie die Datei dann Zeile für Zeile und geben Sie jede Zeile mit ihrer Zeilennummer davor aus (beginnend bei `1`), in der Form `<Nummer>: <Zeile>`.

## Beispiel

Das Programm gibt aus:

```
1: apple
2: banana
3: cherry
```
