## Aufgabe

Ein Dateihandle ist ein gewöhnlicher Wert, Sie können ihn also wie jedes andere Argument an eine Funktion übergeben. Schreiben Sie eine Subroutine `log-line`, die einen Handle und eine Meldung aufnimmt und die Meldung in einer eigenen Zeile in den Handle schreibt.

Öffnen Sie `log.txt` zum Schreiben, rufen Sie `log-line` dreimal auf, um `started`, `working` und `done` festzuhalten, schließen Sie dann den Handle, lesen Sie die Datei zurück und geben Sie ihren Inhalt aus.

## Beispiel

Das Programm gibt aus:

```
started
working
done
```
