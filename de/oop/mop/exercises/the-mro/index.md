## Aufgabe

Definieren Sie eine Kette von drei Klassen: `A`, dann `B`, die von `A` erbt, dann `C`, die von `B` erbt. Geben Sie die method resolution order von `C` als Liste von Typnamen aus.

## Beispiel

Das Programm gibt aus:

```
(C B A Any Mu)
```
