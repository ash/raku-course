## Aufgabe

Definieren Sie eine Klasse `Dog`, die nur ein Attribut `name` und keine Methoden hat. Fügen Sie ihr dann mit dem MOP zur Laufzeit eine Methode `speak` hinzu. Die hinzugefügte Methode soll den eigenen `name` des Objekts verwenden und `<name> says woof` liefern. Erzeugen Sie einen Hund namens `Rex` und rufen Sie die neue Methode auf.

## Beispiel

Das Programm gibt aus:

```
Rex says woof
```
