## Aufgabe

Definieren Sie eine Klasse `Animal` mit einer Methode `speak` und eine Klasse `Dog`, die von `Animal` erbt, aber keine eigenen Methoden hinzufügt. Geben Sie mit einer Metamethode auf `Dog` aus, ob `Dog` eine Methode namens `speak` hat (ein schlichtes `True` oder `False`). Das zeigt, dass `find_method` entlang der Vererbungskette sucht und nicht nur bei den eigenen Methoden der Klasse.

## Beispiel

Das Programm gibt aus:

```
True
```
