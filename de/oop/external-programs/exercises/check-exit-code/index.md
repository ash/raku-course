## Aufgabe

Führen Sie einen Befehl aus, der absichtlich fehlschlägt — etwa `sh -c 'exit 4'` — und bewahren Sie das gelieferte `Proc` auf. Geben Sie den Exit-Code des Befehls aus und danach `success` oder `failure`, je nachdem, ob der Befehl gelungen ist.

## Beispiel

Das Programm gibt aus:

```
4
failure
```
