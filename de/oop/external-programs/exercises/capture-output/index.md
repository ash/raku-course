## Aufgabe

Starten Sie mit `run` und `:out` das Programm `echo` mit den drei Wörtern `hello world raku`, fangen Sie seine Ausgabe in einer Variablen auf und zählen Sie dann — statt sie nur auszugeben —, wie viele Wörter die aufgefangene Ausgabe enthält, und geben Sie diese Anzahl aus.

## Beispiel

Das Programm gibt aus:

```
3
```
