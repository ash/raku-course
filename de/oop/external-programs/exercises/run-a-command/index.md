## Aufgabe

Starten Sie mit `run` das Programm `echo` mit zwei getrennten Argumenten: `home:` und `$HOME`. Lassen Sie seine Ausgabe an den Bildschirm gehen. Beachten Sie, dass `$HOME` wörtlich erscheint und das Heimatverzeichnis **nicht** ausgegeben wird — weil bei `run` keine Shell beteiligt ist, findet keine Variablenersetzung statt.

## Beispiel

Das Programm gibt aus:

```
home: $HOME
```
