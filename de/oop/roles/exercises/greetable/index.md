## Aufgabe

Definieren Sie eine Rolle `Sized` mit einer Methode `describe`, die die Zeichenkette `size is <size>` liefert und dafür `self.size` verwendet.

Definieren Sie dann eine Klasse `Box`, die die Rolle `Sized` erfüllt und ein Attribut `size` hat. Erzeugen Sie eine Schachtel mit der Größe `10`, geben Sie das Ergebnis des Aufrufs von `describe` darauf aus und geben Sie dann in einer zweiten Zeile aus, ob die Schachtel `~~ Sized` ist — ob sie also als Trägerin der Rolle erkannt wird.

## Beispiel

Das Programm gibt aus:

```
size is 10
True
```
