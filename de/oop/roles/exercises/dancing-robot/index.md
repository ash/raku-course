## Aufgabe

Definieren Sie eine Klasse `Robot`, deren Methode `speak` `beep` liefert. Definieren Sie eine Rolle `Dancing`, die eine Methode `dance` beisteuert, die `spinning around` liefert.

Erzeugen Sie zwei Roboter, geben Sie die Rolle `Dancing` aber nur einem von beiden. Geben Sie das Ergebnis von `speak` für beide Roboter aus und dann das Ergebnis von `dance` für den Roboter, der tanzen kann.

## Beispiel

Das Programm gibt aus:

```
beep
beep
spinning around
```
