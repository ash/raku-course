## Aufgabe

Definieren Sie eine Basisklasse `Shape` mit einer Methode `name`, die `'shape'` liefert, und einer Methode `describe`, die die Zeichenkette `I am a <name>` liefert (unter Verwendung ihres eigenen `name`).

Definieren Sie dann eine Klasse `Square`, die von `Shape` erbt und `name` so überschreibt, dass sie `'square'` liefert.

Geben Sie die Beschreibung eines `Square` aus.

## Beispiel

Das Programm gibt aus:

```
I am a square
```
