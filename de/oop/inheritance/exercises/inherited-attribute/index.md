## Aufgabe

Definieren Sie eine Basisklasse `Vehicle` mit einem Attribut `wheels`. Definieren Sie dann zwei Klassen, die davon erben: `Bike`, das mit `2` Rädern kommt, und `Car`, das `4` hat.

Erzeugen Sie ein `Bike` und ein `Car` und geben Sie aus, wie viele Räder jedes von beiden hat.

## Beispiel

Das Programm gibt aus:

```
2
4
```
