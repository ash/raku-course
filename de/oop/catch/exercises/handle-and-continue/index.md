## Aufgabe

Laufen Sie über die drei Elemente `ok`, `bad` und `ok`. Führen Sie für jedes einen Block aus, der `processed <item>` ausgibt, aber `die 'boom'` ausführt, wenn das Element `bad` ist. Setzen Sie einen `CATCH`-Phaser in den Block, sodass ein fehlschlagendes Element als `skipped (<item>): <message>` gemeldet wird und die Schleife mit dem nächsten Element weiterläuft, statt anzuhalten.

## Beispiel

Das Programm gibt aus:

```
processed ok
skipped (bad): boom
processed ok
```
