## Aufgabe

Laufen Sie über die Zahlen `1`, `2` und `3`. Geben Sie für jede Zahl `ok: <n>` aus, außer dass Sie bei der Zahl `2` `die "bad: 2"` ausführen sollen. Fügen Sie im Schleifenrumpf einen `CATCH`-Phaser hinzu, der `caught: <message>` ausgibt, sodass ein schlechter Durchlauf nicht die ganze Schleife anhält.

## Beispiel

Das Programm gibt aus:

```
ok: 1
caught: bad: 2
ok: 3
```
