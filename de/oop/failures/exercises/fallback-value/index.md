## Aufgabe

Schreiben Sie eine Subroutine `get`, die ihr Argument liefert, aber `fail` mit der Meldung `bad` aufruft, wenn das Argument `0` ist.

Geben Sie mithilfe des Defined-or-Operators `//`, der als Ersatz `default` liefert, das Ergebnis von `get(5)` und dann von `get(0)` aus.

## Beispiel

Das Programm gibt aus:

```
5
default
```
