## Aufgabe

Zeigen Sie beide Seiten von `try`. Verwenden Sie zuerst einen `try`-Block um eine Berechnung, die gelingt (etwa `6 * 7`), und geben Sie ihr Ergebnis aus. Verwenden Sie dann einen zweiten `try`-Block um Code, der `die 'broken'` ausführt; geben Sie aus, ob dieser Block ein definiertes Ergebnis lieferte, und geben Sie die Meldung der gefangenen Ausnahme aus.

## Beispiel

Das Programm gibt aus:

```
42
False
broken
```
