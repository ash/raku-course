## Aufgabe

Ein fehlschlagender `try`-Block ergibt einen undefinierten Wert. Nutzen Sie das zusammen mit dem Defined-or-Operator `//`, um einen Ersatz bereitzustellen: Führen Sie einen `try`-Block aus, der `die 'no'` ausführt, und verwenden Sie bei einem Fehlschlag stattdessen die Zeichenkette `default`. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
default
```
