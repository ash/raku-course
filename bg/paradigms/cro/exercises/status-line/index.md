## Задача

Вземете състоянието на уеб страница по лесния начин — с **клиентския модул на Cro**, а не със суров сокет. Използвайте `Cro::HTTP::Client.get`, за да изтеглите `http://example.com/`, направете `await` на отговора и отпечатайте неговия `.status` — без никакъв разбор на текст.

> Това упражнение се нуждае от инсталиран модул Cro (`zef install cro`) и работеща мрежова връзка.

## Пример

При изпълнение програмата отпечатва:

```
200
```
