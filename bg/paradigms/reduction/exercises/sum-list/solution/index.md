Ето едно възможно решение на задачата.

## Код

```raku
say [+] 10, 20, 30, 40;
```

🦋 Намерете програмата във файла [sum-list.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/sum-list.raku).

## Изход

```
100
```

## Коментари

1. `[+]` вмъква `+` между всеки елемент на списъка.

1. Сумата `10 + 20 + 30 + 40` е `100`.
