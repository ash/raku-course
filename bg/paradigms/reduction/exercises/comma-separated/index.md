## Задача

С помощта на **метода** `reduce` с блок съединете думите `'Raku', 'is', 'fun'` в един низ, като поставите `', '` между парчетата, така че резултатът да се чете `Raku, is, fun`. Метаоператорът `[~]` слепва парчетата без нищо между тях, така че вмъкването на разделител е работа за блок.

## Пример

Програмата отпечатва:

```
Raku, is, fun
```
