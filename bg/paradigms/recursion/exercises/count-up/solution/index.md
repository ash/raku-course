Ето едно възможно решение на задачата.

## Код

```raku
sub countup($n) {
    return if $n < 1;
    countup($n - 1);
    say $n;
}

countup(3);
```

🦋 Намерете програмата във файла [count-up.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/recursion/count-up.raku).

## Изход

```
1
2
3
```

## Коментари

1. Базовият случай `return if $n < 1` пак спира рекурсията, щом броенето мине под нулата.

1. Именно редът на последните два реда я кара да брои *нагоре*: всяко извикване първо рекурсира чак до базовия случай и едва после отпечатва своето число, докато извикванията се развиват обратно. Затова `1` се отпечатва първо, а `$n` — последно.
