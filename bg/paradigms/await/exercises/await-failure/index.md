## Задача

Когато блокът на обещание хвърли изключение, `await` го хвърля отново на мястото на `await`. Стартирайте обещание, чийто блок прави `die 'boom'`. Изчакайте го вътре в блок `try` с фазер `CATCH`, който отпечатва `caught: <съобщение>`.

## Пример

Програмата отпечатва:

```
caught: boom
```
