За да приемете подпрограма като параметър, декларирайте я със сигила `&`. Вътре в тялото после можете да я извикате по име:

```raku
sub apply(&f, $x) {
    f($x);
}

say apply(* + 3, 10); # 13
```

Параметърът `&f` получава парче код, а `f($x)` го извиква. Тук подадохме `* + 3` — израз _Whatever_, който означава „добави три към каквото ти дадат“, — така че `apply(* + 3, 10)` изчислява `13`.

Също толкова лесно можете да подадете и именувана подпрограма, като се позовете на нея със сигила `&`, за да бъде подадена, а не извикана:

```raku
sub double($n) { $n * 2 }

sub apply(&f, $x) {
    f($x);
}

say apply(&double, 5); # 10
```

Точно така работят `map` и `grep`: те са подпрограми, които приемат друга подпрограма — вашия блок — и я прилагат към всеки елемент. Писането на собствени подпрограми, които приемат код, ги прави също толкова гъвкави.
