Какво отбелязва края на заглавките в HTTP заявка, изпратена през сокет?

{:.quiz}
0 | Точка
1 | Празен ред (допълнително `\r\n`)
0 | Думата `END`
0 | Затварянето на сокета

{% include quiz.html %}

<div class="extended-explanation">

HTTP отделя заглавките от тялото — и сигнализира „няма повече заглавки“ — с празен ред, записан като допълнително `\r\n`. Без него сървърът продължава да чака остатъка от заявката.

</div>
