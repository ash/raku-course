Ето едно възможно решение на задачата.

## Код

```raku
say so none(3, 7, 2) < 0;
```

🦋 Намерете програмата във файла [none-negative.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/junctions/none-negative.raku).

## Изход

```
True
```

## Коментари

1. Съединението `none` е истина, когато не съвпада **нито една** стойност.

1. Нито едно от `3, 7, 2` не е под нулата, така че резултатът е `True`. Една-единствена отрицателна стойност би го направила `False`.
