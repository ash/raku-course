## Задача

Накарайте сървъра да върши истинска работа с входа на клиента, вместо да връща постоянен низ. Напишете сървър, който в **цикъл** (както на предишната страница) чете всяка заявка, взема заявения **път** и го изпраща обратно **с главни букви** — така заявка за `/hello` отговаря с `HELLO`. Пътят е втората дума от първия ред на заявката (`GET /hello HTTP/1.0`); махнете началната `/`, преди да го превърнете в главни букви. Сървърът продължава да обслужва заявка след заявка; спрете го с Ctrl-C.

## Пример

Заявка на път с `curl` го връща с главни букви:

```console
$ curl http://127.0.0.1:8080/hello
HELLO
```
