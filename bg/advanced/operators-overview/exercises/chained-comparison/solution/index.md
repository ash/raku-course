Ето едно възможно решение на задачата.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Можете да намерите пълния код във файла [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Резултат

```
True
```

## Коментари

1. Операторите за сравнение могат да бъдат верижни, затова `0 <= 73 <= 100` се чете като „0 е най-много 73, и 73 е най-много 100". Операторът `<=` позволява крайните стойности, така че резултат от точно `0` или `100` също би бил валиден.

1. И двете части са верни, затова целият израз е `True`. Забележете, че средната стойност `73` е записана само веднъж, въпреки че се сравнява с двата си съседа.

1. Без верижното свойство би трябвало да запишете двете сравнения поотделно и да ги свържете с `&&`, повтаряйки средната стойност: `0 <= 73 && 73 <= 100`. Верижната форма изразява същото по-кратко.
