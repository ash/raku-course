## Задача

Създайте пакет `Temperature`, който групира две неща: `our` променлива `$freezing`, зададена на `0`, и `our` подпрограма `fahrenheit`, която преобразува стойност в Целзий във Фаренхайт (умножава по 9/5 и добавя 32). Извън пакета отпечатайте точката на замръзване, след което отпечатайте стойността по Фаренхайт на `100` градуса Целзий.

## Пример

Програмата отпечатва:

```
0
212
```
