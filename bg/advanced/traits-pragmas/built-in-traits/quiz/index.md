Кой трейт позволява на подпрограмата да **промени променливата на извикващия** чрез параметър?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | нито един — параметрите са записваеми по подразбиране

{% include quiz.html %}

<div class="extended-explanation">

Параметърът е само за четене по подразбиране, затова на обикновен параметър не може да се присвоява стойност. `is rw` свързва параметъра с променливата на извикващия, така че промяна вътре в подпрограмата е видима навън. `is copy` вместо това би дало модифицируемо *копие*, оставяйки извикващия незасегнат.

</div>
