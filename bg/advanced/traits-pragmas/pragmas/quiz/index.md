При активирана по подразбиране прагма `strict` в Raku, какво се случва, когато присвоите на променлива, която никога не сте декларирали, например `$x = 42`?

{:.quiz}
1 | Грешка по време на компилация
0 | Мълчаливо създава `$x`
0 | Извежда предупреждение, но се изпълнява
0 | Задава `$x` на `Nil`

{% include quiz.html %}

<div class="extended-explanation">

`strict` е включена по подразбиране и изисква всяка променлива да бъде декларирана първо с `my`, така че голо `$x = 42` не се компилира — *Variable '$x' is not declared*. Изключването на прагмата с `no strict` би позволило присвояването.

</div>
