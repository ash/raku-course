## Проблем

Дефинирайте изброим тип `Light` с константите `red`, `amber` и `green` (в този ред). Декларирайте променлива, типизирана с изброимия тип, `my Light $current`, и я задайте на `red`. Отпечатайте светлината заедно с числото зад нея, във формат `red is 0`.

След това **сменете светлината няколко пъти** — преприсвоете `$current` на `amber`, после на `green`, като я отпечатвате по същия начин след всяка промяна — така преминавате `red` → `amber` → `green`.

Може да очаквате `$current++` да премине към следващата светлина автоматично — опитайте и вижте какво ще стане.

## Пример

Програмата отпечатва:

```
red is 0
amber is 1
green is 2
```
