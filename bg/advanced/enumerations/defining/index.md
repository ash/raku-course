---
title: Дефиниране на enum
---

{% include menu.html %}

Декларирайте изброим тип с ключовата дума `enum`, име и списък от имена на константи:

```raku
enum Colour <red green blue>;
```

Това създава нов тип, `Colour`, и три константи: `red`, `green` и `blue`. Можете да използвате константите директно по име:

```raku
say red;   # red
say green; # green
```

Зад всяко име стои число, присвоено автоматично от нула в реда, в който сте ги изброили — `red` е `0`, `green` е `1`, `blue` е `2`. Тъй като стойностите са подредени, можете да сравнявате константите:

```raku
say red < blue; # True
```

Променлива може да бъде типизирана с изброимия тип, така че да приема само тези константи:

```raku
my Colour $c = green;
say $c; # green
```

Ако дадено име може да се сблъска с нещо друго във вашата програма, винаги можете да се обърнете към константа чрез името на изброимия тип с `::`:

```raku
say Colour::red; # red
```

Изброимият тип дава на набор от свързани константи име и тип, което прави кода, който ги използва, много по-ясен от голи числа. Следващата тема разглежда [числата зад имената](/bg/advanced/enumerations/values-and-keys).
