## Задача

Даден е хешът `a => 1, b => 2, c => 3`. Използвайте наречие за индексиране, за да изтриете записа `b`, след което отпечатайте колко записа са останали в хеша, за да покажете, че един е бил премахнат.

## Пример

Програмата отпечатва:

```
2
```
