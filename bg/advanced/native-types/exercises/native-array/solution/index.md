Ето едно възможно решение на задачата.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Можете да намерите изходния код във файла [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Резултат

```
555
```

## Коментари

1. Поставянето на нативния тип с размер `uint8` преди масива с `@` декларира масив, в който всеки елемент се съхранява като единичен беззнаков байт — компактното подреждане, което е подходящо за двоични данни.

1. Ограничението за обръщане се прилага към всеки *елемент* (`0..255`), а не към резултата от сумирането им. `.sum` обвива общата сума в обикновен `Int`, така че `100 + 200 + 255` дава пълните `555`.
