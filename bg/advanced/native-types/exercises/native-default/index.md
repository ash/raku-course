## Задача

Правилото, че нативна променлива никога не може да бъде недефинирана, се прилага към всеки нативен тип, не само към `int`. Декларирайте неприсвоен нативен `num` и неприсвоен нативен `str`. Отпечатайте числото и след това отпечатайте низа в квадратни скоби, за да се вижда, че е празен.

## Пример

Програмата отпечатва:

```
0
[]
```
