Нека разгледаме програма, която използва повторно същата променлива за съхраняване на различни видове данни. Използваме `dd`, за да видим какво съдържа контейнерът на всяка стъпка. Този пример е тук с демонстрационна цел и не е препоръчителен стил на програмиране.

```raku
my $value;
dd $value;

$value = 42;
dd $value;

$value = 'forty-two';
dd $value;
```

Всяко извикване на `dd` показва какво съдържа в момента променливата `$value`:

```
$value = Any
$value = 42
$value = "forty-two"
```

В началото променливата е празна и `dd` отчита стойността й като `Any` — неопределената базова стойност, с която започва нетипизиран контейнер. След присвояванията `dd` показва целочислената стойност, а след това низа.

Обърнете внимание, че `dd` не отпечатва тип преди името тук. Нетипизиран контейнер не се ангажира с никакъв тип, така че се показва само стойността. Както ще видите в следващата тема, [контейнер с деклариран тип](/bg/advanced/scalar-containers/type-constraints) се държи по различен начин.
