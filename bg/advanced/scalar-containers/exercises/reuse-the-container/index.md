## Задача

Декларирайте две скаларни променливи една до друга: нетипизирана `$untyped` и типизирана с `Int` -- `$typed`. Изведете и двете с `dd`, докато са още празни, след това присвоете `42` на всяка от тях и отново ги изведете с `dd`. Обърнете внимание как `dd` описва двата контейнера по различен начин.

## Пример

Програмата отпечатва (към стандартната грешка):

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
