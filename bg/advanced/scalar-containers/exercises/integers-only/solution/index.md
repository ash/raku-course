Ето едно възможно решение на задачата.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Можете да намерите изходния код във файла [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Изход

```
250
(Int)
```

## Коментари

1. Ограничението на типа `Int` в `my Int $cars` кара контейнера да отхвърля всяка стойност, която не е цяло число. Директното присвояване на `250.7` (стойност от тип `Rat`) би било грешка по време на компилация.

1. Извикването на `.Int` върху рационалната стойност `250.7` я преобразува в целочислената стойност `250`, като отхвърля дробната част. Преобразуваната стойност отговаря на контейнера. Уверете се, че не бъркате това поведение с закръгляне.

1. Псевдо-методът `.WHAT` потвърждава, че стойността, съхранена в контейнера, е от тип `Int`.
