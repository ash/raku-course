`zef` е инсталаторът на модули за Raku. Вече сте го използвали, за да инсталирате модули по име; той работи и с локална директория на дистрибуция. От вътрешността на дистрибуция можете да я тествате и инсталирате директно:

```
zef test .
zef install .
```

`zef test .` изпълнява файловете под `t/`, а `zef install .` инсталира дистрибуцията във вашия Raku, така че други програми да могат да я използват с `use`. Инсталирането по име -- `zef install Cro` -- прави същото, но първо изтегля дистрибуцията от екосистемата.

За да **публикувате** вашата собствена дистрибуция, така че други да могат да я инсталират по име, я качвате в екосистемата. Обичайният инструмент за това е `fez`:

```
fez upload
```

Това пакетира текущата дистрибуция и я изпраща в екосистемата на Raku, след което `zef install Maths::Simple` ще работи за всеки.

> Тези команди изискват инсталирани `zef`/`fez` и достъп до мрежата, а качването изисква акаунт в екосистемата.

Така жизненият цикъл на споделен модул е: оформете го с `META6.json`, тествайте го с `zef test` и публикувайте го с `fez upload`. Оттам нататък той е просто още едно име, което всеки може да инсталира с `zef install`.
