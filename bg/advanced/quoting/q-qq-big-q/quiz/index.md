Какво отпечатва следната програма?

```raku
say q{a\nb};
```

{:.quiz}
1 | a\nb
0 | a<newline>b
0 | ab
0 | anb

{% include quiz.html %}

<div class="extended-explanation">

Операторът `q` работи като единични кавички: той не обработва екраниращи последователности с обратна наклонена черта като `\n`. Затова низът запазва всичките четири символа `a`, `\`, `n`, `b`. Само интерполираща форма като `qq` (или двойни кавички) би превърнала `\n` в истински нов ред.

</div>
