В частта „Основи" използвахте `MAIN`, за да [получавате аргументи от командния ред](/bg/essentials/the-main-function/reading-command-line-arguments). Raku прави още неща за вас около `MAIN` освен просто да предава стойностите.

## Съобщение за употреба

Ако аргументите от командния ред не съответстват на сигнатурата на `MAIN`, Raku не изпълнява тялото. Вместо това отпечатва автоматично генерирано _съобщение за употреба_, което описва как програмата трябва да бъде извикана.

Вземете тази програма:

```raku
sub MAIN($name) {
    say "Hello, $name!";
}
```

Извикана правилно, тя поздравява човека:

```console
$ raku hello.raku Anna
Hello, Anna!
```

Извикана без аргумент, сигнатурата не съответства и Raku отпечатва съобщението за употреба вместо поздрава:

```console
$ raku hello.raku
Usage:
  hello.raku <name>
```

Съобщението се изгражда от имената на параметрите, така че даването на смислени имена прави текста за помощ полезен безплатно.

## Именувани аргументи

Параметрите на `MAIN` могат да бъдат именувани, а не само позиционни. Именуван параметър се превръща в превключвател `--option=value` на командния ред, а стойността по подразбиране го прави незадължителен:

```raku
sub MAIN(:$name = 'World') {
    say "Hello, $name!";
}
```

```console
$ raku hello.raku
Hello, World!

$ raku hello.raku --name=Raku
Hello, Raku!
```
