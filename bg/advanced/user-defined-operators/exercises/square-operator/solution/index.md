Ето едно възможно решение на задачата.

## Код

```raku
sub postfix:<²>($x) {
    $x ** 2
}

say 5²;
```

🦋 Можете да намерите пълния код във файла [square-operator.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/user-defined-operators/square-operator.raku).

## Резултат

```
25
```

## Коментари

1. Операторът е деклариран като `postfix:<²>`, така че неговият символ — знакът за горен индекс две — се пише след операнда, както в `5²`.

1. Тялото повдига операнда на степен две, така че `5²` се изчислява до `25`. Нищо не ви пречи да използвате Unicode символ, който отразява математическата нотация.
