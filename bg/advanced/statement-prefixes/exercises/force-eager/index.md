## Задача

Префиксът `eager` прави обратното на `lazy`: принуждава списъка да бъде напълно произведен, така че той вече не е мързелив. Покажете контраста с `.is-lazy`.

Отпечатайте дали безкрайният диапазон `1 .. Inf` е мързелив, после дали `eager 1..3` е мързелив и накрая дали `lazy 1..3` е мързелив. Резултатите трябва да са `True`, `False`, `True`.

## Пример

Програмата отпечатва:

```
True
False
True
```
