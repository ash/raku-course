## Задача

`do` работи и пред оператори за управление на потока, превръщайки ги в изрази, които дават стойност. Използвайте `do if 7 > 5 { 'big' } else { 'small' }`, за да изберете етикет, присвоете го на `$label` и го отпечатате.

## Пример

Програмата отпечатва:

```
big
```
