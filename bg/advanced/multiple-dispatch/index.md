В частта „Основи" се запознахте с [_мулти-функциите_](/bg/essentials/more-on-functions/multi-functions): няколко подпрограми, които споделят едно и също име, като Raku избира правилната, като разглежда типовете на аргументите. Този механизъм се нарича _множествено диспечиране_ (multiple dispatch).

Досега изборът се правеше по _типа_ на аргументите. Клаузата `where` ви позволява да отидете по-далеч и да диспечирате и по _стойността_. Тя се записва след параметъра и съдържа условие, което аргументът трябва да удовлетвори, за да бъде избран съответният кандидат:

```raku
multi sub info(Int $n where $n < 0)  { say "$n is negative" }
multi sub info(Int $n where $n == 0) { say "$n is zero" }
multi sub info(Int $n where $n > 0)  { say "$n is positive" }

info(-5);
info(0);
info(7);
```

Всяко извикване отива към кандидата, чието условие е вярно за дадената стойност:

```
-5 is negative
0 is zero
7 is positive
```

И трите кандидата имат една и съща сигнатура, що се отнася до типовете — единичен `Int` — така че без клаузите `where` те биха се сблъскали. Условията ги правят различни.

## Базов случай за рекурсия

Често срещана употреба на `where` е да се осигури точка на спиране на рекурсията като отделен кандидат. Ето отново факториелът, разделен на два мулти-подпрограми:

```raku
multi sub fact(Int $n where $n <= 1) { 1 }
multi sub fact(Int $n)               { $n * fact($n - 1) }

say fact(5); # 120
```

Първият кандидат обработва базовия случай (`$n` равно на `1` или по-малко) и просто връща `1`. Всяка друга стойност отива към втория кандидат, който извиква `fact` отново с по-малко число. Няма `if` вътре във функцията — изборът между базовия случай и рекурсивната стъпка се прави от диспечера.
