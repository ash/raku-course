Масивът е подреден контейнер, чиито елементи сами по себе си са скаларни контейнери.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигилът `@` показва, че такава променлива се държи като обект от тип `Positional`, така че можете да я индексирате, за да достъпите отделни елементи:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Тъй като всеки елемент е скаларен контейнер, можете да му присвоите нова стойност, точно както бихте направили със самостоятелна скаларна променлива:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можете също да присвоите стойност от различен тип, например:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Това е, което прави масивите _изменяеми_: всяка позиция е контейнер, който може да приеме нова стойност. Както ще видите в следващата тема, [списъците](/bg/advanced/ordered-containers/lists) се държат по различен начин.
