Подпрограма може да бъде дефинирана _вътре_ в друга подпрограма. Вложената подпрограма е обикновена подпрограма, но е видима само в подпрограмата, която я съдържа.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Програмата отпечатва:

```
I am the inner subroutine
```

Тук `inner` е декларирана вътре в `outer`, а `outer` я извиква. Това работи, защото `inner` е в обхвата на цялото тяло на `outer`.

Извън `outer` обаче името `inner` не съществува. Следната програма не се компилира:

```raku
sub outer {
    sub inner { 42 }
}

inner; # error: Undeclared routine: inner
```

Влагането е полезно, когато помощна подпрограма е необходима само на една подпрограма. Поставянето й вътре прави ясно, че тя е частен детайл, и предотвратява случайното й извикване от друго място.
