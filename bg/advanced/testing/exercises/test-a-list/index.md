## Проблем

Напишете тестов файл, който използва `plan` (не `done-testing`), за да укаже предварително, че съдържа точно две проверки. Направете тези проверки:

1. С `is-deeply`, че сортирането на списъка `3, 1, 2` дава `[1, 2, 3]`.
1. С `is`, че `10 % 3` е равно на `1`.

Дайте на всяка проверка кратко описание по ваш избор.

## Пример

С описания `sorted` и `remainder` програмата извежда:

```
1..2
ok 1 - sorted
ok 2 - remainder
```
