Ето едно възможно решение на задачата.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Можете да намерите пълния код във файла [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Резултат

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Коментари

1. `plan 2` указва броя преди изпълнението на тестовете, така че редът `1..2` се появява пръв. Ако файлът след това изпълни различен брой проверки, наборът ще бъде отчетен като неуспешен — предпазна мярка, която `done-testing` не може да ви даде.

1. `is-deeply` сравнява двата списъка за точно, типово-осъзнато равенство. Сортирането на `3, 1, 2` дава `1, 2, 3`, което съвпада.

1. `is` сравнява две стойности за обикновено равенство и отчита и двете при неуспех. Тук `10 % 3` е `1`, което съвпада с очакваната стойност, така че вторият тест също минава.
