---
title: Стартиране на тестове
---

{% include menu.html %}

Единичен тестов файл е просто програма на Raku, така че можете да го стартирате директно:

```
raku t/01-basic.rakutest
```

Той извежда TAP резултата на екрана. За повече от един-два файла е нужен _тестов изпълнител_, който стартира цяла директория с тестове и обобщава резултатите. Изпълнителят на Raku е `prove6`:

```
prove6 t/
```

Той изпълнява всеки тестов файл в `t/` и отчита колко файла и теста са минали, с единствен общ резултат успех/неуспех в края — далеч по-лесно за четене от суровия TAP от всеки файл.

Когато дистрибуцията има `META6.json`, инструментът за модули стартира тестовете вместо вас:

```
zef test .
```

`zef test` намира директорията `t/`, изпълнява набора и отчита резултата — което е точно това, което се случва автоматично преди инсталирането на дистрибуция. Така тестовете служат двойно: вие ги изпълнявате по време на разработка с `prove6`, а екосистемата ги изпълнява, за да провери дистрибуцията, преди някой да я инсталира.

> Тестовите файлове се именуват с разширение `.rakutest` (или `.t`) и по конвенция са номерирани, както в `t/01-basic.rakutest`.
