---
title: Извеждане на сигнатури на функции
---

{% include menu.html %}

Извикване на `dd` без аргументи вътре в подпрограма отпечатва сигнатурата на тази подпрограма: нейното име и списъка с параметри, ако има такива. Разгледайте следния пример с две подпрограми:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Програмата отпечатва сигнатурите, а не стойности:

```console
sub f1()
sub f2($x)
```

Това е особено полезно при мулти-функции, където показва кой кандидат е бил реално извикан:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Изходът посочва съответстващия вариант всеки път:

```console
sub g()
sub g($x)
```
