## Проблем

Дадена ви е следната вложена структура от данни:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Направете две неща с нея:

1. Отпечатайте дъмп на `@data`, удобен за разработчици, с `dd`.
2. Отпечатайте същото представяне като низ, с префикс `Structure: `.

## Пример

Програмата отпечатва два подобни реда:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
