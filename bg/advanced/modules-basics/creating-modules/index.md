С нарастването на програмите е полезно да ги разделяте на части за повторна употреба. _Модулът_ е единица код, съхранена в собствен файл, която други програми могат да заредят и използват.

Файлът на модула има разширение `.rakumod` и започва с именуване на модула чрез `unit module`. Подпрограмите, които пишете вътре, са частни по подразбиране; за да направите някоя достъпна за кода, който използва модула, я маркирайте с характеристиката `is export`.

Ето модул, съхранен във файл на име `Greeting.rakumod`:

```raku
unit module Greeting;

sub hello($name) is export {
    return "Hello, $name!";
}
```

Подпрограмата `hello` носи `is export`, така че ще бъде видима за всяка програма, която използва модула. Подпрограма без `is export` ще остане частна за модула.

Модулът може също да споделя данни чрез `our` променливи, които стават достъпни чрез името на модула. Добавянето на номер на версия към `Greeting` е толкова просто, колкото един допълнителен ред във файла:

```raku
our $version = '1.0';
```

С този ред в `Greeting.rakumod`, стойността е достъпна като `$Greeting::version` навсякъде, където модулът е зареден.

Следващите теми показват [как програмата зарежда такъв модул](/bg/advanced/modules-basics/using-modules) и какво точно получава от него.
