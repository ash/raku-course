## Задача

Създайте модул на име `Shouter`, във файл `Shouter.rakumod`, който експортира подпрограма `shout`, връщаща аргумента си с главни букви.

След това напишете отделна програма, която използва модула, за да отпечата `shout('hi')`.

## Пример

При стартиране с модула в пътя за търсене, програмата отпечатва:

```console
$ raku -I. shout.raku
HI
```
