## Задача

Създайте модул на име `Maths`, във файл `Maths.rakumod`, който експортира подпрограма `square`, връщаща квадрата на аргумента си.

След това напишете отделна програма, която използва модула, за да отпечата `square(6)`.

## Пример

При стартиране с модула в пътя за търсене, програмата отпечатва:

```console
$ raku -I. maths.raku
36
```
