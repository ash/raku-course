## Задача

`WHAT` не просто описва тип — той връща самия типов обект, който можете да сравните с оператора `===`.

Декларирайте две променливи: `$a`, съдържаща цялото число `42`, и `$b`, съдържаща низа `'x'`. За всяка от тях отпечатайте дали нейният `WHAT` е типът `Int`.

## Пример

Програмата отпечатва:

```
True
False
```
