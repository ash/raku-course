## Задача

Контейнерът може да носи стойност по подразбиране, зададена с характеристиката `is default`. Докато не присвоите нещо, четенето на променливата връща тази стойност по подразбиране, а `.VAR.default` я докладва.

Декларирайте скалар `$count` със стойност по подразбиране `0`. Без да присвоявате нищо на него, отпечатайте самата променлива, а след това отпечатайте стойността по подразбиране на нейния контейнер. И двата реда трябва да покажат `0`.

## Пример

Програмата отпечатва:

```
0
0
```
