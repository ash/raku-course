Низовете могат да бъдат разделяни на части и съединявани обратно по няколко начина.

Методът `words` разделя низ на списък от думи, разделени с интервали:

```raku
say 'Hello big World'.words; # (Hello big World)
```

Методът `split` разделя низ по разделител, който вие избирате:

```raku
say 'a,b,c'.split(','); # (a b c)
```

Важен специален случай е разделянето по **празен низ** `''`: то разбива низ на отделни символи, но добавя и празен низ в самото начало и в самия край, така че резултатът има два елемента повече, отколкото бихте очаквали:

```raku
say 'abc'.split('').elems;        # 5 — the three letters, plus an empty string at each end
say 'abc'.split('', :skip-empty); # (a b c) — the :skip-empty adverb drops the empties
```

За разделяне на символи методът `comb`, извикан без аргументи, го прави директно — без излишни празни елементи за почистване:

```raku
say 'Raku'.comb; # (R a k u)
```

В обратната посока методът `join` слепва списък от стойности в един низ, поставяйки разделител между тях:

```raku
say <a b c>.join('-'); # a-b-c
```

Още два метода работят с части от низ. Методът `substr` извлича част, при зададена начална позиция и, по избор, дължина:

```raku
say 'Hello World'.substr(0, 5); # Hello
say 'Hello World'.substr(6);    # World
```

А `trim` премахва интервалите от двата края на низ:

```raku
say '  hi  '.trim; # hi
```
