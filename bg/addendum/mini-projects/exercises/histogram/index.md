## Задача

Имайки данни за продажби `apples => 5, pears => 3, plums => 8`, отпечатайте проста
стълбовидна диаграма: всеки етикет, после табулация, после стълб от знаци `#` с
дължина, равна на стойността му, подредени по етикет.

## Пример

Програмата отпечатва:

```
apples	#####
pears	###
plums	########
```
