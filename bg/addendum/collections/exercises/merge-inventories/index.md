## Задача

Два магазина държат наличностите си в хешове:
`apples => 3, pears => 2` и `apples => 4, plums => 5`. Слейте ги в един, като
съберете количествата за ключовете, които се появяват и в двата. Отпечатайте
резултата, подреден по ключ, като двойки `ключ: сума`, свързани със запетаи.

## Пример

Програмата отпечатва:

```
apples: 7, pears: 2, plums: 5
```
