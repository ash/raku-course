## Задача

Имайки три дължини на страни, преценете дали образуват равностранен, равнобедрен или
разностранен триъгълник — или изобщо не триъгълник, когато най-дългата страна е твърде
дълга. Класифицирайте `(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)` и `(1, 2, 10)`.

## Пример

Програмата отпечатва:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
