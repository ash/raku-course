## Задача

Отворете файл на име `out.txt` за писане. Докато манипулаторът е отворен, запишете в него числата `1`, `2` и `3`, всяко на свой ред, използвайки цикъл. След това затворете манипулатора, прочетете файла обратно и отпечатайте съдържанието му.

## Пример

Програмата отпечатва:

```
1
2
3
```
