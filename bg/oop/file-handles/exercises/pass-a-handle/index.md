## Задача

Манипулаторът на файл е обикновена стойност, така че можете да го подадете на функция като всеки друг аргумент. Напишете подпрограма `log-line`, която приема манипулатор и съобщение и записва съобщението в манипулатора на свой собствен ред.

Отворете `log.txt` за писане, извикайте `log-line` три пъти, за да запишете `started`, `working` и `done`, после затворете манипулатора, прочетете файла обратно и отпечатайте съдържанието му.

## Пример

Програмата отпечатва:

```
started
working
done
```
