## Задача

Запазете число във файл и го заредете обратно. Запишете числото `42` (следвано от нов ред) във файл на име `number.txt`. След това прочетете файла обратно, превърнете съдържанието му в цяло число и отпечатайте това число, умножено по две.

## Пример

Програмата отпечатва:

```
84
```
