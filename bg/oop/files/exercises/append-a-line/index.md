## Задача

Изградете малък журнален файл, като добавяте към него многократно. Запишете реда `start` във файл на име `log.txt`, после с цикъл **добавете** още три реда — `entry 1`, `entry 2` и `entry 3` — без да изтривате вече написаното. Накрая прочетете целия файл и го отпечатайте.

## Пример

Програмата отпечатва:

```
start
entry 1
entry 2
entry 3
```
