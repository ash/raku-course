В [раздела за контейнерите](/bg/advanced/containers) използвахте `.^name`, за да попитате стойността за нейния тип. Същите метаизвиквания с `.^` ви позволяват да разгледате клас и обектите му: имената им, атрибутите им и мястото им в йерархията.

Методът `.^name` връща името на класа:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметодът `.^attributes` изброява атрибутите на класа. Всеки се показва с типа си и с вътрешното си частно име (формата `$!`, с която се запознахте при [частните атрибути](/bg/oop/methods/private-attributes)):

```raku
say Dog.^attributes; # (Str $!name)
```

Интроспекцията е полезна за инструменти, които работят с обекти общо — например за да отпечатат всеки атрибут на обект, без да знаят класа му предварително. Следващата тема разглежда как да видите веригата на наследяване на класа.
