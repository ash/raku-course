Процедурата `dir` връща елементите на директория — всеки като обект-път. Редът им не е фиксиран, така че често се сортира резултатът заради предвидим изход.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Това отпечатва имената на файловете в директорията `box`, по ред:

```
a.txt
b.txt
```

Всеки елемент е пълен обект-път; методът `basename` дава само крайното име, без частта с директорията. От обект-път можете да зададете всички същите въпроси както преди — `.f`, `.d`, `.e`, — така че можете например да обходите директория и да отделите само файловете.
