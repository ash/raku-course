За да работите със самата файлова система — да проверявате какво съществува и да създавате директории, — Raku използва _обекти-пътища_. Всеки низ може да бъде превърнат в такъв с метода `.IO`, а обектът-път след това отговаря на въпроси за този път.

Най-честите въпроси са дали пътят съществува и какво представлява:

```raku
spurt 'greeting.txt', 'hi';

say 'greeting.txt'.IO.e; # True  — съществува ли?
say 'greeting.txt'.IO.f; # True  — файл ли е?
say 'greeting.txt'.IO.d; # False — директория ли е?
```

`.e` проверява съществуването, `.f` проверява за обикновен файл, а `.d` — за директория.

За да създадете нова директория, използвайте `mkdir`:

```raku
mkdir 'reports';
say 'reports'.IO.d; # True
```

Следващата тема показва как да изброите какво съдържа дадена директория.
