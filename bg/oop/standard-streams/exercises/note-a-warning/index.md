## Задача

Програма обработва стойност, която се оказва отрицателна. Използвайте `note`, за да изпратите предупреждение в стандартната грешка, когато стойността е под нулата, и `say`, за да изпратите истинския резултат — нейната абсолютна стойност — в стандартния изход. Използвайте стойността `-3`.

## Пример

И двата реда се появяват на екрана:

```
Warning: the value is negative
3
```

Ако стандартната грешка бъде отхвърлена, остава само резултатът:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
