Методът може да приема параметри, точно както подпрограма. Изброявате ги в скоби след името на метода:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

Методът `deposit` приема един параметър — `$amount` — и го добавя към баланса на обекта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Всяко извикване работи върху обекта, върху който е извикано, така че един и същ метод може да обновява различни обекти независимо. Методите могат да приемат позиционни и именувани параметри, стойности по подразбиране и всичко останало, което вече видяхте в сигнатурите на подпрограмите.
