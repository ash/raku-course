## Задача

Дефинирайте клас `Robot` с променяем атрибут `position`, който по подразбиране е `0`, и метод `move`, който придвижва позицията с даден брой стъпки. Направете броя на стъпките по подразбиране `1`, така че извикването на `move` без аргумент да мести робота с една стъпка.

Създайте робот, преместете го с `5` стъпки, после го преместете без аргумент, после още `2` стъпки и отпечатайте крайната му позиция.

## Пример

Програмата отпечатва:

```
8
```
