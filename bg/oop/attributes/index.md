Празният клас не е особено полезен. За да може обектът да носи собствени данни, давате на класа _атрибути_. Атрибут се декларира вътре в класа с ключовата дума `has`:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Всеки обект от класа получава свое собствено копие на тези атрибути. Стойностите им се задават при създаването на обекта, като ги подадете на `new` като именувани аргументи:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

`$.` в `has $.name` върши две неща наведнъж: декларира атрибут и създава метод със същото име — _аксесор_, — който връща стойността на атрибута:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Различните обекти пазят свои собствени стойности, независимо един от друг:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Следващите теми показват как да направите атрибутите променяеми и как да им дадете стойности по подразбиране. (Има и начин да се декларират _частни_ атрибути, скрити от външния свят; ще се върнем към него, щом въведем методите.)
