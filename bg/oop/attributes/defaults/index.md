На атрибута може да се даде _стойност по подразбиране_, която се използва, когато обектът се създава без стойност за него. Запишете стойността по подразбиране след атрибута, с `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Забележете, че подобно на променливите, типът на атрибутите може да бъде наложен.

Ако не подадете `weight` на `new`, атрибутът взема стойността по подразбиране:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Пак можете да пренебрегнете стойността по подразбиране, като подадете стойност:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Без стойност по подразбиране и без стойност, подадена на `new`, атрибутът просто е недефиниран, точно като новосъздадена скаларна променлива.
