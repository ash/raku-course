## Задача

Използвайте `run`, за да стартирате `echo` с два отделни аргумента: `home:` и `$HOME`. Оставете изхода ѝ да отиде на екрана. Забележете, че `$HOME` се появява буквално и домашната директория **не** се отпечатва — понеже `run` не намесва обвивка, няма разгъване на променливи.

## Пример

Програмата отпечатва:

```
home: $HOME
```
