Коя функция подава командата си през системната **обвивка**, позволявайки канали и пренасочване?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` подава един-единствен низ на обвивката, която тълкува възможности като каналите. `run` стартира програма направо с отделни аргументи и без обвивка, което е по-безопасно и е по-добрият избор по подразбиране.

</div>
