_Ролята_ е сноп от поведение (а понякога и данни), който може да се споделя от няколко класа. Докато наследяването казва, че класът _е_ вид друг клас, ролята описва нещо, което класът _може да прави_.

Дефинирате роля с ключовата дума `role`, досущ като клас, и я давате на клас с трейта `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Класът `Person` вече има метода `hello` от ролята, все едно е бил написан в самия клас:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Клас, който изпълнява роля, се разпознава като притежаващ тази роля:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Забележете, че методът `hello` на ролята използва `self.name`, макар самата роля да няма атрибут `name`. Това е наред: методът се изпълнява като част от онзи клас, който компонира ролята, а този клас предоставя `name`. Следващата тема показва, че класът може да поеме повече от една роля наведнъж.
