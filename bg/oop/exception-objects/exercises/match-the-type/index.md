## Задача

Вградените грешки имат свои собствени типове изключения, по които можете да съпоставяте. Напишете блок, който изчислява `1 / 0` и се опитва да използва резултата, при което се хвърля `X::Numeric::DivideByZero`. Във фазера `CATCH` на блока използвайте `when X::Numeric::DivideByZero`, за да съпоставите точно този тип, и отпечатайте `cannot divide by zero`.

## Пример

Програмата отпечатва:

```
cannot divide by zero
```
