Досега типовете данни, които използвахте — числа, низове, масиви и така нататък, — бяха вградени в Raku. _Обектно-ориентираното програмиране_ ви позволява да дефинирате свои собствени типове, наречени _класове_, и да създавате стойности от тези типове, наречени _обекти_.

Клас се дефинира с ключовата дума `class`, следвана от име и блок:

```raku
class Dog {
}
```

Този клас `Dog` засега е празен, но вече е нов тип. За да създадете обект от класа — _екземпляр_, — извикайте метода `new` върху името на класа:

```raku
class Dog {
}

my $rex = Dog.new;
say $rex; # Dog.new
```

Променливата `$rex` вече съдържа обект `Dog`. Всяко извикване на `new` създава отделен обект:

```raku
my $rex = Dog.new;
my $fido = Dog.new;
```

`$rex` и `$fido` са две различни кучета, макар че класът все още няма съдържание. В следващите раздели ще дадете на класа собствени данни (_атрибути_) и собствено поведение (_методи_). Първата тема разглежда по-отблизо разликата между клас и неговите екземпляри.
