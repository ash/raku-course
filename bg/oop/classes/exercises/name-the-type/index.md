## Задача

Дефинирайте два празни класа, `Cat` и `Dog`, и създайте екземпляр на `Cat` на име `$felix`. Отпечатайте типа на `$felix` с `WHAT`. След това на още два реда отпечатайте дали този тип съвпада с `Cat` и дали съвпада с `Dog`, използвайки оператора `===`.

## Пример

Програмата отпечатва:

```
(Cat)
True
False
```
