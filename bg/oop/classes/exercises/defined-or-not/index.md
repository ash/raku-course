## Задача

Дефинирайте два празни класа, `Cat` и `Dog`. След това обходете в цикъл четирите стойности `Cat`, `Dog`, `Cat.new` и `Dog.new`, като отпечатате за всяка дали е дефинирана. Забележете, че двата обекта на типа са недефинирани, а двата екземпляра са дефинирани — независимо към кой клас принадлежат.

## Пример

Програмата отпечатва:

```
False
False
True
True
```
