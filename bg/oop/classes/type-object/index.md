Когато напишете име на клас като `Dog`, вие се позовавате на _обекта на типа_ на класа. Обектът на типа представя самия тип, а не някакъв конкретен обект от този тип. _Екземплярът_, създаден с `new`, е действителен обект.

Raku различава двете. Методът `defined` връща `False` за обект на типа и `True` за екземпляр:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Обектът на типа се смята за _недефиниран_, защото не съдържа конкретни данни — той е само описанието на един тип. Екземплярът е _дефиниран_: той е истински обект.

И двата съобщават един и същ тип чрез `WHAT`, с който се запознахте в [раздела за контейнерите](/bg/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Скобите около `(Dog)` са начинът на Raku да покаже тип. Така `Dog` и `Dog.new` споделят типа `Dog`; разликата е, че единият е самият тип, а другият — обект от този тип.
