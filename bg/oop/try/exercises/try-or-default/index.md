## Задача

Блок `try`, който се проваля, се изчислява до недефинирана стойност. Използвайте това с оператора „определено или“ `//`, за да подадете резервен вариант: изпълнете блок `try`, който прави `die 'no'`, и ако той се провали, използвайте вместо това низа `default`. Отпечатайте резултата.

## Пример

Програмата отпечатва:

```
default
```
