## Задача

Дефинирайте клас `Animal` с метод `speak` и клас `Dog`, който наследява `Animal`, но не добавя свои собствени методи. С помощта на метаметод върху `Dog` отпечатайте дали `Dog` има метод на име `speak` (просто `True` или `False`). Това показва, че `find_method` търси по веригата на наследяване, а не само сред собствените методи на класа.

## Пример

Програмата отпечатва:

```
True
```
