Ето едно възможно решение на задачата.

## Код

```raku
my regex year  { \d ** 4 }
my regex month { \d ** 2 }

if '2025-06' ~~ / <year> '-' <month> / {
    say $<year>;
    say $<month>;
}
```

🦋 Намерете програмата във файла [year-token.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/what-is-a-grammar/year-token.raku).

## Изход

```
｢2025｣
｢06｣
```

## Коментари

1. Декларирани са два именувани регулярни израза, всеки от които описва по едно парче от датата: четирицифрена `year` и двуцифрен `month`.

1. Шаблонът ги съчетава с буквално тире между тях и всеки се прихваща под собственото си име. Изграждането на по-голям шаблон от малки именувани части е точно идеята, която граматиката формализира.
