За да изпълните граматика, извикайте нейния метод `.parse` с низа за анализ:

```raku
grammar Pair {
    token TOP   { <key> '=' <value> }
    token key   { \w+ }
    token value { \w+ }
}

my $m = Pair.parse('x=5');
say $m<key>;   # ｢x｣
say $m<value>; # ｢5｣
```

`.parse` връща обект на съвпадението, когато граматиката съвпадне с **целия** низ, и `Nil`, когато не съвпадне. Понеже целият вход трябва да съвпадне, няма нужда от котвите `^` и `$` — `.parse` добавя това изискване вместо вас:

```raku
say Pair.parse('x=5').defined; # True
say Pair.parse('x=').defined;  # False
```

[Обектът на съвпадението](/bg/regexes/matching/match-object) работи точно като онези, които срещнахте по-рано. Всеки токен, използван в граматиката, става именувано прихващане, така че `$m<key>` и `$m<value>` дават съвпадналите части. Токените се влагат един в друг, така че граматиката изгражда малко дърво от съвпадения — темата на по-късен раздел.
