Когато разбирате низ с граматика, Raku започва от токен на име `TOP`. Той е входната точка — описанието на **целия** вход. Всичко останало в граматиката съществува, за да го подпомага.

Токенът `TOP` обикновено се позовава на други токени по име, разбивайки задачата на по-малки части:

```raku
grammar Pair {
    token TOP   { <key> '=' <value> }
    token key   { \w+ }
    token value { \w+ }
}
```

Прочетете `TOP` на глас: „ключ, после знак за равенство, после стойност“. Токените `key` и `value` казват как изглежда всяка от тези части. Точно това разделяне е целият смисъл на граматиката — всеки токен има една малка, ясно именувана задача, а `TOP` ги сглобява.

`TOP` е само споразумение, налагано от `.parse`; другите токени могат да се наричат както пожелаете. Имената, които изберете, стават и именуваните прихващания в резултата, така че граматика с добри имена дава самоописващо се дърво на съвпаденията, както ще видите скоро.
