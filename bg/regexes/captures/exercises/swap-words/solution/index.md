Ето едно възможно решение на задачата.

## Код

```raku
if 'Grace Hopper' ~~ / (\w+) ' ' (\w+) / {
    say "$1, $0";
}
```

🦋 Намерете програмата във файла [swap-words.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/captures/swap-words.raku).

## Изход

```
Hopper, Grace
```

## Коментари

1. Собственото име и фамилията се прихващат в `$0` и `$1`.

1. В низ с двойни кавички всяко прихващане се интерполира като съвпадналия си текст. Отпечатването на `"$1, $0"` слага фамилията първа, следвана от буквална запетая с интервал и после собственото име.
