Номерираните прихващания са удобни, но когато шаблонът порасне, имената са по-ясни от числата. За да дадете име на прихващане, напишете `$<име>=( … )`:

```raku
if 'Anna:30' ~~ / $<name>=(\w+) ':' $<age>=(\d+) / {
    say $<name>; # ｢Anna｣
    say $<age>;  # ｢30｣
}
```

До прихванатите парчета сега се стига по име през `$<name>` и `$<age>` вместо през `$0` и `$1`. Това е същото като да напишете `$/<name>`, защото имената живеят вътре в променливата на съвпадението `$/`.

Именуваните прихващания правят шаблона четим почти като описание на данните:

```raku
if 'x=5' ~~ / $<key>=(\w+) '=' $<value>=(\w+) / {
    say "key is $<key>, value is $<value>"; # key is x, value is 5
}
```

Както и при позиционните прихващания, всяко именувано прихващане е обект на съвпадението, така че `$<age>.Str` дава обикновения текст, а `$<age>.from` дава позицията му.
