Какво отпечатва следната програма?

```raku
if 'ab12cd' ~~ / (\w+) (\d+) / {
    say "$0 $1";
}
```

{:.quiz}
0 | ab 12
1 | ab1 2
0 | ab12 cd
0 | 12 ab

{% include quiz.html %}

<div class="extended-explanation">

Лакомият `\w+` съпоставя словесни знаци докъдето може, но така, че да остави поне една цифра за `\d+`. Той взема `ab1`, а `\d+` след това съпоставя единствената останала цифра `2`. Затова `$0` е `ab1`, а `$1` е `2`.

</div>
