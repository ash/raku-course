Какво отпечатва следната програма? Класът е **отрицателен**.

```raku
say 'abc123' ~~ / <-[a..z]> /;
```

{:.quiz}
1 | ｢1｣
0 | ｢a｣
0 | ｢abc｣
0 | False

{% include quiz.html %}

<div class="extended-explanation">

Класът `<-[a..z]>` съпоставя един знак, който **не** е малка буква. При обхождане на `abc123` отляво първите три знака са малки букви и се прескачат; първият знак, който не е малка буква, е цифрата `1`, така че съвпадението е `｢1｣`.

</div>
