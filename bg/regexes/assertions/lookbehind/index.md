_Погледът назад_ проверява какво стои непосредствено **преди** текущата позиция:

* `<?after …>` — успява, ако текстът назад съвпада (положителен поглед назад)
* `<!after …>` — успява, ако текстът назад **не** съвпада (отрицателен поглед назад)

Това ви позволява да съпоставите нещо само заради онова, което го предхожда, без този префикс да влиза в резултата. Например прихванете цифрите, които следват знака за долар, но оставете `$` извън съвпадението:

```raku
if '$100' ~~ / <?after '$'> \d+ / {
    say $/; # ｢100｣
}
```

Твърдението `<?after '$'>` изисква `$` непосредствено преди текущата позиция, а после `\d+` съпоставя цифрите. Съвпадението е `100`, без знака за долар.

Погледът напред и погледът назад често се комбинират. Парче текст, обвито в `<?after …>` и `<?before …>`, съвпада само когато стои между изискваните съседи — удобен начин да извлечете стойност от познат контекст.
