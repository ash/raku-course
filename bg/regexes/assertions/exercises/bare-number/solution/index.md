Ето едно възможно решение на задачата.

## Код

```raku
say '5 and $9' ~~ / <!after '$'> \d+ /;
```

🦋 Намерете програмата във файла [bare-number.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/assertions/bare-number.raku).

## Изход

```
｢5｣
```

## Коментари

1. `<!after '$'>` е отрицателен поглед назад: той успява само когато знакът непосредствено преди текущата позиция **не** е `$`. Той проверява този съсед, без да го поглъща.

1. Цифрата `9` е отхвърлена, защото стои веднага след `$`, така че машината вместо това съпоставя по-ранната `5`, пред която няма нищо.
