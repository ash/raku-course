## Задача

Низът `'5 and $9'` съдържа две числа: обикновено `5` и цена `$9`. С помощта на **отрицателен поглед назад** напишете шаблон, който съпоставя число само когато непосредствено преди него **не** стои `$`. Отпечатайте съвпадението.

## Пример

Програмата отпечатва:

```
｢5｣
```
