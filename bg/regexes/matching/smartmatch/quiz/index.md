Какво отпечатва следната програма? Забележете, че този път няма `so`, а съпоставянето използва формата `m/.../`.

```raku
say 'the cat sat' ~~ m/sat/;
```

{:.quiz}
0 | True
0 | False
1 | ｢sat｣
0 | Nil

{% include quiz.html %}

<div class="extended-explanation">

`m/sat/` съпоставя по същия начин, както би направил `/sat/`. Без `so`, който да го преобразува в булева стойност, интелигентното съпоставяне връща самия обект на съвпадението, който `say` отпечатва между ъглови скоби като `｢sat｣`.

</div>
