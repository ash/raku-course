Ето едно възможно решение на задачата.

## Код

```raku
'database' ~~ /base/;
say $/.Str;
```

🦋 Намерете програмата във файла [matched-text.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/matching/matched-text.raku).

## Изход

```
base
```

## Коментари

1. Всяко интелигентно съпоставяне съхранява резултата си в специалната променлива на съвпадението `$/`, така че няма нужда да го присвояваме на своя собствена променлива.

1. Обектът на съвпадението съдържа съвпадналия текст; извикването на `.Str` върху `$/` връща този текст като обикновен низ. Отпечатването на самия обект на съвпадението вместо това би показало `｢base｣`.
