## Problema

Date tre lunghezze di lato, decidi se formano un triangolo equilatero, isoscele o
scaleno — oppure nessun triangolo, quando il lato più lungo è troppo lungo. Classifica
`(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)` e `(1, 2, 10)`.

## Esempio

Il programma stampa:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
