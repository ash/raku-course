## Problema

Scrivi una classe `Stack` con metodi per spingere un valore, estrarre il valore in cima,
sbirciare quello in cima senza rimuoverlo e riferire la propria dimensione. Spingi `1`,
`2`, `3`, poi stampa il risultato dello sbirciare, dell'estrarre e del chiedere la
dimensione.

## Esempio

Il programma stampa:

```
3
3
2
```
