## Problema

La *radice numerica* di un numero è ciò che si ottiene sommandone ripetutamente le cifre
finché non resta una sola cifra. Per `987654`: `9+8+7+6+5+4 = 39`, poi `3+9 = 12`, poi
`1+2 = 3`. Calcola e stampa la radice numerica di `987654`.

## Esempio

Il programma stampa:

```
3
```
