## Problema

Due negozi tengono le proprie scorte in hash: `apples => 3, pears => 2` e
`apples => 4, plums => 5`. Uniscili in uno solo, sommando le quantità per le chiavi che
compaiono in entrambi. Stampa il risultato ordinato per chiave, come coppie
`chiave: totale` unite da virgole.

## Esempio

Il programma stampa:

```
apples: 7, pears: 2, plums: 5
```
