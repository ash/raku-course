## Problema

In molti linguaggi di programmazione un identificatore valido comincia con una lettera o
un trattino basso e prosegue con lettere, cifre o trattini bassi. Per `count`, `total2`,
`2fast`, `my-var` e `_hidden`, stampa se ciascuno è un identificatore valido secondo
quella regola classica.

(Raku stesso è più generoso: `my-var` è un identificatore Raku perfettamente valido.
Guarda anche quella variante nella pagina della soluzione.)

## Esempio

Il programma stampa:

```
count: valid
total2: valid
2fast: invalid
my-var: invalid
_hidden: valid
```
