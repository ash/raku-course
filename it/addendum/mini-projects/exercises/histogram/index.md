## Problema

Date le vendite `apples => 5, pears => 3, plums => 8`, stampa un semplice grafico a barre:
ogni etichetta, poi una tabulazione, poi una barra di caratteri `#` lunga quanto il suo
valore, in ordine di etichetta.

## Esempio

Il programma stampa:

```
apples	#####
pears	###
plums	########
```
