## Problema

Crea un modulo chiamato `Shouter`, in un file `Shouter.rakumod`, che esporti una subroutine `shout` che restituisce il suo argomento in maiuscolo.

Poi scrivi un programma separato che usa il modulo per stampare `shout('hi')`.

## Esempio

Eseguendo con il modulo nel percorso di ricerca, il programma stampa:

```console
$ raku -I. shout.raku
HI
```
