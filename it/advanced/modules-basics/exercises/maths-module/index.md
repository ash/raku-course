## Problema

Crea un modulo chiamato `Maths`, in un file `Maths.rakumod`, che esporti una subroutine `square` che restituisce il quadrato del suo argomento.

Poi scrivi un programma separato che usa il modulo per stampare `square(6)`.

## Esempio

Eseguendo con il modulo nel percorso di ricerca, il programma stampa:

```console
$ raku -I. maths.raku
36
```
