## Problema

Costruisci un acronimo a partire da una frase: prendi la prima lettera di ogni parola, uniscile e stampa il risultato in maiuscolo.

Usa questa frase:

```raku
my $phrase = 'hyper text markup language';
```

## Esempio

Il programma stampa:

```
HTML
```
