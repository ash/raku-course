## Problema

Un `when` può confrontare un *tipo*, non solo un valore. Dato il numero `3.14` memorizzato in una variabile, usa `given`/`when` per indicare di che tipo di valore si tratta: stampa `integer` per un `Int`, `rational` per un `Rat` e `string` per uno `Str`.

## Esempio

Il programma stampa:

```
rational
```
