## Problema

Scrivi una subroutine `stats` che definisca una subroutine helper **annidata** `double`, la quale restituisce il doppio del suo argomento. All'interno di `stats`, usa l'helper per stampare il valore di `double(3) + double(5)`.

Poi chiama `stats`.

## Esempio

Il programma stampa:

```
16
```
