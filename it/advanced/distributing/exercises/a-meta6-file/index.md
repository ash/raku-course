## Problema

Scrivi un `META6.json` per una distribuzione chiamata `Greet::Simple`, versione `0.0.1`, che fornisce il modulo `Greet::Simple` dal file `lib/Greet/Simple.rakumod`. A differenza dell'array `depends` vuoto nell'esempio teorico, questa distribuzione **dipende da** un'altra distribuzione, `JSON::Fast` — elencala nell'array `depends`.

> Questo esercizio produce un file, non un output di programma.

## Esempio

Un file minimo corretto è simile a quello nella soluzione.
