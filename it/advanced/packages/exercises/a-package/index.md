## Problema

Crea un package `Temperature` che raggruppi due cose: una variabile `our` `$freezing` impostata a `0` e una subroutine `our` `fahrenheit` che converte un valore Celsius in Fahrenheit (moltiplica per 9/5 e aggiungi 32). Dall'esterno del package, stampa il punto di congelamento, poi stampa il valore in Fahrenheit di `100` gradi Celsius.

## Esempio

Il programma stampa:

```
0
212
```
