## Problema

Hai una lista di numeri, alcuni dei quali si ripetono:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Stampa quanti valori _distinti_ contiene. Usa un set.

## Esempio

Il programma stampa:

```
7
```
