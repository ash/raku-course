## Problema

Sono dati due set di nomi di frutta:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Calcola la loro intersezione e salvala in una variabile. Poi stampa due righe: quanti valori hanno in comune i due set e se `apple` è tra quei valori comuni (non dovrebbe esserlo).

## Esempio

Il programma stampa:

```
2
False
```
