## Problema

Dichiarate una variabile scalare `$discount` in modo che abbia un valore predefinito di `0`. Stampate la variabile prima di assegnarle qualsiasi valore — il programma deve stampare `0` senza produrre alcun avvertimento.

Poi assegnate `15` alla variabile e stampatela di nuovo.

## Esempio

Il programma stampa due righe:

```
0
15
```
