## Problema

La regola per cui una variabile nativa non può mai essere indefinita si applica a ogni tipo nativo, non solo a `int`. Dichiara un `num` nativo non assegnato e una `str` nativa non assegnata. Stampa il numero, e poi stampa la stringa tra parentesi quadre in modo che il suo essere vuota sia visibile.

## Esempio

Il programma stampa:

```
0
[]
```
