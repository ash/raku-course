L'operatore `x` ripete una stringa, quindi `'ab' x 3` produce `'ababab'`. Trovandosi tra i suoi due operandi, a quale categoria appartiene `x`?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Ciò che conta è la posizione, non se l'operatore è un simbolo o una parola. `x` si trova *tra* due operandi, quindi è un operatore **infisso**, proprio come `+` o `~`, solo scritto come una lettera.

</div>
