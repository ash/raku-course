## Problema

Parti dalla forma non interpolante `q` e attiva solo l'avverbio closure. Data una variabile `$x` che contiene `10`, stampa una riga che contenga il calcolo incorporato `{$x ** 2}` *e* un `$x` letterale, non interpolato. Questo mostra che l'avverbio closure valuta il codice tra parentesi graffe lasciando le variabili `$` invariate.

## Esempio

Il programma stampa:

```
$x squared is 100
```
