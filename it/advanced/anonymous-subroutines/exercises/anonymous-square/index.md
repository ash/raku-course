## Problema

Una subroutine anonima non deve essere prima memorizzata: puoi passarla direttamente a un'altra routine. Usando la forma `sub` (non un blocco a freccia), passa una subroutine anonima "quadrato" direttamente a `map` sulla lista `1, 2, 3` e stampa il risultato.

## Esempio

Il programma stampa:

```
(1 4 9)
```
