## Problema

Dato l'hash `a => 1, b => 2, c => 3`, usa un avverbio di accesso tramite indice per eliminare l'elemento `b`, poi stampa quanti elementi rimangono nell'hash per dimostrare che uno è stato rimosso.

## Esempio

Il programma stampa:

```
2
```
