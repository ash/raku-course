## Problema

Scrivi un blocco Pod con un'intestazione `=head1` `Greeting` e un paragrafo `Hello, world!` in cui la parola `world` è marcata in grassetto con `B<…>`. Renderizzalo con `raku --doc`.

> Esegui il file con `raku --doc` per vedere il testo renderizzato.

## Esempio

Renderizzato con `raku --doc`, stampa:

```
Greeting

Hello, world!
```
