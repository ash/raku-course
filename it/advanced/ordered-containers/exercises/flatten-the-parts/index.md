## Problema

Ti vengono dati due array:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Combinali in un singolo array _piatto_ (non annidato). Stampa l'array e poi il numero dei suoi elementi.

## Esempio

Il programma stampa:

```
[1 2 3 4 5]
5
```
