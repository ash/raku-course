## Problema

`do` funziona anche davanti alle istruzioni di controllo del flusso, trasformandole in espressioni che producono un valore. Usate `do if 7 > 5 { 'big' } else { 'small' }` per scegliere un'etichetta, assegnatela a `$label` e stampatela.

## Esempio

Il programma stampa:

```
big
```
