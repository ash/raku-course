## Problema

Un URL è stato suddiviso in pezzi e memorizzato in un array. Ricomponi i pezzi in un'unica stringa usando un meta-operatore di riduzione, stampa l'URL risultante e sulla riga successiva stampa quanti caratteri è lungo.

## Esempio

Per l'array di input:

```raku
my @parts = <http :// example .com>;
```

il programma stampa:

```
http://example.com
18
```
