## Problema

Scrivi un programma che stampi la media (la media aritmetica) di un array di numeri. Usa un meta-operatore di riduzione per sommare i valori.

I dati di input sono codificati nel programma, ad esempio:

```raku
my @data = 10, 20, 30, 40;
```

## Esempio

Il programma stampa la media degli elementi di `@data`:

```
25
```
