Nel modulo `Test`, quale funzione ha successo quando una condizione booleana è vera?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` accetta una condizione e ha successo quando è vera. `is` confronta un valore effettivo con uno atteso, `plan` dichiara quanti test aspettarsi e `done-testing` termina il file ed emette il piano.
