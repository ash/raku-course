## Problema

Scrivi una grammatica che riconosce una singola `word` (uno o più caratteri di parola). Scrivi una **classe di azioni** il cui metodo `TOP` produce la forma **maiuscola** della parola. Analizza `'hello'` con la classe di azioni e stampa `.made`.

## Esempio

Il programma stampa:

```
HELLO
```
