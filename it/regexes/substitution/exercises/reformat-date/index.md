## Problema

La stringa `'2025-06-15'` è una data nell'ordine `anno-mese-giorno`. Usando le catture in una sostituzione, riscrivila nell'ordine `giorno/mese/anno`: `15/06/2025`. Stampa il risultato.

## Esempio

Il programma stampa:

```
15/06/2025
```
