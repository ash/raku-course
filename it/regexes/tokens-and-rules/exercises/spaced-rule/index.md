## Problema

Scrivi una grammatica il cui `TOP` sia una **rule** che riconosce tre parole separate da spazi. Ogni parola è un token di uno o più caratteri di parola. Analizza `'the quick fox'` e stampa se l'analisi è riuscita (un semplice `True` o `False`).

## Esempio

Il programma stampa:

```
True
```
