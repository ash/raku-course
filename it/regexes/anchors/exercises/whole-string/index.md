## Problema

Scrivi uno schema che riesce solo quando l'**intera** stringa è fatta di lettere minuscole e nient'altro. Mettilo alla prova su `'hello'` e stampa un semplice `True` o `False`.

## Esempio

Il programma stampa:

```
True
```
