## Problema

Scrivi una grammatica che analizza un `bool`, che è o la parola `true` o la parola `false`. Usa un **proto token** con due varianti `:sym<…>`. Analizza `'true'`, `'false'` e anche `'unknown'` (che non è né l'una né l'altra), stampando se ciascuna analisi è riuscita.

## Esempio

Il programma stampa:

```
True
True
False
```
