## Problema

Dichiara un regex con nome `word` che riconosce uno o più caratteri di parola. Usalo **due volte** in un unico schema per riconoscere due parole separate da uno spazio, come in `'cat dog'`. Stampa entrambe le parole catturate, ciascuna sulla propria riga.

## Esempio

Il programma stampa:

```
｢cat｣
｢dog｣
```
