## Problema

Dichiara un regex con nome chiamato `word` che riconosce uno o più caratteri di parola. Poi usalo (come `<word>`) per riconoscere la stringa `'hello world'`, e stampa la parola catturata.

## Esempio

Il programma stampa:

```
｢hello｣
```
