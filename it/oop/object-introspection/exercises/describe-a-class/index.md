## Problema

Definisci una classe base `Animal` e una classe `Dog` che ne eredita. Poi stampa il nome della classe `Dog` e, sulla riga successiva, il numero di tipi nella sua catena di ereditarietà (usa `.^mro` e conta i suoi elementi). Infine, su una terza riga, stampa se una classe di nome `Cat` compare da qualche parte in quella catena.

## Esempio

Il programma stampa:

```
Dog
4
False
```
