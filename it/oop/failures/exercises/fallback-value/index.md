## Problema

Scrivi una subroutine `get` che restituisce il suo argomento, ma chiama `fail` con il messaggio `bad` quando l'argomento è `0`.

Usando l'operatore defined-or `//` per fornire un ripiego pari a `default`, stampa il risultato di `get(5)` e poi quello di `get(0)`.

## Esempio

Il programma stampa:

```
5
default
```
