## Problema

Un metodo di classe può prendere parametri, proprio come qualunque altro metodo. Definisci una classe `Geometry` con un metodo di classe `circle-area` che prende un raggio e restituisce l'area di un cerchio (usa `π` o `pi`), arrotondata a un intero. La formula appartiene alla classe nel suo insieme — non c'è di mezzo alcun oggetto cerchio. Chiama il metodo sulla classe con un raggio di `10` e stampa il risultato.

## Esempio

Il programma stampa:

```
314
```
