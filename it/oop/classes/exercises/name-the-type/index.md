## Problema

Definisci due classi vuote, `Cat` e `Dog`, e crea un'istanza di `Cat` chiamata `$felix`. Stampa il tipo di `$felix` con `WHAT`. Poi, su altre due righe, stampa se quel tipo è lo stesso di `Cat` e se è lo stesso di `Dog`, usando l'operatore `===`.

## Esempio

Il programma stampa:

```
(Cat)
True
False
```
