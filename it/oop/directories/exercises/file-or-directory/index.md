## Problema

Crea un file chiamato `a.txt`. Poi poni allo *stesso* percorso due domande: è un file regolare (`.f`)? è una directory (`.d`)? Stampa entrambe le risposte, per vedere che i due test danno risultati opposti per un unico percorso.

## Esempio

Il programma stampa:

```
True
False
```
