## Problema

Un blocco `try` che fallisce vale un valore non definito. Usa questo fatto con l'operatore defined-or `//` per fornire un ripiego: esegui un blocco `try` che fa `die 'no'` e, se fallisce, usa al suo posto la stringa `default`. Stampa il risultato.

## Esempio

Il programma stampa:

```
default
```
