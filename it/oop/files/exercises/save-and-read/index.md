## Problema

Salva un numero in un file e ricaricalo. Scrivi il numero `42` (seguito da un ritorno a capo) in un file chiamato `number.txt`. Poi rileggi il file, trasforma il suo contenuto in un intero e stampa quell'intero moltiplicato per due.

## Esempio

Il programma stampa:

```
84
```
