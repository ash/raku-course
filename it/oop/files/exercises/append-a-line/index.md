## Problema

Costruisci un piccolo file di log aggiungendovi ripetutamente in coda. Scrivi la riga `start` in un file chiamato `log.txt`, poi usa un ciclo per **aggiungere in coda** altre tre righe — `entry 1`, `entry 2` ed `entry 3` — senza cancellare ciò che c'è già. Infine leggi tutto il file e stampalo.

## Esempio

Il programma stampa:

```
start
entry 1
entry 2
entry 3
```
