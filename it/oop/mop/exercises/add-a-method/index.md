## Problema

Definisci una classe `Dog` che ha soltanto un attributo `name` e nessun metodo. Poi usa il MOP per aggiungerle a runtime un metodo `speak`. Il metodo aggiunto deve usare il `name` dell'oggetto stesso e restituire `<nome> says woof`. Crea un cane di nome `Rex` e chiama il nuovo metodo.

## Esempio

Il programma stampa:

```
Rex says woof
```
