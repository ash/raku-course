## Problema

Apri per la scrittura un file chiamato `out.txt`. Tenendo l'handle aperto, scrivici i numeri `1`, `2` e `3`, ciascuno sulla propria riga, usando un ciclo. Poi chiudi l'handle, rileggi il file e stampane il contenuto.

## Esempio

Il programma stampa:

```
1
2
3
```
