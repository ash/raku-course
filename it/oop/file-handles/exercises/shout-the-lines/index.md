## Problema

Scrivi le tre parole `apple`, `banana` e `cherry`, ciascuna sulla propria riga, in un file chiamato `words.txt`. Poi leggi il file riga per riga e stampa ogni riga preceduta dal suo numero di riga (a partire da `1`), nella forma `<numero>: <riga>`.

## Esempio

Il programma stampa:

```
1: apple
2: banana
3: cherry
```
