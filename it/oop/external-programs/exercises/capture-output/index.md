## Problema

Usa `run` con `:out` per lanciare `echo` con le tre parole `hello world raku`, cattura il suo output in una variabile e poi — invece di limitarti a stamparlo — conta quante parole contiene l'output catturato e stampa quel numero.

## Esempio

Il programma stampa:

```
3
```
