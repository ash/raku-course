## Problema

Usa `run` per lanciare `echo` con due argomenti separati: `home:` e `$HOME`. Lascia che il suo output vada sullo schermo. Nota che `$HOME` compare alla lettera e la directory home **non** viene stampata — poiché `run` non coinvolge una shell, non c'è alcuna espansione di variabili.

## Esempio

Il programma stampa:

```
home: $HOME
```
