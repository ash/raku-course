## Problema

Definisci una classe `Label` con un solo attributo `text` che si possa cambiare (`is rw`). Crea un'etichetta con il testo `draft`, poi **aggiungi** ` (revised)` in coda al suo testo attraverso l'accessore — senza ricreare l'oggetto — e stampa il risultato.

## Esempio

Il programma stampa:

```
draft (revised)
```
