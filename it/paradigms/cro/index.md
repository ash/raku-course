Costruire servizi web veri su socket grezzi diventa in fretta faticoso: analizzare le richieste, instradare gli URL, servire molti client, parlare HTTPS. **Cro** è il framework Raku che ti toglie tutto questo di mano. È il modo consueto e moderno di scrivere server e client web in Raku.

Questa sezione conclusiva è un breve giro attorno a Cro — quel tanto che basta per vederne la forma. Cro non fa parte del nucleo, quindi per eseguire questi esempi installalo prima con `zef install cro`.
