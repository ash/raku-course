## Problema

Amplia il servizio di saluto con una **seconda** rotta: una rotta `GET` per il percorso `bye` che restituisce il testo semplice `Goodbye!`. Mantieni anche la rotta originale `hello`.

> Questo esercizio ha bisogno di Cro installato (`zef install cro`).

## Esempio

Una richiesta di `/bye` restituisce:

```
Goodbye!
```
