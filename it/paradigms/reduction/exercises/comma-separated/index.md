## Problema

Usando il **metodo** `reduce` con un blocco, unisci le parole `'Raku', 'is', 'fun'` in un'unica stringa con `', '` fra i pezzi, così che il risultato si legga `Raku, is, fun`. Il metaoperatore `[~]` incolla i pezzi senza nulla in mezzo, quindi inserire un separatore è compito di un blocco.

## Esempio

Il programma stampa:

```
Raku, is, fun
```
