Ecco una possibile soluzione del compito.

## Codice

```raku
say [+] 10, 20, 30, 40;
```

🦋 Trova il programma nel file [sum-list.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/sum-list.raku).

## Output

```
100
```

## Commenti

1. `[+]` inserisce `+` fra ogni elemento dell'elenco.

1. La somma `10 + 20 + 30 + 40` fa `100`.
