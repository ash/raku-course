## Problema

Usando un blocco `react`, dividi un unico flusso in due raccolte. Osserva un supply costruito da `4, 42, 7, 100, 15` e, dentro il corpo del `whenever`, spingi ogni valore maggiore di `10` in `@big` e il resto in `@small`. Stampa entrambi gli array dopo che il blocco react è finito.

## Esempio

Il programma stampa:

```
[4 7]
[42 100 15]
```
