## Problema

Scrivi una subroutine ricorsiva `power($base, $exp)` che eleva `$base` alla potenza `$exp` moltiplicando, senza usare l'operatore `**`. Il caso base è `$exp == 0`, che dà `1`; altrimenti la risposta è `$base` per `power($base, $exp - 1)`. Stampa `power(2, 10)`.

## Esempio

Il programma stampa:

```
1024
```
