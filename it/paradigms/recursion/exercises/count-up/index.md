## Problema

Scrivi una subroutine ricorsiva `countup` che stampa i numeri da `1` fino a `$n`, ciascuno sulla propria riga. Il trucco: ricorri **prima**, poi stampa — così i numeri escono in ordine crescente anche se ogni chiamata si occupa del numero più grande. Chiama `countup(3)`.

## Esempio

Il programma stampa:

```
1
2
3
```
