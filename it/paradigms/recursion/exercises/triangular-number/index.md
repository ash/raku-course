## Problema

L'_n_-esimo numero triangolare è la somma `n + (n - 1) + … + 1`, con il numero triangolare di ordine zero pari a `0`. Scrivi una subroutine ricorsiva `tri` che lo calcola, ma esprimila con **due candidati `multi`** invece che con una condizione dentro un unico corpo: un candidato per il caso base, uno per il passo ricorsivo. Stampa `tri(5)`.

## Esempio

Il programma stampa:

```
15
```
