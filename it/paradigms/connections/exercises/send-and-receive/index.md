## Problema

Apri un socket verso `example.com` sulla porta `80`, invia una richiesta HTTP **HEAD** minima (che chiede solo le intestazioni, non il corpo della pagina), ricevi la risposta e stampane la prima riga (la riga di stato).

> Questo esercizio ha bisogno di una connessione di rete funzionante per girare.

## Esempio

Quando gira, il programma stampa una riga come:

```
HTTP/1.1 200 OK
```
