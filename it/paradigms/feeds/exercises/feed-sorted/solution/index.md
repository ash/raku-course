Ecco una possibile soluzione del compito.

## Codice

```raku
(3, 1, 2) ==> sort() ==> my @sorted;
say @sorted;
```

🦋 Trova il programma nel file [feed-sorted.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/feeds/feed-sorted.raku).

## Output

```
[1 2 3]
```

## Commenti

1. Il flusso manda i tre numeri dentro `sort`, che li ordina.

1. Il risultato ordinato scorre in `@sorted`.
