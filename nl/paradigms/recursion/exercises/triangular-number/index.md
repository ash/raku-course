## Opgave

Het _n_-de driehoeksgetal is de som `n + (n - 1) + … + 1`, waarbij het nulde driehoeksgetal `0` is. Schrijf een recursieve subroutine `tri` die het berekent, maar druk het uit met **twee `multi`-kandidaten** in plaats van een voorwaarde binnen één body: één kandidaat voor het basisgeval, één voor de recursieve stap. Druk `tri(5)` af.

## Voorbeeld

Het programma drukt af:

```
15
```
