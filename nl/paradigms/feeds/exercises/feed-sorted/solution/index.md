Hier is een mogelijke oplossing voor de taak.

## Code

```raku
(3, 1, 2) ==> sort() ==> my @sorted;
say @sorted;
```

🦋 Je kunt de broncode vinden in het bestand [feed-sorted.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/feeds/feed-sorted.raku).

## Uitvoer

```
[1 2 3]
```

## Opmerkingen

1. De feed stuurt de drie getallen naar `sort`, die ze op volgorde zet.

1. Het gesorteerde resultaat stroomt naar `@sorted`.
