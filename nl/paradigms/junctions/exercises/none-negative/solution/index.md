Hier is een mogelijke oplossing voor de taak.

## Code

```raku
say so none(3, 7, 2) < 0;
```

🦋 Je kunt de broncode vinden in het bestand [none-negative.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/junctions/none-negative.raku).

## Uitvoer

```
True
```

## Opmerkingen

1. Een `none`-junctie is waar wanneer **geen enkele** waarde op de vergelijking matcht.

1. Geen van `3, 7, 2` ligt onder nul, dus is het resultaat `True`. Eén negatieve waarde zou het `False` maken.
