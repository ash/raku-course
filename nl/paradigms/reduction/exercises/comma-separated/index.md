## Opgave

Voeg met de **methode** `reduce` en een blok de woorden `'Raku', 'is', 'fun'` samen tot één string met `', '` tussen de stukken, zodat het resultaat `Raku, is, fun` leest. De meta-operator `[~]` plakt stukken zonder iets ertussen aaneen, dus een scheidingsteken invoegen is een taak voor een blok.

## Voorbeeld

Het programma drukt af:

```
Raku, is, fun
```
