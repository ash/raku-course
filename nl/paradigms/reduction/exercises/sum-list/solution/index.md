Hier is een mogelijke oplossing voor de taak.

## Code

```raku
say [+] 10, 20, 30, 40;
```

🦋 Je kunt de broncode vinden in het bestand [sum-list.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/sum-list.raku).

## Uitvoer

```
100
```

## Opmerkingen

1. `[+]` voegt `+` tussen elk element van de lijst in.

1. De som `10 + 20 + 30 + 40` is `100`.
