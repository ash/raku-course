## Opgave

Zoek en druk met de **methode** `reduce` en een blok de langste string in de lijst `'cat', 'elephant', 'dog', 'fox'` af — degene met de meeste tekens. Een meta-operator helpt hier niet: het blok moet de twee kandidaten zelf vergelijken.

## Voorbeeld

Het programma drukt af:

```
elephant
```
