Dit onderdeel gaat over _reactief_ programmeren: code schrijven die op een stroom waarden reageert zodra die binnenkomen, in plaats van er een voor een om te vragen. Het centrale type is de _supply_.

Een supply is een bron van waarden in de loop van de tijd — zie het als een stroom waarop je je kunt abonneren. Je hangt een stuk code aan een supply, en die code draait één keer voor **elke** waarde die de supply produceert. Deze stijl waarin "waarden naar jou geduwd worden" is het tegenovergestelde van waarden uit een lijst halen, en het is precies wat je wilt voor gebeurtenissen, berichten en live gegevens.
