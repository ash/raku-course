## Opgave

Wanneer het blok van een promise werpt, werpt `await` die exceptie opnieuw op het punt van de `await`. Start een promise waarvan het blok `die 'boom'` doet. Wacht haar af binnen een `try`-blok met een `CATCH`-faser die `caught: <message>` afdrukt.

## Voorbeeld

Het programma drukt af:

```
caught: boom
```
