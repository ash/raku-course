## Opgave

Breid de begroetingsservice uit met een **tweede** route: een `GET`-route voor het pad `bye` die de kale tekst `Goodbye!` teruggeeft. Behoud ook de oorspronkelijke route `hello`.

> Deze oefening heeft Cro geïnstalleerd nodig (`zef install cro`).

## Voorbeeld

Een verzoek om `/bye` geeft terug:

```
Goodbye!
```
