## Opgave

Haal de status van een webpagina op de gemakkelijke manier op — met de **Cro-clientmodule** in plaats van een kale socket. Gebruik `Cro::HTTP::Client.get` om `http://example.com/` op te halen, `await` het antwoord, en druk de `.status` ervan af — geen tekstontleding nodig.

> Deze oefening heeft de module Cro geïnstalleerd (`zef install cro`) en een werkende netwerkverbinding nodig.

## Voorbeeld

Bij het draaien drukt het programma af:

```
200
```
