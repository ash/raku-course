## Opgave

Verzamel met een `react`-blok en één enkele `whenever` de waarden van een supply die uit de strings `'a'`, `'b'`, `'c'` gebouwd is, en duw elk daarvan **in hoofdletters** in een array. Druk de array af nadat het react-blok klaar is.

## Voorbeeld

Het programma drukt af:

```
[A B C]
```
