## Opgave

Splits met een `react`-blok één stroom in twee verzamelingen. Bekijk een supply die uit `4, 42, 7, 100, 15` gebouwd is en duw binnen de `whenever`-body elke waarde groter dan `10` in `@big` en de rest in `@small`. Druk beide arrays af nadat het react-blok klaar is.

## Voorbeeld

Het programma drukt af:

```
[4 7]
[42 100 15]
```
