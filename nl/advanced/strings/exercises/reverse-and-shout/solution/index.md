Hier is een mogelijke oplossing voor de taak.

## Code

```raku
say 'raku'.flip.uc;
```

🦋 Je kunt de broncode vinden in het bestand [reverse-and-shout.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/strings/reverse-and-shout.raku).

## Uitvoer

```
UKAR
```

## Opmerkingen

1. De methoden worden van links naar rechts toegepast: `flip` keert `'raku'` eerst om tot `'ukar'`, en daarna maakt `uc` er `'UKAR'` van.

1. Omdat elke methode een nieuwe string teruggeeft, kun je ze in één uitdrukking aaneenketenen.
