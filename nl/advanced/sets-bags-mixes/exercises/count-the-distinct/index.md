## Probleem

Je hebt een lijst met getallen, waarvan sommige zich herhalen:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Druk af hoeveel _unieke_ waarden de lijst bevat. Gebruik een set.

## Voorbeeld

Het programma drukt af:

```
7
```
