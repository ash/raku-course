## Opgave

Een `when` kan matchen op een *type*, niet alleen op een waarde. Gebruik, gegeven het getal `3.14` opgeslagen in een variabele, `given`/`when` om te rapporteren wat voor soort waarde het is: druk `integer` af voor een `Int`, `rational` voor een `Rat`, en `string` voor een `Str`.

## Voorbeeld

Het programma drukt af:

```
rational
```
