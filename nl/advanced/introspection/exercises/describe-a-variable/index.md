## Probleem

Je hebt een variabele met typebeperking:

```raku
my Str $lang = 'Raku';
```

Druk drie feiten erover af, elk op een eigen regel:

1. het type van zijn waarde;
2. het type van zijn container;
3. zijn naam, inclusief de sigil.

## Voorbeeld

Het programma drukt af:

```
Str
Scalar
$lang
```
