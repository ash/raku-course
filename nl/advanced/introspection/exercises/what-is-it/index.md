## Probleem

`WHAT` beschrijft niet alleen een type — het geeft het type object zelf terug, dat je kunt vergelijken met de `===`-operator.

Declareer twee variabelen: `$a` met het gehele getal `42` en `$b` met de string `'x'`. Druk voor elk af of zijn `WHAT` het `Int`-type is.

## Voorbeeld

Het programma drukt af:

```
True
False
```
