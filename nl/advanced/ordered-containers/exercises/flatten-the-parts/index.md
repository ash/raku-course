## Probleem

Je hebt twee arrays:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Combineer ze tot een enkel _plat_ array (niet een genest array). Print het array en vervolgens het aantal elementen.

## Voorbeeld

Het programma print:

```
[1 2 3 4 5]
5
```
