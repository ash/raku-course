title: Geordende containers
---

{% include menu.html %}

Geordende containers bewaren meerdere elementen en behouden hun volgorde, zodat elk element bereikt kan worden via zijn positie. (In bijzondere gevallen kunnen ze ook een enkel element bevatten, of helemaal geen.) De meest voorkomende geordende containers zijn _arrays_ en _lists_.

De `@` sigil geeft aan dat een variabele bedoeld is om meerdere elementen te bevatten. Een variabele met de `@` sigil ondersteunt subscripting, zodat je een element kunt opvragen via zijn index, zoals je al hebt gezien in het deel Essentials.

In dit deel bekijken we van dichtbij hoe arrays en lists verschillen _als containers_: welke je kunt wijzigen, wat er gebeurt als je de ene container in de andere plaatst, en hoe _binding_ een naam aan een container geeft zonder iets te kopiëren.
