## Opgave

`do` werkt ook voor control-flow-statements, waardoor ze expressies worden die een waarde opleveren. Gebruik `do if 7 > 5 { 'big' } else { 'small' }` om een label te kiezen, wijs het toe aan `$label` en print het.

## Voorbeeld

Het programma print:

```
big
```
