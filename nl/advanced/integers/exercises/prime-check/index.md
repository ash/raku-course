## Probleem

De `is-prime` methode beantwoordt een vraag die meestal moeilijk met het blote oog te zien is. Gebruik het op twee getallen die op het eerste gezicht allebei priem lijken: `97` en `91`. Druk het resultaat voor elk getal op een eigen regel af.

(`91` is de valkuil — het is gelijk aan `7 × 13`.)

## Voorbeeld

Het programma drukt af:

```
True
False
```
