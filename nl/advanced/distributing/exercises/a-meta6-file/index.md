## Opgave

Schrijf een `META6.json` voor een distributie met de naam `Greet::Simple`, versie `0.0.1`, die de module `Greet::Simple` levert uit het bestand `lib/Greet/Simple.rakumod`. Anders dan de lege `depends` in het theorievoorbeeld **hangt** deze distributie **af van** een andere distributie, `JSON::Fast` — zet die in de array `depends`.

> Deze oefening levert een bestand op, geen programma-uitvoer.

## Voorbeeld

Een minimaal correct bestand ziet eruit als dat in de oplossing.
