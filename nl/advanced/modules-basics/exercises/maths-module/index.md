## Opgave

Maak een module genaamd `Maths`, in een bestand `Maths.rakumod`, die een subroutine `square` exporteert die het kwadraat van zijn argument teruggeeft.

Schrijf vervolgens een apart programma dat de module gebruikt om `square(6)` af te drukken.

## Voorbeeld

Uitgevoerd met de module op het zoekpad, drukt het programma af:

```console
$ raku -I. maths.raku
36
```
