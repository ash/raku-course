## Opgave

Maak een module genaamd `Shouter`, in een bestand `Shouter.rakumod`, die een subroutine `shout` exporteert die zijn argument in hoofdletters teruggeeft.

Schrijf vervolgens een apart programma dat de module gebruikt om `shout('hi')` af te drukken.

## Voorbeeld

Uitgevoerd met de module op het zoekpad, drukt het programma af:

```console
$ raku -I. shout.raku
HI
```
