{% include menu.html %}

Een _module_ is een bestand met herbruikbare code — subroutines, variabelen en meer — dat andere programma's kunnen laden en delen. Dit gedeelte behandelt de basis in drie stappen: hoe je een module **schrijft** en aangeeft wat deze beschikbaar maakt, hoe een programma er een **laadt** met `use`, en hoe **importeren** de namen van een module in je bereik brengt.
