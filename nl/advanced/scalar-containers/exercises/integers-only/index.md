## Probleem

Declareer een container `$cars` die alleen gehele getallen mag bevatten.

Je hebt een waarde die is verkregen via verkeersmodelleringsberekeningen: `250.7`. Sla deze op in `$cars`, waarbij je de waarde naar een geheel getal converteert zodat de toewijzing wordt geaccepteerd. Druk vervolgens de waarde en het type af.

## Voorbeeld

Het programma drukt af:

```
250
(Int)
```
