## Probleem

Declareer een scalaire variabele `$discount` zodat deze een standaardwaarde van `0` heeft. Druk de variabele af voordat je er iets aan toewijst — het programma moet `0` afdrukken zonder een waarschuwing te produceren.

Wijs vervolgens `15` toe aan de variabele en druk deze opnieuw af.

## Voorbeeld

Het programma drukt twee regels af:

```
0
15
```
