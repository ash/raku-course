## Opgave

Gegeven de hash `a => 1, b => 2, c => 3`, gebruik een subscript-adverb om het item `b` te verwijderen en druk vervolgens af hoeveel items de hash nog heeft, om te laten zien dat er een is verwijderd.

## Voorbeeld

Het programma drukt af:

```
2
```
