Welke functie in de `Test`-module slaagt wanneer een Booleaanse voorwaarde waar is?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` neemt een voorwaarde en slaagt wanneer deze waar is. `is` vergelijkt een werkelijke waarde met een verwachte waarde, `plan` geeft aan hoeveel tests er verwacht worden, en `done-testing` sluit het bestand af en genereert het plan.

</div>
