## Opgave

De regel dat een native variabele nooit ongedefinieerd kan zijn, geldt voor elk native type, niet alleen voor `int`. Declareer een niet-toegewezen native `num` en een niet-toegewezen native `str`. Druk het getal af, en druk vervolgens de string af binnen vierkante haken zodat de leegte zichtbaar is.

## Voorbeeld

Het programma drukt af:

```
0
[]
```
