## Opgave

Het natuurlijke gebruik van een native type met vaste grootte is een compacte array van bytes. Declareer een `uint8`-array met de waarden `100`, `200` en `255` -- elk past in een enkele byte -- en druk de som van de elementen af.

Merk op dat de elementen binnen `0..255` blijven, maar hun som hoeft dat niet: `.sum` geeft een gewoon `Int` terug.

## Voorbeeld

Het programma drukt af:

```
555
```
