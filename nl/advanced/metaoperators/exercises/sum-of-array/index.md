## Probleem

Schrijf een programma dat het gemiddelde (het rekenkundig gemiddelde) van een array getallen afdrukt. Gebruik een reductie-meta-operator om de waarden op te tellen.

De invoergegevens zijn hard gecodeerd in het programma, bijvoorbeeld:

```raku
my @data = 10, 20, 30, 40;
```

## Voorbeeld

Het programma drukt het gemiddelde van de elementen van `@data` af:

```
25
```
