## Opgave

Het symbool van een operator kan elk willekeurig teken zijn, inclusief een Unicode-teken. Definieer een **postfix**-operator `²` die zijn operand kwadrateert, zodat `5²` gelijk is aan `5 ** 2`. Druk vervolgens `5²` af.

## Voorbeeld

Het programma drukt af:

```
25
```
