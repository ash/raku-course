## Opgave

Een eigen trait kan een argument aannemen in plaats van alleen aanwezig of afwezig te zijn. Schrijf een trait `is role(...)` die een string accepteert en, in een hash met de naam van de subroutine als sleutel, de rol vastlegt die aan die subroutine is toegekend.

Pas `is role('admin')` toe op een subroutine `login` en druk daarna de rol af die voor `login` is opgeslagen.

## Voorbeeld

Het programma drukt af:

```
admin
```
