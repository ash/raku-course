## Opgave

Nest een module `Inner` binnen een module `Outer`. Declareer binnen `Inner` een `our`-variabele `$base` ingesteld op `10` en een `our sub doubled` die `$base` vermenigvuldigd met twee retourneert. Benader van buiten beide modules de variabele via zijn volledige geneste naam en roep de subroutine aan via zijn volledige geneste naam. Druk beide resultaten af.

## Voorbeeld

Het programma drukt af:

```
10
20
```
