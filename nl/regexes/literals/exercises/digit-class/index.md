## Opgave

Eén tekenklasse kan meer dan één bereik combineren. Schrijf een klasse die één teken matcht dat ofwel een kleine letter **of** een cijfer is, en gebruik haar om het eerste zulke teken in de string `'  @x7'` (die met spaties en een `@` begint) te vinden. Druk de match af.

Gebruik geen voorgedefinieerde klasse als `\w` — schrijf de bereiken zelf.

## Voorbeeld

Het programma drukt af:

```
｢x｣
```
