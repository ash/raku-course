Tot nu toe kon een patroon overal binnen een string matchen. Een _anker_ matcht helemaal geen teken — het beweert in plaats daarvan een **positie**: het begin van de string, het einde, of de grens van een woord.

Ankers zijn wat je laat zeggen "de string moet hiermee beginnen", "de hele string moet precies dit zijn" of "dit moet een volledig woord zijn, niet slechts een deel ervan".
