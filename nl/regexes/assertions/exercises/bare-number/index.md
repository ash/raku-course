## Opgave

De string `'5 and $9'` bevat twee getallen: een kale `5` en een prijs `$9`. Schrijf met een **negatieve lookbehind** een patroon dat een getal alleen matcht wanneer er **niet** onmiddellijk een `$` aan voorafgaat. Druk de match af.

## Voorbeeld

Het programma drukt af:

```
｢5｣
```
