## Opgave

Match de letterlijke tekst `base` in de string `'database'`. Ken het resultaat niet aan een variabele toe; lees de match in plaats daarvan uit de automatische matchvariabele `$/`, en druk **alleen de gematchte tekst** als gewone string af (niet tussen hoekhaken).

## Voorbeeld

Het programma drukt af:

```
base
```
