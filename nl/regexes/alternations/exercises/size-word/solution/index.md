Hier is een mogelijke oplossing voor de taak.

## Code

```raku
say 'a large pizza' ~~ / small | medium | large /;
```

🦋 Je kunt de broncode vinden in het bestand [size-word.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/alternations/size-word.raku).

## Uitvoer

```
｢large｣
```

## Opmerkingen

1. Het alternatief somt drie mogelijkheden op; het patroon matcht degene die in de string aanwezig is.

1. Alleen `large` komt voor, dus dat is de match.
