## Opgave

Alternatieven in een alternatie hoeven geen letterlijke woorden te zijn — het kan elk deelpatroon zijn. Schrijf een patroon dat ofwel het letterlijke woord `cat` **of** één cijfer (`\d`) matcht. Test het op de string `'item 5'` en druk de match af.

## Voorbeeld

Het programma drukt af:

```
｢5｣
```
