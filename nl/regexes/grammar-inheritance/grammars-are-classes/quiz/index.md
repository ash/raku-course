Welk sleutelwoord laat de ene grammatica van de andere erven?

{:.quiz}
1 | `is`
0 | `does`
0 | `extends`
0 | `inherits`

{% include quiz.html %}

<div class="extended-explanation">

Een grammatica is een soort klasse, dus gebruikt ze hetzelfde sleutelwoord voor overerving: `grammar Loud is Base { … }`. De afgeleide grammatica erft dan de tokens van de basis en mag afzonderlijke tokens overschrijven.
