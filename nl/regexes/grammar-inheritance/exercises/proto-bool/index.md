## Opgave

Schrijf een grammatica die een `bool` ontleedt, wat ofwel het woord `true` of het woord `false` is. Gebruik een **prototoken** met twee `:sym<…>`-varianten. Ontleed `'true'`, `'false'` en ook `'unknown'` (dat geen van beide is), en druk voor elk af of het geslaagd is.

## Voorbeeld

Het programma drukt af:

```
True
True
False
```
