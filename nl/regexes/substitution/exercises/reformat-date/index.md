## Opgave

De string `'2025-06-15'` is een datum in de volgorde `jaar-maand-dag`. Herschrijf haar met captures in een substitutie naar de volgorde `dag/maand/jaar`: `15/06/2025`. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
15/06/2025
```
