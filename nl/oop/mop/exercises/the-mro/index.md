## Opgave

Definieer een keten van drie klassen: `A`, daarna `B` die van `A` erft, daarna `C` die van `B` erft. Druk de method resolution order van `C` af als een lijst met typenamen.

## Voorbeeld

Het programma drukt af:

```
(C B A Any Mu)
```
