## Opgave

Schrijf een subroutine `get` die haar argument teruggeeft, maar `fail` aanroept met de melding `bad` wanneer het argument `0` is.

Druk met behulp van de defined-or-operator `//`, die als terugval `default` levert, het resultaat af van `get(5)` en daarna van `get(0)`.

## Voorbeeld

Het programma drukt af:

```
5
default
```
