## Opgave

Definieer een klasse `Label` met één attribuut `text` dat gewijzigd kan worden (`is rw`). Maak een label met de tekst `draft` en **plak** daarna ` (revised)` achter de tekst via de accessor — zonder het object opnieuw te maken — en druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
draft (revised)
```
