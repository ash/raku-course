## Opgave

Definieer twee lege klassen, `Cat` en `Dog`, en maak een `Cat`-instantie met de naam `$felix`. Druk het type van `$felix` af met `WHAT`. Druk daarna, op nog twee regels, af of dat type hetzelfde is als `Cat` en of het hetzelfde is als `Dog`, met behulp van de operator `===`.

## Voorbeeld

Het programma drukt af:

```
(Cat)
True
False
```
