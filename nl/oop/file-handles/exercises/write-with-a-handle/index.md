## Opgave

Open een bestand met de naam `out.txt` om te schrijven. Schrijf er, met de handle open, de getallen `1`, `2` en `3` naartoe, elk op een eigen regel, met behulp van een lus. Sluit daarna de handle, lees het bestand terug en druk de inhoud af.

## Voorbeeld

Het programma drukt af:

```
1
2
3
```
