## Opgave

Een bestandshandle is een gewone waarde, dus je kunt hem net als elk ander argument aan een functie meegeven. Schrijf een subroutine `log-line` die een handle en een melding aanneemt en de melding op een eigen regel naar de handle schrijft.

Open `log.txt` om te schrijven, roep `log-line` drie keer aan om `started`, `working` en `done` vast te leggen, sluit daarna de handle, lees het bestand terug en druk de inhoud af.

## Voorbeeld

Het programma drukt af:

```
started
working
done
```
