## Opgave

Een `try`-blok dat mislukt evalueert naar een ongedefinieerde waarde. Gebruik dat samen met de defined-or-operator `//` om een terugval te leveren: draai een `try`-blok dat `die 'no'` doet, en gebruik als het mislukt de string `default` in plaats daarvan. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
default
```
