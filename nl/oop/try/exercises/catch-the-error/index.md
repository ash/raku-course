## Opgave

Laat beide kanten van `try` zien. Gebruik eerst een `try`-blok om een berekening die slaagt (bijvoorbeeld `6 * 7`) en druk het resultaat af. Gebruik daarna een tweede `try`-blok om code die `die 'broken'` doet; druk af of dat blok een gedefinieerd resultaat opleverde, en druk de melding van de gevangen exceptie af.

## Voorbeeld

Het programma drukt af:

```
42
False
broken
```
