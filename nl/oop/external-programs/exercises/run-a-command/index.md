## Opgave

Gebruik `run` om `echo` te starten met twee afzonderlijke argumenten: `home:` en `$HOME`. Laat de uitvoer naar het scherm gaan. Merk op dat `$HOME` letterlijk verschijnt en dat de thuismap **niet** afgedrukt wordt — omdat er bij `run` geen shell aan te pas komt, is er geen variabele-expansie.

## Voorbeeld

Het programma drukt af:

```
home: $HOME
```
