Welke functie geeft haar commando door aan de systeem**shell**, wat pipes en omleiding mogelijk maakt?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` geeft één enkele string aan de shell, die mogelijkheden als pipes interpreteert. `run` start een programma rechtstreeks met afzonderlijke argumenten en zonder shell, wat veiliger is en de betere standaardkeuze.

</div>
