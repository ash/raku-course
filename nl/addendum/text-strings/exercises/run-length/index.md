## Opgave

Comprimeer de string `aaabbbbcc` door elke reeks gelijke letters te vervangen door
de letter gevolgd door de lengte van de reeks, wat `a3b4c2` geeft. Druk de
gecomprimeerde string af.

## Voorbeeld

Het programma drukt af:

```
a3b4c2
```
