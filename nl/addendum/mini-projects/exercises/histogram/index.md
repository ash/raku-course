## Opgave

Druk voor de verkoopcijfers `apples => 5, pears => 3, plums => 8` een eenvoudige staaf-
grafiek af: elk label, dan een tab, dan een staaf van `#`-tekens zo lang als zijn waarde,
geordend op label.

## Voorbeeld

Het programma drukt af:

```
apples	#####
pears	###
plums	########
```
