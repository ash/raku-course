## Opgave

Schrijf met meervoudige dispatch een subroutine `describe` die verschillend reageert op
een geheel getal, een string en een lijst. Roep haar aan met `42`, `'hi'` en `[1, 2, 3]`.

## Voorbeeld

Het programma drukt af:

```
integer 42
string hi
list of 3
```
