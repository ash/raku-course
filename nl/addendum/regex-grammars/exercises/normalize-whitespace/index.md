## Opgave

Ruim de volgende string op zodat voorafgaande en afsluitende spaties verdwijnen en
elk gat binnenin één enkele spatie is. Druk het resultaat af.

```raku
my $messy = '  too    many     spaces   ';
```

## Voorbeeld

Het programma drukt af:

```
too many spaces
```
