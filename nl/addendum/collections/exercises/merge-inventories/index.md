## Opgave

Twee winkels houden hun voorraad in hashes bij:
`apples => 3, pears => 2` en `apples => 4, plums => 5`. Combineer ze tot één,
waarbij je de hoeveelheden optelt voor sleutels die in beide voorkomen. Druk het resultaat gesorteerd op
sleutel af, als paren `sleutel: totaal` met komma's ertussen.

## Voorbeeld

Het programma drukt af:

```
apples: 7, pears: 2, plums: 5
```
