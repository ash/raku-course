## Uzdevums

Viena rakstzīmju klase var apvienot vairāk nekā vienu diapazonu. Uzrakstiet klasi, kas piemeklē vienu rakstzīmi, kura ir vai nu mazais burts, **vai** cipars, un izmantojiet to, lai atrastu pirmo tādu rakstzīmi virknē `'  @x7'` (kas sākas ar atstarpēm un `@`). Izdrukājiet sakritību.

Neizmantojiet iepriekš definētu klasi, piemēram, `\w`, — uzrakstiet diapazonus pats.

## Piemērs

Programma izdrukā:

```
｢x｣
```
