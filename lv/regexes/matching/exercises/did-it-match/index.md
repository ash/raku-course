## Uzdevums

Uzrakstiet programmu, kas izdrukā `True` vai `False` (vienkāršu Būla vērtību, nevis sakritības objektu) atkarībā no tā, vai virkne `'Hello, World'` satur tekstu `World`.

## Piemērs

Programma izdrukā:

```
True
```
