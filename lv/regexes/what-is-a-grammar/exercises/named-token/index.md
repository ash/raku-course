## Uzdevums

Deklarējiet nosauktu regulāro izteiksmi `word`, kas piemeklē vienu vai vairākas vārda rakstzīmes. Pēc tam izmantojiet to (kā `<word>`), lai piemeklētu virkni `'hello world'`, un izdrukājiet satverto vārdu.

## Piemērs

Programma izdrukā:

```
｢hello｣
```
