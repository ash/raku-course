## Uzdevums

Uzrakstiet raksturu, kas izdodas tikai tad, kad virkne **sākas** ar ciparu. Pārbaudiet to uz `'3 apples'` un izdrukājiet vienkāršu `True` vai `False`.

## Piemērs

Programma izdrukā:

```
True
```
