## Uzdevums

Uzrakstiet gramatiku, kas parsē `bool`, kas ir vai nu vārds `true`, vai vārds `false`. Izmantojiet **proto marķieri** ar diviem `:sym<…>` variantiem. Parsējiet `'true'`, `'false'` un arī `'unknown'` (kas nav ne viens, ne otrs), izdrukājot, vai katra parsēšana izdevās.

## Piemērs

Programma izdrukā:

```
True
True
False
```
