## Uzdevums

Parādiet, kādu atšķirību rada atkāpšanās. Deklarējiet **vienu un to pašu** raksturu — vienu vai vairākus ciparus, kam seko burtisks `5` — divreiz: vienreiz kā `regex` un vienreiz kā `token`. Piemeklējiet katru pret `'12345'` un izdrukājiet katram vienkāršu `True` vai `False`.

## Piemērs

Programma izdrukā:

```
True
False
```
