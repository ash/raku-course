## Uzdevums

Deklarējiet skalāro mainīgo `$discount` tā, lai tam būtu noklusētā vērtība `0`. Izdrukājiet mainīgo, pirms tam kas nav piešķirts — programmai jāizdrukā `0`, neradot nevienu brīdinājumu.

Pēc tam piešķiriet mainīgajam `15` un izdrukājiet to vēlreiz.

## Piemērs

Programma izdrukā divas rindas:

```
0
15
```
