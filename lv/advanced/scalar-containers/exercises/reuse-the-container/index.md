## Uzdevums

Deklarējiet blakus divus skalāros mainīgos: bez tipa `$untyped` un ar tipu `Int` `$typed`. Izmetiet abus ar `dd`, kamēr tie vēl ir tukši, pēc tam piešķiriet katram `42` un izmetiet abus vēlreiz. Ieskatieties, kā `dd` abus konteinerus apraksta atšķirīgi.

## Piemērs

Programma izdrukā (standarta kļūdu plūsmā):

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
