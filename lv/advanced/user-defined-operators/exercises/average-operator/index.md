## Uzdevums

Definējiet infiksa operatoru `avg`, kas atgriež savu divu operandu vidējo vērtību. Pēc tam izmantojiet to, lai izdrukātu `4` un `10` vidējo vērtību.

## Piemērs

Programma izdrukā:

```
7
```
