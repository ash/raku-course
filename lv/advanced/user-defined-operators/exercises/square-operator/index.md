## Uzdevums

Operatora simbols var būt jebkura rakstzīme, ieskaitot Unikoda rakstzīmi. Definējiet **postfiksa** operatoru `²`, kas kāpina savu operandu kvadrātā, lai `5²` nozīmētu `5 ** 2`. Pēc tam izdrukājiet `5²`.

## Piemērs

Programma izdrukā:

```
25
```
