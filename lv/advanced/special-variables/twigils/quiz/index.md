Kurš tvigils apzīmē **dinamisku** mainīgo, kas tiek meklēts caur izsaukumu steku?

{:.quiz}
1 | `*`
0 | `?`
0 | `!`
0 | `.`

{% include quiz.html %}

<div class="extended-explanation">

Tvigils `*` apzīmē dinamisku mainīgo, kā `$*OUT` vai `$*greeting`. Tvigils `?` ir kompilēšanas laika vērtībām, `!` — privātam atribūtam un `.` — atribūta piekļuves metodei.
