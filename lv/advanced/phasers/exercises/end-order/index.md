## Uzdevums

Programmā var būt vairāk nekā viens `END` fāzeris. Ja tā ir, tie izpildās **apgrieztā** secībā attiecībā pret to, kā tie tika uzrakstīti — pēdējais deklarētais izpildās pirmais (pēdējais iekšā, pirmais ārā).

Uzrakstiet divus `END` fāzerus, kur pirmais izdrukā `first END` un otrais izdrukā `second END`, kam seko parasts `say 'body'`. Paredziet un reproducējiet izvades secību.

## Piemērs

Programma izdrukā:

```
body
second END
first END
```
