## Uzdevums

Uzrakstiet apaksprogrammu `describe`, kas pienem obligatu pozicionalo nosaukumu un pec tam savac jebkuru skaitu nosaukto argumentu uzsucosaja hesa (`*%opts`). Tai jabut atgriezt virkni forma `name: key=value, key=value, ...`, uzskaitot katru opciju ar atslgam alfabetiska seciba.

Izsauciet to ka `describe('Anna', colour => 'red', size => 5)` un izvadiet rezultatu.

## Piemers

Programma izvada:

```
Anna: colour=red, size=5
```
