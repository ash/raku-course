## Uzdevums

Izveidojiet pakotni `Temperature`, kas grupē kopā divas lietas: `our` mainīgo `$freezing`, kas iestatīts uz `0`, un `our` apakšprogrammu `fahrenheit`, kas pārvērš Celsija vērtību Fārenheitā (reizina ar 9/5 un pieskaita 32). Ārpus pakotnes izdrukājiet sasalšanas punktu, pēc tam izdrukājiet `100` Celsija grādu Fārenheita vērtību.

## Piemērs

Programma izdrukā:

```
0
212
```
