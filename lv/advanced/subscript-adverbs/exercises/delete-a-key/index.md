## Uzdevums

Dots jaukteklis `a => 1, b => 2, c => 3`; ar indeksa apstākļvārdu izdzēsiet ierakstu `b` un pēc tam izdrukājiet, cik ierakstu jauktenī palicis, lai parādītu, ka viens ir noņemts.

## Piemērs

Programma izdrukā:

```
2
```
