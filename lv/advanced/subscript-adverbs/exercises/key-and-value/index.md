## Uzdevums

Dots jaukteklis `x => 10, y => 20`; ar indeksa apstākļvārdu izdrukājiet kopā gan atslēgu `x`, gan zem tās glabāto vērtību.

## Piemērs

Programma izdrukā:

```
(x 10)
```
