## Uzdevums

URL ir sadalīts gabalos un saglabāts masīvā. Salīmējiet gabalus atpakaļ vienā virknē, izmantojot redukcijas metaoperatoru, izdrukājiet iegūto URL un nākamajā rindā izdrukājiet, cik rakstzīmju tajā ir.

## Piemērs

Ievades masīvam:

```raku
my @parts = <http :// example .com>;
```

programma izdrukā:

```
http://example.com
18
```
