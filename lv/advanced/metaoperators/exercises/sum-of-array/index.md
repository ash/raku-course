## Uzdevums

Uzrakstiet programmu, kas izdrukā skaitļu masīva vidējo vērtību (aritmētisko vidējo). Izmantojiet redukcijas metaoperatoru, lai saskaitītu vērtības.

Ievades dati ir iekodēti programmā, piemēram:

```raku
my @data = 10, 20, 30, 40;
```

## Piemērs

Programma izdrukā `@data` elementu vidējo vērtību:

```
25
```
