## Uzdevums

Jums ir dota šāda ligzdota datu struktūra:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Izdariet ar to divas lietas:

1. Izdrukājiet izstrādātājam draudzīgu `@data` izmetumu, izmantojot `dd`.
2. Izdrukājiet to pašu atveidojumu kā virkni ar priekšā liktu tekstu `Structure: `.

## Piemērs

Programma izdrukā divas līdzīgas rindas:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
