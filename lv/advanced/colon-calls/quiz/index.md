Ko izdrukā šī programma?

```raku
say 'programming'.substr: 0, 3;
```

{:.quiz}
1 | pro
0 | program
0 | ing
0 | (0 3)

{% include quiz.html %}

<div class="extended-explanation">

Kols par argumentu sarakstu paņem *visu* atlikušo instrukcijas daļu, tāpēc `substr: 0, 3` ir tas pats, kas `substr(0, 3)` — tiek nodoti abi argumenti. Sākot ar indeksu `0` un ņemot `3` rakstzīmes, iznāk `pro`.

</div>
