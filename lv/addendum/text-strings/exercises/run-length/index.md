## Uzdevums

Saspiediet virkni `aaabbbbcc`, katru vienādu burtu sēriju aizstājot ar burtu, kam
seko sērijas garums, iegūstot `a3b4c2`. Izdrukājiet saspiesto virkni.

## Piemērs

Programma izdrukā:

```
a3b4c2
```
