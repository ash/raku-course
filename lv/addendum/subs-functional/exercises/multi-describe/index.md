## Uzdevums

Izmantojot daudzkārtējo nosūtīšanu, uzrakstiet apakšprogrammu `describe`, kas
atšķirīgi reaģē uz veselu skaitli, virkni un sarakstu. Izsauciet to ar `42`,
`'hi'` un `[1, 2, 3]`.

## Piemērs

Programma izdrukā:

```
integer 42
string hi
list of 3
```
