## Uzdevums

Divi veikali savus krājumus glabā jaucējtabulās:
`apples => 3, pears => 2` un `apples => 4, plums => 5`. Apvienojiet tos vienā,
saskaitot daudzumus tām atslēgām, kas parādās abās. Izdrukājiet rezultātu,
sakārtotu pēc atslēgas, kā `atslēga: kopā` pārus, savienotus ar komatiem.

## Piemērs

Programma izdrukā:

```
apples: 7, pears: 2, plums: 5
```
