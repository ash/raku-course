## Uzdevums

Doti trīs malu garumi; izlemiet, vai tie veido vienādmalu, vienādsānu vai
dažādmalu trijstūri — vai arī nekādu trijstūri, kad garākā mala ir pārāk gara.
Klasificējiet `(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)` un `(1, 2, 10)`.

## Piemērs

Programma izdrukā:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
