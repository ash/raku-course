## Uzdevums

Uzrakstiet klasi `Vector` ar `x` un `y` un metodi `add`, kas atgriež *jaunu*
vektoru — abu summu. Dodiet tai metodi `Str`, lai tas izdrukātos kā `(x, y)`.
Saskaitiet `(1, 2)` un `(3, 4)` un izdrukājiet rezultātu.

## Piemērs

Programma izdrukā:

```
(4, 6)
```
