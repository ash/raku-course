## Uzdevums

Uzrakstiet klasi `Stack` ar metodēm, kas ieliek vērtību, izņem augšējo vērtību,
palūkojas uz augšējo, to neizņemot, un paziņo tā izmēru. Ielieciet `1`, `2`, `3`,
tad izdrukājiet palūkošanās, izņemšanas un izmēra prasīšanas rezultātu.

## Piemērs

Programma izdrukā:

```
3
3
2
```
