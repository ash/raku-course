## Uzdevums

Definējiet divas tukšas klases `Cat` un `Dog`. Pēc tam palaidiet ciklu pāri četrām vērtībām `Cat`, `Dog`, `Cat.new` un `Dog.new`, izdrukājot, vai katra no tām ir definēta. Ievērojiet, ka abi tipa objekti ir nedefinēti, bet abas instances — definētas, neatkarīgi no tā, kurai klasei tās pieder.

```

False
True
True
```
