## Uzdevums

Definējiet divas tukšas klases `Cat` un `Dog` un izveidojiet `Cat` instanci ar nosaukumu `$felix`. Izdrukājiet `$felix` tipu ar `WHAT`. Pēc tam vēl divās rindās ar operatoru `===` izdrukājiet, vai šis tips ir tas pats, kas `Cat`, un vai tas ir tas pats, kas `Dog`.

## Piemērs

Programma izdrukā:

```
(Cat)
True
False
```
