## Uzdevums

Faila turis ir parasta vērtība, tāpēc to var padot funkcijai tāpat kā jebkuru citu argumentu. Uzrakstiet apakšprogrammu `log-line`, kas ņem turi un paziņojumu un ieraksta paziņojumu turī savā rindā.

Atveriet `log.txt` rakstīšanai, izsauciet `log-line` trīs reizes, lai pierakstītu `started`, `working` un `done`, pēc tam aizveriet turi, nolasiet failu atpakaļ un izdrukājiet tā saturu.

## Piemērs

Programma izdrukā:

```
started
working
done
```
