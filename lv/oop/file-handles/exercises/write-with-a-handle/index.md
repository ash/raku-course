## Uzdevums

Atveriet failu ar nosaukumu `out.txt` rakstīšanai. Turot turi atvērtu, ierakstiet tajā skaitļus `1`, `2` un `3`, katru savā rindā, izmantojot ciklu. Pēc tam aizveriet turi, nolasiet failu atpakaļ un izdrukājiet tā saturu.

## Piemērs

Programma izdrukā:

```
1
2
3
```
