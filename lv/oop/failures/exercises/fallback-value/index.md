## Uzdevums

Uzrakstiet apakšprogrammu `get`, kas atgriež savu argumentu, taču izsauc `fail` ar paziņojumu `bad`, kad arguments ir `0`.

Izmantojot defined-or operatoru `//`, lai nodrošinātu atkāpšanās vērtību `default`, izdrukājiet `get(5)` un pēc tam `get(0)` rezultātu.

## Piemērs

Programma izdrukā:

```
5
default
```
