## Uzdevums

Pirms kaut ko izveidojat, izdrukājiet, vai fails ar nosaukumu `test.txt` eksistē. Pēc tam izveidojiet to un izdrukājiet, vai tas eksistē tagad. Vienam un tam pašam ceļam vispirms jāziņo `False` un pēc tam `True`.

## Piemērs

Programma izdrukā:

```
False
True
```
