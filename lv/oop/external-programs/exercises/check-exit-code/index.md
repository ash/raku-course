## Uzdevums

Palaidiet komandu, kas ar nolūku neizdodas — piemēram, `sh -c 'exit 4'` —, un paturiet `Proc`, ko tā atgriež. Izdrukājiet komandas izejas kodu un pēc tam izdrukājiet `success` vai `failure` atkarībā no tā, vai komanda izdevās.

## Piemērs

Programma izdrukā:

```
4
failure
```
