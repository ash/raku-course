## Uzdevums

Izmantojiet `run`, lai palaistu `echo` ar diviem atsevišķiem argumentiem: `home:` un `$HOME`. Ļaujiet tā izvadei aiziet uz ekrānu. Ievērojiet, ka `$HOME` parādās burtiski un mājas direktorija **netiek** izdrukāta — jo `run` neiesaista čaulu, mainīgo izvēršanas nav.

## Piemērs

Programma izdrukā:

```
home: $HOME
```
