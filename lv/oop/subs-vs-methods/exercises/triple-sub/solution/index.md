Šeit ir iespējams risinājums uzdevumam.

## Kods

```raku
sub triple($x) {
    $x * 3;
}

say triple(7);
```

🦋 Atrodiet programmu failā [triple-sub.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/subs-vs-methods/triple-sub.raku).

## Izvade

```
21
```

## Komentāri

1. Kā apakšprogramma `triple` ir patstāvīga darbība: vērtību, ar ko strādāt, tā saņem kā argumentu.

1. Māsas vingrinājums to pašu uzdevumu risina kā metodi, lai abas pieejas varētu salīdzināt.
