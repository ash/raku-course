## Uzdevums

Uzrakstiet bloku, kas dara `die 'timeout'`, ar fāzeri `CATCH`, kas izdrukā noķertā izņēmuma paziņojumu ar priekšā liktu `Error: `.

## Piemērs

Programma izdrukā:

```
Error: timeout
```
