## Uzdevums

Parādiet abas `try` puses. Vispirms izmantojiet `try` bloku ap aprēķinu, kas izdodas (piemēram, `6 * 7`), un izdrukājiet tā rezultātu. Pēc tam izmantojiet otru `try` bloku ap kodu, kas dara `die 'broken'`; izdrukājiet, vai šis bloks deva definētu rezultātu, un izdrukājiet noķertā izņēmuma paziņojumu.

## Piemērs

Programma izdrukā:

```
42
False
broken
```
