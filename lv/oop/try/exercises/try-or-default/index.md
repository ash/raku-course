## Uzdevums

`try` bloks, kas neizdodas, izrēķinās par nedefinētu vērtību. Izmantojiet to kopā ar defined-or operatoru `//`, lai nodrošinātu atkāpšanās vērtību: izpildiet `try` bloku, kas dara `die 'no'`, un, ja tas neizdodas, izmantojiet virkni `default`. Izdrukājiet rezultātu.

## Piemērs

Programma izdrukā:

```
default
```
