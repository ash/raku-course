Šeit ir iespējams risinājums uzdevumam.

## Kods

```raku
say so none(3, 7, 2) < 0;
```

🦋 Atrodiet programmu failā [none-negative.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/junctions/none-negative.raku).

## Izvade

```
True
```

## Komentāri

1. `none` savienojums ir patiess, kad salīdzinājumam neatbilst **neviena** vērtība.

1. Neviens no `3, 7, 2` nav zem nulles, tāpēc rezultāts ir `True`. Viena vienīga negatīva vērtība padarītu to par `False`.
