## Uzdevums

Izmantojot `one` savienojumu, pārbaudiet, vai **tieši viens** no skaitļiem `1, 2, 3` ir vienāds ar `2`. Izdrukājiet vienkāršu `True` vai `False`.

## Piemērs

Programma izdrukā:

```
True
```
