## Uzdevums

Atveriet ligzdu uz `example.com` portā `80`, nosūtiet minimālu HTTP **HEAD** pieprasījumu (kas prasa tikai galvenes, nevis lappuses ķermeni), saņemiet atbildi un izdrukājiet tās pirmo rindu (statusa rindu).

> Šim vingrinājumam darbam vajadzīgs strādājošs tīkla savienojums.

## Piemērs

Palaista programma izdrukā rindu, piemēram:

```
HTTP/1.1 200 OK
```
