## Uzdevums

Izmantojot `react` bloku, sadaliet vienu straumi divās kolekcijās. Vērojiet supply, kas uzbūvēta no `4, 42, 7, 100, 15`, un `whenever` ķermenī ielieciet katru vērtību, kas lielāka par `10`, masīvā `@big`, bet pārējās — masīvā `@small`. Izdrukājiet abus masīvus pēc tam, kad `react` bloks ir beidzies.

## Piemērs

Programma izdrukā:

```
[4 7]
[42 100 15]
```
