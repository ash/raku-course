## Problema

Dadas las palabras `<apple banana pear cherry>`, usa `.hyper` para ejecutar una tubería en paralelo manteniendo el orden original: pasa a mayúsculas cada palabra, conserva solo las de **más de cuatro** letras y une lo que quede en una sola cadena separada por espacios. Imprímela.

## Ejemplo

El programa imprime:

```
APPLE BANANA CHERRY
```
