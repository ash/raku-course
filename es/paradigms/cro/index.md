Construir servicios web reales sobre sockets en crudo se vuelve tedioso enseguida: analizar peticiones, encaminar URL, atender a muchos clientes, hablar HTTPS. **Cro** es el framework de Raku que hace todo esto por ti. Es la manera estándar y moderna de escribir servidores y clientes web en Raku.

Esta sección final es un recorrido breve por Cro, apenas lo suficiente para ver su forma. Cro no forma parte del núcleo, así que para ejecutar estos ejemplos primero lo instalas con `zef install cro`.
