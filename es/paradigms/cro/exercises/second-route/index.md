## Problema

Amplía el servicio de saludo con una **segunda** ruta: una ruta `GET` para la ruta `bye` que devuelva el texto simple `Goodbye!`. Conserva también la ruta original `hello`.

> Este ejercicio necesita Cro instalado (`zef install cro`).

## Ejemplo

Una petición a `/bye` devuelve:

```
Goodbye!
```
