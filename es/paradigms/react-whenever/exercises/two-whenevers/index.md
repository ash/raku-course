## Problema

Sigue el saldo de una cuenta bancaria alimentada por dos flujos con **papeles opuestos**. Crea dos supplies con nombre — ingresos a partir de `100, 50, 200` y reintegros a partir de `30, 120` — y, en un solo bloque `react` con dos bloques `whenever`, **suma** al saldo cada ingreso y **resta** de él cada reintegro. Imprime el saldo final.

## Ejemplo

El programa imprime:

```
200
```
