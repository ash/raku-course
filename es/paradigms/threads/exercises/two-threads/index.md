## Problema

Arranca dos hilos. Cada uno calcula un valor y lo guarda en una variable compartida: el primero calcula `10 * 10`, el segundo `20 * 20`. Une ambos hilos y solo entonces suma los dos resultados e imprime el total.

## Ejemplo

El programa imprime:

```
500
```
