## Problema

Escribe una subrutina recursiva `power($base, $exp)` que eleve `$base` a la potencia `$exp` multiplicando, sin usar el operador `**`. El caso base es `$exp == 0`, que da `1`; en caso contrario la respuesta es `$base` por `power($base, $exp - 1)`. Imprime `power(2, 10)`.

## Ejemplo

El programa imprime:

```
1024
```
