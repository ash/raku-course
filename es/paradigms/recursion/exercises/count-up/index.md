## Problema

Escribe una subrutina recursiva `countup` que imprima los números de `1` hasta `$n`, cada uno en su propia línea. El truco: recurre **primero** y después imprime, para que los números salgan en orden creciente aunque cada llamada se ocupe del número mayor. Llama a `countup(3)`.

## Ejemplo

El programa imprime:

```
1
2
3
```
