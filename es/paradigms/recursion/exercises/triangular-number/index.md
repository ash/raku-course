## Problema

El _n_-ésimo número triangular es la suma `n + (n - 1) + … + 1`, siendo `0` el número triangular de orden cero. Escribe una subrutina recursiva `tri` que lo calcule, pero exprésala con **dos candidatos `multi`** en lugar de con un condicional dentro de un solo cuerpo: un candidato para el caso base y otro para el paso recursivo. Imprime `tri(5)`.

## Ejemplo

El programa imprime:

```
15
```
