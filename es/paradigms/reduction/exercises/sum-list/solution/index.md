Aquí tienes una posible solución para la tarea.

## Código

```raku
say [+] 10, 20, 30, 40;
```

🦋 Puedes encontrar el código fuente en el archivo [sum-list.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/sum-list.raku).

## Salida

```
100
```

## Comentarios

1. `[+]` inserta `+` entre todos los elementos de la lista.

1. La suma `10 + 20 + 30 + 40` es `100`.
