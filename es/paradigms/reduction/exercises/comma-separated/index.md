## Problema

Usando el **método** `reduce` con un bloque, une las palabras `'Raku', 'is', 'fun'` en una sola cadena con `', '` entre las piezas, de modo que el resultado se lea `Raku, is, fun`. El metaoperador `[~]` pega las piezas sin nada en medio, así que insertar un separador es tarea de un bloque.

## Ejemplo

El programa imprime:

```
Raku, is, fun
```
