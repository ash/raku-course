## Problema

Abre un socket hacia `example.com` en el puerto `80`, envía una petición HTTP **HEAD** mínima (que pide solo las cabeceras, no el cuerpo de la página), recibe la respuesta e imprime su primera línea (la línea de estado).

> Este ejercicio necesita una conexión de red que funcione para ejecutarse.

## Ejemplo

Al ejecutarlo, el programa imprime una línea como:

```
HTTP/1.1 200 OK
```
