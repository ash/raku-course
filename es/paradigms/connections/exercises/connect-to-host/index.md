## Problema

Intenta abrir un socket TCP hacia `example.com` en el puerto `80`, pero protege el intento con `try` para que un fallo no tumbe el programa. Si la conexión tiene éxito, imprime `connected to example.com` y cierra el socket; en caso contrario imprime `could not connect to example.com`.

> Este ejercicio necesita una conexión de red que funcione para conectar de verdad.

## Ejemplo

Cuando la conexión tiene éxito, el programa imprime:

```
connected to example.com
```
