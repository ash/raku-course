## Problema

`grep` es una función de orden superior: recibe un bloque y conserva los elementos para los que el bloque es verdadero. Usa `grep` para contar cuántos números del rango `1..10` son mayores que `5`, e imprime el recuento.

## Ejemplo

El programa imprime:

```
5
```
