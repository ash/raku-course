## Problema

Se te da una lista de números, algunos de los cuales se repiten:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Imprime cuántos valores _distintos_ contiene. Usa un set.

## Ejemplo

El programa imprime:

```
7
```
