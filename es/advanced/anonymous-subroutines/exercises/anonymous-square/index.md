## Problema

Una subrutina anonima no tiene que almacenarse primero: puedes pasarla directamente a otra rutina. Usando la forma `sub` (no un bloque puntiagudo), pasa una subrutina anonima de "cuadrado" directamente a `map` sobre la lista `1, 2, 3`, e imprime el resultado.

## Ejemplo

El programa imprime:

```
(1 4 9)
```
