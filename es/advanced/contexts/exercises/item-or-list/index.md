## Problema

Toma el array `1, 2, 3` y empaquétalo en un escalar `$x` usando el contextualizador de **elemento**, de modo que `$x` contenga el array completo como un solo valor. Luego usa el contextualizador de **lista** para ejecutar un bucle `for` sobre `$x`, contando las iteraciones. Como el contexto de lista despliega el array empaquetado de vuelta en sus elementos, el bucle se ejecuta tres veces. Imprime el conteo.

## Ejemplo

El programa imprime:

```
3
```
