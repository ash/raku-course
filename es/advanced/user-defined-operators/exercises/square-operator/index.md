## Problema

El símbolo de un operador puede ser cualquier carácter, incluyendo uno Unicode. Define un operador **postfijo** `²` que eleve al cuadrado su operando, de modo que `5²` signifique `5 ** 2`. Luego imprime `5²`.

## Ejemplo

El programa imprime:

```
25
```
