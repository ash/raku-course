## Problema

Crea un módulo llamado `Maths`, en un archivo `Maths.rakumod`, que exporte una subrutina `square` que devuelva el cuadrado de su argumento.

Luego escribe un programa separado que use el módulo para imprimir `square(6)`.

## Ejemplo

Al ejecutar con el módulo en la ruta de búsqueda, el programa imprime:

```console
$ raku -I. maths.raku
36
```
