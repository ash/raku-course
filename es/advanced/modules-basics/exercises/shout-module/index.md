## Problema

Crea un módulo llamado `Shouter`, en un archivo `Shouter.rakumod`, que exporte una subrutina `shout` que devuelva su argumento en mayúsculas.

Luego escribe un programa separado que use el módulo para imprimir `shout('hi')`.

## Ejemplo

Al ejecutar con el módulo en la ruta de búsqueda, el programa imprime:

```console
$ raku -I. shout.raku
HI
```
