## Problema

El prefijo `eager` hace lo contrario de `lazy`: fuerza a que una lista se produzca completamente, de modo que ya no sea perezosa. Muestra el contraste con `.is-lazy`.

Imprime si el rango infinito `1 .. Inf` es perezoso, luego si `eager 1..3` es perezoso, y finalmente si `lazy 1..3` es perezoso. Los resultados deben ser `True`, `False`, `True`.

## Ejemplo

El programa imprime:

```
True
False
True
```
