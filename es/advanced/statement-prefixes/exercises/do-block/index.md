## Problema

`do` también funciona delante de sentencias de flujo de control, convirtiéndolas en expresiones que producen un valor. Usa `do if 7 > 5 { 'big' } else { 'small' }` para elegir una etiqueta, asígnala a `$label` e imprímela.

## Ejemplo

El programa imprime:

```
big
```
