## Problema

El método `is-prime` responde a una pregunta que normalmente es difícil de determinar a simple vista. Úsalo con dos números que a primera vista parecen primos: `97` y `91`. Imprime el resultado de cada uno en su propia línea.

(`91` es la trampa: es igual a `7 x 13`.)

## Ejemplo

El programa imprime:

```
True
False
```
