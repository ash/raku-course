## Problema

Gracias a los enteros de precisión arbitraria, Raku puede calcular `2 ** 1000` de forma exacta. El número es demasiado largo para contarlo a simple vista, así que haz que el programa te lo diga: imprime cuántos dígitos decimales tiene el valor de `2 ** 1000`.

## Ejemplo

El programa imprime:

```
302
```
