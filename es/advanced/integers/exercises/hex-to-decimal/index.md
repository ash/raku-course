## Problema

Leer una base y escribirla de nuevo son operaciones inversas. Toma el número hexadecimal `1A`, almacena su valor decimal en una variable e imprime dos líneas: primero el valor decimal, y luego ese mismo valor convertido de vuelta a una cadena hexadecimal.

## Ejemplo

El programa imprime:

```
26
1A
```
