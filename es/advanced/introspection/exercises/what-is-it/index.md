## Problema

`WHAT` no solo describe un tipo, sino que devuelve el objeto de tipo en sí, que puedes comparar con el operador `===`.

Declara dos variables: `$a` con el entero `42` y `$b` con la cadena `'x'`. Para cada una, imprime si su `WHAT` es el tipo `Int`.

## Ejemplo

El programa imprime:

```
True
False
```
