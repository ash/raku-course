## Problema

Se te da una variable con tipo:

```raku
my Str $lang = 'Raku';
```

Imprime tres datos sobre ella, cada uno en su propia línea:

1. el tipo de su valor;
2. el tipo de su contenedor;
3. su nombre, incluyendo el sigil.

## Ejemplo

El programa imprime:

```
Str
Scalar
$lang
```
