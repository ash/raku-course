El operador `x` repite una cadena, de modo que `'ab' x 3` da `'ababab'`. Al situarse entre sus dos operandos, a que categoría pertenece `x`?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Lo que importa es la posición, no si el operador es un símbolo o una palabra. `x` se situa *entre* dos operandos, por lo que es un operador **infijo**, igual que `+` o `~`, solo que se escribe con una letra.

</div>
