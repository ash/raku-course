## Problema

El operador `**` se vincula con más fuerza que `+`, por lo que `2 ** 3 + 1` se lee como `(2 ** 3) + 1`, que es `9`. Agrega paréntesis para anular esa precedencia, haciendo que la suma ocurra *primero*, e imprime el resultado.

## Ejemplo

El programa imprime:

```
16
```
