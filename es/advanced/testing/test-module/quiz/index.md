En el módulo `Test`, ¿qué función pasa cuando una condición booleana es verdadera?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` toma una condición y pasa cuando es verdadera. `is` compara un valor real con uno esperado, `plan` indica cuántas pruebas se esperan, y `done-testing` finaliza el archivo y emite el plan.

</div>
