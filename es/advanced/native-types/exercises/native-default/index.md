## Problema

La regla de que una variable nativa nunca puede ser indefinida se aplica a todos los tipos nativos, no solo a `int`. Declara un `num` nativo sin asignar y un `str` nativo sin asignar. Imprime el número, y luego imprime la cadena dentro de corchetes para que su vacío sea visible.

## Ejemplo

El programa imprime:

```
0
[]
```
