## Problema

La forma con dos puntos debe ser la *última* llamada en una cadena, pero las llamadas anteriores pueden usar paréntesis normalmente. Comienza con las palabras `a`, `b`, `c`, invierte su orden con `.reverse`, y luego une el resultado con un guion usando la forma con **dos puntos**. Imprime el resultado.

## Ejemplo

El programa imprime:

```
c-b-a
```
