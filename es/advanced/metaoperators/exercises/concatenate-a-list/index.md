## Problema

Una URL ha sido dividida en partes y almacenada en un array. Une las partes de nuevo en una sola cadena usando un meta-operador de reducción, imprime la URL resultante y en la siguiente línea imprime cuántos caracteres tiene.

## Ejemplo

Para el array de entrada:

```raku
my @parts = <http :// example .com>;
```

el programa imprime:

```
http://example.com
18
```
