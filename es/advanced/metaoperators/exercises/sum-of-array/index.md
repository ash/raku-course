## Problema

Escribe un programa que imprima el promedio (la media aritmética) de un array de números. Usa un meta-operador de reducción para sumar los valores.

Los datos de entrada están escritos directamente en el programa, por ejemplo:

```raku
my @data = 10, 20, 30, 40;
```

## Ejemplo

El programa imprime la media de los elementos de `@data`:

```
25
```
