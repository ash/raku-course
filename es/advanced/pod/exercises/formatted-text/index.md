## Problema

Escribe un bloque Pod con un encabezado `=head1` `Greeting` y un párrafo `Hello, world!` en el que la palabra `world` esté marcada en negrita con `B<…>`. Renderízalo con `raku --doc`.

> Ejecuta el archivo con `raku --doc` para ver el texto renderizado.

## Ejemplo

Renderizado con `raku --doc`, imprime:

```
Greeting

Hello, world!
```
