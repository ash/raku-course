## Problema

Crea un paquete `Temperature` que agrupe dos cosas: una variable `our` llamada `$freezing` con valor `0`, y una subrutina `our` llamada `fahrenheit` que convierta un valor en Celsius a Fahrenheit (multiplicar por 9/5 y sumar 32). Desde fuera del paquete, imprime el punto de congelación y luego imprime el valor en Fahrenheit de `100` grados Celsius.

## Ejemplo

El programa imprime:

```
0
212
```
