## Problema

Escribe una subrutina `power` con un parámetro obligatorio `$base` y un parámetro **opcional** `$exp`. Cuando se proporciona el exponente, eleva la base a ese valor; cuando se omite, eleva al cuadrado por defecto (usa el operador defined-or `//` para proporcionar `2`).

Llámala una vez solo con la base, y otra vez con la base y un exponente.

## Ejemplo

El programa imprime:

```
25
125
```
