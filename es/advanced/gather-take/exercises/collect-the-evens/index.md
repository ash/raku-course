## Problema

Usando `gather` y `take`, construye una lista en la que cada numero del `1` al `4` aparezca tantas veces como su propio valor: `1` una vez, `2` dos veces, `3` tres veces y `4` cuatro veces. Imprime la lista resultante.

## Ejemplo

El programa imprime:

```
[1 2 2 3 3 3 4 4 4 4]
```
