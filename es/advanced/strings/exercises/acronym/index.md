## Problema

Construye un acrónimo a partir de una frase: toma la primera letra de cada palabra, únelas e imprime el resultado en mayúsculas.

Usa esta frase:

```raku
my $phrase = 'hyper text markup language';
```

## Ejemplo

El programa imprime:

```
HTML
```
