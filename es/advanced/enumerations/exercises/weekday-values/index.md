## Problema

Un enum asigna nombres a números, pero también puedes hacerlo al revés: llamando al tipo del enum como una función, con un número, devuelve la constante correspondiente.

Define un enum `Day` cuyas constantes `Mon` a `Fri` estén numeradas del `1` al `5`. Luego busca e imprime las constantes para los números `5` y `1`.

## Ejemplo

El programa imprime:

```
Fri
Mon
```
