## Problema

Usando `given`/`when`, imprime la etapa de la vida para una edad definida en el código según estas bandas:

* `child` para 0-12,
* `teenager` para 13-19,
* `adult` para 20-64,
* `senior` para 65 en adelante.

Una edad negativa no tiene sentido, así que imprime `invalid` para cualquier numero menor que cero. Asegúrate de que ese caso se maneje antes de las comprobaciones de rango.

## Ejemplo

Para la edad `30`, el programa imprime:

```
adult
```
