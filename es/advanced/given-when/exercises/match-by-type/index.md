## Problema

Un `when` puede comparar contra un *tipo*, no solo un valor. Dado el numero `3.14` almacenado en una variable, usa `given`/`when` para indicar que tipo de valor es: imprime `integer` para un `Int`, `rational` para un `Rat`, y `string` para un `Str`.

## Ejemplo

El programa imprime:

```
rational
```
