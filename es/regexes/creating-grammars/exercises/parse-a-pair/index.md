## Problema

Escribe una gramática que analice un nombre completo con la forma `nombre apellido`, donde el nombre y el apellido son cada uno una serie de caracteres de palabra separados por un espacio. Úsala para analizar `'Grace Hopper'` e imprime el apellido capturado.

## Ejemplo

El programa imprime:

```
｢Hopper｣
```
