## Problema

La cadena `'report.txt'` es un nombre base y una extensión separados por un punto. Usando dos capturas posicionales, empareja la cadena e imprime el nombre base en una línea y la extensión en la siguiente.

## Ejemplo

El programa imprime:

```
report
txt
```
