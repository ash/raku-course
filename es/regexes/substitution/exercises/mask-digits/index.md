## Problema

Toma la cadena `'PIN 1234'` y produce una **copia** en la que cada dígito esté reemplazado por un `#`, usando el operador `S///` para que el original quede intacto. Imprime la copia enmascarada y después imprime el original para mostrar que no se modificó.

## Ejemplo

El programa imprime:

```
PIN ####
PIN 1234
```
