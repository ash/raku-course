## Problema

Una misma clase de caracteres puede combinar más de un rango. Escribe una clase que empareje un carácter que sea una letra minúscula **o** un dígito, y úsala para encontrar el primer carácter así en la cadena `'  @x7'` (que empieza con espacios y una `@`). Imprime la coincidencia.

No uses una clase predefinida como `\w`: escribe tú los rangos.

## Ejemplo

El programa imprime:

```
｢x｣
```
