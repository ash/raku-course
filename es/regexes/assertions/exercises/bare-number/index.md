## Problema

La cadena `'5 and $9'` contiene dos números: un simple `5` y un precio `$9`. Usando un **lookbehind negativo**, escribe un patrón que empareje un número solo cuando **no** lo preceda inmediatamente un `$`. Imprime la coincidencia.

## Ejemplo

El programa imprime:

```
｢5｣
```
