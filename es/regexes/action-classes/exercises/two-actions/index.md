## Problema

Una misma gramática se puede emparejar con distintas clases de acciones para producir resultados distintos. Escribe una sola gramática que analice dos números separados por una coma, como en `'10,20'`. Escribe **dos** clases de acciones: una cuyo `TOP` produzca su **suma** y otra cuyo `TOP` produzca su **diferencia** (el primero menos el segundo). Analiza `'10,20'` con cada clase de acciones por turno e imprime ambos resultados.

## Ejemplo

El programa imprime:

```
30
-10
```
