## Problema

Usando el cuantificador `**` con un **rango**, escribe un patrón que empareje de dos a cuatro dígitos seguidos. Pruébalo con `'abc12345'` e imprime la coincidencia. Como el cuantificador es voraz, debe tomar tantos dígitos como le permita el rango.

## Ejemplo

El programa imprime:

```
｢1234｣
```
