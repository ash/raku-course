## Problema

Declara un regex con nombre `word` que empareje uno o más caracteres de palabra. Úsalo **dos veces** en un mismo patrón para emparejar dos palabras separadas por un espacio, como en `'cat dog'`. Imprime ambas palabras capturadas, cada una en su propia línea.

## Ejemplo

El programa imprime:

```
｢cat｣
｢dog｣
```
