## Problema

Un método de clase puede recibir parámetros, igual que cualquier otro método. Define una clase `Geometry` con un método de clase `circle-area` que reciba un radio y devuelva el área de un círculo (usa `π` o `pi`), redondeada a un entero. La fórmula pertenece a la clase en conjunto: no hay ningún objeto círculo de por medio. Llama al método sobre la clase con un radio de `10` e imprime el resultado.

## Ejemplo

El programa imprime:

```
314
```
