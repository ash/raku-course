## Problema

Construye un pequeño archivo de registro añadiéndole líneas repetidamente. Escribe la línea `start` en un archivo llamado `log.txt` y después usa un bucle para **añadir** otras tres líneas — `entry 1`, `entry 2` y `entry 3` — sin borrar lo que ya hay. Por último, lee el archivo entero e imprímelo.

## Ejemplo

El programa imprime:

```
start
entry 1
entry 2
entry 3
```
