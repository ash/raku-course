## Problema

Define una clase base `Vehicle` con un atributo `wheels`. Después define dos clases que hereden de ella: `Bike`, que viene con `2` ruedas, y `Car`, que viene con `4`.

Crea una `Bike` y un `Car` e imprime el número de ruedas de cada uno.

## Ejemplo

El programa imprime:

```
2
4
```
