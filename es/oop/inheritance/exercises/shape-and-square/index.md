## Problema

Define una clase base `Shape` con un método `name` que devuelva `'shape'` y un método `describe` que devuelva la cadena `I am a <nombre>` (usando su propio `name`).

Después define una clase `Square` que herede de `Shape` y sobrescriba `name` para devolver `'square'`.

Imprime la descripción de un `Square`.

## Ejemplo

El programa imprime:

```
I am a square
```
