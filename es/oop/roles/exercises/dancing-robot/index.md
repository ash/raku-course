## Problema

Define una clase `Robot` cuyo método `speak` devuelva `beep`. Define un rol `Dancing` que añada un método `dance` que devuelva `spinning around`.

Crea dos robots, pero dale el rol `Dancing` solo a uno de ellos. Imprime el resultado de `speak` para ambos robots y después el resultado de `dance` para el robot que sabe bailar.

## Ejemplo

El programa imprime:

```
beep
beep
spinning around
```
