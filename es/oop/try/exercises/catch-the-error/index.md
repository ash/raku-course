## Problema

Muestra las dos caras de `try`. Primero usa un bloque `try` alrededor de un cálculo que funciona (por ejemplo `6 * 7`) e imprime su resultado. Después usa un segundo bloque `try` alrededor de código que hace `die 'broken'`; imprime si ese bloque produjo un resultado definido e imprime el mensaje de la excepción capturada.

## Ejemplo

El programa imprime:

```
42
False
broken
```
