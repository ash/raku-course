## Problema

Usa `run` para lanzar `echo` con dos argumentos separados: `home:` y `$HOME`. Deja que su salida vaya a la pantalla. Fíjate en que `$HOME` aparece tal cual y la carpeta personal **no** se imprime: como `run` no implica a ninguna shell, no hay expansión de variables.

## Ejemplo

El programa imprime:

```
home: $HOME
```
