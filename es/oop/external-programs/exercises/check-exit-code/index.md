## Problema

Ejecuta una orden que falle a propósito — por ejemplo `sh -c 'exit 4'` — y guarda el `Proc` que devuelve. Imprime el código de salida de la orden y después imprime `success` o `failure` según si la orden tuvo éxito o no.

## Ejemplo

El programa imprime:

```
4
failure
```
