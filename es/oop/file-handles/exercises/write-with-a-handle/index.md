## Problema

Abre para escritura un archivo llamado `out.txt`. Manteniendo el manejador abierto, escríbele los números `1`, `2` y `3`, cada uno en su propia línea, usando un bucle. Después cierra el manejador, vuelve a leer el archivo e imprime su contenido.

## Ejemplo

El programa imprime:

```
1
2
3
```
