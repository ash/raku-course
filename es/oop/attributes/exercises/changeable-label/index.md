## Problema

Define una clase `Label` con un único atributo `text` que se pueda cambiar (`is rw`). Crea una etiqueta con el texto `draft` y después **añade** ` (revised)` al final de su texto a través del accesor — sin volver a crear el objeto — e imprime el resultado.

## Ejemplo

El programa imprime:

```
draft (revised)
```
