## Problema

Escribe una subrutina `get` que devuelva su argumento, pero que llame a `fail` con el mensaje `bad` cuando el argumento sea `0`.

Usando el operador defined-or `//` para aportar un repliegue de `default`, imprime el resultado de `get(5)` y después el de `get(0)`.

## Ejemplo

El programa imprime:

```
5
default
```
