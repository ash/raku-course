## Problema

Escribe una subrutina `reciprocal` que devuelva `1` dividido por su argumento, pero que use `fail` con el mensaje `no reciprocal of zero` cuando el argumento sea `0`.

Imprime el resultado de `reciprocal(4)`. Después imprime el resultado de `reciprocal(0)`, pero usa el operador `//` para replegarte a la cadena `undefined` cuando la llamada falle, en lugar de comprobar tú mismo `.defined`.

## Ejemplo

El programa imprime:

```
0.25
undefined
```
