## Problema

Define una clase `A`. Después define `B` y `C`, que heredan ambas de `A`. Por último define `D`, que hereda tanto de `B` como de `C`. Imprime el orden de resolución de métodos de `D` como lista de nombres de tipo.

## Ejemplo

El programa imprime:

```
(D B C A Any Mu)
```
