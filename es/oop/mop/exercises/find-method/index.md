## Problema

Define una clase `Animal` con un método `speak` y una clase `Dog` que herede de `Animal` pero no añada métodos propios. Usando un metamétodo sobre `Dog`, imprime si `Dog` tiene un método llamado `speak` (un simple `True` o `False`). Esto muestra que `find_method` busca a lo largo de la cadena de herencia, y no solo entre los métodos propios de la clase.

## Ejemplo

El programa imprime:

```
True
```
