## Problema

Define una clase `Dog` que solo tenga un atributo `name` y ningún método. Después usa el MOP para añadirle un método `speak` en tiempo de ejecución. El método añadido debe usar el `name` del propio objeto y devolver `<nombre> says woof`. Crea un perro llamado `Rex` y llama al método nuevo.

## Ejemplo

El programa imprime:

```
Rex says woof
```
