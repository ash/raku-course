## Problema

Define dos clases vacías, `Cat` y `Dog`, y crea una instancia de `Cat` llamada `$felix`. Imprime el tipo de `$felix` con `WHAT`. Después, en otras dos líneas, imprime si ese tipo es el mismo que `Cat` y si es el mismo que `Dog`, usando el operador `===`.

## Ejemplo

El programa imprime:

```
(Cat)
True
False
```
