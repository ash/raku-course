## Problema

Define dos clases vacías, `Cat` y `Dog`. Después recorre los cuatro valores `Cat`, `Dog`, `Cat.new` y `Dog.new`, imprimiendo para cada uno si está definido. Fíjate en que los dos objetos de tipo no están definidos y las dos instancias sí, sin importar a qué clase pertenezcan.

## Ejemplo

El programa imprime:

```
False
False
True
True
```
