## Problema

Define una clase base `Animal` y una clase `Dog` que herede de ella. Después imprime el nombre de la clase `Dog` y, en la línea siguiente, el número de tipos de su cadena de herencia (usa `.^mro` y cuenta sus elementos). Por último, en una tercera línea, imprime si una clase llamada `Cat` aparece en algún lugar de esa cadena.

## Ejemplo

El programa imprime:

```
Dog
4
False
```
