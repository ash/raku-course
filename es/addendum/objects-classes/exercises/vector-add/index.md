## Problema

Escribe una clase `Vector` con `x` e `y` y un método `add` que devuelva un vector
*nuevo*: la suma de dos. Dale un método `Str` para que se imprima como `(x, y)`. Suma
`(1, 2)` y `(3, 4)` e imprime el resultado.

## Ejemplo

El programa imprime:

```
(4, 6)
```
