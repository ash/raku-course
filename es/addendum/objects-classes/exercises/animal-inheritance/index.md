## Problema

Crea una clase base `Animal` con un `name` y un método `greet` que diga lo que dice
el animal. Las subclases `Dog` y `Cat` definen cada una su propio sonido. Haz que
saluden un `Dog` llamado `Rex` y un `Cat` llamado `Tom`.

## Ejemplo

El programa imprime:

```
Rex says Woof
Tom says Meow
```
