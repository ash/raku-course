## Problema

Escribe una clase `Stack` con métodos para apilar un valor, desapilar el valor de
arriba, echar un vistazo al de arriba sin quitarlo e informar de su tamaño. Apila `1`,
`2`, `3`, e imprime después el resultado de mirar, desapilar y preguntar el tamaño.

## Ejemplo

El programa imprime:

```
3
3
2
```
