## Problema

Dos tiendas guardan sus existencias en hashes:
`apples => 3, pears => 2` y `apples => 4, plums => 5`. Combínalos en uno solo,
sumando las cantidades de las claves que aparecen en ambos. Imprime el resultado
ordenado por clave, como pares `clave: total` unidos con comas.

## Ejemplo

El programa imprime:

```
apples: 7, pears: 2, plums: 5
```
