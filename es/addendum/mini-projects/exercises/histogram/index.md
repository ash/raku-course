## Problema

Dadas las cifras de ventas `apples => 5, pears => 3, plums => 8`, imprime un
diagrama de barras sencillo: cada etiqueta, después un tabulador y después una barra
de caracteres `#` tan larga como su valor, ordenado por etiqueta.

## Ejemplo

El programa imprime:

```
apples	#####
pears	###
plums	########
```
