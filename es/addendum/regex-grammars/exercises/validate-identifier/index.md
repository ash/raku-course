## Problema

En muchos lenguajes de programación, un identificador válido empieza por una letra o
un guion bajo y continúa con letras, dígitos o guiones bajos. Para `count`,
`total2`, `2fast`, `my-var` y `_hidden`, imprime si cada uno es un identificador
válido según esa regla clásica.

(Raku es más generoso: `my-var` es un identificador de Raku perfectamente válido.
Consulta también esa variante en la página de la solución.)

## Ejemplo

El programa imprime:

```
count: valid
total2: valid
2fast: invalid
my-var: invalid
_hidden: valid
```
