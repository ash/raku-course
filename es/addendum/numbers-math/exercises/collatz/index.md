## Problema

Partiendo de un número, el proceso de Collatz lo divide por dos cuando es par y lo
sustituye por `3n + 1` cuando es impar, repitiendo hasta llegar a `1`. Cuenta
cuántos pasos hacen falta para bajar `27` hasta `1`, e imprime ese recuento.

## Ejemplo

El programa imprime:

```
111
```
