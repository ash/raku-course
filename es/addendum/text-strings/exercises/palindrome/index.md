## Problema

Un palíndromo se lee igual hacia delante que hacia atrás. Para cada una de las
palabras `level`, `hello` y `racecar`, imprime la palabra seguida de `yes` o `no`
según sea o no un palíndromo.

## Ejemplo

El programa imprime:

```
level: yes
hello: no
racecar: yes
```
