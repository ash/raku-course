## Problema

Escribe una subrutina `compose` que reciba dos funciones y devuelva una función
nueva que las aplique una tras otra: primero la segunda, después la primera. Compón
«duplicar» con «sumar uno», y llama después al resultado con `5` (dando `12`).

## Ejemplo

El programa imprime:

```
12
```
