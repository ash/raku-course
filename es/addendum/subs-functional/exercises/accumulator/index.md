## Problema

Escribe una subrutina que arranque un acumulador con un valor dado y devuelva una
función que sume al total acumulado cada vez que se la llame y devuelva el nuevo
total. Arranca en `100`, y suma después `10`, `25` y `-5`, imprimiendo cada
resultado.

## Ejemplo

El programa imprime:

```
110
135
130
```
