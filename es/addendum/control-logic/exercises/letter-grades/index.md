## Problema

Convierte cada una de las puntuaciones `95`, `82`, `71` y `58` en una nota con
letra: `A` para 90 y más, `B` para 80–89, `C` para 70–79, `D` para 60–69 y `F` por
debajo de eso. Imprime cada puntuación con su nota.

## Ejemplo

El programa imprime:

```
95 -> A
82 -> B
71 -> C
58 -> F
```
