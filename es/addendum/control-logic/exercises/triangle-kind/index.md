## Problema

Dadas tres longitudes de lado, decide si forman un triángulo equilátero, isósceles
o escaleno, o ningún triángulo en absoluto cuando el lado más largo es demasiado
largo. Clasifica `(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)` y `(1, 2, 10)`.

## Ejemplo

El programa imprime:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
