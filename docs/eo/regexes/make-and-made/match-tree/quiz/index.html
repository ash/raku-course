Kvizo — La kongruarbo

Kion presas la jena programo?

grammar Point {
    token TOP { <x> ',' <y> }
    token x   { \d+ }
    token y   { \d+ }
}

say Point.parse('3,4')<y>;
0｢3｣
1｢4｣
0｢3,4｣
0｢y｣

Ĉiu ĵetono fariĝas nomita branĉo de la kongruarbo. <y> sur la rezulto atingas la ĵetonon y, kiu kongruis kun 4, do la programo presas ｢4｣.
