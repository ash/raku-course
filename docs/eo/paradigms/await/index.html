await

Samtempa kaj reaktiva kodo lanĉas laboron, kiu finiĝas poste. Iam vi devas atendi tiun laboron kaj uzi ĝian rezulton. La ilo por tio estas await.

Vi jam renkontis await ĉe promesoj. Ĉi tiu sekcio kunigas la ideon: kiel await atendas unu aŭ multajn promesojn, kaj kiel reaktivaj konstruoj kiel react provizas la saman garantion «atendu ĝis preta» por fluoj.

Temoj en ĉi tiu sekcio

  • Atendi promeson
  • Atendi la finon

Praktiko

Vin atendas 2 kvizoj pri la enhavo de ĉi tiu sekcio.

  • Kvizo — await
  • Kvizo — await kaj sleep
