Lösung: Schlüssel und Wert

Hier ist eine mögliche Lösung der Aufgabe.

Code

my %h = x => 10, y => 20;
say %h<x>:kv;

🦋 Du findest den Quellcode in der Datei key-and-value.raku.

Ausgabe

(x 10)

Kommentare

  1. Das Adverb :kv gibt sowohl den Schlüssel als auch den Wert als Liste zurück.

  2. Bei einem Hash ist der Schlüssel der Name, mit dem du indizierst, daher gibt %h<x>:kv die Liste (x 10) zurück.
