Paquetes y espacios de nombres

Un espacio de nombres (namespace) es un contenedor con nombre para otros elementos con nombre, como variables y subrutinas. Mantiene los nombres separados para evitar colisiones: Maths::pi y Physics::pi pueden existir sin conflicto. Un paquete (package) es el tipo más básico de espacio de nombres.

Ya has utilizado un espacio de nombres sin nombrarlo: cada module crea uno. Esta sección examina los paquetes directamente y cómo las variables our y el separador :: te permiten acceder a un espacio de nombres desde afuera.
