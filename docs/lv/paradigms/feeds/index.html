Datu plūsmas

Plūsma (feed) ļauj uzrakstīt saraksta darbību ķēdi tādā secībā, kādā tās notiek, gluži kā konveijeru. Tā vietā, lai map ligzdotu grep iekšienē, kas savukārt ligzdo sort iekšienē, jūs datus sūtāt no viena posma uz nākamo ar plūsmas operatoru ==>.

Plūsmas dabiski lasās no kreisās uz labo un padara daudzsoļu pārveidojumus viegli izsekojamus. Šī sadaļa parāda plūsmas operatoru un to, kā saķēdēt vairākus posmus.
