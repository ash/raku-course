Целые числа

Вы используете целые числа с самого начала курса. В этом разделе рассматриваются несколько их менее очевидных особенностей.

Самая важная из них — целые числа в Raku имеют произвольную точность: они не ограничены фиксированным количеством байтов и никогда не переполняются без предупреждения. Пока хватает памяти, целое число может расти до любого нужного размера:

say 2 ** 100;
# 1267650600228229401496703205376

Это точное значение, а не приближение. То же самое относится к произведениям больших чисел — факториал 50, например, вычисляется точно:

my $factorial = 1;
$factorial = $factorial * $_ for 1..50;
say $factorial;
# 30414093201713378043612608166064768844377641568960512000000000000

Чтобы длинные числа было легче читать в исходном коде, можно группировать цифры с помощью подчёркиваний. Компилятор их игнорирует:

say 1_000_000; # 1000000

В следующих темах показано, как записывать целые числа в других системах счисления, и описано несколько полезных методов для целых чисел.
