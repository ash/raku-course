Как установить Raku++ 🆕

Raku++ распространяется через свой репозиторий на GitHub — github.com/ash/rakupp. После установки у вас появится единственный исполняемый файл под названием rakupp.

Готовые сборки

Готовые сборки текущего выпуска доступны для Windows, macOS и Linux. Скачайте ту, что подходит вашей операционной системе, со страницы релизов репозитория — больше настраивать нечего, поскольку у Raku++ нет отдельной виртуальной машины, которую надо было бы устанавливать.

Сборка из исходного кода

Так как Raku++ написан на C++, вы можете собрать его и самостоятельно из исходного кода в репозитории. В репозитории описано, какие инструменты для этого нужны и как выполнить сборку.

Номера версий

Узнать, какая у вас версия, можно с помощью опции --version:

$ rakupp --version
Raku++ (rakupp) 0.5.1 — a Raku interpreter and compiler in C++ (implements Raku 6.d, with 6.e features)

Эта строка сообщает и выпуск самого Raku++ (0.5.1), и версию языка Raku, на которую он ориентируется (6.d, с некоторыми возможностями 6.e). Сравните её с приветственной строкой версии Rakudo на странице установки Rakudo, чтобы увидеть, как каждый из компиляторов представляется.
