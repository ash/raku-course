Oplossing: Optellen tot boven de honderd

Hier is een mogelijke oplossing voor de taak.

Code

my $sum = 0;
my $n   = 0;

loop {
    $n++;
    $sum += $n;
    last if $sum > 100;
}

say "reached $sum after adding 1..$n";

🦋 Je kunt de broncode vinden in het bestand sum-until.raku.

Uitvoer

reached 105 after adding 1..14

Opmerkingen

  1. Een kale loop { } herhaalt eeuwig; de last if $sum > 100 is wat hem beëindigt, zodra de som de drempel overschrijdt.

  2. 1 + 2 + … + 14 is 105, de eerste deelsom boven 100, dus stopt de lus met $n op 14.

  3. Je kunt die som controleren met een reductie:

    say [+] 1..14; # 105
