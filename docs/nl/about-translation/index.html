Over de vertaling

Deze vertaling is door een machine gemaakt. De Nederlandse versie van de cursus is door een taalmodel uit het Engelse origineel vertaald, zonder nalezing door een moedertaalspreker. De inhoud, de codevoorbeelden en de uitvoer van de programma’s zijn intact, maar een formulering kan hier en daar houterig zijn en een term niet de meest gangbare.

Lijkt een passage onduidelijk, raadpleeg dan het Engelse origineel — dat blijft altijd de bron van waarheid.

Code wordt nooit vertaald. Raku-sleutelwoorden, namen van typen, methoden en subroutines en de uitvoer van programma’s (True, False, Nil en dergelijke) blijven staan zoals ze zijn — precies zoals de compiler ze ziet.

Een fout of een ongelukkige vertaling gevonden? Meld het op GitHub — dat is de beste manier om de tekst te verbeteren.
