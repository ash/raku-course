Oplossing: Een onbewerkte string

Hier is een mogelijke oplossing voor de opgave.

Code

say Q{$x and \n};

🦋 Je kunt de broncode vinden in het bestand raw-string.raku.

Uitvoer

$x and \n

Opmerkingen

  1. Q is de meest letterlijke quoting-vorm: hij interpoleert niets en verwerkt geen escapes.

  2. Dus $x blijft als tekst staan en \n blijft een backslash en een n.
