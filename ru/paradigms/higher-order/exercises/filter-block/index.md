## Задача

`grep` — это функция высшего порядка: она принимает блок и оставляет те элементы, для которых
блок истинен. С помощью `grep` посчитайте, сколько чисел в диапазоне `1..10` больше `5`,
и напечатайте это количество.

## Пример

Программа печатает:

```
5
```
