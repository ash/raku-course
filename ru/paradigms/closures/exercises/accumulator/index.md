## Задача

Напишите подпрограмму `make-accumulator`, которая возвращает замыкание, хранящее накопленный
итог. Каждый вызов прибавляет свой аргумент к итогу и возвращает новый итог. Прибавьте `10`,
затем `5` и напечатайте результат второго вызова.

## Пример

Программа печатает:

```
15
```
