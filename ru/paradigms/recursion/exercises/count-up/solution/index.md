Вот один из возможных вариантов решения задачи.

## Код

```raku
sub countup($n) {
    return if $n < 1;
    countup($n - 1);
    say $n;
}

countup(3);
```

🦋 Исходный код можно найти в файле [count-up.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/recursion/count-up.raku).

## Вывод

```
1
2
3
```

## Комментарии

1. Базовый случай `return if $n < 1` по-прежнему останавливает рекурсию, как только счёт
переваливает за ноль.

1. Порядок двух последних строк и заставляет считать *вверх*: каждый вызов сначала уходит
в рекурсию до самого базового случая и только потом, когда вызовы разворачиваются обратно,
печатает своё число. Поэтому `1` печатается первым, а `$n` — последним.
