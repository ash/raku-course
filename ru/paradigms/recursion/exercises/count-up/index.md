## Задача

Напишите рекурсивную подпрограмму `countup`, которая печатает числа от `1` до `$n`, каждое
на своей строке. Хитрость в том, чтобы **сначала** уйти в рекурсию, а печатать потом, — тогда
числа выйдут по возрастанию, хотя каждый вызов и занимается наибольшим числом. Вызовите
`countup(3)`.

## Пример

Программа печатает:

```
1
2
3
```
