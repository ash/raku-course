## Задача

Напишите рекурсивную подпрограмму `power($base, $exp)`, которая возводит `$base` в степень `$exp`
умножением, не пользуясь оператором `**`. Базовый случай — `$exp == 0`, он даёт `1`; иначе ответ
равен `$base`, умноженному на `power($base, $exp - 1)`. Напечатайте `power(2, 10)`.

## Пример

Программа печатает:

```
1024
```
