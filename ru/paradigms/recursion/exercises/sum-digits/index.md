## Задача

Напишите рекурсивную подпрограмму `sum-digits`, которая возвращает сумму десятичных цифр
неотрицательного целого числа. Для числа меньше `10` ответом является само число; иначе прибавьте
последнюю цифру (`$n % 10`) к сумме цифр остатка (`$n div 10`).

Напечатайте `sum-digits(1234)`.

## Пример

Программа печатает:

```
10
```
