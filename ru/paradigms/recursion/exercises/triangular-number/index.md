## Задача

_n_-е треугольное число — это сумма `n + (n - 1) + … + 1`, а нулевое треугольное число равно `0`.
Напишите рекурсивную подпрограмму `tri`, которая его вычисляет, но выразите её **двумя
кандидатами `multi`**, а не условием внутри одного тела: один кандидат для базового случая,
другой для рекурсивного шага. Напечатайте `tri(5)`.

## Пример

Программа печатает:

```
15
```
