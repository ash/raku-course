Строить настоящие веб-сервисы на «сырых» сокетах быстро становится утомительно: разбор запросов,
маршрутизация URL, обслуживание множества клиентов, поддержка HTTPS. **Cro** — фреймворк на Raku,
который делает всё это за вас. Это стандартный современный способ писать на Raku веб-серверы
и клиенты.

Этот заключительный раздел — краткая экскурсия по Cro, ровно настолько, чтобы увидеть его облик.
Cro не входит в ядро, поэтому для запуска примеров сперва установите его командой
`zef install cro`.
