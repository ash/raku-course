## Задача

Расширьте приветственный сервис **вторым** маршрутом: маршрутом `GET` для пути `bye`, который
возвращает обычный текст `Goodbye!`. Исходный маршрут `hello` при этом сохраните.

> Этому упражнению нужен установленный Cro (`zef install cro`).

## Пример

Запрос к `/bye` возвращает:

```
Goodbye!
```
