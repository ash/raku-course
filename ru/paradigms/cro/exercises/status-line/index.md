## Задача

Узнайте статус веб-страницы простым способом — с помощью **клиентского модуля Cro**, а не «сырого»
сокета. Запросите `http://example.com/` через `Cro::HTTP::Client.get`, дождитесь ответа с помощью
`await` и напечатайте его `.status` — никакого разбора текста не потребуется.

> Этому упражнению нужен установленный модуль Cro (`zef install cro`) и работающая сеть.

## Пример

При запуске программа печатает:

```
200
```
