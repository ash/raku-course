Что делает следующая программа?

```raku
my $p = start { sleep 2; 42 };
say 'waiting';
say await $p;
```

{:.quiz}
1 | Сразу печатает `waiting`, а примерно через две секунды печатает `42`
0 | Делает паузу в две секунды, затем печатает `waiting` и `42` вместе
0 | Сразу печатает `waiting` и `42` — sleep происходит в фоне
0 | Печатает `waiting`, затем `Promise` — спящий промис дождаться нельзя

{% include quiz.html %}

<div class="extended-explanation">

`start` возвращает промис **немедленно**: блок вместе со своим `sleep` выполняется в фоновом
потоке. Поэтому `say 'waiting'` срабатывает сразу же. Блокирует выполнение именно `await`:
программа приостанавливается на нём, пока фоновый блок не досмотрит свой двухсекундный сон
и не выдаст `42`, которое затем печатается. Пауза принадлежит строке с `await`, а не строке
со `start`.

</div>
