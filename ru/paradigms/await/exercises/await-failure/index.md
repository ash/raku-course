## Задача

Когда блок промиса бросает исключение, `await` перебрасывает его в точке `await`. Запустите промис,
блок которого выполняет `die 'boom'`. Дождитесь его внутри блока `try` с фазером `CATCH`, который
печатает `caught: <сообщение>`.

## Пример

Программа печатает:

```
caught: boom
```
