## Задача

Даны слова `<apple banana pear cherry>`. С помощью `.hyper` выполните конвейер параллельно,
сохранив исходный порядок: переведите каждое слово в верхний регистр, оставьте только слова
длиннее **четырёх** букв и соедините оставшиеся в одну строку через пробел. Напечатайте её.

## Пример

Программа печатает:

```
APPLE BANANA CHERRY
```
