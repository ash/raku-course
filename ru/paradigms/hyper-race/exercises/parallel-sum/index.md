## Задача

Суммированию порядок безразличен, поэтому `.race` — неупорядоченный напарник `.hyper` — здесь
подходящий инструмент. С помощью `.race` для чисел от `1` до `50`: возведите каждое в квадрат
параллельно, оставьте только **чётные** квадраты и напечатайте их сумму.

## Пример

Программа печатает:

```
22100
```
