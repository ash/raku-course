Чем управляет `:batch(50)` в выражении `(1..1000).hyper(:degree(4), :batch(50))`?

{:.quiz}
1 | Сколько элементов рабочий поток обрабатывает за один заход, прежде чем взять ещё
0 | Сколько рабочих потоков выполняются одновременно
0 | Сколько элементов разрешено обработать всему конвейеру
0 | Число процессорных ядер, которые может использовать программа

{% include quiz.html %}

<div class="extended-explanation">

`:batch` — это **размер порции**: сколько элементов рабочий поток берёт за раз. Число рабочих
потоков задаёт `:degree` (здесь `4`). Большая пачка снижает издержки координации, маленькая —
равномернее распределяет неравную работу. И то и другое — подсказки, которые компилятор может
подправить или проигнорировать.

</div>
