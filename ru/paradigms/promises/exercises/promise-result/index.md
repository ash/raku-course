## Задача

Запустите промис, который выдаёт строку `'raku'`. С помощью `.then` надстройте над ним
продолжение, переводящее её **в верхний регистр** (значение читайте через `.result`), а затем
**второе** `.then`, дописывающее восклицательный знак. Дождитесь итогового промиса и напечатайте
его значение.

## Пример

Программа печатает:

```
RAKU!
```
