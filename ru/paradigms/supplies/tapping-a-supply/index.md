Чтобы подписаться на supply, к нему _подключаются_: вы передаёте методу `.tap` блок,
и этот блок выполняется для каждого значения, которое supply выдаёт. Проще всего
экспериментировать с `Supply.from-list`, который выдаёт значения списка:

```raku
my $s = Supply.from-list(1, 2, 3);
$s.tap(-> $v { say $v });
```

Программа печатает:

```
1
2
3
```

Блок `-> $v { say $v }` и есть _подключение_ (tap). Supply по очереди проталкивает в него каждое
значение, поэтому блок выполняется трижды — по разу на значение.

Подключение может делать со значением что угодно, в том числе накапливать результат:

```raku
my $total = 0;
Supply.from-list(1, 2, 3).tap(-> $v { $total += $v });
say $total; # 6
```

Здесь каждое выданное значение прибавляется к `$total`, который в итоге равен `6`. Подключение —
базовое действие реактивного программирования: соединяете кусочек поведения с потоком и даёте
потоку двигать его.
