Что получит второе подключение к supply **по требованию**, например к `Supply.from-list`?

{:.quiz}
0 | Ничего — первое подключение израсходовало значения
0 | Только значения, выданные после его подключения
1 | Всю последовательность с самого начала
0 | Ошибку

{% include quiz.html %}

<div class="extended-explanation">

Supply по требованию проигрывает свои значения заново для каждого подключения. Каждое подключение
независимо и получает полную последовательность с самого начала — в отличие от живого supply,
где опоздавшие подписчики пропускают более ранние значения.

</div>
