## Задача

Создайте живой supply с помощью `Supplier`. Подключитесь к нему так, чтобы каждое выданное
значение прибавлялось к текущей сумме. Выдайте `10`, `20` и `30`, затем напечатайте сумму.

## Пример

Программа печатает:

```
60
```
