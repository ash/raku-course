## Задача

Откройте сокет к `example.com` на порт `80`, отправьте минимальный HTTP-запрос **HEAD** (он
запрашивает только заголовки, без тела страницы), получите ответ и напечатайте его первую строку —
строку состояния.

> Для работы этому упражнению нужна работающая сеть.

## Пример

При запуске программа печатает строку вроде такой:

```
HTTP/1.1 200 OK
```
