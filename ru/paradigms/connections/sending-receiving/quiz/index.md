Что обозначает конец заголовков в HTTP-запросе, отправленном через сокет?

{:.quiz}
0 | Точка
1 | Пустая строка (лишний `\r\n`)
0 | Слово `END`
0 | Закрытие сокета

{% include quiz.html %}

<div class="extended-explanation">

HTTP отделяет заголовки от тела — и сообщает «заголовков больше нет» — пустой строкой, которая
записывается как дополнительный `\r\n`. Без неё сервер продолжит ждать остаток запроса.

</div>
