## Задача

С помощью конвейера из двух ступеней возьмите числа `1..8`, оставьте те, что больше `3`, а затем
удвойте каждое из них. Соберите результат в массив и напечатайте его.

## Пример

Программа печатает:

```
[8 10 12 14 16]
```
