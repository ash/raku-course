## Задача

С помощью оператора последовательности с правилом-замыканием постройте бесконечный ряд степеней
тройки (`1, 3, 9, 27, …` — каждый член втрое больше предыдущего) и напечатайте первые пять из них.

## Пример

Программа печатает:

```
(1 3 9 27 81)
```
