## Задача

Заставьте сервер делать настоящую работу с тем, что прислал клиент, вместо возврата фиксированной
строки. Напишите сервер, который в **цикле** (как на предыдущей странице) читает каждый запрос,
берёт запрошенный **путь** и отправляет его обратно **в верхнем регистре**: так, на запрос
`/hello` он отвечает `HELLO`. Путь — это второе слово первой строки запроса
(`GET /hello HTTP/1.0`); перед переводом в верхний регистр отбросьте ведущий `/`. Сервер
обслуживает запрос за запросом; остановите его по Ctrl-C.

## Пример

Запрос пути через `curl` возвращает его заглавными буквами:

```console
$ curl http://127.0.0.1:8080/hello
HELLO
```
