Что возвращает `Thread.start`?

{:.quiz}
0 | Значение, которое выдал блок
1 | Объект `Thread`, представляющий выполняющуюся работу
0 | `True`, если поток запустился
0 | Ничего — он блокируется, пока поток не завершится

{% include quiz.html %}

<div class="extended-explanation">

`Thread.start` запускает блок в новом потоке и немедленно возвращает объект `Thread`. Основная
программа продолжает работу; этот объект понадобится позже, чтобы дождаться завершения потока.

</div>
