## Задача

С помощью блока `react` разделите один поток на два набора. Следите за supply, построенным
из `4, 42, 7, 100, 15`, и в теле `whenever` добавляйте каждое значение больше `10` в `@big`,
а остальные — в `@small`. Напечатайте оба массива после завершения блока react.

## Пример

Программа печатает:

```
[4 7]
[42 100 15]
```
