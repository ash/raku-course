## Задача

Следите за банковским балансом, который питают два потока с **противоположными ролями**. Создайте
два именованных supply — поступления из `100, 50, 200` и списания из `30, 120` — и в одном блоке
`react` с двумя блоками `whenever` **прибавляйте** к балансу каждое поступление и **вычитайте**
из него каждое списание. Напечатайте итоговый баланс.

## Пример

Программа печатает:

```
200
```
