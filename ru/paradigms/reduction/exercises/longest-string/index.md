## Задача

С помощью **метода** `reduce` с блоком найдите и напечатайте самую длинную строку в списке
`'cat', 'elephant', 'dog', 'fox'` — ту, в которой больше всего символов. Метаоператор здесь
не поможет: блок должен сам сравнивать двух кандидатов.

## Пример

Программа печатает:

```
elephant
```
