Вот один из возможных вариантов решения задачи.

## Код

```raku
say [+] 10, 20, 30, 40;
```

🦋 Исходный код можно найти в файле [sum-list.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/sum-list.raku).

## Вывод

```
100
```

## Комментарии

1. `[+]` вставляет `+` между каждыми элементами списка.

1. Сумма `10 + 20 + 30 + 40` равна `100`.
