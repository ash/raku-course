## Задача

С помощью **метода** `reduce` с блоком соедините слова `'Raku', 'is', 'fun'` в одну строку,
поставив между кусочками `', '`, чтобы получилось `Raku, is, fun`. Метаоператор `[~]` склеивает
кусочки вплотную, поэтому вставка разделителя — работа для блока.

## Пример

Программа печатает:

```
Raku, is, fun
```
