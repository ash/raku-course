Вот один из возможных вариантов решения задачи.

## Код

```raku
my @words = 'Raku', 'is', 'fun';

say @words.reduce(-> $a, $b { "$a, $b" });
```

🦋 Исходный код можно найти в файле [comma-separated.raku](https://github.com/ash/raku-course/blob/master/exercises/paradigms/reduction/comma-separated.raku).

## Вывод

```
Raku, is, fun
```

## Комментарии

1. Здесь блок **строит** значение, а не выбирает одно из двух: `$a` — собранная к этому моменту
строка, `$b` — очередное слово, а `"$a, $b"` склеивает их через запятую с пробелом.

1. Первый вызов соединяет `'Raku'` и `'is'` в `Raku, is`; второй присоединяет к этому `'fun'`
и даёт `Raku, is, fun`. Такое соединение с разделителем метаоператор `[~]` сам по себе выразить
не может.

1. В настоящем коде вы взяли бы встроенный метод `join`, который делает ровно это:
`say @words.join(', ');` напечатает то же `Raku, is, fun`. Смысл упражнения — потренироваться
выражать ту же идею блоком `reduce`.
