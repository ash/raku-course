## Задача

С помощью метаоператора свёртки с оператором конкатенации строк `~` склейте односимвольные строки
`'2'`, `'0'`, `'2'`, `'5'` в одну строку и напечатайте её.

## Пример

Программа печатает:

```
2025
```
