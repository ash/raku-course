Что возвращает `pull-one`, когда у итератора больше нет значений, и как это проверить?

{:.quiz}
1 | `IterationEnd`, проверяется через `=:=`
0 | `Nil`, проверяется через `.defined`
0 | пустой список `()`, проверяется через `==`
0 | `0`, проверяется через `=:=`

{% include quiz.html %}

<div class="extended-explanation">

Исчерпанный итератор возвращает объект-маркер `IterationEnd`. Поскольку это один общий объект,
его проверяют по тождественности через `=:=` (проверка «тот же самый объект»), а не по значению
и не по определённости. Цикл `for` пользуется ровно этой проверкой, чтобы понять, когда
остановиться.

</div>
