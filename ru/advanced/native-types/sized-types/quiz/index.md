Что напечатает следующая программа?

```raku
my int8 $i = -128;
$i--;
say $i;
```

{:.quiz}
1 | 127
0 | -129
0 | -128
0 | 0

{% include quiz.html %}

<div class="extended-explanation">

`int8` хранит значения от `-128` до `127`. Обёртывание происходит и у нижней границы: уменьшение наименьшего значения не может дать `-129`, поэтому оно переходит к наибольшему значению — `127`.

</div>
