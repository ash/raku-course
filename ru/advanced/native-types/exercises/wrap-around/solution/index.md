Вот возможное решение задачи.

## Код

```raku
my uint8 $u = 250;
$u += 10;
say $u;

my uint8 $v = 0;
$v--;
say $v;
```

🦋 Исходный код можно найти в файле [wrap-around.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/wrap-around.raku).

## Вывод

```
4
255
```

## Комментарии

1. `uint8` имеет диапазон от `0` до `255`, то есть 256 различных значений. Арифметика над ним фактически выполняется по модулю 256.

1. `250 + 10` дало бы `260`, что не помещается. Происходит обёртывание, и результат оказывается на `260 - 256 = 4` выше нижней границы. Таким образом, переполнение не ограничивается выходом за верхнюю границу на единицу — любой результат за пределами диапазона переносится обратно.

1. В обратном направлении переполнение тоже работает: декремент `0` не может дать `-1` в беззнаковом типе, поэтому значение переходит к максимуму — `255`.
