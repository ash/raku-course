## Задача

Правило о том, что нативная переменная никогда не может быть неопределённой, применяется ко всем нативным типам, а не только к `int`. Объявите неинициализированную нативную переменную `num` и неинициализированную нативную переменную `str`. Выведите число, а затем выведите строку в квадратных скобках, чтобы её пустота была видна.

## Пример

Программа выводит:

```
0
[]
```
