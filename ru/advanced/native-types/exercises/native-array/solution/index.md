Вот возможное решение задачи.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Исходный код можно найти в файле [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Вывод

```
555
```

## Комментарии

1. Указание нативного типа фиксированного размера `uint8` перед массивом с `@` объявляет массив, в котором каждый элемент хранится как один беззнаковый байт — компактная структура, подходящая для двоичных данных.

1. Ограничение на обёртывание применяется к каждому *элементу* (`0..255`), а не к результату их суммирования. `.sum` упаковывает итог в обычный `Int`, поэтому `100 + 200 + 255` даёт полное значение `555`.
