## Задача

Естественное применение нативного типа фиксированного размера — компактный массив байтов. Объявите массив `uint8`, содержащий значения `100`, `200` и `255` — каждое из них помещается в один байт — и выведите сумму его элементов.

Обратите внимание, что сами элементы остаются в диапазоне `0..255`, но их сумма не обязана: `.sum` возвращает обычный `Int`.

## Пример

Программа выводит:

```
555
```
