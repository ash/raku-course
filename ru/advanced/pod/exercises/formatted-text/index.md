## Задача

Напишите блок Pod с заголовком `=head1` `Greeting` и абзацем `Hello, world!`, в котором слово `world` выделено жирным с помощью `B<…>`. Отрисуйте его с помощью `raku --doc`.

> Запустите файл с `raku --doc`, чтобы увидеть отрисованный текст.

## Пример

При отрисовке с помощью `raku --doc` выводится:

```
Greeting

Hello, world!
```
