Для обычных скалярных значений, таких как числа и строки, все три представления выглядят одинаково. Различия начинаются для составных или неопределённых значений. Вот `Pair`, показанный тремя способами:

```raku
say (foo => 1).gist; # foo => 1
say (foo => 1).Str;  # foo	1
say (foo => 1).raku; # :foo(1)
```

Приблизительное правило:

* [`.gist`](../gist) — для вывода, который предназначен для *чтения* человеком (`say`, `note`).
* [`.Str`](../str) — для вывода в виде *простого текста* (`print`, `put`, интерполяция, оператор `~`).
* [`.raku`](../raku-method) — для *кодоподобного* представления при отладке (`dd`).

Каждый из этих методов можно переопределить при написании класса, чтобы ваши собственные объекты печатались красиво. Мы вернёмся к этому, когда будем [создавать классы](/ru/oop/classes) в следующей части.
