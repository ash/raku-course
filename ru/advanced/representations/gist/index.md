---
title: Метод `.gist`
---

{% include menu.html %}

Метод `.gist` возвращает **удобное для человека** представление значения — ту форму, которую вы хотели бы *прочитать*. Именно это печатают `say` (и `note`): они вызывают `.gist` для каждого аргумента.

```raku
say 42.gist;     # 42
say 'Raku'.gist; # Raku
```

Для простых значений gist — это просто само значение. Для составных данных `.gist` добавляет немного форматирования, чтобы структура оставалась читаемой:

```raku
my @a = 'alpha', 'beta', 'gamma';
say @a.gist; # [alpha beta gamma]
```

Типовой объект — значение, которое представляет сам тип — отображается через gist как имя в скобках, что позволяет легко заметить его в выводе:

```raku
say Int.gist; # (Int)
```
