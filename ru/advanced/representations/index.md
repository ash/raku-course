---
title: Преобразование значений в текст
---

{% include menu.html %}

Каждый раз, когда программа показывает значение — когда вы используете `say`, печатаете его или вставляете в строку — это значение должно быть преобразовано в текст. В Raku нет единого фиксированного способа сделать это. Вместо этого каждое значение несёт в себе несколько стандартных методов, каждый из которых создаёт строку для определённой цели:

* `.gist` — удобная для человека форма, именно её печатает `say`.
* `.Str` — простая строковая форма, используемая в строковом контексте.
* `.raku` — форма, похожая на код, удобная при отладке.

Все три — обычные методы, определённые для каждого значения в языке, поэтому они одинаково работают для числа, строки, массива или объекта вашего собственного класса. На следующих страницах мы рассмотрим каждый метод по очереди, а затем поможем выбрать подходящий; [следующий раздел знакомит с `dd`](/ru/advanced/dd) — инструментом Rakudo, построенным поверх `.raku`.
