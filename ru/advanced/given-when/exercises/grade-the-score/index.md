## Задача

Используя `given`/`when`, напечатайте жизненный этап для заданного возраста по следующим группам:

* `child` для 0–12,
* `teenager` для 13–19,
* `adult` для 20–64,
* `senior` для 65 и старше.

Отрицательный возраст не имеет смысла, поэтому для любого числа меньше нуля печатайте `invalid`. Убедитесь, что этот случай обрабатывается до проверки диапазонов.

## Пример

Для возраста `30` программа печатает:

```
adult
```
