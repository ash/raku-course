## Задача

`when` может сопоставлять не только значения, но и *типы*. Имея число `3.14`, сохранённое в переменной, используйте `given`/`when`, чтобы определить, какого вида это значение: напечатайте `integer` для `Int`, `rational` для `Rat` и `string` для `Str`.

## Пример

Программа печатает:

```
rational
```
