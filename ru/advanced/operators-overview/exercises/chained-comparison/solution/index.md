Вот возможное решение задачи.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Исходный код можно найти в файле [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Вывод

```
True
```

## Комментарии

1. Операторы сравнения можно объединять в цепочки, поэтому `0 <= 73 <= 100` читается как «0 не больше 73, а 73 не больше 100». Оператор `<=` допускает граничные значения, так что результат ровно `0` или `100` тоже считается допустимым.

1. Обе части истинны, поэтому всё выражение равно `True`. Обратите внимание, что среднее значение `73` записано только один раз, хотя сравнивается с обоими соседями.

1. Без возможности объединения в цепочки пришлось бы записывать оба сравнения отдельно и соединять их с помощью `&&`, повторяя среднее значение: `0 <= 73 && 73 <= 100`. Цепочечная форма выражает то же самое более кратко.
