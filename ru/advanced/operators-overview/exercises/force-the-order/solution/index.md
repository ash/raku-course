Вот возможное решение задачи.

## Код

```raku
say 2 ** (3 + 1);
```

🦋 Исходный код можно найти в файле [force-the-order.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/force-the-order.raku).

## Вывод

```
16
```

## Комментарии

1. Без скобок `**` связывался бы теснее, чем `+`, давая `(2 ** 3) + 1 = 9`.

1. Скобки повышают приоритет сложения, поэтому сначала вычисляется `3 + 1`, и выражение становится `2 ** 4`, что равно `16`. Скобки всегда позволяют переопределить приоритет по умолчанию.
