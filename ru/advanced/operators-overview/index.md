Когда выражение содержит несколько операторов, Raku должен решить, в каком порядке их применять. Два правила определяют это: _приоритет_ и _ассоциативность_.

## Приоритет

Приоритет определяет, какой оператор связывается теснее. Умножение имеет более высокий приоритет, чем сложение, поэтому выполняется первым:

```raku
say 2 + 3 * 4; # 14
```

Выражение читается как `2 + (3 * 4)`, давая `14`, а не `20`. Вы всегда можете использовать скобки, чтобы задать другой порядок:

```raku
say (2 + 3) * 4; # 20
```

## Ассоциативность

Ассоциативность определяет порядок между операторами с _одинаковым_ приоритетом. Вычитание является левоассоциативным, поэтому группируется слева:

```raku
say 8 - 3 - 2; # 3
```

Это `(8 - 3) - 2`, что равно `3`. Возведение в степень, напротив, является правоассоциативным:

```raku
say 2 ** 3 ** 2; # 512
```

Здесь выражение группируется как `2 ** (3 ** 2)`, то есть `2 ** 9`, что равно `512`.

## Цепочки сравнений

Операторы сравнения можно _объединять в цепочки_, что читается естественно и работает так, как вы ожидаете из математики:

```raku
say 1 < 2 < 3; # True
say 1 < 5 < 3; # False
```

Среднее значение сравнивается с обоими соседями: `1 < 2 < 3` истинно, потому что `1 < 2` и `2 < 3` оба истинны.
