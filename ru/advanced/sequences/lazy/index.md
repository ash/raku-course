Последовательность не обязана вычислять все свои значения сразу. Последовательности в Raku являются _ленивыми_: каждое значение вычисляется только тогда, когда оно действительно нужно. Это позволяет описывать последовательности, у которых вообще нет конца.

Чтобы записать бесконечную последовательность, используйте `Inf` в качестве конечной точки. Оберните последовательность в скобки, поскольку `...` связывает слабее, чем `=`:

```raku
my $naturals = (1 ... Inf);
```

Без скобок `my $naturals = 1 ... Inf` присвоит переменной только `1`, а затем построит последовательность отдельно — и вычисление бесконечной последовательности без результата приведёт к зависанию программы.

Пока ничего не вычислено. Последовательность будет выдавать значения только по мере запроса. Метод `head` извлекает первые несколько:

```raku
say (1 ... Inf).head(5); # (1 2 3 4 5)
```

Хотя последовательность бесконечна, генерируются только первые пять чисел. Без ленивости программа, пытающаяся построить всю бесконечную последовательность, никогда бы не завершилась.

Для конечной последовательности метод `tail` извлекает значения с конца:

```raku
say (1 ... 100).tail(3); # (98 99 100)
```

Ленивость позволяет отделить _описание_ последовательности от решения о том, какую её часть использовать.
