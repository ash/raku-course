Вот одно из возможных решений этой задачи.

## Код

```raku
say (5, 10 ... 50).tail(3);
```

🦋 Исходный код можно найти в файле [last-three.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/sequences/last-three.raku).

## Вывод

```
(40 45 50)
```

## Комментарии

1. Начальные значения `5, 10` задают арифметический шаг, равный пяти, и последовательность продолжается до конечной точки `50`.

1. `tail(3)` возвращает три последних значения конечной последовательности — `40, 45, 50` — точно так же, как `head` вернул бы первые несколько.
