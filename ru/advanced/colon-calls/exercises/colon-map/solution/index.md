Вот возможное решение задачи.

## Код

```raku
say (1..10).map(* * 2).grep: * > 10;
```

🦋 Исходный код можно найти в файле [colon-map.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-map.raku).

## Вывод

```
(12 14 16 18 20)
```

## Комментарии

1. Только `grep`, последний вызов в цепочке, может использовать форму с двоеточием. Двоеточие делает `* > 10` его аргументом, точно так же, как `grep(* > 10)`. Поскольку нам по-прежнему нужно вывести результат, `say` теперь используется как функция, а не как метод.

1. Вызов `map` должен сохранить скобки. Если написать `.map: * * 2`, двоеточие поглотит `.grep(* > 10)` как часть аргументов `map`, и цепочка сломается.
