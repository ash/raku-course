## Задача

Вот выражение, которое удваивает числа от `1` до `10`, а затем оставляет только те, что больше `10`:

```raku
(1..10).map(* * 2).grep(* > 10).say;
```

Перепишите его так, чтобы вызов метода `grep` использовал форму с двоеточием вместо скобок. Остальную часть цепочки оставьте без изменений. Помните, что форма с двоеточием поглощает остаток выражения, поэтому только последний вызов в цепочке может её использовать.

## Пример

Программа выводит:

```
(12 14 16 18 20)
```
