## Задача

Форма с двоеточием должна быть *последним* вызовом в цепочке, но вызовы перед ней могут быть обычными, со скобками. Начните со слов `a`, `b`, `c`, разверните их с помощью `.reverse`, а затем соедините результат через дефис, используя форму с **двоеточием**. Выведите результат.

## Пример

Программа выводит:

```
c-b-a
```
