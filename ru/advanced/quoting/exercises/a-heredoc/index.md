## Задача

Используя *интерполирующий* heredoc, составьте письмо-подтверждение заказа из нескольких переменных — имя покупателя `$name`, товар `$item`, цена за единицу `$price` и количество `$count`. Heredoc должен интерполировать переменные *и* вычислить итоговую сумму прямо в тексте с помощью встроенного блока `{ … }` (`$count * $price`).

Оформите тело heredoc'а с отступом, соответствующим окружающему коду, и выровняйте закрывающий терминатор по тексту, чтобы отступы не попали в вывод. Напечатайте результат.

## Пример

Для `$name = 'Anna'`, `$item = 'Raku Book'`, `$price = 25` и `$count = 3` программа выводит без начальных пробелов:

```
Dear Anna,
You ordered 3 copies of "Raku Book".
That comes to 75 dollars.
Thank you!
```
