## Задача

Сама по себе `*` означает «без ограничения». Используйте её в качестве конечной точки последовательности: запишите чётные числа как бесконечную последовательность `2, 4 ... *`, а затем возьмите первые четыре из них с помощью `head`. Поскольку последовательность неограниченная, только ленивость вычислений делает это безопасным.

## Пример

Программа выводит:

```
(2 4 6 8)
```
