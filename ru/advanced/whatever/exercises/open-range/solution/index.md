Вот одно из возможных решений задачи.

## Код

```raku
say (2, 4 ... *).head(4);
```

🦋 Исходный код можно найти в файле [open-range.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/whatever/open-range.raku).

## Вывод

```
(2 4 6 8)
```

## Комментарии

1. Начальные значения `2, 4` задают арифметический шаг, равный двум, а голая `*` в качестве конечной точки означает, что последовательность никогда не заканчивается.

1. `head(4)` извлекает только первые четыре значения: `2, 4, 6, 8`. Последовательность ленива, поэтому неограниченный хвост никогда не вычисляется — голая звёздочка здесь означает «что угодно, без верхнего предела».
