## Задача

Остроконечный блок может принимать более одного параметра, а сигил `&` позволяет вызывать результат по имени. Сохраните остроконечный блок с двумя параметрами, который складывает свои аргументы, в переменную `&add`, объявленную с сигилом `&`. Затем вызовите его как `add(2, 3)` — без сигила — и выведите результат.

## Пример

Программа выводит:

```
5
```
