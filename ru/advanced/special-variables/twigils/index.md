title: Твигилы
---

{% include menu.html %}

_Твигил_ — это символ, размещаемый между сигилом и именем переменной. Он не меняет имя, но меняет то, как переменная ведёт себя и как она разрешается. Наиболее распространённые твигилы:

* `*` — **динамическая** переменная, например `$*OUT`, ищется по стеку вызовов
* `?` — значение **времени компиляции**, предоставленное компилятором, например `$?FILE`, `$?LINE`
* `!` — **приватный** атрибут объекта, например `$!balance`
* `.` — атрибут, доступный через метод-аксессор, например `$.name`

Вы уже встречали несколько из них, не называя твигилом: `$*OUT` и `$*IN` (динамические), а также `$!`/`$.` в [части об объектах](/ru/oop).

Переменные компилятора с твигилом `?` заполняются на этапе компиляции вашей программы:

```raku
say $?LINE; # the line number of this statement
say $?FILE; # the path of this source file
```

Каждый твигил обозначает определённый вид переменной с первого взгляда: увидев `$*foo`, вы сразу понимаете, что это динамическая переменная, а `$?foo` — что это константа времени компиляции. Следующая тема подробно рассматривает [динамические переменные](/ru/advanced/special-variables/dynamic-variables), поскольку они ведут себя совершенно иначе, чем лексические переменные, которые вы использовали до сих пор.
