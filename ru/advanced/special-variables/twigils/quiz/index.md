Какой твигил обозначает **динамическую** переменную, которая ищется по стеку вызовов?

{:.quiz}
1 | `*`
0 | `?`
0 | `!`
0 | `.`

{% include quiz.html %}

<div class="extended-explanation">

Твигил `*` обозначает динамическую переменную, как, например, `$*OUT` или `$*greeting`. Твигил `?` предназначен для значений времени компиляции, `!` — для приватных атрибутов, а `.` — для аксессоров атрибутов.

</div>
