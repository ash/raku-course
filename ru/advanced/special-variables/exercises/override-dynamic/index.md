## Задача

Покажите, как динамическая переменная проходит через промежуточную подпрограмму, которая ничего о ней не знает.

Напишите подпрограмму `log-it($msg)`, которая выводит сообщение с префиксом из динамической переменной `$*prefix`. Напишите вторую подпрограмму `task`, которая просто вызывает `log-it('working')` и никогда не упоминает `$*prefix`. Затем вызовите `task` дважды, каждый раз из блока, в котором `$*prefix` задаётся разными значениями (`INFO`, затем `DEBUG`).

## Пример

Программа выводит:

```
INFO: working
DEBUG: working
```
