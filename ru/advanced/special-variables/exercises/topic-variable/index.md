## Задача

`$_` — это переменная *темы* (topic variable). Цикл `for` устанавливает её в каждый элемент по очереди, а вызов метода, записанный с начальной точкой и без инвоканта — например, `.chars` — действует на неё, так что `.chars` означает `$_.chars`.

Пройдитесь в цикле по трём строкам `'apple'`, `'fig'` и `'cherry'`. Для каждой из них выведите строку вида `<слово> has <n> letters`, используя переменную темы `$_` для слова и вызов с начальной точкой `.chars` для его длины. Обратите внимание, как `$_` становится каждой строкой по очереди.

## Пример

Программа выводит:

```
apple has 5 letters
fig has 3 letters
cherry has 6 letters
```
