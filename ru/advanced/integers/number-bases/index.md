Целочисленный литерал не обязательно записывать в десятичной системе. Raku понимает три наиболее распространённые альтернативные системы счисления сразу, каждая со своим префиксом:

```raku
say 0xFF;   # 255  — hexadecimal (base 16)
say 0b1010; # 10   — binary (base 2)
say 0o17;   # 15   — octal (base 8)
```

Какую бы систему счисления вы ни использовали в исходном коде, значение остаётся тем же целым числом; отличается только запись.

Для любой другой системы счисления используйте форму `:основание<число>`:

```raku
say :16<FF>;   # 255
say :2<1010>;  # 10
```

Чтобы выполнить обратное преобразование — от числа к его представлению в другой системе счисления — вызовите метод `base`. Он возвращает строку цифр:

```raku
say 255.base(16); # FF
say 10.base(2);   # 1010
```
