У целых чисел есть ряд полезных методов и функций. Вот несколько из тех, которые пригодятся чаще всего.

Метод `is-prime` сообщает, является ли число простым:

```raku
say 17.is-prime; # True
say 18.is-prime; # False
```

Операторы `gcd` и `lcm` возвращают наибольший общий делитель и наименьшее общее кратное двух чисел:

```raku
say 12 gcd 18; # 6
say 4 lcm 6;   # 12
```

Метод `abs` возвращает абсолютное значение, а `sign` возвращает `-1`, `0` или `1` в зависимости от того, является ли число отрицательным, нулём или положительным:

```raku
say (-5).abs;  # 5
say (-5).sign; # -1
say 0.sign;    # 0
```
