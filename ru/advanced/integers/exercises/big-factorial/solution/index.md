Вот возможное решение задачи.

## Код

```raku
say (2 ** 1000).chars;
```

🦋 Исходный код можно найти в файле [big-factorial.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/integers/big-factorial.raku).

## Вывод

```
302
```

## Комментарии

1. `2 ** 1000` вычисляется точно: Raku не округляет и не переполняет значение, потому что целые числа имеют произвольную точность.

1. `chars` — обычно строковый метод, но при вызове на целом числе он сначала преобразует число в его десятичный текст, а затем считает символы. Поскольку здесь нет ни знака минус, ни десятичной точки, количество символов точно равно количеству цифр — `302`.
