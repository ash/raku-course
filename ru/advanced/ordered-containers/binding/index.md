---
title: Привязка с помощью `:=`
---

{% include menu.html %}

До сих пор каждая созданная вами переменная порождала новый контейнер, и присваивание через `=` помещало значение _в_ этот контейнер. Привязка, записываемая через `:=`, работает иначе: она делает имя ссылкой на _уже существующий_ контейнер, а не создаёт новый.

После привязки оба имени разделяют один и тот же контейнер, поэтому изменение через одно из них видно через другое:

```raku
my $x = 10;
my $y := $x;

$x = 20;
say $y; # 20
```

Здесь `$y := $x` не копирует значение `10`. Оно делает `$y` другим именем для того же контейнера, что и `$x`. Когда `$x` позже устанавливается в `20`, чтение `$y` тоже возвращает `20`.

Сравните это с обычным присваиванием, которое копирует значение в отдельный контейнер:

```raku
my $x = 10;
my $y = $x; # обычная копия

$x = 20;
say $y; # 10
```

Привязка работает и с массивами. Следующий пример делает `@alias` другим именем для `@data`:

```raku
my @data = 1, 2, 3;
my @alias := @data;

@alias[0] = 99;
say @data; # [99 2 3]
```

Ещё один нюанс: если вы привяжете имя непосредственно к литеральному значению, за ним не стоит контейнер, поэтому имя становится доступным только для чтения:

```raku
my $pi := 3.14;
$pi = 3;
```
