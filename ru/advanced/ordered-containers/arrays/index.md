title: Массивы

Массив — это упорядоченный контейнер, элементы которого сами являются скалярными контейнерами.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигил `@` указывает на то, что переменная ведёт себя как объект `Positional`, поэтому вы можете обращаться к отдельным элементам по индексу:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Поскольку каждый элемент является скалярным контейнером, вы можете присвоить ему новое значение точно так же, как обычной скалярной переменной:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Вы также можете присвоить значение другого типа, например:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Именно это делает массивы _изменяемыми_: каждый элемент — это контейнер, который может принять новое значение. Как вы увидите в следующей теме, [списки](/ru/advanced/ordered-containers/lists) ведут себя иначе.
