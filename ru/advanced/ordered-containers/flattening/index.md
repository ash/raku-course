Когда вы помещаете один массив внутрь другого, Raku _не_ объединяет их элементы автоматически. Рассмотрите следующую программу:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

Массив `@c` содержит всего два элемента: массивы `@a` и `@b`. Raku сохраняет каждый контейнер как отдельный элемент, а не рассыпает его содержимое во внешний массив. То же самое происходит, если значение помещается среди других:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Когда вам действительно нужна единая плоская последовательность, запросите это явно с помощью функции `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Упаковка в элемент (Itemisation)

Иногда нужно противоположное: защитить контейнер от разворачивания, даже внутри `flat`. Конструкция `$(...)` _упаковывает_ свой аргумент, помечая результат как один элемент. Сравните предыдущий пример с этим:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Здесь `$(@a)` сохраняет `@a` как один элемент, тогда как `@b` по-прежнему разворачивается в свои два значения. Это снова идея сигила `$`: `$` означает «рассматривать это как одну вещь».
