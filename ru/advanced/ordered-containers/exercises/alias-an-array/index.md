## Задача

Вам дан массив:

```raku
my @original = 10, 20, 30;
```

Создайте второе имя, `@alias`, которое ссылается на _тот же самый_ массив (не копируйте его).
На этот раз добавьте новый элемент в `@original` с помощью `push`, а затем напечатайте
`@alias`, чтобы показать, что псевдоним видит не только изменения значений, но и структурные
изменения.

## Пример

Программа печатает:

```
[10 20 30 40]
```
