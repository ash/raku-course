## Задача

Вам даны два массива:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Объедините их в один _плоский_ массив (а не вложенный). Напечатайте массив, а затем количество
его элементов.

## Пример

Программа печатает:

```
[1 2 3 4 5]
5
```
