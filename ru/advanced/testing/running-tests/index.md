Отдельный тестовый файл --- это обычная программа на Raku, поэтому его можно запустить напрямую:

```
raku t/01-basic.rakutest
```

Он выводит TAP-вывод на экран. Для более чем одного-двух файлов удобнее использовать _средство запуска тестов_, которое запускает целую директорию с тестами и обобщает результаты. В Raku это `prove6`:

```
prove6 t/
```

Эта команда запускает все тестовые файлы в директории `t/` и сообщает, сколько файлов и тестов прошло, с общим итогом в конце --- это гораздо удобнее для чтения, чем необработанный TAP-вывод каждого файла.

Когда у дистрибутива есть `META6.json`, инструмент управления модулями запускает тесты за вас:

```
zef test .
```

`zef test` находит директорию `t/`, запускает набор тестов и сообщает результат --- именно это происходит автоматически перед установкой дистрибутива. Таким образом, тесты выполняют двойную функцию: вы запускаете их во время разработки с помощью `prove6`, а экосистема запускает их для проверки дистрибутива перед его установкой.

> Тестовые файлы имеют расширение `.rakutest` (или `.t`) и по соглашению нумеруются, например `t/01-basic.rakutest`.
