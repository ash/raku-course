Вот возможное решение задачи.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Исходный код можно найти в файле [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Вывод

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Комментарии

1. `plan 2` указывает количество тестов до их выполнения, поэтому строка `1..2` появляется первой. Если затем файл выполнит другое количество проверок, набор тестов будет считаться неудачным --- это защита, которую `done-testing` обеспечить не может.

1. `is-deeply` сравнивает два списка на точное, типизированное равенство. Сортировка `3, 1, 2` даёт `1, 2, 3`, что совпадает.

1. `is` сравнивает два значения на простое равенство и при неудаче выводит оба. Здесь `10 % 3` равно `1`, что совпадает с ожидаемым значением, поэтому второй тест тоже проходит.
