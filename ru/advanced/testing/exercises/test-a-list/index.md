## Задача

Напишите тестовый файл, который использует `plan` (а не `done-testing`), чтобы заранее указать, что он содержит ровно две проверки. Сделайте эти проверки:

1. С помощью `is-deeply` проверьте, что сортировка списка `3, 1, 2` даёт `[1, 2, 3]`.
1. С помощью `is` проверьте, что `10 % 3` равно `1`.

Дайте каждой проверке короткое описание на ваш выбор.

## Пример

С описаниями `sorted` и `remainder` программа выводит:

```
1..2
ok 1 - sorted
ok 2 - remainder
```
