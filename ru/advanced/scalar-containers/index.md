---
title: Скалярные контейнеры
---

{% include menu.html %}

Как следует из названия, скалярные контейнеры хранят единичные (скалярные) значения. Такие контейнеры обозначаются сигилом `$`.

Вот один из самых простых и прямолинейных примеров использования скаляра:

```raku
my $lang = 'Raku';
```

Переменная `$lang` — это скалярный контейнер.

По умолчанию скалярные контейнеры не накладывают ограничений на тип данных, поэтому в них можно хранить значение любого типа. Простейшая демонстрация этого — повторное использование одной и той же переменной для хранения сначала целого числа, а затем строки:

```raku
my $value = 42;
$value = 'forty-two';
```

(Автор не рекомендует вам программировать таким образом.)

Внутренне это означает, что по умолчанию новый контейнер может хранить значения типа `Any`. `Any` — это базовый тип для большинства других типов, таких как `Int` или `Str`.
