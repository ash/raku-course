## Задача

Объявите рядом две скалярные переменные: нетипизированную `$untyped` и типизированную `Int` `$typed`. Выведите обе с помощью `dd`, пока они ещё пусты, затем присвойте каждой `42` и снова выведите обе. Обратите внимание, как `dd` описывает два контейнера по-разному.

## Пример

Программа выводит (в стандартный поток ошибок):

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
