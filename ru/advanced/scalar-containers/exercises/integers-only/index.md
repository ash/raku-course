## Задача

Объявите контейнер `$cars`, который может хранить только целые числа.

Вам дано значение, полученное в результате моделирования транспортного потока: `250.7`. Сохраните его в `$cars`, преобразовав в целое число, чтобы присваивание было принято. Затем выведите значение и его тип.

## Пример

Программа выводит:

```
250
(Int)
```
