## Задача

Объявите скалярную переменную `$discount` так, чтобы её значение по умолчанию было `0`. Выведите переменную до присваивания чего-либо — программа должна напечатать `0` без каких-либо предупреждений.

Затем присвойте переменной значение `15` и снова выведите её.

## Пример

Программа выводит две строки:

```
0
15
```
