Вот одно из возможных решений задачи.

## Код

```raku
my $discount is default(0);
say $discount;

$discount = 15;
say $discount;
```

🦋 Исходный код можно найти в файле [default-discount.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/default-discount.raku).

Конечно, более простым решением было бы напрямую инициализировать переменную значением `0`:

```raku
my $discount = 0;
say $discount;

$discount = 15;
say $discount;
```

## Вывод

```
0
15
```

## Комментарии

1. Трейт `is default(0)` задаёт контейнеру значение, к которому он обращается, пока ему ничего не было присвоено. Чтение переменной возвращает `0`, и, в отличие от значения по умолчанию без объявления, не вызывает предупреждения о _неинициализированном значении_.

1. После присваивания контейнер содержит `15`, и значение по умолчанию больше не играет никакой роли.
