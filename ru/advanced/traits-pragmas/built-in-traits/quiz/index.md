Какой типаж позволяет подпрограмме **изменять переменную вызывающей стороны** через параметр?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | ни один — параметры по умолчанию доступны для записи

{% include quiz.html %}

<div class="extended-explanation">

По умолчанию параметр доступен только для чтения, поэтому обычному параметру нельзя присвоить значение. `is rw` привязывает параметр к самой переменной вызывающей стороны, так что изменение внутри подпрограммы видно снаружи. `is copy` вместо этого создал бы изменяемую *копию*, оставив переменную вызывающей стороны нетронутой.

</div>
