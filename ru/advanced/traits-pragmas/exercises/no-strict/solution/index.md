Вот возможное решение задачи.

## Код

```raku
no strict;

$a = 10;
$b = 20;
say $a + $b;
```

🦋 Исходный код можно найти в файле [no-strict.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/traits-pragmas/no-strict.raku).

## Вывод

```
30
```

## Комментарии

1. `no strict` отключает требование объявления переменных, поэтому `$a` и `$b` можно присваивать без `my`. При включённой по умолчанию `strict` каждая из этих строк вызвала бы ошибку компиляции.

1. После присваивания переменные ведут себя как обычно, поэтому `$a + $b` равно `30`. Ослабление правила лексическое — оно действует только до конца области видимости, в которой появляется `no strict`.

1. Это демонстрация, а не рекомендуемая практика: `strict` включена по умолчанию не зря — она перехватывает опечатки в именах переменных на этапе компиляции. В реальном коде оставляйте её включённой и объявляйте переменные с помощью `my`.
