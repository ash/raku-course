## Задача

По умолчанию параметры подпрограммы доступны только для чтения, поэтому подпрограмма не может изменить переменную вызывающей стороны. Типаж `is rw` снимает это ограничение.

Напишите подпрограмму `double`, единственный параметр которой помечен `is rw`, и которая удваивает его на месте (`$n *= 2`). Вызовите её для переменной со значением `21`, затем выведите переменную, чтобы показать, что она стала `42`.

## Пример

Программа выводит:

```
42
```
