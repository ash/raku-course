## Задача

Пользовательский типаж может принимать аргумент, а не просто присутствовать или отсутствовать. Напишите типаж `is role(...)`, который принимает строку и записывает в хеш, индексированный по имени подпрограммы, роль, назначенную этой подпрограмме.

Примените `is role('admin')` к подпрограмме `login`, затем выведите роль, сохранённую для `login`.

## Пример

Программа выводит:

```
admin
```
