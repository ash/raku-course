## Задача

Напишите подпрограмму `power` с обязательным параметром `$base` и **необязательным** параметром `$exp`. Когда показатель степени передан, возведите основание в эту степень; когда он опущен, по умолчанию возведите в квадрат (используйте оператор defined-or `//`, чтобы подставить `2`).

Вызовите её один раз только с основанием и один раз с основанием и показателем степени.

## Пример

Программа выводит:

```
25
125
```
