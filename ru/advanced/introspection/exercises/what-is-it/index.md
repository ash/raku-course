## Задача

`WHAT` не просто описывает тип — он возвращает сам объект типа, который можно сравнить оператором `===`.

Объявите две переменные: `$a` с целым числом `42` и `$b` со строкой `'x'`. Для каждой из них напечатайте, совпадает ли её `WHAT` с типом `Int`.

## Пример

Программа печатает:

```
True
False
```
