## Задача

Дана типизированная переменная:

```raku
my Str $lang = 'Raku';
```

Напечатайте три факта о ней, каждый на отдельной строке:

1. тип её значения;
2. тип её контейнера;
3. её имя, включая сигил.

## Пример

Программа печатает:

```
Str
Scalar
$lang
```
