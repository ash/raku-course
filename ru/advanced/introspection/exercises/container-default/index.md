## Задача

Контейнер может иметь значение по умолчанию, заданное трейтом `is default`. Пока вы ничего не присвоили, при чтении переменной возвращается это значение по умолчанию, а `.VAR.default` его сообщает.

Объявите скаляр `$count` со значением по умолчанию `0`. Не присваивая ему ничего, напечатайте саму переменную, а затем значение по умолчанию её контейнера. Обе строки должны показать `0`.

## Пример

Программа печатает:

```
0
0
```
