## Задача

Только `our` делает имя видимым за пределами пакета; `my` сохраняет его приватным. Создайте пакет `Config` с переменной `our` `$port`, равной `8080`, **и** переменной `my` `$secret`, равной `42`. Снаружи выведите `$Config::port`, а затем выведите, определена ли `$Config::secret` — она не должна быть определена, потому что переменная `my` не является частью пространства имён.

## Пример

Программа выводит:

```
8080
False
```
