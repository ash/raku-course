## Задача

Вложите модуль `Inner` в модуль `Outer`. Внутри `Inner` объявите переменную `our` `$base`, равную `10`, и подпрограмму `our sub doubled`, которая возвращает `$base`, умноженную на два. Снаружи обоих модулей обратитесь к переменной по её полному вложенному имени и вызовите подпрограмму по её полному вложенному имени. Выведите оба результата.

## Пример

Программа выводит:

```
10
20
```
