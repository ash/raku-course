## Задача

Создайте пакет `Temperature`, который объединяет две вещи: переменную `our` `$freezing`, равную `0`, и подпрограмму `our` `fahrenheit`, которая преобразует значение в градусах Цельсия в Фаренгейт (умножить на 9/5 и прибавить 32). Снаружи пакета выведите точку замерзания, а затем значение в Фаренгейтах для `100` градусов Цельсия.

## Пример

Программа выводит:

```
0
212
```
