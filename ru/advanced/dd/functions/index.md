---
title: Сигнатура функции
---

{% include menu.html %}

Вызов `dd` без аргументов внутри подпрограммы печатает сигнатуру этой подпрограммы: её имя и список параметров, если они есть. Рассмотрим следующий пример с двумя подпрограммами:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Программа печатает сигнатуры, а не какие-либо значения:

```console
sub f1()
sub f2($x)
```

Это особенно полезно с мультифункциями, где `dd` показывает, какой именно кандидат был вызван:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Вывод указывает подходящий вариант каждый раз:

```console
sub g()
sub g($x)
```
