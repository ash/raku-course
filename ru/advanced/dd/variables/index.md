---
title: Вывод переменных
---

{% include menu.html %}

Вызовите `dd`, чтобы увидеть, что содержит переменная, так же как вы бы сделали это с помощью `say`:

```raku
my $var = 42;
dd $var;
```

Вместе со значением `dd` также показывает имя переменной:

```console
$var = 42
```

Если у переменной объявлен тип, тип тоже появляется. Сравните вывод следующей программы с предыдущей:

```raku
my Int $var = 42;
dd $var;
```

```console
Int $var = 42
```

В этом главное отличие от `say`: один вызов `dd` для скаляра показывает имя и, когда он известен, тип данных — так что вы можете расставить несколько вызовов `dd` в программе и всё равно понять, какой вывод относится к какой переменной.

Вы также можете выводить дамп более сложных структур данных, таких как массивы или хэши. В этом случае `dd` печатает кодоподобное представление значения:

```raku
my @arr = 10, 20, [1, 2, 3], 30;
dd @arr;
```

```console
[10, 20, [1, 2, 3], 30]
```

Обратите внимание, что вложенный массив остаётся чётко видимым (имя переменной при этом не печатается). То же работает для хэшей, ключи которых `dd` печатает в отсортированном порядке:

```raku
my %hash =
    gamma => 'g',
    alpha => 'a',
    beta  => 'b';
dd %hash;
```

```console
{:alpha("a"), :beta("b"), :gamma("g")}
```
