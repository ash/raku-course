## Задача

Дана следующая вложенная структура данных:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Сделайте с ней два действия:

1. Выведите дамп `@data` для разработчика с помощью `dd`.
2. Выведите то же представление в виде строки с префиксом `Structure: `.

## Пример

Программа печатает две похожие строки:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
