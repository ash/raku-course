Подпрограмма может быть определена _внутри_ другой подпрограммы. Вложенная подпрограмма — это обычная подпрограмма, но она видна только внутри той подпрограммы, которая её содержит.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Программа выводит:

```
I am the inner subroutine
```

Здесь `inner` объявлена внутри `outer`, и `outer` её вызывает. Это работает, потому что `inner` находится в области видимости на протяжении всего тела `outer`.

Однако за пределами `outer` имя `inner` не существует. Следующая программа не скомпилируется:

```raku
sub outer {
    sub inner { 42 }
}

inner; # error: Undeclared routine: inner
```

Вложенность полезна, когда вспомогательная подпрограмма нужна только одной подпрограмме. Размещение её внутри делает очевидным, что это внутренняя деталь реализации, и предотвращает случайный вызов из другого места.
