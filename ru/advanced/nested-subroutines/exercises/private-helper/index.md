## Задача

Напишите подпрограмму `stats`, которая определяет **вложенную** вспомогательную подпрограмму `double`, возвращающую удвоенное значение своего аргумента. Внутри `stats` используйте помощник, чтобы вывести значение `double(3) + double(5)`.

Затем вызовите `stats`.

## Пример

Программа выводит:

```
16
```
