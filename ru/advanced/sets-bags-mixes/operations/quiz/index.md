Что напечатает следующая программа?

```raku
say (set(1, 2) ∪ set(2, 3)).elems;
```

{:.quiz}
1 | 3
0 | 4
0 | 2
0 | 1

{% include quiz.html %}

<div class="extended-explanation">

Объединение собирает все значения из обоих множеств, но множество хранит каждое значение только один раз. У двух множеств общее значение `2`, поэтому объединение — это `{1, 2, 3}`, то есть три различных элемента.

</div>
