## Задача

Даны два множества названий фруктов:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Вычислите их пересечение и сохраните его в переменной. Затем напечатайте две строки: сколько общих значений у двух множеств и является ли `apple` одним из этих общих значений (не должно быть).

## Пример

Программа печатает:

```
2
False
```
