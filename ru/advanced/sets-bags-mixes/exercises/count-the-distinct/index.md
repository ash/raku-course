## Задача

Дан список чисел, некоторые из которых повторяются:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Напечатайте, сколько _уникальных_ значений он содержит. Используйте множество.

## Пример

Программа печатает:

```
7
```
