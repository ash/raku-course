## Задача

Создайте модуль с именем `Maths` в файле `Maths.rakumod`, который экспортирует подпрограмму
`square`, возвращающую квадрат своего аргумента.

Затем напишите отдельную программу, которая использует этот модуль и печатает `square(6)`.

## Пример

Запущенная с модулем в пути поиска, программа печатает:

```console
$ raku -I. maths.raku
36
```
