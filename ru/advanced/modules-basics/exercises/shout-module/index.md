## Задача

Создайте модуль с именем `Shouter` в файле `Shouter.rakumod`, который экспортирует подпрограмму
`shout`, возвращающую свой аргумент в верхнем регистре.

Затем напишите отдельную программу, которая использует этот модуль и печатает `shout('hi')`.

## Пример

Запущенная с модулем в пути поиска, программа печатает:

```console
$ raku -I. shout.raku
HI
```
