Чтобы использовать модуль, загрузите его с помощью инструкции `use`. После этого имена, которые модуль экспортирует, доступны так, как будто вы написали их сами.

Имея файл `Greeting.rakumod` из предыдущей темы, программа использует его следующим образом:

```raku
use Greeting;

say hello('Anna');
```

Поскольку `hello` была помечена `is export`, инструкция `use` делает её доступной, и программа вызывает её напрямую:

```
Hello, Anna!
```

Чтобы Raku нашёл модуль, тот должен находиться в пути поиска модулей. Когда файл модуля лежит в том же каталоге, что и ваша программа, укажите Raku искать там с помощью опции `-I.` (точка означает «текущий каталог»):

```console
$ raku -I. program.raku
Hello, Anna!
```

Установленные модули (о них позже в разделе [Установка модулей из сети](/ru/advanced/installing-modules)) находятся автоматически, поэтому опция `-I` нужна только для модулей, которые лежат рядом с вашей программой.
