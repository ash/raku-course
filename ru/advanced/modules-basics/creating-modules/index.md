По мере роста программ удобно разделять их на повторно используемые части. _Модуль_ — это единица кода, хранящаяся в отдельном файле, которую другие программы могут загружать и использовать.

Файл модуля имеет расширение `.rakumod` и начинается с объявления имени модуля с помощью `unit module`. Подпрограммы, написанные внутри, по умолчанию являются приватными; чтобы сделать одну из них доступной для кода, использующего модуль, пометьте её трейтом `is export`.

Вот модуль, сохранённый в файле `Greeting.rakumod`:

```raku
unit module Greeting;

sub hello($name) is export {
    return "Hello, $name!";
}
```

Подпрограмма `hello` помечена `is export`, поэтому она будет видна любой программе, использующей этот модуль. Подпрограмма без `is export` останется приватной для модуля.

Модуль также может делиться данными через переменные `our`, которые доступны через имя модуля. Добавить номер версии в `Greeting` — это просто ещё одна строка в файле:

```raku
our $version = '1.0';
```

С этой строкой в `Greeting.rakumod` значение доступно как `$Greeting::version` везде, где модуль загружен.
