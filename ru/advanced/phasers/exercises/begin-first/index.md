## Задача

Фейзер `BEGIN` — это не просто блок, который выполняется рано, — это ещё и *выражение*, значение которого вычисляется один раз, на этапе компиляции, и затем фиксируется в программе.

Используйте `BEGIN { 2 + 3 }` для инициализации переменной `$compiled` и выведите её. Выражение `2 + 3` вычисляется, пока программа ещё компилируется, но сохранённое значение полностью доступно во время выполнения.

## Пример

Программа выводит:

```
5
```
