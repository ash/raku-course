## Задача

Фейзер `END` выполняется после основного кода, поэтому он видит *финальное* состояние ваших переменных — что делает его идеальным для вывода итоговой информации.

Объявите счётчик `$count` со значением `0` и напишите фейзер `END` (поместите его перед основным кодом), который выводит `processed $count items`. Затем в основном теле программы увеличьте счётчик три раза с помощью цикла. Итоговое сообщение должно показать финальное значение счётчика, а не значение на момент записи фейзера.

## Пример

Программа выводит:

```
processed 3 items
```
