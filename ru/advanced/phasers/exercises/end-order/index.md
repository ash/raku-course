## Задача

Программа может содержать более одного фейзера `END`. В этом случае они выполняются в **обратном** порядке по отношению к тому, как были записаны — последний объявленный выполняется первым (последним пришёл — первым ушёл).

Напишите два фейзера `END`: первый выводит `first END`, а второй — `second END`, затем добавьте обычный `say 'body'`. Предскажите и воспроизведите порядок вывода.

## Пример

Программа выводит:

```
body
second END
first END
```
