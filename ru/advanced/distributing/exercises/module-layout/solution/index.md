Вот возможное решение задачи.

## Структура

```
Greet-Simple/
├── META6.json
├── README.md
├── lib/
│   └── Greet/
│       └── Simple.rakumod
└── t/
    └── 01-basic.rakutest
```

## Комментарии

1. `META6.json` находится в корне; исходный код модуля располагается в `lib/`, причём путь каталогов соответствует частям имени, разделённым `::`.

1. Тесты находятся в `t/`. При такой структуре команды `zef test .` и `zef install .` работают из корневой директории.
