## Задача

Напишите `META6.json` для дистрибутива с именем `Greet::Simple`, версии `0.0.1`, который предоставляет модуль `Greet::Simple` из файла `lib/Greet/Simple.rakumod`. В отличие от пустого `depends` в теоретическом примере, этот дистрибутив **зависит от** другого дистрибутива, `JSON::Fast` — укажите его в массиве `depends`.

> Это упражнение создаёт файл, а не вывод программы.
