`zef` — это установщик модулей Raku. Вы уже использовали его для установки модулей по имени; он также работает с локальной директорией дистрибутива. Из директории дистрибутива можно запустить тестирование и установку напрямую:

```
zef test .
zef install .
```

`zef test .` запускает файлы из `t/`, а `zef install .` устанавливает дистрибутив в вашу среду Raku, чтобы другие программы могли его подключать через `use`. Установка по имени — `zef install Cro` — делает то же самое, предварительно скачав дистрибутив из экосистемы.

Чтобы **опубликовать** свой дистрибутив, чтобы другие могли установить его по имени, нужно загрузить его в экосистему. Обычно для этого используется `fez`:

```
fez upload
```

Эта команда упаковывает текущий дистрибутив и отправляет его в экосистему Raku, после чего `zef install Maths::Simple` заработает для всех.

> Эти команды требуют установленных `zef`/`fez` и доступа к сети, а для загрузки необходима учётная запись в экосистеме.

Таким образом, жизненный цикл общедоступного модуля таков: подготовить его с файлом `META6.json`, протестировать с помощью `zef test` и опубликовать через `fez upload`. После этого он становится просто ещё одним именем, которое может установить любой через `zef install`.
