В выражении `@a[0]`, к какой категории относится обращение по индексу `[0]`?

{:.quiz}
0 | postfix
1 | postcircumfix
0 | circumfix
0 | infix

{% include quiz.html %}

<div class="extended-explanation">

Обращение по индексу окружает своё содержимое скобками *и* следует за термом (здесь `@a`), что делает его постциркумфиксным оператором. Обычный постфикс (как `++`) не использует окружающих скобок, а циркумфикс (как конструктор массива `[1, 2, 3]`) окружает, но не следует за термом.

</div>
