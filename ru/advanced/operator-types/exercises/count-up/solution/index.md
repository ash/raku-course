Вот одно из возможных решений задачи.

## Код

```raku
my $n = 9;

say $n++;
say $n;
```

🦋 Исходный код можно найти в файле [count-up.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operator-types/count-up.raku).

## Вывод

```
9
10
```

## Комментарии

1. `++` — это постфиксный оператор: он стоит после своего операнда. Используемый как выражение, `$n++` сначала возвращает *старое* значение `9` — именно его выводит `say` — и только затем увеличивает переменную.

1. Вторая строка показывает, что `$n` действительно стало равным `10`. (Префиксная форма `++$n` сначала увеличила бы значение и вернула `10`.)
