Вы уже использовали множество операторов — `+`, `~`, `++` и другие. В Raku операторы классифицируются по тому, _где_ они расположены относительно своих операндов. Знание категорий пригодится позже, когда вы будете определять собственные операторы.

## `prefix`

Префиксный оператор стоит _перед_ единственным операндом:

```raku
my $x = 5;
say -$x; # -5
say ?$x; # True
```

Здесь `-` меняет знак числа, а `?` преобразует значение в его булево представление.

## `infix`

Инфиксный оператор стоит _между_ двумя операндами. Большинство знакомых арифметических и строковых операторов являются инфиксными:

```raku
say 3 + 4;       # 7
say 'a' ~ 'b';   # ab
```

Инфиксный оператор не обязательно является символом пунктуации — он может быть словом. Оператор `gcd`, с которым вы встречались при изучении [целых чисел](/ru/advanced/integers), например, является инфиксным оператором, записанным как имя между двумя операндами:

```raku
say 12 gcd 18;   # 6
```

## `postfix`

Постфиксный оператор стоит _после_ единственного операнда:

```raku
my $x = 5;
$x++;
say $x; # 6
```

## `circumfix` и `postcircumfix`

Циркумфиксный оператор _окружает_ свой операнд. Квадратные скобки, создающие массив, являются циркумфиксным оператором:

```raku
my @a = [1, 2, 3];
```

Постциркумфиксный оператор окружает что-то, но следует за термом. Обращение по индексу является постциркумфиксным оператором — `[1]` после `@a`:

```raku
my @a = 10, 20, 30;
say @a[1]; # 20
```

Эти названия — `prefix`, `infix`, `postfix`, `circumfix` и `postcircumfix` — это те же слова, которые Raku использует при [объявлении нового оператора](/ru/advanced/user-defined-operators), как вы увидите позже.
