Вот один из возможных вариантов решения задачи.

## Код

```raku
my @data = 10, 20, 30, 40;

say ([+] @data) / @data.elems;
```

🦋 Исходный код можно найти в файле [sum-of-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/metaoperators/sum-of-array.raku).

## Вывод

```
25
```

## Комментарии

1. Метаоператор свёртки `[+]` ставит оператор `+` между всеми элементами `@data`, поэтому
`[+] @data` равносильно `10 + 20 + 30 + 40`, то есть `100`. Скобки нужны для того, чтобы
свёртка выполнилась раньше деления.

1. Деление суммы на `@data.elems`, число элементов, даёт среднее значение `25`. Если бы
результат не делился нацело, Raku выдал бы точное значение типа `Rat`, а не округлил его.
