## Задача

Напишите программу, которая печатает среднее (среднее арифметическое) массива чисел.
Для сложения значений используйте метаоператор свёртки.

Входные данные заданы прямо в программе, например:

```raku
my @data = 10, 20, 30, 40;
```

## Пример

Программа печатает среднее значение элементов `@data`:

```
25
```
