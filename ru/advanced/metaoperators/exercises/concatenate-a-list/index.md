## Задача

URL разбит на части и сохранён в массиве. Склейте части обратно в одну строку с помощью
метаоператора свёртки, напечатайте получившийся URL, а на следующей строке — его длину
в символах.

## Пример

Для такого входного массива:

```raku
my @parts = <http :// example .com>;
```

программа печатает:

```
http://example.com
18
```
