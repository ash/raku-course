## Задача

Напишите две мульти-подпрограммы с именем `abs-value`, принимающие целое число и возвращающие его абсолютное значение. Используйте конструкцию `where` для отдельной обработки отрицательного случая — не используйте `if` внутри подпрограмм и не используйте встроенную функцию `abs`.

Напечатайте результат для `-7` и для `4`.

## Пример

Программа печатает:

```
7
4
```
