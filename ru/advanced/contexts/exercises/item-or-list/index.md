## Задача

Возьмите массив `1, 2, 3` и упакуйте его в скаляр `$x` с помощью контекстуализатора **элемента**, чтобы `$x` содержал весь массив как одно значение. Затем используйте контекстуализатор **списка**, чтобы запустить цикл `for` по `$x`, подсчитывая итерации. Поскольку контекст списка раскрывает упакованный массив обратно в его элементы, цикл выполнится три раза. Выведите счётчик.

## Пример

Программа выводит:

```
3
```
