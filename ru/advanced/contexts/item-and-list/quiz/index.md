Что выведет следующая программа?

```raku
my @a = 1, 2, 3;
my $n = 0;
$n++ for $(@a);
say $n;
```

{:.quiz}
0 | 3
1 | 1
0 | 0
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Контекстуализатор `$( … )` принудительно задаёт контекст элемента, поэтому массив рассматривается как одно значение, а не как список элементов. Цикл `for`, таким образом, видит один элемент и выполняет тело только один раз, оставляя `$n` равным `1`. Без `$( )` цикл выполнился бы три раза.

</div>
