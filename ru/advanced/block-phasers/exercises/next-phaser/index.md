## Задача

Фазер `NEXT` выполняется в *конце* каждой итерации цикла, что является удобным моментом для отчёта о прогрессе.

Заведите накопительную сумму в `$sum`, начиная с `0`. Выполните цикл по `1..3`; на каждом проходе сначала добавляйте текущее число к `$sum`. Используйте фазер `NEXT`, чтобы печатать `sum so far: $sum` после каждой итерации.

Обратите внимание на порядок: фазер `NEXT` выполняется после тела, поэтому он показывает сумму, *включая* текущее число.

## Пример

Программа выводит:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
