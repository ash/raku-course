## Задача

Помимо перечисления имён пакета, вы можете обратиться к имени динамически, используя его как ключ в stash пакета. Дан модуль `Circle.rakumod`:

```raku
unit module Circle;

our $pi = 3.14;
```

Напишите отдельную программу, которая загружает модуль и выводит значение `$pi`, обращаясь к нему через stash с помощью `Circle::{'$pi'}` — а не через квалифицированное `$Circle::pi`.

## Пример

При запуске с модулем в пути поиска программа выводит:

```console
$ raku -I. lookup.raku
3.14
```
