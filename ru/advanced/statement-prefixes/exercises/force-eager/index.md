## Задача

Префикс `eager` делает противоположное тому, что делает `lazy`: он заставляет список быть полностью вычисленным, так что он больше не является ленивым. Продемонстрируйте контраст с помощью `.is-lazy`.

Выведите, является ли бесконечный диапазон `1 .. Inf` ленивым, затем является ли `eager 1..3` ленивым и, наконец, является ли `lazy 1..3` ленивым. Результаты должны быть `True`, `False`, `True`.

## Пример

Программа выводит:

```
True
False
True
```
