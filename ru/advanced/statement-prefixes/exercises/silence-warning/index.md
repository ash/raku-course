## Задача

`quietly` подавляет предупреждения и, подобно `do`, возвращает значение своего блока. Объявите переменную для имени без значения, затем соберите приветствие `"Hello, " ~ $name ~ "!"` внутри блока `quietly`, чтобы предупреждение о неинициализированном значении было скрыто. Присвойте значение блока переменной `$greeting` и напечатайте его.

## Пример

Программа выводит:

```
Hello, !
```
