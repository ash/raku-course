В части «Основы» вы узнали, [как создавать строки](/ru/essentials/strings) — конкатенация, интерполяция и длина строки. Строки также обладают богатым набором методов. В этом разделе собраны наиболее полезные из них. (Поиск с помощью [регулярных выражений](/ru/regexes) — это отдельная большая тема, которая рассматривается в своей собственной части позже.)

Три метода изменяют регистр букв в строке:

```raku
say 'raku'.uc; # RAKU  — upper case
say 'RAKU'.lc; # raku  — lower case
say 'raku'.tc; # Raku  — title case (first letter capitalised)
```

Метод `flip` переворачивает символы строки в обратном порядке:

```raku
say 'Raku'.flip; # ukaR
```

А оператор `x` повторяет строку заданное количество раз:

```raku
say 'ab' x 3; # ababab
```
