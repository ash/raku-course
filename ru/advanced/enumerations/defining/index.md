Объявите перечисление с помощью ключевого слова `enum`, имени и списка имен констант:

```raku
enum Colour <red green blue>;
```

Это создает новый тип `Colour` и три константы: `red`, `green` и `blue`. Вы можете использовать константы напрямую по имени:

```raku
say red;   # red
say green; # green
```

За каждым именем стоит число, автоматически назначаемое от нуля в порядке перечисления — `red` равно `0`, `green` равно `1`, `blue` равно `2`. Поскольку значения упорядочены, константы можно сравнивать:

```raku
say red < blue; # True
```

Переменную можно типизировать перечислением, чтобы она принимала только эти константы:

```raku
my Colour $c = green;
say $c; # green
```

Если имя может конфликтовать с чем-то другим в вашей программе, вы всегда можете обратиться к константе через имя перечисления с помощью `::`:

```raku
say Colour::red; # red
```

Перечисление дает набору связанных констант имя и тип, что делает код, использующий их, гораздо понятнее, чем голые числа. В следующей теме рассматриваются [числа, стоящие за именами](/ru/advanced/enumerations/values-and-keys).
