## Задача

Определите перечисление `Coin`, константы которого содержат их стоимость в центах: `penny` равно 1, `nickel` равно 5, `dime` равно 10, а `quarter` равно 25. Используя `.enums`, напечатайте, сколько констант содержит перечисление, а затем напечатайте сумму всех их значений.

## Пример

Программа печатает:

```
4
41
```
