Вот один из возможных вариантов решения задачи.

## Код

```raku
my $n = 987654;

while $n >= 10 {
    $n = [+] $n.comb;
}

say $n;
```

🦋 Исходный код можно найти в файле [digital-root.raku](https://github.com/ash/raku-course/blob/master/exercises/addendum/numbers-math/digital-root.raku).

## Вывод

```
3
```

## Комментарии

1. `$n.comb` разбивает число на отдельные символы-цифры, а `[+]` складывает их, автоматически
превращая строки в числа.

1. Цикл повторяется, пока в результате остаётся больше одной цифры, поэтому он останавливается,
как только `$n` становится меньше `10`.
