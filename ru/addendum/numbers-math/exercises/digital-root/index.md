## Задача

*Цифровой корень* числа получается многократным сложением его цифр, пока не останется одна цифра.
Для `987654`: `9+8+7+6+5+4 = 39`, затем `3+9 = 12`, затем `1+2 = 3`. Вычислите и напечатайте
цифровой корень числа `987654`.

## Пример

Программа печатает:

```
3
```
