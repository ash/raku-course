Вот один из возможных вариантов решения задачи.

## Код

```raku
my $n = 360;
my @factors;

for 2..$n -> $d {
    while $n %% $d {
        @factors.push($d);
        $n div= $d;
    }
}

say @factors;
```

🦋 Исходный код можно найти в файле [prime-factors.raku](https://github.com/ash/raku-course/blob/master/exercises/addendum/numbers-math/prime-factors.raku).

## Вывод

```
[2 2 2 3 3 5]
```

## Комментарии

1. Для каждого кандидата в делители `$d` внутренний `while` выделяет его из `$n` столько раз,
сколько тот помещается, добавляя `$d` в список при каждом делении. Поскольку меньшие множители
удаляются первыми, любое `$d`, на которое `$n` ещё делится, гарантированно простое.

1. `$n div= $d` — это целочисленное деление обратно в `$n`; оно уменьшает число, пока не останется
одна `1`.
