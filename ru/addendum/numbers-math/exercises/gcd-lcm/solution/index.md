Вот один из возможных вариантов решения задачи.

## Код

```raku
my ($a, $b) = 24, 36;

my $g = $a gcd $b;

say "gcd = $g";
say "lcm = { $a * $b div $g }";
```

🦋 Исходный код можно найти в файле [gcd-lcm.raku](https://github.com/ash/raku-course/blob/master/exercises/addendum/numbers-math/gcd-lcm.raku).

## Вывод

```
gcd = 12
lcm = 72
```

## Комментарии

1. `gcd` — встроенный инфиксный оператор, поэтому `$a gcd $b` сразу даёт наибольший общий делитель.

1. Наименьшее общее кратное — это произведение двух чисел, делённое на их НОД; оно вычисляется
прямо внутри интерполяции `{ ... }` с помощью целочисленного деления `div`.
