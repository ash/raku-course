## Задача

Во многих языках программирования допустимый идентификатор начинается с буквы или подчёркивания
и продолжается буквами, цифрами или подчёркиваниями. Для `count`, `total2`, `2fast`, `my-var`
и `_hidden` напечатайте, является ли каждый из них допустимым идентификатором по этому
классическому правилу.

(Сам Raku щедрее: `my-var` — вполне допустимый идентификатор Raku. Этот вариант тоже разобран
на странице решения.)

## Пример

Программа печатает:

```
count: valid
total2: valid
2fast: invalid
my-var: invalid
_hidden: valid
```
