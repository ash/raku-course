## Задача

Приведите в порядок следующую строку так, чтобы пробелы в начале и в конце исчезли, а каждый
промежуток внутри стал одним пробелом. Напечатайте результат.

```raku
my $messy = '  too    many     spaces   ';
```

## Пример

Программа печатает:

```
too many spaces
```
