## Задача

Напишите класс `Stack` с методами, которые кладут значение на вершину, снимают верхнее значение,
подглядывают на вершину, не снимая её, и сообщают размер. Положите `1`, `2`, `3`, затем напечатайте
результат подглядывания, снятия и запроса размера.

## Пример

Программа печатает:

```
3
3
2
```
