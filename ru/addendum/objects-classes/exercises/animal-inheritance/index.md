## Задача

Создайте базовый класс `Animal` с полем `name` и методом `greet`, который сообщает, что говорит
животное. Подклассы `Dog` и `Cat` определяют каждый свой звук. Пусть поздороваются `Dog` по имени
`Rex` и `Cat` по имени `Tom`.

## Пример

Программа печатает:

```
Rex says Woof
Tom says Meow
```
