## Задача

Напишите класс `Account` с балансом `balance`, начинающимся с `0`, методом `deposit` и методом
`withdraw`, который отказывает (с сообщением), когда денег не хватает. Внесите `100`, снимите `30`,
попробуйте снять `200`, а затем напечатайте баланс.

## Пример

Программа печатает:

```
declined: insufficient funds
70
```
