## Задача

Напишите класс `Vector` с полями `x` и `y` и методом `add`, возвращающим *новый* вектор — сумму
двух. Добавьте ему метод `Str`, чтобы он печатался как `(x, y)`. Сложите `(1, 2)` и `(3, 4)`
и напечатайте результат.

## Пример

Программа печатает:

```
(4, 6)
```
