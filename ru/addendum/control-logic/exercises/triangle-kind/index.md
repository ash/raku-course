## Задача

По трём длинам сторон определите, образуют ли они равносторонний, равнобедренный
или разносторонний треугольник — или же не образуют треугольника вовсе, когда самая длинная
сторона слишком велика. Классифицируйте `(3, 3, 3)`, `(3, 3, 5)`, `(3, 4, 5)` и `(1, 2, 10)`.

## Пример

Программа печатает:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
