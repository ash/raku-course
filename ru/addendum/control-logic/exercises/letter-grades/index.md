## Задача

Превратите каждый из баллов `95`, `82`, `71` и `58` в буквенную оценку: `A` — за 90 и выше,
`B` — за 80–89, `C` — за 70–79, `D` — за 60–69 и `F` — за всё, что ниже. Напечатайте каждый балл
вместе с его оценкой.

## Пример

Программа печатает:

```
95 -> A
82 -> B
71 -> C
58 -> F
```
