## Задача

Напишите подпрограмму, которая начинает накопление с заданного значения и возвращает функцию,
прибавляющую при каждом вызове очередное число к текущей сумме и возвращающую новую сумму.
Начните со `100`, затем прибавьте `10`, `25` и `-5`, печатая каждый результат.

## Пример

Программа печатает:

```
110
135
130
```
