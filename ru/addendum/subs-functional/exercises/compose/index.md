## Задача

Напишите подпрограмму `compose`, которая принимает две функции и возвращает новую функцию,
применяющую их одну за другой: сначала вторую, затем первую. Скомпонуйте «удвоить» с «прибавить
единицу», а затем вызовите результат на `5` (получится `12`).

## Пример

Программа печатает:

```
12
```
