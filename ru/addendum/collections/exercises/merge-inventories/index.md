## Задача

Два магазина хранят свои запасы в хешах: `apples => 3, pears => 2`
и `apples => 4, plums => 5`. Объедините их в один, складывая количества для ключей, которые
встречаются в обоих. Напечатайте результат, отсортированный по ключу, парами `ключ: сумма`,
разделёнными запятыми.

## Пример

Программа печатает:

```
apples: 7, pears: 2, plums: 5
```
