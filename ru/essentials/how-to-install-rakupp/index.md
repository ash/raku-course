Raku++ распространяется через свой сайт [raku.online](https://raku.online) и свой
репозиторий на GitHub — [github.com/ash/rakupp](https://github.com/ash/rakupp). После
установки у вас появится единственный исполняемый файл под названием `rakupp` — больше
настраивать нечего, поскольку у Raku++ нет отдельной виртуальной машины, которую надо было
бы устанавливать.

## Установщик

В macOS, Linux и системах BSD одна команда скачивает сборку для вашего компьютера,
проверяет её и добавляет `rakupp` в ваш `PATH`. Права администратора для этого не нужны:

```console
$ curl -fsSL https://raku.online/install.sh | sh
```

В Windows вместо этого выполните следующую команду в окне PowerShell или скачайте мастер
установки `rakupp-setup-windows-x64.exe` со страницы релизов репозитория:

```console
> irm https://raku.online/install-windows.ps1 | iex
```

Установщик спросит, хотите ли вы, чтобы Raku++ был доступен ещё и под именем `raku`.
После установки откройте новое окно терминала, чтобы новый `PATH` вступил в силу. Позже
команда `rakupp upgrade` обновит его до самого свежего выпуска.

## Другие способы установки

* В macOS через Homebrew: `brew tap ash/rakupp && brew install rakupp`.
* Через Docker, ничего не устанавливая: команда `docker run --rm -it ghcr.io/ash/rakupp`
  запускает интерактивную оболочку REPL.
* Готовые архивы для каждой платформы лежат на странице релизов репозитория.
* Так как Raku++ написан на C++, вы можете собрать его и самостоятельно из исходного кода;
  в репозитории описано, какие инструменты для этого нужны.

## Номера версий

Узнать, какая у вас версия, можно с помощью опции `--version`:

```console
$ rakupp --version
Raku++ 5.4.1 (2026-10-13) arm64-darwin
```

Эта строка сообщает выпуск самого Raku++ (`5.4.1`), дату его сборки и платформу, для
которой собран исполняемый файл. Версия языка Raku — это отдельная вещь, и её можно
узнать у самого языка:

```console
$ rakupp -e 'say $*RAKU.version'
v6.d
```

Сравните это с приветственной строкой версии Rakudo на странице
[установки Rakudo](/ru/essentials/how-to-install-rakudo), чтобы увидеть, как каждый
из компиляторов представляется.
