Чтобы выполнить программу на Raku, вам потребуется установленный компилятор. В этом курсе используется Rakudo; другой компилятор, [Raku++](/ru/essentials/the-rakupp-compiler), устанавливается [отдельно](/ru/essentials/how-to-install-rakupp). Зайдите на [сайт Rakudo](https://rakudo.org), чтобы скачать версию, подходящую для вашей операционной системы.

## Исходники

Установщик для вашей системы можно скачать на странице [rakudo.org/downloads](https://rakudo.org/downloads). Существуют версии для всех основных операционных систем: Windows, Mac OS и Linux. Есть и исходные коды, которые вы можете собрать самостоятельно.

## Docker-образы

Rakudo доступен и в виде docker-образа. Его можно использовать как для запуска программ, так и для проверки небольших скриптов в оболочке REPL. Все инструкции вы найдёте на [github.com/Raku/docker](https://github.com/Raku/docker).

## Номера версий

Система нумерации версий Rakudo составляет номер версии из двух частей: года и месяца даты выпуска. Так вы сразу видите, насколько свеж ваш компилятор. Выполните следующую команду, чтобы увидеть номер версии:

```console
$ raku -v
Welcome to 𝐑𝐚𝐤𝐮𝐝𝐨™ v2026.06.
Implementing the 𝐑𝐚𝐤𝐮™ programming language v6.d.
Built on MoarVM version 2026.06.
```

Здесь видно три номера версий. Первый — это версия самого Rakudo: `v2026.06`. Затем идёт версия языка Raku: `v6.d`. Обновления пока получают следующую букву в качестве младшей части версии, например `v6.e` и так далее. Наконец, мы видим название виртуальной машины, которую использует этот компилятор: MoarVM версии `2026.06`.
