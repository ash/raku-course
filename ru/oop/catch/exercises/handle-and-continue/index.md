## Задача

Пройдите циклом по трём элементам: `ok`, `bad` и `ok`. Для каждого выполните блок, который
печатает `processed <элемент>`, но делает `die 'boom'`, когда элемент равен `bad`. Поместите
внутрь блока фазер `CATCH`, чтобы сбойный элемент отмечался как `skipped (<элемент>):
<сообщение>`, а цикл продолжался со следующего элемента, а не останавливался.

## Пример

Программа печатает:

```
processed ok
skipped (bad): boom
processed ok
```
