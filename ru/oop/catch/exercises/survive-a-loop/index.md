## Задача

Пройдите циклом по числам `1`, `2` и `3`. Для каждого числа печатайте `ok: <n>`, но когда число
равно `2`, выполняйте `die "bad: 2"`. Добавьте внутрь тела цикла фазер `CATCH`, который печатает
`caught: <сообщение>`, чтобы одна сбойная итерация не останавливала весь цикл.

## Пример

Программа печатает:

```
ok: 1
caught: bad: 2
ok: 3
```
