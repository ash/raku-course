Процедура `dir` возвращает записи каталога — каждую в виде объекта пути. Их порядок не
фиксирован, поэтому результат обычно сортируют, чтобы вывод был предсказуемым.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Программа печатает имена файлов в каталоге `box` по порядку:

```
a.txt
b.txt
```

Каждая запись — это полноценный объект пути; метод `basename` даёт только последнее имя,
без части с каталогом. У объекта пути можно спросить всё то же, что и раньше — `.f`, `.d`,
`.e`, — так что можно, например, пройти по каталогу и отобрать только файлы.
