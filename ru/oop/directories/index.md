Для работы с самой файловой системой — проверки того, что существует, и создания каталогов —
Raku использует _объекты пути_. Любую строку можно превратить в такой объект методом `.IO`,
и объект пути затем отвечает на вопросы об этом пути.

Чаще всего спрашивают, существует ли путь и что именно по нему находится:

```raku
spurt 'greeting.txt', 'hi';

say 'greeting.txt'.IO.e; # True  — существует ли?
say 'greeting.txt'.IO.f; # True  — это файл?
say 'greeting.txt'.IO.d; # False — это каталог?
```

`.e` проверяет существование, `.f` — обычный ли это файл, а `.d` — каталог ли это.

Чтобы создать новый каталог, используйте `mkdir`:

```raku
mkdir 'reports';
say 'reports'.IO.d; # True
```

Следующая тема показывает, как узнать, что содержится в каталоге.
