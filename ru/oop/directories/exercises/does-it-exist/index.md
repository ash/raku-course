## Задача

Прежде чем что-либо создавать, напечатайте, существует ли файл `test.txt`. Затем создайте его
и напечатайте, существует ли он теперь. Один и тот же путь должен сначала сообщить `False`,
а потом `True`.

## Пример

Программа печатает:

```
False
True
```
