## Задача

Создайте файл `a.txt`. Затем задайте *одному и тому же* пути два вопроса: обычный ли это файл
(`.f`) и каталог ли это (`.d`)? Напечатайте оба ответа, чтобы увидеть, что для одного пути эти
две проверки дают противоположные результаты.

## Пример

Программа печатает:

```
True
False
```
