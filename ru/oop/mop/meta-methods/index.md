_Метаметод_ вызывается через `.^`, а не через `.`. Обычный `.method` выполняет метод объекта,
а `.^method` вызывает метод у **метаобъекта** объекта — он спрашивает о типе, а не действует
как тип.

Вы уже встречали `.^name`, который возвращает имя типа:

```raku
say 42.^name; # Int
```

Другие метаметоды исследуют устройство типа. `.^attributes` перечисляет его атрибуты,
а `.^find_method` сообщает, существует ли метод:

```raku
class Animal {
    has $.name;
    method speak { 'generic' }
}

say Animal.^attributes.elems;          # 1
say so Animal.^find_method('speak');   # True
say so Animal.^find_method('fly');     # False
```

`.^mro` возвращает _порядок разрешения методов_ — цепочку типов, которые Raku по очереди
просматривает при поиске метода. Это линия наследования класса:

```raku
class A {}
class B is A {}

say B.^mro.map(*.^name); # (B A Any Mu)
```

`B` наследует от `A`, а всякий тип в конечном счёте — от `Any` и `Mu`, поэтому вызов метода
у объекта `B` ищется ровно по этому пути. Эти метаметоды превращают устройство ваших типов
в данные, которые можно запрашивать во время выполнения.
