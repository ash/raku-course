Вот один из возможных вариантов решения задачи.

## Код

```raku
class A {
}

class B is A {
}

class C is B {
}

say C.^mro.map(*.^name);
```

🦋 Исходный код можно найти в файле [the-mro.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/mop/the-mro.raku).

## Вывод

```
(C B A Any Mu)
```

## Комментарии

1. `.^mro` возвращает цепочку типов, которые Raku просматривает при разрешении метода.

1. Цепочка идёт по линии наследования шаг за шагом: `C`, затем его родитель `B`, затем родитель
`B` — `A`, и наконец `Any` и `Mu`, которыми заканчивается всякий тип. Более глубокая иерархия
просто делает список длиннее.
