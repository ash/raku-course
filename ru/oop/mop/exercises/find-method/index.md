## Задача

Определите класс `Animal` с методом `speak` и класс `Dog`, который наследует от `Animal`,
но не добавляет собственных методов. С помощью метаметода у `Dog` напечатайте, есть ли у `Dog`
метод по имени `speak` (просто `True` или `False`). Это показывает, что `find_method` просматривает
цепочку наследования, а не только собственные методы класса.

## Пример

Программа печатает:

```
True
```
