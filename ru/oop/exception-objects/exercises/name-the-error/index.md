## Задача

Напишите подпрограмму `risky`, которая делает `die 'sub failed'`. Затем вызовите её изнутри
блока, в котором есть фазер `CATCH`. `CATCH` должен напечатать имя типа исключения (через
`.^name`), а затем его сообщение (через `.message`). Это показывает, что `CATCH` обрабатывает
исключения, брошенные кодом, который блок *вызывает*, а не только `die`, написанный прямо
в блоке.

## Пример

Программа печатает:

```
X::AdHoc
sub failed
```
