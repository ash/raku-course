## Задача

У встроенных ошибок есть собственные типы исключений, которые можно сопоставлять. Напишите блок,
который вычисляет `1 / 0` и пытается воспользоваться результатом, из-за чего бросается
`X::Numeric::DivideByZero`. В фазере `CATCH` этого блока сопоставьте этот конкретный тип через
`when X::Numeric::DivideByZero` и напечатайте `cannot divide by zero`.

## Пример

Программа печатает:

```
cannot divide by zero
```
