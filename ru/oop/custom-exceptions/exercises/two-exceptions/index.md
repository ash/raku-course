## Задача

Определите два собственных класса исключений, `TooSmall` и `TooBig`, каждый наследующий
от `Exception`, с методами `message`, возвращающими соответственно `too small` и `too big`.

Пройдите циклом по этим двум типам и для каждого бросьте исключение этого типа внутри
собственного блока. Возьмите фазер `CATCH` с ветвью `when` для каждого типа, печатающей `small`
для `TooSmall` и `big` для `TooBig`. Так вы увидите, что задействуются обе ветви.

## Пример

Программа печатает:

```
small
big
```
