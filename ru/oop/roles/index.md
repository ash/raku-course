_Роль_ — это набор поведения (а иногда и данных), который могут разделять несколько классов.
Если наследование говорит, что класс _является_ разновидностью другого, то роль описывает то,
что класс _умеет делать_.

Роль определяется ключевым словом `role`, во многом как класс, и передаётся классу трейтом
`does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Теперь у класса `Person` есть метод `hello` из роли — так, как если бы он был написан в самом
классе:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Класс, выполняющий роль, распознаётся как обладающий этой ролью:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Обратите внимание, что метод `hello` из роли использует `self.name`, хотя у самой роли нет
атрибута `name`. И это нормально: метод выполняется как часть того класса, который включает
эту роль, а `name` предоставляет уже класс. Следующая тема показывает, что класс может брать
на себя сразу несколько ролей.
