## Задача

Определите роль `Sized` с методом `describe`, который возвращает строку `size is <размер>`,
используя `self.size`.

Затем определите класс `Box`, который выполняет роль `Sized` и имеет атрибут `size`. Создайте
коробку размера `10`, напечатайте результат вызова у неё `describe`, а второй строкой
напечатайте, верно ли `~~ Sized` для этой коробки, то есть распознаётся ли она как выполняющая
роль.

## Пример

Программа печатает:

```
size is 10
True
```
