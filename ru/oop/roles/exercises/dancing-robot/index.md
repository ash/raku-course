## Задача

Определите класс `Robot`, метод `speak` которого возвращает `beep`. Определите роль `Dancing`,
добавляющую метод `dance`, который возвращает `spinning around`.

Создайте двух роботов, но роль `Dancing` дайте только одному из них. Напечатайте результат
`speak` для обоих роботов, а затем результат `dance` для того робота, который умеет танцевать.

## Пример

Программа печатает:

```
beep
beep
spinning around
```
