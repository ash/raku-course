## Задача

Определите класс `Counter` с единственным атрибутом `count`, который можно изменять (`is rw`)
и который по умолчанию равен `0`.

Создайте счётчик и сначала напечатайте его `count`, чтобы убедиться, что он начинается
со значения по умолчанию. Затем увеличьте его пять раз в цикле и напечатайте итоговое значение.

## Пример

Программа печатает:

```
0
5
```
