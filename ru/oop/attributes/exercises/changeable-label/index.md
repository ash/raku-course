## Задача

Определите класс `Label` с единственным атрибутом `text`, который можно изменять (`is rw`).
Создайте метку с текстом `draft`, затем **допишите** к её тексту ` (revised)` через аксессор —
не создавая объект заново — и напечатайте результат.

## Пример

Программа печатает:

```
draft (revised)
```
