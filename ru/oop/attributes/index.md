Пустой класс не слишком полезен. Чтобы объект мог нести собственные данные, классу дают
_атрибуты_. Атрибут объявляется внутри класса ключевым словом `has`:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Каждый объект класса получает собственную копию этих атрибутов. Их значения задаются при
создании объекта: они передаются в `new` как именованные аргументы:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

Запись `$.` в `has $.name` делает сразу две вещи: объявляет атрибут и создаёт одноимённый
метод — _аксессор_, — который возвращает значение атрибута:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Разные объекты хранят собственные значения, независимо друг от друга:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Следующие темы показывают, как сделать атрибуты изменяемыми и как задать им значения
по умолчанию. (Есть также способ объявить _приватные_ атрибуты, скрытые снаружи; мы вернёмся
к нему, когда будут введены методы.)
