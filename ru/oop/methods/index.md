Атрибуты дают объекту данные; _методы_ дают ему поведение. Метод — это подпрограмма, которая
принадлежит классу и вызывается у объекта. Объявляется он ключевым словом `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

Метод вызывается у объекта через точку, точно так же, как аксессор:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Внутри метода объект, у которого метод был вызван, доступен как `self`. К атрибутам обращаются
через их аксессоры, записываемые как `$.name`, `$.age` и так далее. Они работают
и в интерполируемых строках:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```

Следующие темы посвящены приватным атрибутам (теперь, когда у нас есть методы, чтобы ими
пользоваться), методам с параметрами и методам, вызывающим другие методы.
