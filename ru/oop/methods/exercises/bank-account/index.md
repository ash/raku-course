## Задача

Определите класс `Robot` с изменяемым атрибутом `position`, по умолчанию равным `0`, и методом
`move`, который продвигает позицию на заданное число шагов. Сделайте так, чтобы число шагов
по умолчанию равнялось `1` — тогда вызов `move` без аргумента сдвигает робота на один шаг.

Создайте робота, переместите его на `5` шагов, затем вызовите `move` без аргумента, затем
переместите ещё на `2` шага и напечатайте его итоговую позицию.

## Пример

Программа печатает:

```
8
```
