## Задача

Определите класс `Celsius` с атрибутом `degrees` и методом `to-fahrenheit`, который переводит
температуру в градусы Фаренгейта по формуле `degrees × 9 / 5 + 32`.

Создайте объект `Celsius` для `100` градусов и напечатайте его значение по Фаренгейту.

## Пример

Программа печатает:

```
212
```
