Читать или записывать файл целиком удобно, но иногда нужно пройти по файлу строка за строкой
или держать файл открытым, многократно в него записывая. Для этого используется _файловый
дескриптор_.

Самый простой способ читать файл построчно не требует даже явного дескриптора: метод `lines`
у объекта пути выдаёт строки по одной, готовые для цикла `for`:

```raku
spurt 'words.txt', "one\ntwo\nthree\n";

for 'words.txt'.IO.lines -> $line {
    say $line.uc;
}
```

Каждая `$line` — это одна строка, без завершающего перевода строки. Программа печатает:

```
ONE
TWO
THREE
```

Чтобы писать в файл через дескриптор, откройте его с помощью `open` и флага `:w` (запись),
пользуйтесь методами `say` или `print` дескриптора, а по окончании закройте его через `close`:

```raku
my $fh = open 'out.txt', :w;
$fh.say('first line');
$fh.say('second line');
$fh.close;
```

Закрытие дескриптора гарантирует, что всё записанное сброшено на диск. Построчное чтение,
как выше, — это обычный способ работать с файлами, которые слишком велики, чтобы целиком
затянуть их в память.
