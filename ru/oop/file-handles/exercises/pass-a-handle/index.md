## Задача

Файловый дескриптор — обычное значение, поэтому его можно передать в функцию, как и любой
другой аргумент. Напишите подпрограмму `log-line`, которая принимает дескриптор и сообщение
и записывает сообщение в дескриптор на отдельной строке.

Откройте `log.txt` на запись, трижды вызовите `log-line`, чтобы записать `started`, `working`
и `done`, затем закройте дескриптор, прочитайте файл обратно и напечатайте его содержимое.

## Пример

Программа печатает:

```
started
working
done
```
