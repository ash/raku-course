## Задача

Откройте файл `out.txt` на запись. Не закрывая дескриптор, запишите в него в цикле числа `1`,
`2` и `3`, каждое на своей строке. Затем закройте дескриптор, прочитайте файл обратно
и напечатайте его содержимое.

## Пример

Программа печатает:

```
1
2
3
```
