## Задача

Запишите три слова — `apple`, `banana` и `cherry`, каждое на своей строке, — в файл `words.txt`.
Затем прочитайте файл построчно и напечатайте каждую строку с её номером (начиная с `1`)
в виде `<номер>: <строка>`.

## Пример

Программа печатает:

```
1: apple
2: banana
3: cherry
```
