## Задача

Напишите подпрограмму `reciprocal`, которая возвращает `1`, делённую на свой аргумент, но при
аргументе `0` вызывает `fail` с сообщением `no reciprocal of zero`.

Напечатайте результат `reciprocal(4)`. Затем напечатайте результат `reciprocal(0)`, но
воспользуйтесь оператором `//`, чтобы при сбое подставить строку `undefined`, вместо того чтобы
самостоятельно проверять `.defined`.

## Пример

Программа печатает:

```
0.25
undefined
```
