## Задача

Напишите подпрограмму `lookup`, которая возвращает `100`, когда её аргумент равен `'a'`,
и в остальных случаях вызывает `fail` с сообщением `no such key`.

Вызовите `lookup('z')` и напечатайте результат, если он определён. Если нет — напечатайте
`not found`, а второй строкой причину сбоя, взятую из самого `Failure` (`reason: <сообщение>`).

## Пример

Программа печатает:

```
not found
reason: no such key
```
