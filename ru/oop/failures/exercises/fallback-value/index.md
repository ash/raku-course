## Задача

Напишите подпрограмму `get`, которая возвращает свой аргумент, но при аргументе `0` вызывает
`fail` с сообщением `bad`.

Используя оператор `//` («определённое или») для подстановки запасного значения `default`,
напечатайте результат `get(5)`, а затем `get(0)`.

## Пример

Программа печатает:

```
5
default
```
