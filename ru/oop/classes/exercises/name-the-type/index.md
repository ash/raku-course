## Задача

Определите два пустых класса, `Cat` и `Dog`, и создайте экземпляр `Cat` по имени `$felix`.
Напечатайте тип `$felix` с помощью `WHAT`. Затем на двух следующих строках напечатайте,
совпадает ли этот тип с `Cat` и совпадает ли он с `Dog`, используя оператор `===`.

## Пример

Программа печатает:

```
(Cat)
True
False
```
