## Задача

Определите два пустых класса, `Cat` и `Dog`. Затем пройдите циклом по четырём значениям —
`Cat`, `Dog`, `Cat.new` и `Dog.new` — печатая для каждого, определено ли оно. Обратите внимание,
что оба объекта типа не определены, а оба экземпляра определены, независимо от того, какому
классу они принадлежат.

## Пример

Программа печатает:

```
False
False
True
True
```
