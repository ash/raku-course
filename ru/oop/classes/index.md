До сих пор все типы данных, которыми вы пользовались, — числа, строки, массивы и так далее —
были встроены в Raku. _Объектно-ориентированное программирование_ позволяет определять
собственные типы, называемые _классами_, и создавать значения этих типов, называемые
_объектами_.

Класс определяется ключевым словом `class`, за которым следуют имя и блок:

```raku
class Dog {
}
```

Этот класс `Dog` пока пуст, но он уже является новым типом. Чтобы создать объект класса —
_экземпляр_ — вызовите метод `new` у имени класса:

```raku
class Dog {
}

my $rex = Dog.new;
say $rex; # Dog.new
```

Теперь переменная `$rex` содержит объект `Dog`. Каждый вызов `new` создаёт отдельный объект:

```raku
my $rex = Dog.new;
my $fido = Dog.new;
```

`$rex` и `$fido` — две разные собаки, хотя у класса пока нет никакого содержимого.
В следующих разделах вы дадите классу собственные данные (_атрибуты_) и собственное поведение
(_методы_). Первая тема подробнее рассматривает разницу между классом и его экземплярами.
