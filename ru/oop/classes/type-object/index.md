Когда вы пишете имя класса, например `Dog`, вы обращаетесь к _объекту типа_ этого класса.
Объект типа представляет сам тип, а не какой-то конкретный объект этого типа. _Экземпляр_,
созданный с помощью `new`, — это настоящий объект.

Raku умеет их различать. Метод `defined` возвращает `False` для объекта типа и `True`
для экземпляра:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Объект типа считается _неопределённым_, потому что не содержит конкретных данных — это лишь
описание типа. Экземпляр же _определён_: это настоящий объект.

Оба сообщают один и тот же тип через `WHAT`, с которым вы встречались
в [разделе о контейнерах](/ru/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Круглые скобки вокруг `(Dog)` — это принятый в Raku способ показать тип. Итак, `Dog`
и `Dog.new` имеют один и тот же тип `Dog`; разница в том, что одно — это сам тип, а другое —
объект этого типа.
