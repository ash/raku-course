## Задача

С помощью `run` с `:out` запустите `echo` с тремя словами `hello world raku`, перехватите его
вывод в переменную, а затем — вместо того чтобы просто напечатать его — посчитайте, сколько слов
содержит перехваченный вывод, и напечатайте это число.

## Пример

Программа печатает:

```
3
```
