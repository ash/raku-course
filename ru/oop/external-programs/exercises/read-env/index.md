## Задача

Создайте файл `notes.txt` и запишите в него несколько строк. Поместите его имя в переменную
окружения `NOTES`. Затем с помощью `shell` запустите `wc -l`, беря имя файла из `$NOTES`, чтобы
потомок посчитал строки и напечатал их число. Наконец, удалите файл средствами Raku —
через `unlink`, а не через оболочку.

## Пример

Программа печатает:

```
3
```

(и не оставляет после себя `notes.txt`).
