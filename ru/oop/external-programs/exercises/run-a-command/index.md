## Задача

С помощью `run` запустите `echo` с двумя отдельными аргументами: `home:` и `$HOME`. Пусть его
вывод идёт на экран. Обратите внимание, что `$HOME` появляется буквально, а домашний каталог
**не** печатается: раз `run` обходится без оболочки, подстановки переменной не происходит.

## Пример

Программа печатает:

```
home: $HOME
```
