## Задача

Запустите команду, которая нарочно завершается неудачей, — например `sh -c 'exit 4'` —
и сохраните возвращённый ею `Proc`. Напечатайте код возврата команды, а затем напечатайте
`success` или `failure` в зависимости от того, удалась ли команда.

## Пример

Программа печатает:

```
4
failure
```
