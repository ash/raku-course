Какая функция передаёт свою команду через системную **оболочку**, позволяя использовать
конвейеры и перенаправление?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` передаёт одну строку оболочке, которая разбирает такие возможности, как конвейеры.
`run` запускает программу напрямую, с отдельными аргументами и без оболочки, что безопаснее
и лучше подходит в качестве варианта по умолчанию.

</div>
