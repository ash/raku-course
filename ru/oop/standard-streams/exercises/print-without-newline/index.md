## Задача

Используя дескриптор стандартного вывода `$*OUT`, напечатайте буквы `a` и `b` с помощью `print`
(который не добавляет перевод строки), а затем букву `c` с помощью `say`. Все три буквы должны
оказаться на одной строке.

## Пример

Программа печатает:

```
abc
```
