## Задача

Программа обрабатывает значение, которое оказывается отрицательным. Используйте `note`, чтобы
отправить предупреждение в стандартный поток ошибок, когда значение меньше нуля, и `say`, чтобы
отправить настоящий результат — его абсолютное значение — в стандартный вывод. Возьмите значение
`-3`.

## Пример

На экране появляются обе строки:

```
Warning: the value is negative
3
```

Если отбросить стандартный поток ошибок, останется только результат:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
