## Задача

Определите базовый класс `Employee` с атрибутом `name`, методом `role`, возвращающим `'staff'`,
и методом `badge`, который возвращает строку `<имя> - <роль>` (используя собственный `role`).

Затем определите два дочерних класса, `Manager` и `Intern`, которые наследуют от `Employee`
и переопределяют `role`, возвращая `'manager'` и `'intern'` соответственно.

Напечатайте бейдж менеджера по имени `Anna` и стажёра по имени `Bob`.

## Пример

Программа печатает:

```
Anna - manager
Bob - intern
```
