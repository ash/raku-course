В [разделе о контейнерах](/ru/advanced/containers) вы использовали `.^name`, чтобы спросить
у значения его тип. Те же метавызовы через `.^` позволяют исследовать класс и его объекты:
их имена, их атрибуты и место в иерархии.

Метаметод `.^name` возвращает имя класса:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметод `.^attributes` перечисляет атрибуты класса. Каждый показан со своим типом
и внутренним приватным именем (та самая форма `$!`, с которой вы встречались
в [приватных атрибутах](/ru/oop/methods/private-attributes)):

```raku
say Dog.^attributes; # (Str $!name)
```

Интроспекция полезна для инструментов, работающих с объектами обобщённо, — например, чтобы
напечатать все атрибуты объекта, не зная заранее его класса. Следующая тема показывает,
как увидеть цепочку наследования класса.
