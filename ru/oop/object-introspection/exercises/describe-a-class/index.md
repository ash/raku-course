## Задача

Определите базовый класс `Animal` и класс `Dog`, который от него наследует. Затем напечатайте
имя класса `Dog`, а на следующей строке — количество типов в его цепочке наследования
(используйте `.^mro` и посчитайте её элементы). Наконец, третьей строкой напечатайте, встречается
ли где-нибудь в этой цепочке класс с именем `Cat`.

## Пример

Программа печатает:

```
Dog
4
False
```
