## Задача

Постройте небольшой файл журнала, многократно дописывая в него. Запишите строку `start` в файл
`log.txt`, затем в цикле **допишите** ещё три строки — `entry 1`, `entry 2` и `entry 3`, —
не стирая того, что уже там есть. Наконец, прочитайте файл целиком и напечатайте его.

## Пример

Программа печатает:

```
start
entry 1
entry 2
entry 3
```
