## Задача

Сохраните число в файл и загрузите его обратно. Запишите число `42` (с переводом строки в конце)
в файл `number.txt`. Затем прочитайте файл, превратите его содержимое в целое число
и напечатайте это число, умноженное на два.

## Пример

Программа печатает:

```
84
```
