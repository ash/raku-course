Вот один из возможных вариантов решения задачи.

## Код

```raku
spurt 'number.txt', "42\n";

my $n = slurp('number.txt').trim.Int;
say $n * 2;
```

🦋 Исходный код можно найти в файле [save-and-read.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/files/save-and-read.raku).

## Вывод

```
84
```

## Комментарии

1. `spurt` создаёт файл и записывает в него строку; `slurp` читает весь файл обратно в строку.
Вместе они дают полный цикл «сохранить и загрузить».

1. То, что возвращает `slurp`, — это текст, `"42\n"`, поэтому мы отсекаем завершающий перевод
строки через `trim` и вызываем `.Int`, чтобы превратить его в число перед арифметикой. Результат
`42 * 2` равен `84`.

1. Впрочем, программа работает и без `.trim.Int`.
