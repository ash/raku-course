Проще всего работать с файлом, читая или записывая его целиком.

Процедура `spurt` записывает строку в файл, создавая его (или заменяя содержимое, если файл
уже существует):

```raku
spurt 'greeting.txt', "Hello, file!\n";
```

Процедура `slurp` читает всё содержимое файла обратно в строку:

```raku
my $text = slurp 'greeting.txt';
print $text; # Hello, file!
```

Вместе `spurt` и `slurp` позволяют сохранить данные и снова их загрузить двумя короткими
вызовами. (Здесь используется `print`, а не `say`, потому что текст уже заканчивается переводом
строки.)

Такие операции над файлом целиком идеальны, когда файл достаточно мал, чтобы спокойно уместиться
в памяти. Для файлов побольше или когда файл нужно обрабатывать построчно, используется
[файловый дескриптор](/ru/oop/file-handles), которому посвящён конец этого раздела. Следующая
тема показывает, как дописывать в файл, а не заменять его.
