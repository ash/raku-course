По умолчанию `spurt` заменяет всё, что было в файле. Чтобы вместо этого дописать в конец
существующего файла, передайте именованный аргумент `:append`:

```raku
spurt 'log.txt', "line1\n";
spurt 'log.txt', "line2\n", :append;

print slurp 'log.txt';
```

Второй `spurt` сохраняет прежнее содержимое и добавляет новую строку после него, поэтому в файле
оказываются обе строки:

```
line1
line2
```

Без `:append` второй вызов перезаписал бы файл, оставив только `line2`. Дописывание полезно,
например, для журналов, где каждый запуск программы добавляет записи к растущей летописи,
а не начинает её заново.
