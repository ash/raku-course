## Задача

Блок `try`, давший сбой, вычисляется в неопределённое значение. Воспользуйтесь этим вместе
с оператором `//` («определённое или»), чтобы подставить запасной вариант: выполните блок `try`,
который делает `die 'no'`, и, если он даст сбой, возьмите вместо результата строку `default`.
Напечатайте результат.

## Пример

Программа печатает:

```
default
```
