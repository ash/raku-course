## Задача

Покажите обе стороны `try`. Сначала оберните в блок `try` вычисление, которое проходит успешно
(например, `6 * 7`), и напечатайте его результат. Затем возьмите второй блок `try` вокруг кода,
который выполняет `die 'broken'`; напечатайте, дал ли этот блок определённый результат,
и напечатайте сообщение перехваченного исключения.

## Пример

Программа печатает:

```
42
False
broken
```
