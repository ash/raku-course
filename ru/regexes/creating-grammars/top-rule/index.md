Когда вы разбираете строку грамматикой, Raku начинает с токена по имени `TOP`. Это точка входа —
описание **всего** ввода. Всё остальное в грамматике существует ради него.

Токен `TOP` обычно ссылается на другие токены по имени, разбивая задачу на меньшие части:

```raku
grammar Pair {
    token TOP   { <key> '=' <value> }
    token key   { \w+ }
    token value { \w+ }
}
```

Прочитайте `TOP` вслух: «ключ, затем знак равенства, затем значение». Токены `key` и `value`
говорят, как выглядит каждая из этих частей. В этом разделении и весь смысл грамматики: у каждого
токена одна небольшая, ясно названная работа, а `TOP` собирает их вместе.

`TOP` — всего лишь соглашение, которого придерживается `.parse`; остальные токены можно называть
как угодно. Выбранные вами имена становятся ещё и именованными захватами в результате, поэтому
хорошо названная грамматика даёт самоописывающее дерево совпадений — как вы вскоре увидите.
