## Задача

Напишите грамматику, разбирающую время вида `час:минута:секунда`, где каждая из трёх частей —
вереница цифр. Разберите ею `'09:30:45'` и напечатайте захваченные секунды.

## Пример

Программа печатает:

```
｢45｣
```
