Вот один из возможных вариантов решения задачи.

## Код

```raku
say 'https://example' ~~ / http | https /;
```

🦋 Исходный код можно найти в файле [http-or-https.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/alternations/http-or-https.raku).

## Вывод

```
｢https｣
```

## Комментарии

1. В начале строки подошли бы и `http`, и `https`, но `|` использует сопоставление по самому
длинному токену.

1. Поэтому побеждает более длинное `https`, хотя `http` записан первым.

## Другой вариант решения

Эти два слова различаются лишь конечной `s`, поэтому вместо альтернативы можно сделать эту `s`
необязательной с помощью квантификатора `?`:

```raku
say 'https://example' ~~ / https? /; # ｢https｣
```

Знак `?` связывается только с тем атомом, который стоит прямо перед ним, — с буквой `s`, — а не
со всем словом, поэтому `https?` читается как `http`, за которым идёт необязательная `s`. Один
этот шаблон подходит и для `http`, и для `https`, и, будучи жадным, он берёт `s` всякий раз,
когда она есть.
