Разделите два или более варианта вертикальной чертой `|`. Шаблон совпадает, если совпадает
**любой** из них:

```raku
say 'no thanks' ~~ / yes | no /; # ｢no｣
```

Шаблон попробовал `yes` и `no`; в строке есть `no`, оно и совпало.

Вариантов можно перечислить сколько угодно:

```raku
say 'the sky is blue' ~~ / red | green | blue /; # ｢blue｣
```

Вариантами может быть любой подшаблон, а не только буквальные слова: в них могут входить классы
символов, квантификаторы и захваты. Чтобы удержать альтернативу как единое целое внутри большего
шаблона, сгруппируйте её квадратными скобками `[ ]`, которые
[группируют **без** захвата](/ru/regexes/captures/non-capturing):

```raku
say 'cathouse' ~~ / [ cat | dog ] house /; # ｢cathouse｣
```

Здесь альтернатива `cat | dog` — одна единица, за которой должно следовать `house`.
