Что выведет следующая программа? Обратите внимание, что `so` здесь нет, а сопоставление
использует форму `m/.../`.

```raku
say 'the cat sat' ~~ m/sat/;
```

{:.quiz}
0 | True
0 | False
1 | ｢sat｣
0 | Nil

{% include quiz.html %}

<div class="extended-explanation">

`m/sat/` сопоставляет так же, как это сделало бы `/sat/`. Без `so`, приводящего результат
к логическому значению, умное сопоставление возвращает сам объект совпадения, который `say`
печатает в угловых кавычках как `｢sat｣`.

</div>
