## Задача

Сопоставьте буквальный текст `base` в строке `'database'`. Не присваивайте результат переменной;
вместо этого возьмите совпадение из автоматической переменной совпадения `$/` и напечатайте
**только совпавший текст** как обычную строку (не в угловых кавычках).

## Пример

Программа печатает:

```
base
```
