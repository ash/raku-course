Вот один из возможных вариантов решения задачи.

## Код

```raku
'database' ~~ /base/;
say $/.Str;
```

🦋 Исходный код можно найти в файле [matched-text.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/matching/matched-text.raku).

## Вывод

```
base
```

## Комментарии

1. Всякое умное сопоставление сохраняет свой результат в специальной переменной совпадения `$/`,
поэтому присваивать его собственной переменной не нужно.

1. Объект совпадения хранит совпавший текст; вызов `.Str` у `$/` возвращает этот текст как
обычную строку. Печать самого объекта совпадения показала бы вместо этого `｢base｣`.
