Вот один из возможных вариантов решения задачи.

## Код

```raku
my $m = 'abc9x2z' ~~ /\d/;
say $m.from;
say $m.to;
```

🦋 Исходный код можно найти в файле [where-digit.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/matching/where-digit.raku).

## Вывод

```
3
4
```

## Комментарии

1. Класс `\d` соответствует одной цифре. Движок останавливается на **первой** найденной — это `9`
на индексе `3` (позиции считаются от нуля); до более поздней `2` дело не доходит.

1. `.from` даёт начало совпадения, `3`, а `.to` — позицию сразу за его концом, `4`. Разность
`.to - .from` равна длине совпадения — здесь одному символу.
