## Задача

Покажите, какую разницу создаёт возврат назад. Объявите **один и тот же** шаблон — одну или более
цифр, за которыми идёт буквальная `5`, — дважды: один раз как `regex`, другой как `token`.
Сопоставьте каждый со строкой `'12345'` и напечатайте для каждого простое `True` или `False`.

## Пример

Программа печатает:

```
True
False
```
