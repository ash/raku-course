Какое ключевое слово стоит взять для именованного шаблона, который должен сопоставлять
**пробельные символы** между своими частями — так, как это записано в шаблоне?

{:.quiz}
0 | `regex`
0 | `token`
1 | `rule`
0 | `grammar`

{% include quiz.html %}

<div class="extended-explanation">

`rule` — это `token` с включёнными значимыми пробелами, поэтому пробелы, записанные между его
частями, должны присутствовать во вводе. Обычный `token` эти пробелы игнорирует, как и `regex`
(который вдобавок возвращается назад).

</div>
