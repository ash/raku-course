Что выведет следующая программа? Шаблон записан прописными буквами, а текст — в смешанном
регистре.

```raku
say 'Hello' ~~ /:i HELLO/;
```

{:.quiz}
1 | ｢Hello｣
0 | ｢HELLO｣
0 | True
0 | False

{% include quiz.html %}

<div class="extended-explanation">

Наречие `:i` отключает различие прописных и строчных букв, и работает это в обе стороны — здесь
шаблон из прописных букв `HELLO` совпадает с текстом в смешанном регистре. Результат — совпавший
текст в том виде, в каком он есть в строке: `｢Hello｣`.

</div>
