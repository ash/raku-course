## Задача

Строка `'Grace Hopper'` состоит из имени и фамилии, разделённых пробелом. Захватите каждое слово,
а затем напечатайте имя в порядке `Фамилия, Имя` — фамилия, запятая с пробелом, затем имя.

Подстановка для этого не нужна: захватите слова и напечатайте их через интерполяцию строк.

## Пример

Программа печатает:

```
Hopper, Grace
```
