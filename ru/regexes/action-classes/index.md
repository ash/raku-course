Встроенные блоки `{ make … }` работают, но захламляют грамматику логикой и делают её труднее для
чтения. Аккуратное решение — _класс действий_: отдельный класс, методы которого названы по токенам
грамматики и выполняют `make` для каждого из них.

В этом разделе показано, как написать класс действий, как передать его в `.parse` и когда его
стоит предпочесть встроенным действиям.
