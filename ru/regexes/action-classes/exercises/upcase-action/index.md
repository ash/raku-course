## Задача

Напишите грамматику, сопоставляющую одно слово `word` (один или более словесных символов).
Напишите **класс действий**, метод `TOP` которого делает форму этого слова **в верхнем регистре**.
Разберите `'hello'` с этим классом действий и напечатайте `.made`.

## Пример

Программа печатает:

```
HELLO
```
