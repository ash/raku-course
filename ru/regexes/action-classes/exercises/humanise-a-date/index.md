## Задача

Напишите грамматику, разбирающую дату в формате ISO, например `'2026-07-05'`, на три токена:
`year`, `month` и `day`. Напишите **класс действий**, в котором метод каждого токена делает
(`make`) значение: `year` и `day` делают своё число как целое, а `month` делает **английское
название месяца** (`1` → `January`, …, `12` → `December`). Метод `TOP` затем читает эти три
значения через `.made` и делает человекочитаемую строку вроде `'5 July 2026'`. Разберите
`'2026-07-05'` с этим классом действий и напечатайте `.made`.

## Пример

Программа печатает:

```
5 July 2026
```
