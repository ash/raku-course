Вот один из возможных вариантов решения задачи.

## Код

```raku
say 'say "hi" and "bye"' ~~ / '"' .+? '"' /;
```

🦋 Исходный код можно найти в файле [frugal-match.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/quantifiers/frugal-match.raku).

## Вывод

```
｢"hi"｣
```

## Комментарии

1. Знак `?` после `.+` делает квантификатор экономным, поэтому он берёт как можно меньше
символов.

1. Из-за этого он останавливается на первой закрывающей `"`, захватывая только `"hi"`. Жадный
`.+` дотянулся бы до последней `"` и совпал бы с `"hi" and "bye"`.
