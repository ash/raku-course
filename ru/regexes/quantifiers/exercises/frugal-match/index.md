## Задача

Строка `'say "hi" and "bye"'` содержит два куска в кавычках. Напишите шаблон, который
с помощью экономного квантификатора находит **только первый** из них — от первой `"` до ближайшей
`"`. Напечатайте совпадение.

## Пример

Программа печатает:

```
｢"hi"｣
```
