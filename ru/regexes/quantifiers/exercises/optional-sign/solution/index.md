Вот один из возможных вариантов решения задачи.

## Код

```raku
say '-42' ~~ / '-'? \d+ /;
```

🦋 Исходный код можно найти в файле [optional-sign.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/quantifiers/optional-sign.raku).

## Вывод

```
｢-42｣
```

## Комментарии

1. Часть `'-'?` соответствует необязательному знаку минус — нулю или одному такому знаку.

1. Затем `\d+` сопоставляет вереницу цифр. Тот же шаблон подойдёт и для числа без знака,
например `42`.
