Вот один из возможных вариантов решения задачи.

## Код

```raku
my $d = '2025-06-15';
$d ~~ s/ (\d+) '-' (\d+) '-' (\d+) /$2\/$1\/$0/;
say $d;
```

🦋 Исходный код можно найти в файле [reformat-date.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/substitution/reformat-date.raku).

## Вывод

```
15/06/2025
```

## Комментарии

1. Шаблон захватывает год в `$0`, месяц в `$1`, а день в `$2`.

1. Замена выписывает их в новом порядке — `$2/$1/$0`, — а косые черты экранированы как `\/`.
По краям замены пробелов нет, потому что там они вставились бы буквально.
