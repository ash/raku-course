## Задача

Строка `'2025-06-15'` — это дата в порядке `год-месяц-день`. С помощью захватов в подстановке
перепишите её в порядке `день/месяц/год`: `15/06/2025`. Напечатайте результат.

## Пример

Программа печатает:

```
15/06/2025
```
