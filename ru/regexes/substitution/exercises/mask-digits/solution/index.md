Вот один из возможных вариантов решения задачи.

## Код

```raku
my $orig = 'PIN 1234';
say S:g/\d/#/ given $orig;
say $orig;
```

🦋 Исходный код можно найти в файле [mask-digits.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/substitution/mask-digits.raku).

## Вывод

```
PIN ####
PIN 1234
```

## Комментарии

1. Оператор `S///` с заглавной буквы делает ту же работу, что и `s///`, но **возвращает новую
строку** вместо изменения переменной на месте. С `:g` он заменяет в возвращаемой копии каждую
цифру `\d` на `#`. К `$orig` он применяется через `given`, который делает строку темой.

1. Печать `$orig` после этого показывает, что там по-прежнему `PIN 1234`: в отличие от `s///`,
оригинал остался нетронутым.
