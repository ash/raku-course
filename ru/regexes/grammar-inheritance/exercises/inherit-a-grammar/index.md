## Задача

Напишите базовую грамматику `Animal`, чей `TOP` сопоставляет токен `sound` (любое слово). Затем
напишите две грамматики, наследующие от неё: `Dog`, которая переопределяет `sound` на `woof`,
и `Cat`, которая переопределяет его на `meow`. Разберите `'woof'` грамматикой `Dog`, `'meow'`
грамматикой `Cat` и — чтобы показать, что каждая держится своего звука, — ещё и `'meow'`
грамматикой `Dog`. Напечатайте, удался ли каждый разбор.

## Пример

Программа печатает:

```
True
True
False
```
