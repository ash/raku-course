## Задача

Напишите грамматику, разбирающую `bool`, который является либо словом `true`, либо словом
`false`. Используйте **proto-токен** с двумя вариантами `:sym<…>`. Разберите `'true'`, `'false'`,
а также `'unknown'` (который не подходит ни под один вариант), напечатав, удался ли каждый
разбор.

## Пример

Программа печатает:

```
True
True
False
```
