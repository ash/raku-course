Вот один из возможных вариантов решения задачи.

## Код

```raku
say 'I love Raku' ~~ / 'love Raku' /;
```

🦋 Исходный код можно найти в файле [match-a-word.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/literals/match-a-word.raku).

## Вывод

```
｢love Raku｣
```

## Комментарии

1. Пробел между словами здесь значим, поэтому фраза заключена в кавычки: `'love Raku'`.
Без кавычек движок регулярных выражений проигнорировал бы пробел и искал бы `loveRaku`, чего
в строке нет.

1. Умное сопоставление возвращает объект совпадения, охватывающий всю фразу в кавычках, — его
`say` и печатает в угловых кавычках.
