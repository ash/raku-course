## Задача

Используя один из предопределённых классов символов с обратной косой чертой, напишите шаблон,
соответствующий первому символу, который **не** является цифрой, в строке `'42abc'`. Напечатайте
совпадение.

## Пример

Программа печатает:

```
｢a｣
```
