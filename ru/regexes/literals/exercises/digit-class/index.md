## Задача

Один класс символов может объединять несколько диапазонов. Напишите класс, соответствующий одному
символу, который является либо строчной буквой, **либо** цифрой, и найдите с его помощью первый
такой символ в строке `'  @x7'` (она начинается с пробелов и знака `@`). Напечатайте совпадение.

Не используйте предопределённый класс вроде `\w` — выпишите диапазоны сами.

## Пример

Программа печатает:

```
｢x｣
```
