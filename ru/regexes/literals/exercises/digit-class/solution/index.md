Вот один из возможных вариантов решения задачи.

## Код

```raku
say '  @x7' ~~ / <[a..z 0..9]> /;
```

🦋 Исходный код можно найти в файле [digit-class.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/literals/digit-class.raku).

## Вывод

```
｢x｣
```

## Комментарии

1. Класс может содержать несколько диапазонов подряд. `<[a..z 0..9]>` соответствует одному
символу, который является строчной буквой **или** цифрой. Пробел между диапазонами стоит лишь
для удобочитаемости: `<[a..z0..9]>` означает ровно то же самое, потому что пробелы внутри
`<[…]>` игнорируются, как и везде в регулярном выражении.

1. Просматривая строку слева, два пробела и `@` в класс не входят и пропускаются; первым
подходящим символом оказывается `x`. (Этот составной класс близок к тому, что обозначает
сокращение `\w`.)
