Что выведет следующая программа?

```raku
say 'a_1 b' ~~ /\W/;
```

{:.quiz}
0 | ｢a｣
0 | ｢_｣
0 | ｢1｣
1 | ｢ ｣

{% include quiz.html %}

<div class="extended-explanation">

Класс `\W` соответствует первому символу, который **не** является буквой, цифрой или
подчёркиванием. Символы `a`, `_` и `1` — все словесные, поэтому первым несловесным оказывается
пробел.

</div>
