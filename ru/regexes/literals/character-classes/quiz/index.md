Что выведет следующая программа? Класс здесь **отрицающий**.

```raku
say 'abc123' ~~ / <-[a..z]> /;
```

{:.quiz}
1 | ｢1｣
0 | ｢a｣
0 | ｢abc｣
0 | False

{% include quiz.html %}

<div class="extended-explanation">

Класс `<-[a..z]>` соответствует одному символу, который **не** является строчной буквой. Просматривая
`abc123` слева направо, первые три символа — строчные буквы, и они пропускаются; первый символ,
не являющийся строчной буквой, — это цифра `1`, поэтому совпадение равно `｢1｣`.

</div>
