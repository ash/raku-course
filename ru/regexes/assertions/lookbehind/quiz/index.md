Что выведет следующая программа?

```raku
say 'a=5' ~~ / <?after '='> \d+ /;
```

{:.quiz}
1 | ｢5｣
0 | ｢=5｣
0 | ｢a=5｣
0 | False

{% include quiz.html %}

<div class="extended-explanation">

Положительный просмотр назад `<?after '='>` требует, чтобы непосредственно перед текущей позицией
стоял `=`, а затем `\d+` сопоставляет цифры. Знак `=` проверяется, но не поглощается, поэтому
совпадение — только `｢5｣`.

</div>
