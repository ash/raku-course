## Задача

Строка `'5 and $9'` содержит два числа: обычное `5` и цену `$9`. С помощью **отрицательного
просмотра назад** напишите шаблон, который сопоставляет число, только если непосредственно перед
ним **нет** знака `$`. Напечатайте совпадение.

## Пример

Программа печатает:

```
｢5｣
```
