Вот один из возможных вариантов решения задачи.

## Код

```raku
say '5 and $9' ~~ / <!after '$'> \d+ /;
```

🦋 Исходный код можно найти в файле [bare-number.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/assertions/bare-number.raku).

## Вывод

```
｢5｣
```

## Комментарии

1. `<!after '$'>` — это отрицательный просмотр назад: он срабатывает, только если символ прямо
перед текущей позицией **не** является `$`. Этого соседа он проверяет, не поглощая.

1. Цифра `9` отвергается, потому что стоит сразу после `$`, поэтому движок сопоставляет более
раннее `5`, перед которым ничего нет.
