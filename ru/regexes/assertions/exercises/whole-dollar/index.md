## Задача

Соедините просмотр назад и просмотр вперёд, чтобы сопоставить **целую долларовую** сумму: цифры,
идущие сразу после `$` и **не** сопровождаемые десятичной точкой. Так `$50` подходит (даёт `50`),
а `$3.99` — нет, потому что там есть центы.

Используйте положительный просмотр назад для `$` и отрицательный просмотр вперёд для `.`,
а после цифр добавьте границу слова `>>`, чтобы число сопоставлялось целиком. Напечатайте
совпадение для `'$50'`.

## Пример

Программа печатает:

```
｢50｣
```
