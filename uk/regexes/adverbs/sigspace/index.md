Усередині регексу пробіли зазвичай ігноруються — вони потрібні лише для того, щоб шаблон легше читався. Саме тому `/foo bar/` збігається з `foobar`. Проте інколи ви справді хочете, щоб пробіл у шаблоні означав «тут є пробільний символ». Прислівник `:s` (скорочення від `:sigspace`, «значущий пробіл») робить саме це:

```raku
say so 'foo    bar' ~~ /:s foo bar/; # True
say so 'foobar'     ~~ /:s foo bar/; # False
```

З `:s` пробіл між `foo` та `bar` у шаблоні вимагає пробільного символу між двома словами в рядку. Годиться один або більше пробілів (чи табуляцій), тож послідовність пробілів у `'foo    bar'` теж підходить.

Значущі пробіли стають особливо важливими у граматиках, де вони дозволяють писати шаблони, що читаються як мова, яку ви розбираєте. Ви ще зустрінете їх як різницю між `token` та `rule`.
