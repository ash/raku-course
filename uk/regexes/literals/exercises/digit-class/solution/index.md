Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
say '  @x7' ~~ / <[a..z 0..9]> /;
```

🦋 Вихідний код можна знайти у файлі [digit-class.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/literals/digit-class.raku).

## Вивід

```
｢x｣
```

## Коментарі

1. Клас може містити кілька діапазонів, один за одним. `<[a..z 0..9]>` збігається з одним символом, що є малою літерою **або** цифрою. Пробіл між двома діапазонами стоїть лише для читності — `<[a..z0..9]>` означає точно те саме, бо пробіли всередині `<[…]>` ігноруються, як і всюди в регексі.

1. Скануючи зліва, два пробіли та `@` не належать до класу й пропускаються; першим відповідним символом є `x`. (Цей поєднаний клас близький до того, що позначає скорочення `\w`.)
