Що виведе наведена програма?

```raku
say 'a_1 b' ~~ /\W/;
```

{:.quiz}
0 | ｢a｣
0 | ｢_｣
0 | ｢1｣
1 | ｢ ｣

{% include quiz.html %}

<div class="extended-explanation">

Клас `\W` збігається з першим символом, який **не** є літерою, цифрою чи підкресленням. Символи `a`, `_` та `1` усі є словесними, тож першим несловесним символом є пробіл.

</div>
