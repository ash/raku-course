Деякі класи символів настільки поширені, що Raku дає їм короткі імена. Їх записують зі зворотною косою рискою:

* `\d` — цифра
* `\w` — «словесний» символ: літера, цифра або підкреслення
* `\s` — пробільний символ (пробіл, табуляція, перехід рядка)

```raku
say 'order 66' ~~ /\d/; # ｢6｣
say 'a_b'      ~~ /\w/; # ｢a｣
say '  hi'     ~~ /\s/; # ｢ ｣
```

Кожен із них має партнера у верхньому регістрі, що збігається з **протилежним** набором:

* `\D` — усе, що не є цифрою
* `\W` — усе, що не є словесним символом
* `\S` — усе, що не є пробільним символом

```raku
say '  hi' ~~ /\S/; # ｢h｣
```

Нарешті, одна крапка `.` збігається з **будь-яким** символом узагалі:

```raku
say 'abc' ~~ /./; # ｢a｣
```

Ці наперед визначені класи заощаджують чимало набирання, і ви користуватиметеся ними постійно в решті цієї частини.
