Що виведе наведена програма? Клас тут **заперечний**.

```raku
say 'abc123' ~~ / <-[a..z]> /;
```

{:.quiz}
1 | ｢1｣
0 | ｢a｣
0 | ｢abc｣
0 | False

{% include quiz.html %}

<div class="extended-explanation">

Клас `<-[a..z]>` збігається з одним символом, який **не** є малою літерою. Скануючи `abc123` зліва, перші три символи є малими літерами й пропускаються; першим символом, що не є малою літерою, є цифра `1`, тож збігом стає `｢1｣`.

</div>
