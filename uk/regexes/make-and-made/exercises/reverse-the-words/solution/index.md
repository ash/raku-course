Ось одне з можливих розв'язань задачі.

## Код

```raku
grammar Phrase {
    token TOP  { <word> [ ' ' <word> ]* { make $<word>».made.join(' ') } }
    token word { \w+ { make $/.flip } }
}

say Phrase.parse('hello world').made;
```

🦋 Знайдіть програму у файлі [reverse-the-words.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/make-and-made/reverse-the-words.raku).

## Вивід

```
olleh dlrow
```

## Коментарі

1. Кожен токен `word` створює власний перевернутий текст: його вбудований блок виконується щоразу, коли слово зіставляється, а `make $/.flip` зберігає слово — `$/` є поточним збігом — записане навпаки.

1. `TOP` зіставляється зі словами за допомогою `<word> [ ' ' <word> ]*` — одне слово, а потім будь-яка кількість «пробіл, потім слово» — і поєднує їх. `$<word>` є списком усіх збігів слів; `».made` витягає перевернутий текст, збережений кожним із них, а `.join(' ')` відбудовує фразу з пробілами.

1. Форма «елемент, потім елемент, потім елемент…» трапляється достатньо часто, щоб мати скорочення: розділювач `%`. Запис `<word>+ % ' '` означає «одне або більше `<word>`, розділених пробілом» і зіставляється точно з тими самими фразами, що й `<word> [ ' ' <word> ]*`, — просто компактніше.

1. Тож `make` та `made` працюють тут на двох рівнях: дрібні шматки створюють свої значення, а ціле створюється з них. Читання `.made` на результаті дає `olleh dlrow`.
