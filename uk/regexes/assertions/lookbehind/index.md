_Огляд назад_ перевіряє, що стоїть безпосередньо **перед** поточною позицією:

* `<?after …>` — успішний, якщо текст позаду збігається (стверджувальний огляд назад)
* `<!after …>` — успішний, якщо текст позаду **не** збігається (заперечний огляд назад)

Це дозволяє зіставити щось лише через те, що йому передує, не включаючи цей префікс у результат. Наприклад, захопимо цифри, що йдуть після знака долара, залишивши `$` поза збігом:

```raku
if '$100' ~~ / <?after '$'> \d+ / {
    say $/; # ｢100｣
}
```

Твердження `<?after '$'>` вимагає, щоб просто перед поточною позицією стояв `$`, а потім `\d+` зіставляється з цифрами. Збігом є `100`, без знака долара.

Огляд уперед і огляд назад часто поєднують. Шматок тексту, обгорнутий у `<?after …>` та `<?before …>`, збігається лише тоді, коли стоїть між потрібними сусідами, — зручний спосіб видобути значення з відомого контексту.
