Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
if 'Grace Hopper' ~~ / (\w+) ' ' (\w+) / {
    say "$1, $0";
}
```

🦋 Вихідний код можна знайти у файлі [swap-words.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/captures/swap-words.raku).

## Вивід

```
Hopper, Grace
```

## Коментарі

1. Ім'я та прізвище захоплюються в `$0` та `$1`.

1. Усередині рядка з подвійними лапками кожне захоплення інтерполюється як зіставлений із ним текст. Виведення `"$1, $0"` ставить прізвище першим, за ним — літеральні кому й пробіл, а потім ім'я.
