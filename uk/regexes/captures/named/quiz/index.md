Що виведе наведена програма?

```raku
if 'ab12cd' ~~ / (\w+) (\d+) / {
    say "$0 $1";
}
```

{:.quiz}
0 | ab 12
1 | ab1 2
0 | ab12 cd
0 | 12 ab

{% include quiz.html %}

<div class="extended-explanation">

Жадібний `\w+` зіставляється зі словесними символами настільки далеко, наскільки може, все ще лишаючи `\d+` бодай одну цифру. Він бере `ab1`, а `\d+` далі зіставляється з єдиною цифрою `2`, що лишилася. Тож `$0` є `ab1`, а `$1` є `2`.

</div>
