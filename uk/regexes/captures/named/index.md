Пронумеровані захоплення зручні, але, коли шаблон розростається, імена зрозуміліші за числа. Щоб дати захопленню ім'я, запишіть `$<ім'я>=( … )`:

```raku
if 'Anna:30' ~~ / $<name>=(\w+) ':' $<age>=(\d+) / {
    say $<name>; # ｢Anna｣
    say $<age>;  # ｢30｣
}
```

До захоплених шматків тепер дістаються за іменем через `$<name>` та `$<age>` замість `$0` і `$1`. Це те саме, що записати `$/<name>`, бо імена живуть усередині змінної збігу `$/`.

Іменовані захоплення роблять шаблон схожим на опис самих даних:

```raku
if 'x=5' ~~ / $<key>=(\w+) '=' $<value>=(\w+) / {
    say "key is $<key>, value is $<value>"; # key is x, value is 5
}
```

Як і позиційне, кожне іменоване захоплення є об'єктом збігу, тож `$<age>.Str` дає звичайний текст, а `$<age>.from` — його позицію.
