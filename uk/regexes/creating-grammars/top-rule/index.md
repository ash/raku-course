Коли ви розбираєте рядок граматикою, Raku починає з токена з іменем `TOP`. Це точка входу — опис **усього** вхідного тексту. Усе інше в граматиці існує, щоб його підтримати.

Токен `TOP` зазвичай посилається на інші токени за іменем, розбиваючи задачу на дрібніші частини:

```raku
grammar Pair {
    token TOP   { <key> '=' <value> }
    token key   { \w+ }
    token value { \w+ }
}
```

Прочитайте `TOP` уголос: «ключ, потім знак рівності, потім значення». Токени `key` та `value` кажуть, який вигляд має кожна з цих частин. Цей поділ і є всім сенсом граматики — кожен токен має одну невелику, чітко названу роботу, а `TOP` збирає їх докупи.

`TOP` — лише домовленість, яку забезпечує `.parse`; інші токени можна називати як завгодно. Вибрані вами імена стають також іменованими захопленнями в результаті, тож граматика з гарними іменами дає самоописове дерево збігів, як ви незабаром побачите.
