Оператором, який застосовує регекс до рядка, є розумне зіставлення `~~`:

```raku
say 'the cat sat' ~~ /cat/; # ｢cat｣
```

Шаблон, записаний між скісними рисками, є найпоширенішою формою, але є ще дві, що означають те саме й іноді зрозуміліші:

```raku
say 'the cat sat' ~~ m/cat/;  # ｢cat｣
say 'the cat sat' ~~ rx/cat/; # ｢cat｣
```

Форма `m/.../` підкреслює, що ви _зіставляєте_, і стає в пригоді, коли до зіставлення хочеться додати параметри (з цими параметрами, які називають [_наріччями_](/uk/regexes/adverbs), ви познайомитеся згодом). Форма `rx/.../` створює значення-регекс, ще не зіставляючи його.

Дуже часто вам важливо лише, чи рядок збігся, а не що саме знайдено. Оскільки успішний збіг є істинним значенням, а невдалий — хибним, результат можна використовувати просто в булевому контексті. Найчистіший спосіб отримати звичайні `True` чи `False` — функція `so`:

```raku
say so 'the cat sat' ~~ /cat/; # True
say so 'the cat sat' ~~ /dog/; # False
```

Це робить регекс природною умовою для `if`:

```raku
if 'the cat sat' ~~ /cat/ {
    say 'found it';   # found it
}
```
