Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
'database' ~~ /base/;
say $/.Str;
```

🦋 Вихідний код можна знайти у файлі [matched-text.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/matching/matched-text.raku).

## Вивід

```
base
```

## Коментарі

1. Кожне розумне зіставлення зберігає свій результат у спеціальній змінній збігу `$/`, тож присвоювати його власній змінній не потрібно.

1. Об'єкт збігу містить текст, що збігся; виклик `.Str` для `$/` повертає цей текст як звичайний рядок. Виведення самого об'єкта збігу натомість показало б `｢base｣`.
