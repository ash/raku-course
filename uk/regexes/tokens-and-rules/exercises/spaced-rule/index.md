## Завдання

Напишіть граматику, чий `TOP` є **правилом** (`rule`), що зіставляється з трьома словами, розділеними пробілами. Кожне слово — це токен з одного або більше словесних символів. Розберіть `'the quick fox'` і надрукуйте, чи це вдалося (просте `True` або `False`).

## Приклад

Програма друкує:

```
True
```
