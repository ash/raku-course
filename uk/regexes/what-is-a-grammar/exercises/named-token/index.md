## Завдання

Оголосіть іменований регекс `word`, що зіставляється з одним або більше словесних символів. Потім використайте його (як `<word>`) для зіставлення з рядком `'hello world'` і надрукуйте захоплене слово.

## Приклад

Програма друкує:

```
｢hello｣
```
