Ось одне з можливих розв'язань задачі.

## Код

```raku
my regex year  { \d ** 4 }
my regex month { \d ** 2 }

if '2025-06' ~~ / <year> '-' <month> / {
    say $<year>;
    say $<month>;
}
```

🦋 Знайдіть програму у файлі [year-token.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/what-is-a-grammar/year-token.raku).

## Вивід

```
｢2025｣
｢06｣
```

## Коментарі

1. Оголошено два іменовані регекси, кожен із яких описує один шматок дати: чотирицифровий `year` та двоцифровий `month`.

1. Шаблон поєднує їх, ставлячи між ними літеральний дефіс, і кожен захоплюється під власним іменем. Побудова більшого шаблону з дрібних іменованих частин — це саме та ідея, яку формалізує граматика.
