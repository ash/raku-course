## Завдання

Напишіть шаблон, який зіставляється з будь-яким із трьох слів розміру: `small`, `medium` чи `large`. Перевірте його на `'a large pizza'` і виведіть збіг.

## Приклад

Програма виводить:

```
｢large｣
```
