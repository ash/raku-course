Що виведе наведена програма? Зверніть увагу на квантифікатор `*` при `a`.

```raku
say 'br' ~~ / b a* r /;
```

{:.quiz}
1 | ｢br｣
0 | ｢bar｣
0 | False
0 | ｢b｣

{% include quiz.html %}

<div class="extended-explanation">

`*` означає «нуль чи більше», тож `a*` цілком радо зіставляється взагалі без жодного `a`. У `br` між `b` та `r` немає `a`, але шаблон усе одно збігається, бо нуль повторень дозволено, даючи `｢br｣`.

</div>
