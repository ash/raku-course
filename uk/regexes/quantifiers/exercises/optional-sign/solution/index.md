Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
say '-42' ~~ / '-'? \d+ /;
```

🦋 Вихідний код можна знайти у файлі [optional-sign.raku](https://github.com/ash/raku-course/blob/master/exercises/regexes/quantifiers/optional-sign.raku).

## Вивід

```
｢-42｣
```

## Коментарі

1. Частина `'-'?` збігається з необов'язковим знаком мінус — нулем або одним таким знаком.

1. Далі `\d+` збігається з низкою цифр. Той самий шаблон збігається й з числом без знака, як-от `42`.
