## Завдання

Напишіть граматику, що розбирає `number`, який може бути або десятковим цілим числом (одна чи більше цифр), або шістнадцятковим літералом (`0x`, за яким ідуть шістнадцяткові цифри `0`–`9`, `a`–`f`). Скористайтеся **прототокеном** із двома варіантами `:sym<…>`: `dec` та `hex`. Розберіть `'0xff'` і надрукуйте, чи це вдалося.

## Приклад

Програма друкує:

```
True
```
