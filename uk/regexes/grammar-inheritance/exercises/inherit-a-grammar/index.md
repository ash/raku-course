## Завдання

Напишіть базову граматику `Animal`, чий `TOP` зіставляється з токеном `sound` (будь-яке слово). Потім напишіть дві граматики, що успадковують її: `Dog`, яка перевизначає `sound` на `woof`, і `Cat`, яка перевизначає його на `meow`. Розберіть `'woof'` граматикою `Dog`, `'meow'` граматикою `Cat` і — щоб показати, що кожна зберігає свій власний звук — також `'meow'` граматикою `Dog`. Надрукуйте, чи вдався кожен розбір.

## Приклад

Програма друкує:

```
True
True
False
```
