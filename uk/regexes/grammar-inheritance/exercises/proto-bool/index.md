## Завдання

Напишіть граматику, що розбирає `bool`, який є або словом `true`, або словом `false`. Скористайтеся **прототокеном** із двома варіантами `:sym<…>`. Розберіть `'true'`, `'false'`, а також `'unknown'` (яке не є ні тим, ні тим), друкуючи, чи вдався кожен розбір.

## Приклад

Програма друкує:

```
True
True
False
```
