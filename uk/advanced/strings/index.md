У частині «Основи» ви дізналися, [як будувати рядки](/uk/essentials/strings) — конкатенація, інтерполяція та довжина рядка. Рядки також мають багатий набір методів. Цей розділ збирає найкорисніші з них. (Пошук за [регулярними виразами](/uk/regexes) — окрема, більша тема, розглянута далі у власній частині.)

Три методи змінюють регістр літер рядка:

```raku
say 'raku'.uc; # RAKU  — верхній регістр
say 'RAKU'.lc; # raku  — нижній регістр
say 'raku'.tc; # Raku  — заголовний регістр (перша літера велика)
```

Метод `flip` обертає символи рядка:

```raku
say 'Raku'.flip; # ukaR
```

А оператор `x` повторює рядок задану кількість разів:

```raku
say 'ab' x 3; # ababab
```

Наступні теми показують, як шукати всередині рядків і як розбивати їх на частини та склеювати назад.
