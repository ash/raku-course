У Raku є вбудовані типи для роботи з календарними датами та годинниковим часом. Календарну дату подає тип `Date`. Ви створюєте її, вказавши рік, місяць і день:

```raku
my $d = Date.new(2026, 6, 27);
say $d; # 2026-06-27
```

Маючи дату, можна прочитати її складові:

```raku
my $d = Date.new(2026, 6, 27);
say $d.year;  # 2026
say $d.month; # 6
say $d.day;   # 27
```

Метод `day-of-week` повертає, на який день тижня припадає дата, з нумерацією від `1` для понеділка до `7` для неділі:

```raku
say Date.new(2026, 6, 27).day-of-week; # 6
```

27 червня 2026 року — субота, тож результат — `6`.

Метод `is-leap-year` повідомляє, чи припадає дата на високосний рік:

```raku
say Date.new(2024, 1, 1).is-leap-year; # True
say Date.new(2026, 1, 1).is-leap-year; # False
```

Щоб отримати сьогоднішню дату, викличте `Date.today`. Її вивід ми тут не показуємо, бо він залежить від дня, коли ви запускаєте програму.
