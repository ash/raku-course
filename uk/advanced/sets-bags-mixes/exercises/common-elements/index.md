## Завдання

Вам дано дві множини назв фруктів:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Обчисліть їхній переріз і збережіть його у змінній. Потім виведіть два рядки: скільки значень є спільними для обох множин і чи є `apple` одним із цих спільних значень (не має бути).

## Приклад

Програма виводить:

```
2
False
```
