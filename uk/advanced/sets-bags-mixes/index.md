Окрім масивів і хешів, Raku пропонує кілька спеціалізованих контейнерів для наборів значень. Найпростіший із них — `Set`, невпорядкований набір _різних_ значень, де кожне значення або є членом, або ні, а дублікати ігноруються.

Множина створюється підпрограмою `set`. Повторювані значення злипаються в одне:

```raku
my $s = set(1, 2, 3, 2, 1);
say $s.elems; # 3
```

Хоча передано п'ять чисел, множина має лише три елементи, бо `1` і `2` траплялися більш ніж один раз.

Головне запитання, яке ставлять множині, — чи належить їй значення. Оператор `∈` (читається як «є елементом») повертає булеве значення:

```raku
say 2 ∈ set(1, 2, 3); # True
say 9 ∈ set(1, 2, 3); # False
```

Якщо вам зручніше лишатися в межах чистого ASCII, той самий оператор можна записати як `(elem)`:

```raku
say 2 (elem) set(1, 2, 3); # True
```

Наступні теми показують, як поєднувати множини, і знайомлять із мультимножинами та сумішами — близькими родичами множини.
