## Завдання

URL розбито на частини й збережено в масиві. Склейте частини назад в один рядок за допомогою метаоператора згортки, виведіть отриманий URL, а наступним рядком — його довжину в символах.

## Приклад

Для такого вхідного масиву:

```raku
my @parts = <http :// example .com>;
```

програма виводить:

```
http://example.com
18
```
