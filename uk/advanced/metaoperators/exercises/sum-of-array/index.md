## Завдання

Напишіть програму, яка виводить середнє (середнє арифметичне) масиву чисел. Для додавання значень скористайтеся метаоператором згортки.

Вхідні дані задано просто в програмі, наприклад:

```raku
my @data = 10, 20, 30, 40;
```

## Приклад

Програма виводить середнє значення елементів `@data`:

```
25
```
