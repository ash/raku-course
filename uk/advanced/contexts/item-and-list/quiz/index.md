Що виведе наведена програма?

```raku
my @a = 1, 2, 3;
my $n = 0;
$n++ for $(@a);
say $n;
```

{:.quiz}
0 | 3
1 | 1
0 | 0
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Контекстуалізатор `$( … )` задає штучний контекст, тож масив розглядається як одне значення, а не як список елементів. Отже, цикл `for` бачить один елемент і виконує своє тіло лише раз, залишаючи `$n` рівним `1`. Без `$( )` цикл пройшов би три ітерації.

</div>
