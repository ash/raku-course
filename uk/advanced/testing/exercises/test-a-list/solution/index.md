Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Вихідний код можна знайти у файлі [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Вивід

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Коментарі

1. `plan 2` оголошує кількість до виконання будь-якого тесту, тож рядок `1..2` з'являється першим. Якби файл потім виконав іншу кількість перевірок, набір було б визнано невдалим — запобіжник, якого `done-testing` дати не може.

1. `is-deeply` порівнює два списки на точну рівність з урахуванням типів. Сортування `3, 1, 2` дає `1, 2, 3`, що збігається.

1. `is` порівнює два значення на звичайну рівність і в разі невдачі повідомляє обидва. Тут `10 % 3` дорівнює `1`, що збігається з очікуваним значенням, тож другий тест теж проходить.
