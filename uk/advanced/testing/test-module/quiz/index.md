Яка функція модуля `Test` проходить, коли булева умова істинна?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` приймає умову й проходить, коли вона істинна. `is` порівнює фактичне значення з очікуваним, `plan` каже, скільки тестів очікувати, а `done-testing` завершує файл і видає план.

</div>
