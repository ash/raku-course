Окремий файл тестів є просто програмою на Raku, тож його можна запустити напряму:

```
raku t/01-basic.rakutest
```

Він виводить свій TAP-вивід на екран. Якщо файлів більше ніж один-два, вам знадобиться _запускач тестів_, який виконує цілий каталог тестів і підсумовує результати. Запускачем у Raku є `prove6`:

```
prove6 t/
```

Це виконує кожен файл тестів у каталозі `t/` і повідомляє, скільки файлів і тестів пройшло, з єдиним загальним підсумком «пройдено/не пройдено» наприкінці — це значно легше читати, ніж сирий TAP із кожного файлу.

Коли дистрибутив має `META6.json`, засіб роботи з модулями виконує його тести за вас:

```
zef test .
```

`zef test` знаходить каталог `t/`, виконує набір і повідомляє результат — саме це й відбувається автоматично перед установленням дистрибутива. Тож тести служать подвійно: ви запускаєте їх під час розробки через `prove6`, а екосистема запускає їх, щоб перевірити дистрибутив, перш ніж хтось його встановить.

> Файли тестів іменують із розширенням `.rakutest` (або `.t`) і за угодою нумерують, як-от `t/01-basic.rakutest`.
