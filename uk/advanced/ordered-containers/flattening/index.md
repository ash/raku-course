Коли ви кладете один масив усередину іншого, Raku _не_ зливає їхні елементи автоматично. Розгляньмо таку програму:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

Масив `@c` має лише два елементи — масиви `@a` та `@b`. Raku зберігає кожен контейнер як один елемент, а не висипає його вміст у зовнішній масив. Те саме стається зі значенням, поставленим серед інших:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Коли вам справді потрібна одна плоска послідовність, попросіть про неї явно за допомогою підпрограми `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Штучність

Іноді потрібно протилежне: захистити контейнер від сплощення, навіть усередині `flat`. Конструкція `$(...)` робить свій аргумент _штучним_ — позначає результат як один елемент. Порівняйте попередній приклад із цим:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Тут `$(@a)` зберігає `@a` як один елемент, тоді як `@b` усе одно сплощується у свої два значення. Це знову та сама ідея сигіла `$`: `$` означає «розглядай це як одну річ».
