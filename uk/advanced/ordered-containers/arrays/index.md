Масив — це впорядкований контейнер, елементи якого самі є скалярними контейнерами.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигіл `@` вказує, що така змінна поводиться як об'єкт `Positional`, тож її можна індексувати, щоб дістатися до окремих елементів:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Оскільки кожен елемент є скалярним контейнером, йому можна присвоїти нове значення точно так само, як окремій скалярній змінній:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можна також присвоїти значення іншого типу, наприклад:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Саме це робить масиви _змінюваними_: кожна комірка є контейнером, який може прийняти нове значення. Як ви побачите в наступній темі, [списки](/uk/advanced/ordered-containers/lists) поводяться інакше.
