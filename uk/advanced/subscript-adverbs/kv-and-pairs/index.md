Інші наріччя змінюють те, **що** індекс повертає. За замовчуванням індекс повертає значення; ці повертають більше:

* `:v` — значення (за замовчуванням)
* `:k` — ключ (або індекс)
* `:kv` — і ключ, і значення
* `:p` — `Pair` із ключа та значення

Для масиву «ключем» є індекс:

```raku
my @a = 10, 20, 30;

say @a[1]:kv; # (1 20)
say @a[1]:p;  # 1 => 20
```

`@a[1]:kv` повертає індекс і значення разом як список, а `@a[1]:p` повертає їх як пару.

Те саме працює для хешів і особливо стає в пригоді на зрізі з кількох ключів одразу:

```raku
my %h = a => 1, b => 2, c => 3;

say %h<a c>:kv; # (a 1 c 3)
```

Тут зріз із двох ключів повертається як чергування ключів і значень. Саме на ці наріччя часто спираються `map`, `for` та їхні побратими, коли потрібно обробляти ключі й значення пліч-о-пліч, не розбиваючи роботу на окремі пошуки.
