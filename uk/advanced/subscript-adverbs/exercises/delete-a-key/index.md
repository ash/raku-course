## Завдання

Маючи хеш `a => 1, b => 2, c => 3`, скористайтеся наріччям індексу, щоб видалити запис `b`, а потім виведіть, скільки записів залишилося в хеші, щоб показати, що один було вилучено.

## Приклад

Програма виводить:

```
2
```
