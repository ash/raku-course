Ось можливий розв'язок завдання.

## Код

```raku
say (1, 2, 3).map(sub ($x) { $x * $x });
```

🦋 Ви можете знайти вихідний код у файлі [anonymous-square.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/anonymous-subroutines/anonymous-square.raku).

## Вивід

```
(1 4 9)
```

## Коментарі

1. `sub ($x) { $x * $x }` не має імені й не зберігається у змінній — вона передається прямо в `map` як аргумент.

1. `map` застосовує її до кожного елемента `1, 2, 3`, піднісши їх до квадрата і отримавши `(1 4 9)`. Передача анонімної підпрограми безпосередньо таким чином — найпоширеніша причина для їх написання.
