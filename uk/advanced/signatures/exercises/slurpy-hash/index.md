## Завдання

Напишіть підпрограму `describe`, яка приймає обов'язкове позиційне ім'я, а потім збирає будь-яку кількість іменованих аргументів у всеїдний хеш (`*%opts`). Вона має повертати рядок виду `name: key=value, key=value, ...`, перелічуючи кожен параметр із ключами в алфавітному порядку.

Викличте її як `describe('Anna', colour => 'red', size => 5)` і виведіть результат.

## Приклад

Програма виводить:

```
Anna: colour=red, size=5
```
