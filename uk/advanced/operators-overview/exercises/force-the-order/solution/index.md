Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
say 2 ** (3 + 1);
```

🦋 Вихідний код можна знайти у файлі [force-the-order.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/force-the-order.raku).

## Вивід

```
16
```

## Коментарі

1. Без дужок `**` зв'язувався б міцніше за `+`, даючи `(2 ** 3) + 1 = 9`.

1. Дужки підвищують пріоритет додавання, тож `3 + 1` обчислюється першим і вираз стає `2 ** 4`, що дорівнює `16`. Дужки завжди дозволяють перекрити типовий пріоритет.
