Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Вихідний код можна знайти у файлі [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Вивід

```
True
```

## Коментарі

1. Оператори порівняння можна об'єднувати в ланцюжки, тож `0 <= 73 <= 100` читається як «0 не більше за 73, і 73 не більше за 100». Оператор `<=` дозволяє краї, тож бал рівно `0` чи `100` теж вважався б дійсним.

1. Обидві частини істинні, тож увесь вираз дає `True`. Зверніть увагу, що середнє значення `73` записано лише раз, хоча його порівнюють з обома сусідами.

1. Без можливості будувати ланцюжки довелося б виписати обидва порівняння й з'єднати їх через `&&`, повторивши середнє значення: `0 <= 73 && 73 <= 100`. Ланцюжкова форма каже те саме стисліше.
