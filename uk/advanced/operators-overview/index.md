Коли вираз містить кілька операторів, Raku має вирішити, в якому порядку їх застосовувати. Цим керують два правила: _пріоритет_ і _асоціативність_.

## Пріоритет

Пріоритет визначає, який оператор зв'язується міцніше. Множення має вищий пріоритет за додавання, тож воно відбувається першим:

```raku
say 2 + 3 * 4; # 14
```

Вираз читається як `2 + (3 * 4)`, даючи `14`, а не `20`. Ви завжди можете скористатися дужками, щоб нав'язати інший порядок:

```raku
say (2 + 3) * 4; # 20
```

## Асоціативність

Асоціативність визначає порядок між операторами _однакового_ пріоритету. Віднімання є лівоасоціативним, тож воно групується зліва:

```raku
say 8 - 3 - 2; # 3
```

Це `(8 - 3) - 2`, тобто `3`. Піднесення до степеня, навпаки, є правоасоціативним:

```raku
say 2 ** 3 ** 2; # 512
```

Тут вираз групується як `2 ** (3 ** 2)`, тобто `2 ** 9`, що дорівнює `512`.

## Ланцюжки порівнянь

Оператори порівняння можна об'єднувати в _ланцюжки_, що читається природно й робить те, чого ви очікуєте з математики:

```raku
say 1 < 2 < 3; # True
say 1 < 5 < 3; # False
```

Середнє значення порівнюється з обома сусідами: `1 < 2 < 3` істинне, бо істинні і `1 < 2`, і `2 < 3`.
