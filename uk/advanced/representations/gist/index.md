---
title: Метод `.gist`
---

{% include menu.html %}

Метод `.gist` повертає **зручне для людини** представлення значення — форму, яку ви хотіли б *прочитати*. Саме це друкують `say` (та `note`): вони викликають `.gist` для кожного аргументу.

```raku
say 42.gist;     # 42
say 'Raku'.gist; # Raku
```

Для простих значень gist — це просто саме значення. Для складених даних `.gist` додає невелике форматування, щоб структура залишалася читабельною:

```raku
my @a = 'alpha', 'beta', 'gamma';
say @a.gist; # [alpha beta gamma]
```

Об'єкт типу — значення, що представляє сам тип — відображається як його ім'я в дужках, що дозволяє легко помітити його у виводі:

```raku
say Int.gist; # (Int)
```
