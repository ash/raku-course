title: Вибір правильного методу
---

{% include menu.html %}

Для повсякденних скалярних значень, таких як числа та рядки, усі три представлення виглядають однаково. Вони починають відрізнятися для складених або невизначених значень. Ось `Pair`, показаний трьома способами:

```raku
say (foo => 1).gist; # foo => 1
say (foo => 1).Str;  # foo	1
say (foo => 1).raku; # :foo(1)
```

Загальне правило:

* [`.gist`](../gist) — для виводу, призначеного для *читання* людиною (`say`, `note`).
* [`.Str`](../str) — для виводу, який є *простим текстом* (`print`, `put`, інтерполяція, оператор `~`).
* [`.raku`](../raku-method) — для *подібного до коду* представлення під час налагодження (`dd`).

Кожен із цих методів може мати вашу власну реалізацію, коли ви пишете клас, тому ваші власні об'єкти теж будуть гарно друкуватися. Ми повернемося до цього, коли будемо [створювати класи](/uk/oop/classes) у наступній частині.
