---
title: Метод `.raku`
---

{% include menu.html %}

Третій метод представлення, `.raku`, повертає рядок із **подібним до коду** представленням значення — в ідеалі рядок, який можна вставити назад у програму, щоб відтворити те саме значення. Кожне значення в Raku має цей метод.

```raku
say 42.raku;        # 42
say 'Raku'.raku;    # "Raku"
say (1, 2, 3).raku; # (1, 2, 3)
```

Зверніть увагу, що рядок `'Raku'` повертається з лапками навколо нього, тому ви можете відрізнити число від рядка з першого погляду — саме такі деталі потрібні під час налагодження.

Метод також працює для складених даних, включаючи вкладені структури:

```raku
my @data = 1, [2, 3], 4;
say @data.raku; # [1, [2, 3], 4]
```

Оскільки `.raku` повертає звичайний рядок, ви можете використовувати його будь-де, де очікується рядок, наприклад, всередині інтерпольованого повідомлення:

```raku
my @data = 10, 20, 30;
say "The data is { @data.raku }";
# The data is [10, 20, 30]
```

Використовуйте `.raku`, коли вам потрібне подібне до коду представлення у вигляді рядка для поєднання з вашими власними повідомленнями. Дуже скоро ми познайомимося з `dd`, інструментом Rakudo, який друкує таке саме представлення за один крок.
