Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
my @squares = gather for 1..6 {
    take $_ ** 2 if $_ %% 2;
};

say @squares;
```

🦋 Вихідний код можна знайти у файлі [squares.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/squares.raku).

## Вивід

```
[4 16 36]
```

## Коментарі

1. Умова `if $_ %% 2` вирішує, *чи* брати, а `$_ ** 2` — *що* брати. Цю умову проходять лише парні числа `2`, `4`, `6`.

1. Їхні квадрати `4`, `16`, `36` — єдині значення, передані до `take`, тож `gather` збирає саме їх. Виконання фільтрації й перетворення разом в одному `take` — це те, чого звичайний `map` не виражає так чисто.
