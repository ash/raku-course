## Завдання

`WHAT` не просто описує тип — він повертає сам об'єкт типу, який можна порівняти оператором `===`.

Оголосіть дві змінні: `$a`, що містить ціле число `42`, і `$b`, що містить рядок `'x'`. Для кожної виведіть, чи є її `WHAT` типом `Int`.

## Приклад

Програма виводить:

```
True
False
```
