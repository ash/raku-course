## Завдання

Контейнер може нести типове значення, задане трейтом `is default`. Доки ви нічого не присвоїли, читання змінної повертає це типове значення, а `.VAR.default` повідомляє про нього.

Оголосіть скаляр `$count` із типовим значенням `0`. Нічого йому не присвоюючи, виведіть саму змінну, а потім типове значення її контейнера. Обидва рядки мають показати `0`.

## Приклад

Програма виводить:

```
0
0
```
