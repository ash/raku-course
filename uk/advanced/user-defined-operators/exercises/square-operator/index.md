## Завдання

Символом оператора може бути будь-який знак, зокрема й символ Unicode. Визначте **постфіксний** оператор `²`, який підносить свій операнд до квадрата, так щоб `5²` означало `5 ** 2`. Потім виведіть `5²`.

## Приклад

Програма виводить:

```
25
```
