## Завдання

Напишіть дві мульти-підпрограми з іменем `abs-value`, які приймають ціле число й повертають його абсолютне значення. Скористайтеся реченням `where`, щоб обробити від'ємний випадок окремо, — не використовуйте всередині підпрограм жодного `if` і не використовуйте вбудований `abs`.

Виведіть результат для `-7` та для `4`.

## Приклад

Програма виводить:

```
7
4
```
