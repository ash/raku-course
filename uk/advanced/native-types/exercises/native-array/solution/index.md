Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Вихідний код можна знайти у файлі [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Вивід

```
555
```

## Коментарі

1. Постановка машинного типу фіксованого розміру `uint8` перед масивом із `@` оголошує масив, кожен елемент якого зберігається як один беззнаковий байт, — компактне розміщення, що пасує двійковим даним.

1. Межа загортання стосується кожного *елемента* (`0..255`), а не результату їхнього підсумовування. `.sum` упаковує підсумок у звичайний `Int`, тож `100 + 200 + 255` дає повні `555`.
