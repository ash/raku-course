## Завдання

Природне застосування машинного типу фіксованого розміру — компактний масив байтів. Оголосіть масив `uint8`, що містить значення `100`, `200` та `255` — кожне вміщується в один байт, — і виведіть суму його елементів.

Зверніть увагу, що елементи лишаються в межах `0..255`, але їхня сума не мусить: `.sum` повертає звичайний `Int`.

## Приклад

Програма виводить:

```
555
```
