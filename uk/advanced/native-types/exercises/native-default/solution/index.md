Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
my num $n;
my str $s;

say $n;
say "[$s]";
```

🦋 Вихідний код можна знайти у файлі [native-default.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-default.raku).

## Вивід

```
0
[]
```

## Коментарі

1. Машинний `num` не може бути невизначеним, тож, як і машинний `int`, він починає з `0`, а не з `(Num)`.

1. Машинний `str` починає з порожнього рядка, — саме тому між дужками нічого немає. Жоден із машинних типів ніколи не містить невизначеного значення.

1. Специфікатори типів тут украй важливі. Приберіть їх — напишіть `my $n; my $s;` — і змінні стануть звичайними контейнерами, які починають *невизначеними* (`Any`). Тоді `say $n` виводить `(Any)`, а інтерполяція невизначеної `$s` попереджає: *«Use of uninitialized value … in string context»*. Саме машинні типи `num` та `str` гарантують типові значення `0` та порожній рядок.
