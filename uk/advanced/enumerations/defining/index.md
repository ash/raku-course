Оголосіть перелічення за допомогою ключового слова `enum`, імені та списку імен констант:

```raku
enum Colour <red green blue>;
```

Це створює новий тип `Colour` і три константи: `red`, `green` та `blue`. Константи можна використовувати безпосередньо за іменем:

```raku
say red;   # red
say green; # green
```

За кожним іменем стоїть число, призначене автоматично від нуля в тому порядку, в якому ви їх перелічили: `red` — це `0`, `green` — `1`, `blue` — `2`. Оскільки значення впорядковані, константи можна порівнювати:

```raku
say red < blue; # True
```

Змінну можна типізувати переліченням, щоб вона приймала лише ці константи:

```raku
my Colour $c = green;
say $c; # green
```

Якщо ім'я може конфліктувати з чимось іншим у вашій програмі, до константи завжди можна звернутися через ім'я перелічення з `::`:

```raku
say Colour::red; # red
```

Перелічення дає набору споріднених констант ім'я й тип, що робить код, який їх використовує, значно зрозумілішим за голі числа. Наступна тема розглядає [числа, що стоять за іменами](/uk/advanced/enumerations/values-and-keys).
