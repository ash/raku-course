Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Вихідний код можна знайти у файлі [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Вивід

```
250
(Int)
```

## Коментарі

1. Обмеження типу `Int` у `my Int $cars` змушує контейнер відкидати будь-яке значення, що не є цілим числом. Пряме присвоєння `250.7` (значення `Rat`) було б помилкою під час компіляції.

1. Виклик `.Int` для раціонального значення `250.7` перетворює його на ціле `250`, відкидаючи дробову частину. Перетворене значення вміщується в контейнер. Не плутайте цю поведінку з округленням.

1. Псевдометод `.WHAT` підтверджує, що значення, збережене в контейнері, має тип `Int`.
