## Завдання

Оголосіть поруч дві скалярні змінні: нетипізовану `$untyped` і типізовану як `Int` `$typed`. Виведіть дамп обох, поки вони ще порожні, потім присвойте кожній `42` і знову виведіть дамп обох. Придивіться уважно, як `dd` по-різному описує ці два контейнери.

## Приклад

Програма виводить (у стандартний потік помилок):

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
