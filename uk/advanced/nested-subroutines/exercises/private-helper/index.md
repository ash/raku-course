## Завдання

Напишіть підпрограму `stats`, яка визначає **вкладену** допоміжну підпрограму `double`, що повертає подвоєне значення свого аргументу. Усередині `stats` скористайтеся помічником, щоб вивести значення `double(3) + double(5)`.

Потім викличте `stats`.

## Приклад

Програма виводить:

```
16
```
