## Завдання

`do` працює й перед операторами керування потоком виконання, перетворюючи їх на вирази, що дають значення. Скористайтеся `do if 7 > 5 { 'big' } else { 'small' }`, щоб обрати позначку, присвойте її `$label` і виведіть.

## Приклад

Програма виводить:

```
big
```
