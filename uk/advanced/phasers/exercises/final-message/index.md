## Завдання

Фазер `END` виконується після основного коду, тож він бачить *остаточний* стан ваших змінних, — що робить його ідеальним для підсумку.

Оголосіть лічильник `$count` зі значенням `0` і напишіть фазер `END` (поставте його перед основним кодом), який виводить `processed $count items`. Потім в основному тілі збільште лічильник тричі за допомогою циклу. Підсумок має повідомити остаточне число, а не значення на мить написання фазера.

## Приклад

Програма виводить:

```
processed 3 items
```
