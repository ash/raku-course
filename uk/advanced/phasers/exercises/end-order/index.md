## Завдання

Програма може мати більш ніж один фазер `END`. Коли їх кілька, вони виконуються у **зворотному** порядку до того, як були записані: оголошений останнім виконується першим (останнім прийшов — першим вийшов).

Напишіть два фазери `END`: перший виводить `first END`, другий — `second END`, а за ними — звичайний `say 'body'`. Передбачте й відтворіть порядок виводу.

## Приклад

Програма виводить:

```
body
second END
first END
```
