## Задача

Фазер `NEXT` запускається *наприкінці* кожної ітерації циклу, що є вдалим моментом для звіту про прогрес.

Ведіть поточну суму у `$sum`, починаючи з `0`. Виконайте цикл по `1..3`; на кожному проході спочатку додайте поточне число до `$sum`. Використайте фазер `NEXT`, щоб друкувати `sum so far: $sum` після кожної ітерації.

Зверніть увагу на порядок: фазер `NEXT` запускається після тіла, тому він повідомляє суму *включно* з поточним числом.

## Приклад

Програма виводить:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
