## Завдання

Створіть модуль під назвою `Maths` у файлі `Maths.rakumod`, який експортує підпрограму `square`, що повертає квадрат свого аргументу.

Потім напишіть окрему програму, яка використовує модуль, щоб вивести `square(6)`.

## Приклад

Запущена з модулем на шляху пошуку, програма виводить:

```console
$ raku -I. maths.raku
36
```
