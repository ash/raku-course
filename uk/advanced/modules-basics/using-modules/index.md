Щоб скористатися модулем, завантажте його оператором `use`. Після цього імена, які модуль експортує, доступні так, ніби ви написали їх самі.

Маючи файл `Greeting.rakumod` із попередньої теми, програма використовує його так:

```raku
use Greeting;

say hello('Anna');
```

Оскільки `hello` було позначено `is export`, оператор `use` робить її доступною, і програма викликає її напряму:

```
Hello, Anna!
```

Щоб Raku знайшов модуль, той має бути на шляху пошуку модулів. Коли файл модуля лежить у тому самому каталозі, що й ваша програма, ви кажете Raku шукати там за допомогою опції `-I.` (крапка означає «поточний каталог»):

```console
$ raku -I. program.raku
Hello, Anna!
```

Встановлені модулі (про них далі в темі [Встановлення модулів із мережі](/uk/advanced/installing-modules)) знаходяться автоматично, тож опція `-I` потрібна лише для модулів, які живуть поруч із вашою власною програмою.
