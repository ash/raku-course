---
title: Вивід сигнатур функцій
---

{% include menu.html %}

Виклик `dd` без аргументів усередині підпрограми друкує сигнатуру цієї підпрограми: її ім'я та список параметрів, якщо вони є. Розгляньте наступний приклад з двома підпрограмами:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Програма друкує сигнатури, а не будь-які значення:

```console
sub f1()
sub f2($x)
```

Це особливо корисно з мультифункціями, де це показує, який кандидат був насправді викликаний:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Вивід називає відповідний варіант кожного разу:

```console
sub g()
sub g($x)
```
