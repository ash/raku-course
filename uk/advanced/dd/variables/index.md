title: Вивід змінних
---

{% include menu.html %}

Викличте `dd`, щоб побачити, що містить змінна, так само як ви це зробили б за допомогою `say`:

```raku
my $var = 42;
dd $var;
```

Разом зі значенням `dd` також показує ім'я змінної:

```console
$var = 42
```

Якщо змінна має оголошений тип, тип також з'являється. Порівняйте вивід наступної програми з попередньою:

```raku
my Int $var = 42;
dd $var;
```

```console
Int $var = 42
```

Це головна відмінність від `say`: один виклик `dd` для скаляра показує вам ім'я та, якщо відомо, тип даних — тому ви можете розмістити кілька викликів `dd` у програмі й однаково розпізнати, який вивід належить якій змінній.

Ви також можете дампити більш складні структури даних, такі як масиви або хеші. Тут `dd` друкує подібне до коду представлення значення:

```raku
my @arr = 10, 20, [1, 2, 3], 30;
dd @arr;
```

```console
[10, 20, [1, 2, 3], 30]
```

Зверніть увагу, що вкладений масив залишається чітко видимим (хоча ім'я змінної не друкується). Те саме працює для хешів, ключі яких `dd` друкує у відсортованому порядку:

```raku
my %hash =
    gamma => 'g',
    alpha => 'a',
    beta  => 'b';
dd %hash;
```

```console
{:alpha("a"), :beta("b"), :gamma("g")}
```
