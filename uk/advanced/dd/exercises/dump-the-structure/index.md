## Завдання

Вам дано таку вкладену структуру даних:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Зробіть із нею дві речі:

1. Виведіть зручний для розробника дамп `@data` за допомогою `dd`.
2. Виведіть те саме подання рядком із префіксом `Structure: `.

## Приклад

Програма виводить два схожі рядки:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
