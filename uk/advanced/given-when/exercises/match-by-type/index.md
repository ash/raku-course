## Завдання

`when` може зіставлятися з *типом*, а не лише зі значенням. Маючи число `3.14`, збережене у змінній, скористайтеся `given`/`when`, щоб повідомити, що це за значення: виведіть `integer` для `Int`, `rational` для `Rat` і `string` для `Str`.

## Приклад

Програма виводить:

```
rational
```
