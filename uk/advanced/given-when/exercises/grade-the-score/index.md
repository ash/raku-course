## Завдання

За допомогою `given`/`when` виведіть життєвий етап для жорстко заданого віку за такими смугами:

* `child` для 0–12,
* `teenager` для 13–19,
* `adult` для 20–64,
* `senior` для 65 і більше.

Від'ємний вік не має сенсу, тож для будь-якого числа менше нуля виведіть `invalid`. Подбайте, щоб цей випадок оброблявся перед перевірками діапазонів.

## Приклад

Для віку `30` програма виводить:

```
adult
```
