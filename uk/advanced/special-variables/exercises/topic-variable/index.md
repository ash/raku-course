## Завдання

`$_` — це *топічна* змінна. Цикл `for` по черзі встановлює її в кожен елемент, а виклик методу, записаний із провідною крапкою й без отримувача — як-от `.chars`, — діє на неї, тож `.chars` означає `$_.chars`.

Пройдіть циклом три рядки: `'apple'`, `'fig'` та `'cherry'`. Для кожного виведіть рядок виду `<слово> has <n> letters`, використавши топік `$_` для слова та виклик `.chars` із провідною крапкою для його довжини. Простежте, як `$_` по черзі стає кожним рядком.

## Приклад

Програма виводить:

```
apple has 5 letters
fig has 3 letters
cherry has 6 letters
```
