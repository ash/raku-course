Який твіґіл позначає **динамічну** змінну, яку шукають через стек викликів?

{:.quiz}
1 | `*`
0 | `?`
0 | `!`
0 | `.`

{% include quiz.html %}

<div class="extended-explanation">

Твіґіл `*` позначає динамічну змінну, як-от `$*OUT` чи `$*greeting`. Твіґіл `?` призначений для компіляційних значень, `!` — для приватного атрибута, а `.` — для методу доступу до атрибута.

</div>
