Що виведе наведена програма?

```raku
say q{a\nb};
```

{:.quiz}
1 | a\nb
0 | a<новий рядок>b
0 | ab
0 | anb

{% include quiz.html %}

<div class="extended-explanation">

Оператор `q` працює як одинарні лапки: він не обробляє екранованих послідовностей на кшталт `\n`. Тож рядок зберігає всі чотири символи: `a`, `\`, `n`, `b`. Лише інтерполювальна форма на кшталт `qq` (або подвійні лапки) перетворила б `\n` на справжній перехід рядка.

</div>
