Який трейт дозволяє підпрограмі **змінювати змінну викликача** через параметр?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | жоден — параметри доступні для запису за замовчуванням

{% include quiz.html %}

<div class="extended-explanation">

За замовчуванням параметр доступний лише для читання, тож звичайному параметру нічого присвоїти не можна. `is rw` зв'язує параметр із власною змінною викликача, тож зміна всередині підпрограми видима назовні. `is copy` натомість дав би змінювану *копію*, лишивши змінну викликача недоторканою.

</div>
