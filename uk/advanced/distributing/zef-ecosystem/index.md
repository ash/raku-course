`zef` — це встановлювач модулів Raku. Ви вже користувалися ним, щоб встановлювати модулі за іменем; він працює і з локальним каталогом дистрибутива. Зсередини дистрибутива його можна протестувати й встановити напряму:

```
zef test .
zef install .
```

`zef test .` виконує файли з каталогу `t/`, а `zef install .` встановлює дистрибутив у ваш Raku, щоб інші програми могли зробити `use`. Встановлення за іменем — `zef install Cro` — робить те саме, спершу завантаживши дистрибутив з екосистеми.

Щоб **опублікувати** власний дистрибутив і дати іншим змогу встановити його за іменем, ви завантажуєте його в екосистему. Звичним інструментом для цього є `fez`:

```
fez upload
```

Це пакує поточний дистрибутив і подає його до екосистеми Raku, після чого `zef install Maths::Simple` спрацює для будь-кого.

> Цим командам потрібні встановлені `zef`/`fez` і доступ до мережі, а завантаженню — обліковий запис в екосистемі.

Отже, життєвий цикл спільного модуля такий: розкласти його з `META6.json`, протестувати через `zef test` і опублікувати через `fez upload`. Відтоді це просто ще одне ім'я, яке будь-хто може `zef install`.
