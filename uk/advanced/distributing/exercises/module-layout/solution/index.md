Ось один із можливих варіантів розв'язання задачі.

## Структура

```
Greet-Simple/
├── META6.json
├── README.md
├── lib/
│   └── Greet/
│       └── Simple.rakumod
└── t/
    └── 01-basic.rakutest
```

## Коментарі

1. `META6.json` лежить нагорі; вихідний код модуля йде під `lib/`, і шлях його каталогів відповідає частинам імені, розділеним `::`.

1. Тести живуть під `t/`. За такої структури `zef test .` та `zef install .` працюють із верхнього каталогу.
