Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
say <a b c>.reverse.join: '-';
```

🦋 Вихідний код можна знайти у файлі [colon-join.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-join.raku).

## Вивід

```
c-b-a
```

## Коментарі

1. `.reverse` зберігає звичайну форму, бо стоїть посередині ланцюжка. `join` іде останнім, тож може скористатися двокрапкою, передаючи `'-'` точно так само, як це зробив би `join('-')`.

1. Список, обернений на `c, b, a`, потім з'єднується дефісами, даючи `c-b-a`. Форма з двокрапкою працює зі звичайними значеннями, а не лише з блоками.
