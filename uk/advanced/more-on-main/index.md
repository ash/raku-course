У частині «Основи» ви користувалися `MAIN`, [щоб отримувати аргументи командного рядка](/uk/essentials/the-main-function/reading-command-line-arguments). Raku робить навколо `MAIN` більше, ніж просто передає значення всередину.

## Повідомлення про використання

Якщо аргументи в командному рядку не відповідають сигнатурі `MAIN`, Raku не виконує тіла. Натомість він виводить автоматично згенероване _повідомлення про використання_, яке описує, як слід викликати програму.

Візьмімо таку програму:

```raku
sub MAIN($name) {
    say "Hello, $name!";
}
```

Викликана правильно, вона вітає людину:

```console
$ raku hello.raku Anna
Hello, Anna!
```

Викликана без аргументу, вона не відповідає сигнатурі, тож Raku виводить довідку замість привітання:

```console
$ raku hello.raku
Usage:
  hello.raku <name>
```

Повідомлення будується з імен параметрів, тож осмислені імена роблять текст довідки корисним самі собою.

## Іменовані аргументи

Параметри `MAIN` можуть бути не лише позиційними, а й іменованими. Іменований параметр стає перемикачем `--option=value` у командному рядку, а типове значення робить його необов'язковим:

```raku
sub MAIN(:$name = 'World') {
    say "Hello, $name!";
}
```

```console
$ raku hello.raku
Hello, World!

$ raku hello.raku --name=Raku
Hello, Raku!
```
