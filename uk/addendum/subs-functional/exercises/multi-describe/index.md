## Завдання

За допомогою множинної диспетчеризації напишіть підпрограму `describe`, що
по-різному реагує на ціле число, рядок і список. Викличте її з `42`, `'hi'` та
`[1, 2, 3]`.

## Приклад

Програма друкує:

```
integer 42
string hi
list of 3
```
