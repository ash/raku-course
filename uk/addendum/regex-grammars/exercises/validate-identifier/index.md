## Завдання

У багатьох мовах програмування коректний ідентифікатор починається з літери або
підкреслення й далі містить літери, цифри чи підкреслення. Для `count`,
`total2`, `2fast`, `my-var` та `_hidden` надрукуйте, чи є кожен коректним
ідентифікатором за цим класичним правилом.

(Сам Raku щедріший: `my-var` є цілком коректним ідентифікатором Raku.
Погляньте на сторінку рішення і щодо цього варіанту.)

## Приклад

Програма друкує:

```
count: valid
total2: valid
2fast: invalid
my-var: invalid
_hidden: valid
```
