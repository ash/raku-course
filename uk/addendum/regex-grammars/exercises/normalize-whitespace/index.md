## Завдання

Причепуріть наступний рядок так, щоб пробіли на початку й у кінці зникли, а
кожен внутрішній проміжок став одним пробілом. Надрукуйте результат.

```raku
my $messy = '  too    many     spaces   ';
```

## Приклад

Програма друкує:

```
too many spaces
```
