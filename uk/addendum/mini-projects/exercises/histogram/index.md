## Завдання

Маючи показники продажів `apples => 5, pears => 3, plums => 8`, надрукуйте просту
стовпчикову діаграму: кожну назву, потім табуляцію, а потім стовпчик із символів
`#` завдовжки як її значення, упорядкувавши за назвою.

## Приклад

Програма друкує:

```
apples	#####
pears	###
plums	########
```
