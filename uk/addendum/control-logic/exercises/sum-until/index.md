## Завдання

Додавайте цілі числа `1, 2, 3, …` по одному, аж поки поточна сума вперше не
перевищить `100`. Надрукуйте досягнуту суму й те, скільки чисел було додано.

## Приклад

Програма друкує:

```
reached 105 after adding 1..14
```
