## Завдання

Маючи довжини трьох сторін, визначте, чи утворюють вони рівносторонній,
рівнобедрений чи різносторонній трикутник — або взагалі не трикутник, коли
найдовша сторона надто довга. Класифікуйте `(3, 3, 3)`, `(3, 3, 5)`,
`(3, 4, 5)` та `(1, 2, 10)`.

## Приклад

Програма друкує:

```
3 3 3: equilateral
3 3 5: isosceles
3 4 5: scalene
1 2 10: invalid
```
