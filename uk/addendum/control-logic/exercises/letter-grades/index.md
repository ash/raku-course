## Завдання

Перетворіть кожен із балів `95`, `82`, `71` та `58` на літерну оцінку: `A` для
90 і вище, `B` для 80–89, `C` для 70–79, `D` для 60–69 і `F` для нижчих.
Надрукуйте кожен бал разом з його оцінкою.

## Приклад

Програма друкує:

```
95 -> A
82 -> B
71 -> C
58 -> F
```
