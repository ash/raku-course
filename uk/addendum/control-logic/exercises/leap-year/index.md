## Завдання

Рік є високосним, якщо він ділиться на 4, за винятком років-століть, які є
високосними лише тоді, коли діляться на 400. Для років `2000`, `1900`, `2024`
та `2023` надрукуйте, чи є кожен високосним, чи звичайним.

## Приклад

Програма друкує:

```
2000: leap
1900: common
2024: leap
2023: common
```
