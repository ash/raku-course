## Завдання

Паліндром читається однаково вперед і назад. Для кожного зі слів `level`,
`hello` та `racecar` надрукуйте слово, а за ним `yes` або `no` — залежно від
того, чи є воно паліндромом.

## Приклад

Програма друкує:

```
level: yes
hello: no
racecar: yes
```
