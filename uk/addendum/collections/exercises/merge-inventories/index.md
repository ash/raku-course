## Завдання

Дві крамниці тримають свої запаси в хешах:
`apples => 3, pears => 2` та `apples => 4, plums => 5`. Об'єднайте їх в один,
додавши кількості для ключів, що трапляються в обох. Надрукуйте результат,
упорядкований за ключем, парами `ключ: сума`, з'єднаними комами.

## Приклад

Програма друкує:

```
apples: 7, pears: 2, plums: 5
```
