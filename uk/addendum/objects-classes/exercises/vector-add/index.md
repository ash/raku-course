## Завдання

Напишіть клас `Vector` із `x` та `y` і методом `add`, що повертає *новий*
вектор — суму двох. Дайте йому метод `Str`, щоб він друкувався як `(x, y)`.
Додайте `(1, 2)` та `(3, 4)` і надрукуйте результат.

## Приклад

Програма друкує:

```
(4, 6)
```
