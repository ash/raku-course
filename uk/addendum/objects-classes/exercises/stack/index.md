## Завдання

Напишіть клас `Stack` із методами, що кладуть значення, знімають верхнє
значення, зазирають на верхівку, не знімаючи її, і повідомляють його розмір.
Покладіть `1`, `2`, `3`, а потім надрукуйте результат зазирання, знімання й
запиту розміру.

## Приклад

Програма друкує:

```
3
3
2
```
