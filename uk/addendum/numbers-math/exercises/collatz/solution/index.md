Ось одне з можливих розв'язань задачі.

## Код

```raku
my $n = 27;
my $steps = 0;

while $n != 1 {
    $n = $n %% 2 ?? $n div 2 !! 3 * $n + 1;
    $steps++;
}

say $steps;
```

🦋 Знайдіть програму у файлі [collatz.raku](https://github.com/ash/raku-course/blob/master/exercises/addendum/numbers-math/collatz.raku).

## Вивід

```
111
```

## Коментарі

1. Тернарний оператор `?? !!` обирає наступне значення одним виразом: ділить `$n`
навпіл, коли воно парне (`$n %% 2`), а інакше застосовує `3 * $n + 1`.

1. `27` — славетний невеликий випадок, що робить напрочуд довгий гак — `111`
кроків, — перш ніж нарешті осісти на `1`.
