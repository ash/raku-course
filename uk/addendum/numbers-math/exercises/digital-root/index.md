## Завдання

*Цифровий корінь* числа — це те, що виходить, коли раз за разом додавати його
цифри, аж поки не залишиться одна. Для `987654`: `9+8+7+6+5+4 = 39`, потім
`3+9 = 12`, потім `1+2 = 3`. Обчисліть і надрукуйте цифровий корінь `987654`.

## Приклад

Програма друкує:

```
3
```
