Будувати справжні вебсервіси на сирих сокетах швидко стає марудно: розбір запитів, маршрутизація URL, обробка багатьох клієнтів, розмова через HTTPS. **Cro** — це фреймворк Raku, що робить усе це за вас. Це стандартний, сучасний спосіб писати вебсервери та клієнти мовою Raku.

Цей останній розділ є короткою екскурсією по Cro — рівно настільки, щоб побачити його форму. Cro не входить до ядра, тож, щоб запускати ці приклади, спершу встановіть його через `zef install cro`.
