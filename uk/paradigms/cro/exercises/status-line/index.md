## Завдання

Отримайте стан вебсторінки легким шляхом — за допомогою **клієнтського модуля Cro**, а не сирого сокета. Скористайтеся `Cro::HTTP::Client.get`, щоб дістати `http://example.com/`, зробіть `await` відповіді й надрукуйте її `.status` — жодного розбору тексту не потрібно.

> Цій вправі потрібен встановлений модуль Cro (`zef install cro`) та робоче мережеве з'єднання.

## Приклад

Під час запуску програма друкує:

```
200
```
