## Завдання

Розширте сервіс привітання **другим** маршрутом: маршрутом `GET` для шляху `bye`, що повертає звичайний текст `Goodbye!`. Початковий маршрут `hello` теж збережіть.

> Цій вправі потрібен встановлений Cro (`zef install cro`).

## Приклад

Запит до `/bye` повертає:

```
Goodbye!
```
