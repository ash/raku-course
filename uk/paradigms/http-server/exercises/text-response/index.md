## Завдання

Змусьте сервер робити справжню роботу зі вхідними даними клієнта, а не повертати сталий рядок. Напишіть сервер, що в **циклі** (як на попередній сторінці) читає кожен запит, бере запитаний **шлях** і надсилає його назад **великими літерами** — тож запит до `/hello` відповідає `HELLO`. Шлях є другим словом першого рядка запиту (`GET /hello HTTP/1.0`); відкиньте початкову `/`, перш ніж переводити його у верхній регістр. Сервер і далі обслуговує запит за запитом; спиніть його через Ctrl-C.

## Приклад

Запит шляху через `curl` повертає його великими літерами:

```console
$ curl http://127.0.0.1:8080/hello
HELLO
```
