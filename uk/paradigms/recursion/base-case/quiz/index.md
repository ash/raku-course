Що станеться, якщо рекурсивна підпрограма не має досяжного базового випадку?

{:.quiz}
0 | Вона поверне `Nil`
0 | Вона поверне `0`
1 | Вона нескінченно викликатиме себе й зрештою впаде
0 | Компілятор відмовиться її запускати

{% include quiz.html %}

<div class="extended-explanation">

Без досяжного базового випадку кожен виклик робить ще один виклик без кінця. Рекурсія ніколи не завершується, і програма зрештою вичерпує стек викликів та падає. Саме базовий випадок дозволяє рекурсії зупинитися.

</div>
