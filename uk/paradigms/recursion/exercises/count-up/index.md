## Завдання

Напишіть рекурсивну підпрограму `countup`, що друкує числа від `1` до `$n`, кожне на своєму рядку. Хитрість: спершу рекурсуйте, **а потім** друкуйте — тоді числа виходять у зростаючому порядку, хоча кожен виклик обробляє найбільше число. Викличте `countup(3)`.

## Приклад

Програма друкує:

```
1
2
3
```
