## Завдання

_n_-те трикутне число — це сума `n + (n - 1) + … + 1`, причому нульове трикутне число дорівнює `0`. Напишіть рекурсивну підпрограму `tri`, що його обчислює, але виразіть її **двома кандидатами `multi`**, а не умовою всередині одного тіла: один кандидат для базового випадку, другий — для рекурсивного кроку. Надрукуйте `tri(5)`.

## Приклад

Програма друкує:

```
15
```
