Що в HTTP-запиті, надісланому через сокет, позначає кінець заголовків запиту?

{:.quiz}
0 | Крапка
1 | Порожній рядок (додаткове `\r\n`)
0 | Слово `END`
0 | Закриття сокета

{% include quiz.html %}

<div class="extended-explanation">

HTTP відділяє заголовки від тіла — і сигналізує «заголовків більше немає» — порожнім рядком, записаним як додаткове `\r\n`. Без нього сервер і далі чекатиме на решту запиту.

</div>
