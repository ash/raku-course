## Завдання

За допомогою **методу** `reduce` з блоком з'єднайте слова `'Raku', 'is', 'fun'` в один рядок, ставлячи `', '` між шматками, щоб результат читався як `Raku, is, fun`. Метаоператор `[~]` склеює шматки без нічого між ними, тож вставлення розділювача — робота для блоку.

## Приклад

Програма друкує:

```
Raku, is, fun
```
