Щоб підписатися на потік значень, ви _підключаєтеся_ до нього (tap): даєте `.tap` блок, і цей блок виконується на кожне значення, яке видає потік. Найпростіший потік для експериментів — це `Supply.from-list`, що видає значення списку:

```raku
my $s = Supply.from-list(1, 2, 3);
$s.tap(-> $v { say $v });
```

Це друкує:

```
1
2
3
```

Блок `-> $v { say $v }` є _підключенням_. Потік штовхає в нього кожне значення по черзі, тож блок виконується тричі, по разу на значення.

Підключення може робити зі значенням що завгодно, зокрема накопичувати результат:

```raku
my $total = 0;
Supply.from-list(1, 2, 3).tap(-> $v { $total += $v });
say $total; # 6
```

Тут кожне видане значення додається до `$total`, який завершується на `6`. Підключення — це базова дія реактивного програмування: приєднати шматок поведінки до потоку й дати потокові керувати ним.
