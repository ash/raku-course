У [розділі про контейнери](/uk/advanced/containers) ви користувалися `.^name`, щоб запитати значення про його тип. Ті самі метавиклики через `.^` дозволяють досліджувати клас і його об'єкти: їхні імена, атрибути та місце в ієрархії.

Метаметод `.^name` повертає ім'я класу:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметод `.^attributes` перелічує атрибути класу. Кожен показано з його типом і внутрішнім приватним іменем (форма `$!`, з якою ви познайомилися в темі про [приватні атрибути](/uk/oop/methods/private-attributes)):

```raku
say Dog.^attributes; # (Str $!name)
```

Інтроспекція корисна для інструментів, що працюють з об'єктами узагальнено, — наприклад, щоб вивести кожен атрибут об'єкта, не знаючи наперед його класу. Наступна тема розглядає, як побачити ланцюжок успадкування класу.
