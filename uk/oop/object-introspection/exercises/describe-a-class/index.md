## Завдання

Визначте базовий клас `Animal` і клас `Dog`, що успадковує від нього. Потім виведіть ім'я класу `Dog`, а наступним рядком — кількість типів у його ланцюжку успадкування (скористайтеся `.^mro` й порахуйте елементи). Нарешті, третім рядком виведіть, чи трапляється десь у цьому ланцюжку клас на ім'я `Cat`.

## Приклад

Програма виводить:

```
Dog
4
False
```
