Коли в програмі на Raku щось іде не так — бракує файлу, стається явний `die`, — кидається _виняток_. За замовчуванням неперехоплений виняток зупиняє програму. Блок `try` дозволяє виконати код, який може зазнати невдачі, не обрушуючи програми.

Ви загортаєте ризикований код у блок `try`. Якщо всередині кинуто виняток, блок на цьому зупиняється, але програма триває далі:

```raku
my $result = try {
    die 'Boom!';
};

say "Still works";
```

`die` перехоплює `try`, тож програма не падає — вона одразу переходить до наступного оператора й виводить:

```
Still works
```

Коли блок зазнає невдачі отак, він обчислюється в невизначене значення, тож `$result` є невизначеним:

```raku
say $result.defined; # False
```

Перехоплений виняток зберігається в спеціальній змінній `$!`. Звідти можна прочитати його повідомлення:

```raku
say $!.message; # Boom!
```

Отже, `try` перетворює фатальну помилку на щось, що ваша програма може дослідити й на що може відреагувати. Якщо блок виконується без жодного винятку, `$result` містить його значення, а `$!` є невизначеною.
