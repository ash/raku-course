## Завдання

Блок `try`, який зазнає невдачі, обчислюється в невизначене значення. Скористайтеся цим разом з оператором «визначене або» `//`, щоб підставити запасне значення: виконайте блок `try`, який робить `die 'no'`, і, якщо він зазнає невдачі, використайте натомість рядок `default`. Виведіть результат.

## Приклад

Програма виводить:

```
default
```
