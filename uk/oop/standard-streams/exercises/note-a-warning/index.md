## Завдання

Програма обробляє значення, яке виявляється від'ємним. Скористайтеся `note`, щоб надіслати попередження до стандартного потоку помилок, коли значення менше за нуль, і `say`, щоб надіслати справжній результат — його абсолютне значення — до стандартного виводу. Візьміть значення `-3`.

## Приклад

Обидва рядки з'являються на екрані:

```
Warning: the value is negative
3
```

Якщо стандартний потік помилок відкинуто, лишається тільки результат:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
