## Завдання

Програма підсумовує список чисел `3, 5, 7` у циклі. На кожному оберті надсилайте поточну накопичену суму до стандартного потоку помилок як повідомлення про поступ, а після циклу надішліть остаточний результат до стандартного виводу, користуючись дескрипторами потоків напряму.

Це розділення має значення: результат можна перехопити чи передати каналом далі, тоді як повідомлення про поступ не плутатимуться під ногами в стандартному потоці помилок.

## Приклад

Коли ви запускаєте програму, на екрані з'являються обидва потоки — накопичені суми, а потім остаточний результат:

```
running total: 3
running total: 8
running total: 15
15
```

Але якщо відкинути стандартний потік помилок, лишиться тільки справжній результат:

```
$ raku output-and-error.raku 2>/dev/null
15
```
