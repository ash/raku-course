## Завдання

Дескриптор файлу є звичайним значенням, тож його можна передати функції, як і будь-який інший аргумент. Напишіть підпрограму `log-line`, яка приймає дескриптор і повідомлення й записує повідомлення в дескриптор окремим рядком.

Відкрийте `log.txt` для запису, викличте `log-line` тричі, щоб записати `started`, `working` та `done`, потім закрийте дескриптор, прочитайте файл назад і виведіть його вміст.

## Приклад

Програма виводить:

```
started
working
done
```
