## Завдання

Відкрийте файл під назвою `out.txt` для запису. Тримаючи дескриптор відкритим, запишіть у нього числа `1`, `2` та `3`, кожне на своєму рядку, за допомогою циклу. Потім закрийте дескриптор, прочитайте файл назад і виведіть його вміст.

## Приклад

Програма виводить:

```
1
2
3
```
