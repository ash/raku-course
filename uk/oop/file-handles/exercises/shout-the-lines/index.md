## Завдання

Запишіть три слова — `apple`, `banana` та `cherry`, кожне на своєму рядку, — у файл під назвою `words.txt`. Потім прочитайте файл рядок за рядком і виведіть кожен рядок із префіксом у вигляді його номера (починаючи з `1`), у формі `<номер>: <рядок>`.

## Приклад

Програма виводить:

```
1: apple
2: banana
3: cherry
```
