## Завдання

Напишіть підпрограму `get`, яка повертає свій аргумент, але викликає `fail` із повідомленням `bad`, коли аргумент дорівнює `0`.

Скориставшись оператором «визначене або» `//`, щоб підставити запасне значення `default`, виведіть результат `get(5)`, а потім `get(0)`.

## Приклад

Програма виводить:

```
5
default
```
