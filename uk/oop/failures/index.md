Кидання винятку через `die` спиняє все негайно. Іноді це надто різко: ви хочете, щоб підпрограма повідомила, що не змогла дати результат, але дозволила викликачеві вирішити, чи це фатально. Для цього в Raku є _м'які збої_, які створюють через `fail`.

Коли підпрограма викликає `fail`, вона не кидає виняток одразу. Натомість вона повертає викликачеві особливий об'єкт `Failure`. `Failure` є невизначеним, тож викликач може тихо його перевірити:

```raku
sub divide($a, $b) {
    fail 'cannot divide by zero' if $b == 0;
    return $a / $b;
}

say divide(10, 2);         # 5
say divide(10, 0).defined; # False
```

Успішний виклик повертає `5`. Невдалий виклик повертає `Failure`, який для `defined` повідомляє `False`, тож викликач може перевірити результат, перш ніж ним скористатися.

`Failure` називають _м'яким_, бо він перетворюється на справжній кинутий виняток лише тоді, коли ви намагаєтеся скористатися ним як значенням, спершу не перевіривши. Доки ви його обробляєте — наприклад, перевіряючи `defined`, — він лишається тихим. Це дозволяє підпрограмі сигналізувати про негаразд, не змушуючи спинятися всю програму.

## Ви це вже бачили

Такий відкладений стиль збою не є винятковою властивістю `fail`. Раніше в цій частині ви двічі стикалися з тією самою ідеєю.

**Ділення на нуль** тихо створює значення й кидає виняток лише тоді, коли ви ним справді користуєтеся:

```raku
my $x = 1 / 0;   # помилки ще немає
say $x;           # кидає лише тут, коли значення використано
```

**Зовнішня програма, що зазнала невдачі,** повертає `Proc`, який кидає виняток, лише якщо ви відкидаєте його необробленим; збережіть його й дослідіть — і він лишиться тихим значенням:

```raku
run 'sh', '-c', 'exit 1';   # невдалий Proc відкинуто, тож це кидає виняток
```

У кожному з випадків негаразд не спиняє програму тієї миті, коли стається: він стає значенням, яке можна перевірити, і переростає в кинутий виняток, лише коли ви користуєтеся ним без перевірки або ігноруєте його. Тема [Не кожна помилка негайна](/uk/oop/try/deferred-errors) показує ці два випадки поруч.
