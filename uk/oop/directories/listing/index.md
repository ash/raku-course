Підпрограма `dir` повертає записи каталогу — кожен як об'єкт шляху. Їхній порядок не є сталим, тож результат зазвичай сортують заради передбачуваного виводу.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Це виводить імена файлів у каталозі `box` по порядку:

```
a.txt
b.txt
```

Кожен запис є повним об'єктом шляху; метод `basename` дає лише кінцеве ім'я, без частини з каталогом. Об'єктові шляху можна ставити всі ті самі запитання, що й раніше — `.f`, `.d`, `.e`, — тож ви можете, наприклад, пройти каталогом і відібрати самі лише файли.
