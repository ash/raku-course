## Завдання

Створіть файл під назвою `a.txt`. Потім поставте *тому самому* шляху два запитання: чи це звичайний файл (`.f`) і чи це каталог (`.d`)? Виведіть обидві відповіді, щоб побачити, що дві перевірки дають для одного шляху протилежні результати.

## Приклад

Програма виводить:

```
True
False
```
