Коли ви пишете ім'я класу на кшталт `Dog`, ви посилаєтеся на _об'єкт типу_ цього класу. Об'єкт типу представляє сам тип, а не якийсь конкретний об'єкт цього типу. _Екземпляр_, створений через `new`, є справжнім об'єктом.

Raku вміє їх розрізняти. Метод `defined` повертає `False` для об'єкта типу й `True` для екземпляра:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Об'єкт типу вважається _невизначеним_, бо не містить жодних конкретних даних — це лише опис типу. Екземпляр є _визначеним_: це справжній об'єкт.

Обидва повідомляють той самий тип через `WHAT`, з яким ви познайомилися в [розділі про контейнери](/uk/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Дужки навколо `(Dog)` — це спосіб Raku показати тип. Отже, `Dog` і `Dog.new` мають спільний тип `Dog`; різниця в тому, що одне є самим типом, а друге — об'єктом цього типу.
