## Завдання

Визначте два порожні класи, `Cat` та `Dog`, і створіть екземпляр `Cat` під назвою `$felix`. Виведіть тип `$felix` за допомогою `WHAT`. Потім у двох наступних рядках виведіть, чи є цей тип тим самим, що й `Cat`, і чи є він тим самим, що й `Dog`, скориставшись оператором `===`.

## Приклад

Програма виводить:

```
(Cat)
True
False
```
