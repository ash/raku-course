## Завдання

Визначте два порожні класи, `Cat` та `Dog`. Потім пройдіть циклом чотири значення — `Cat`, `Dog`, `Cat.new` та `Dog.new` — і виведіть, чи є кожне з них визначеним. Зверніть увагу, що два об'єкти типу є невизначеними, а два екземпляри — визначеними, незалежно від того, до якого класу вони належать.

## Приклад

Програма виводить:

```
False
False
True
True
```
