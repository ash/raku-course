Досі всі типи даних, якими ви користувалися — числа, рядки, масиви тощо, — були вбудовані в Raku. _Об'єктно-орієнтоване програмування_ дозволяє визначати власні типи, які називають _класами_, і створювати значення цих типів, які називають _об'єктами_.

Клас визначають ключовим словом `class`, за яким ідуть ім'я та блок:

```raku
class Dog {
}
```

Цей клас `Dog` поки що порожній, але він уже є новим типом. Щоб створити об'єкт класу — _екземпляр_, — викличте метод `new` для імені класу:

```raku
class Dog {
}

my $rex = Dog.new;
say $rex; # Dog.new
```

Змінна `$rex` тепер містить об'єкт `Dog`. Кожен виклик `new` створює окремий об'єкт:

```raku
my $rex = Dog.new;
my $fido = Dog.new;
```

`$rex` і `$fido` — два різні пси, хоча клас ще не має жодного вмісту. У наступних розділах ви надасте класу власні дані (_атрибути_) і власну поведінку (_методи_). Перша тема пильніше розглядає різницю між класом та його екземплярами.
