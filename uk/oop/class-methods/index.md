Більшість методів викликають для об'єкта — екземпляра класу. Але метод можна викликати й для самого класу, тобто для об'єкта типу. Такий метод часто називають _методом класу_. Він корисний для значень та операцій, що належать класу як цілому, а не одному конкретному об'єктові.

Метод класу визначають точнісінько так, як будь-який інший метод:

```raku
class Road {
    method speed-limit { 120 }
}
```

і викликають для імені класу замість екземпляра:

```raku
say Road.speed-limit; # 120
```

Одним методом класу ви вже користувалися, не називаючи його: `new` — це метод, який викликають для класу, щоб створити новий об'єкт.

Метод класу не має доступу до атрибутів екземпляра — за ним немає конкретного об'єкта, — тож він працює лише з відомостями, однаковими для кожного об'єкта класу. Коли робота залежить від даних конкретного об'єкта, беріть звичайний метод, викликаний для екземпляра; коли ні, метод класу пасує природно.

Зверніть увагу: хоча методам класу екземпляр не потрібен, у них усе одно можна використати дані об'єкта, коли об'єкт таки є:

```raku
class Road {
    has $.name;
    method speed-limit { 120 }

    method info {
        "The maximum speed on $.name is " ~ self.speed-limit
    }
}

my $R404 = Road.new(name => 'Road 404');
say $R404.info;
```

Ця програма виводить очікуваний результат:

```
The maximum speed on Road 404 is 120
```

Без створеного об'єкта класу виклик на кшталт `say Road.info` спричинив би помилку.
