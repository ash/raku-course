## Завдання

Визначте клас `Converter` із методом класу `km-to-miles`, який приймає кількість кілометрів і повертає відстань у милях (помножити на `0.621`).

Викличте метод для класу для `10` кілометрів і виведіть результат.

## Приклад

Програма виводить:

```
6.21
```
