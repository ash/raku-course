Атрибути дають об'єктові дані; _методи_ дають йому поведінку. Метод — це підпрограма, яка належить класу й викликається для об'єкта. Оголошують її ключовим словом `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

Викликайте метод для об'єкта через крапку, так само як аксесор:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Усередині методу об'єкт, для якого метод викликано, доступний як `self`. До атрибутів дістаються через їхні аксесори, які записують як `$.name`, `$.age` тощо. Вони працюють і всередині інтерпольованих рядків:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```

Наступні теми охоплюють приватні атрибути (тепер, коли ми маємо методи, щоб ними користуватися), методи з параметрами та методи, які викликають інші методи.
