Метод може приймати параметри, так само як підпрограма. Ви перелічуєте їх у дужках після імені методу:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

Метод `deposit` приймає один параметр, `$amount`, і додає його до балансу об'єкта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Кожен виклик працює з тим об'єктом, для якого його зроблено, тож той самий метод може незалежно оновлювати різні об'єкти. Методи можуть приймати позиційні та іменовані параметри, типові значення й усе інше, що ви вже бачили в сигнатурах підпрограм.
