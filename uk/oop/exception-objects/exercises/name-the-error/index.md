## Завдання

Напишіть підпрограму `risky`, яка робить `die 'sub failed'`. Потім викличте її зсередини блоку, що має фазер `CATCH`. `CATCH` має вивести ім'я типу винятку (через `.^name`), а потім його повідомлення (через `.message`). Це показує, що `CATCH` обробляє винятки, кинуті кодом, який блок *викликає*, а не лише `die`, записаним безпосередньо в блоці.

## Приклад

Програма виводить:

```
X::AdHoc
sub failed
```
