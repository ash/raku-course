## Завдання

Визначте клас `Robot`, метод `speak` якого повертає `beep`. Визначте роль `Dancing`, що додає метод `dance`, який повертає `spinning around`.

Створіть двох роботів, але надайте роль `Dancing` лише одному з них. Виведіть результат `speak` для обох роботів, а потім результат `dance` для того робота, який уміє танцювати.

## Приклад

Програма виводить:

```
beep
beep
spinning around
```
