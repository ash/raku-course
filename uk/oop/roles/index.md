_Роль_ — це згорток поведінки (а іноді й даних), який можуть спільно використовувати кілька класів. Якщо успадкування каже, що клас _є_ різновидом іншого, то роль описує те, що клас _уміє робити_.

Роль визначають ключовим словом `role`, дуже схоже на клас, а надають класу трейтом `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Клас `Person` тепер має метод `hello` із ролі, наче його було написано в самому класі:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Клас, який виконує роль, розпізнається як такий, що її має:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Зверніть увагу, що метод `hello` ролі використовує `self.name`, хоча сама роль не має атрибута `name`. Це нормально: метод виконується як частина того класу, який компонує роль, а цей клас надає `name`. Наступна тема показує, що клас може взяти на себе більш ніж одну роль одночасно.
