## Завдання

Скористайтеся `run`, щоб запустити `echo` із двома окремими аргументами: `home:` та `$HOME`. Хай його вивід іде на екран. Зверніть увагу, що `$HOME` з'являється буквально, а домашній каталог **не** виводиться, — бо `run` не залучає оболонки, тож і підстановки змінних немає.

## Приклад

Програма виводить:

```
home: $HOME
```
