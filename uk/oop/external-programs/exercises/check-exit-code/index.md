## Завдання

Запустіть команду, яка навмисне зазнає невдачі, — наприклад, `sh -c 'exit 4'` — і збережіть `Proc`, який вона повертає. Виведіть код завершення команди, а потім виведіть `success` або `failure` залежно від того, чи команда вдалася.

## Приклад

Програма виводить:

```
4
failure
```
