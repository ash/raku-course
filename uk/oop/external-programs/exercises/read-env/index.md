## Завдання

Створіть файл `notes.txt` і запишіть у нього кілька рядків. Покладіть його ім'я у змінну середовища `NOTES`. Потім скористайтеся `shell`, щоб запустити `wc -l`, читаючи ім'я файлу з `$NOTES`, аби дитина порахувала рядки й вивела число. Нарешті видаліть файл із Raku — через `unlink`, а не через оболонку.

## Приклад

Програма виводить:

```
3
```

(і не лишає по собі `notes.txt`.)
