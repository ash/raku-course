Яка функція передає свою команду через системну **оболонку**, дозволяючи канали й перенаправлення?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` передає оболонці один рядок, і та тлумачить можливості на кшталт каналів. `run` запускає програму напряму з окремими аргументами й без оболонки, що безпечніше й краще пасує як вибір за замовчуванням.

</div>
