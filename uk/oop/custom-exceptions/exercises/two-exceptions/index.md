## Завдання

Визначте два власні класи винятків, `TooSmall` та `TooBig`, кожен з яких успадковує від `Exception`, із методами `message`, що повертають `too small` та `too big` відповідно.

Пройдіть циклом ці два типи й для кожного киньте виняток цього типу всередині власного блоку. Скористайтеся фазером `CATCH` із гілкою `when` для кожного типу, виводячи `small` для `TooSmall` та `big` для `TooBig`. Так ви побачите, що використано обидві гілки.

## Приклад

Програма виводить:

```
small
big
```
