Ось один із можливих варіантів розв'язання задачі.

## Код

```raku
spurt 'number.txt', "42\n";

my $n = slurp('number.txt').trim.Int;
say $n * 2;
```

🦋 Вихідний код можна знайти у файлі [save-and-read.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/files/save-and-read.raku).

## Вивід

```
84
```

## Коментарі

1. `spurt` створює файл і записує в нього рядок; `slurp` читає весь файл назад у рядок. Разом вони становлять повний цикл збереження й завантаження.

1. Те, що повертає `slurp`, є текстом — `"42\n"`, — тож ми `trim`-имо завершальний перехід рядка й викликаємо `.Int`, щоб перетворити його на число перед арифметикою. Результатом `42 * 2` є `84`.

1. Утім, програма працює й без `.trim.Int`.
