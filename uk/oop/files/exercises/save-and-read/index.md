## Завдання

Збережіть число у файл і завантажте його назад. Запишіть число `42` (за яким іде перехід рядка) у файл під назвою `number.txt`. Потім прочитайте файл назад, перетворіть його вміст на ціле число й виведіть це число, помножене на два.

## Приклад

Програма виводить:

```
84
```
