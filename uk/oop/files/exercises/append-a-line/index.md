## Завдання

Побудуйте невеликий файл журналу, раз за разом додаючи до нього. Запишіть рядок `start` у файл під назвою `log.txt`, а потім у циклі **додайте** ще три рядки — `entry 1`, `entry 2` та `entry 3`, — не стираючи того, що вже там є. Нарешті прочитайте весь файл і виведіть його.

## Приклад

Програма виводить:

```
start
entry 1
entry 2
entry 3
```
