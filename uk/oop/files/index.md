Найпростіший спосіб працювати з файлом — прочитати або записати його весь за раз.

Підпрограма `spurt` записує рядок у файл, створюючи файл (або замінюючи його вміст, якщо той уже існує):

```raku
spurt 'greeting.txt', "Hello, file!\n";
```

Підпрограма `slurp` читає весь вміст файлу назад у рядок:

```raku
my $text = slurp 'greeting.txt';
print $text; # Hello, file!
```

Разом `spurt` і `slurp` дозволяють зберегти дані й знову завантажити їх двома короткими викликами. (Тут використано `print`, а не `say`, бо текст уже закінчується переходом рядка.)

Ці операції над цілим файлом ідеальні, коли файл достатньо малий, щоб зручно вміститися в пам'яті. Для більших файлів або коли ви хочете обробляти файл рядок за рядком, використовують [дескриптор файлу](/uk/oop/file-handles), розглянутий наприкінці цього розділу. Наступна тема показує, як додавати до файлу замість замінювати його.
