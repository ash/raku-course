За замовчуванням `spurt` замінює те, що було у файлі. Щоб натомість додати в кінець наявного файлу, передайте іменований аргумент `:append`:

```raku
spurt 'log.txt', "line1\n";
spurt 'log.txt', "line2\n", :append;

print slurp 'log.txt';
```

Другий `spurt` зберігає наявний вміст і додає новий рядок після нього, тож у файлі опиняються обидва рядки:

```
line1
line2
```

Без `:append` другий виклик перезаписав би файл, лишивши тільки `line2`. Додавання корисне для таких речей, як файли журналів, де кожен запуск програми дописує до запису, що зростає, замість починати спочатку.
