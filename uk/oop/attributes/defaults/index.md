Атрибуту можна надати _типове значення_, яке використовується, коли об'єкт створюють без значення для нього. Запишіть типове значення після атрибута через `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Зверніть увагу, що, як і для змінних, тип атрибутів можна задати примусово.

Якщо ви не передасте `weight` до `new`, атрибут візьме типове значення:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Типове значення все одно можна перекрити, передавши своє:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Без типового значення й без значення, переданого до `new`, атрибут просто невизначений — точнісінько як щойно створена скалярна змінна.
