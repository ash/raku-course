Порожній клас не надто корисний. Щоб об'єкт міг нести власні дані, класу надають _атрибути_. Атрибут оголошують усередині класу ключовим словом `has`:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Кожен об'єкт класу отримує власну копію цих атрибутів. Їхні значення ви задаєте під час створення об'єкта, передаючи їх до `new` як іменовані аргументи:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

`$.` у `has $.name` робить дві речі водночас: оголошує атрибут і створює однойменний метод — _аксесор_, — який повертає значення атрибута:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Різні об'єкти зберігають власні значення, незалежно одне від одного:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Наступні теми показують, як зробити атрибути змінюваними та як надати їм типові значення. (Є також спосіб оголосити _приватні_ атрибути, приховані ззовні; ми повернемося до нього, коли введемо методи.)
