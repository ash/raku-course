## Завдання

Визначте ланцюжок із трьох класів: `A`, потім `B`, що успадковує від `A`, потім `C`, що успадковує від `B`. Виведіть порядок розв'язання методів для `C` як список імен типів.

## Приклад

Програма виводить:

```
(C B A Any Mu)
```
