## Завдання

Визначте клас `Animal` із методом `speak` і клас `Dog`, що успадковує від `Animal`, але не додає власних методів. За допомогою метаметоду для `Dog` виведіть, чи має `Dog` метод на ім'я `speak` (просте `True` або `False`). Це показує, що `find_method` шукає вздовж ланцюжка успадкування, а не лише серед власних методів класу.

## Приклад

Програма виводить:

```
True
```
