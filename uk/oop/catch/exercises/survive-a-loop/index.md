## Завдання

Пройдіть циклом числа `1`, `2` та `3`. Для кожного числа виведіть `ok: <n>`, але коли число дорівнює `2`, зробіть `die "bad: 2"`. Додайте всередину тіла циклу фазер `CATCH`, який виводить `caught: <message>`, щоб одна невдала ітерація не спиняла всього циклу.

## Приклад

Програма виводить:

```
ok: 1
caught: bad: 2
ok: 3
```
