## Завдання

Пройдіть циклом три елементи: `ok`, `bad` та `ok`. Для кожного виконайте блок, який виводить `processed <item>`, але робить `die 'boom'`, коли елемент дорівнює `bad`. Помістіть усередину блоку фазер `CATCH`, щоб про невдалий елемент повідомлялося як `skipped (<item>): <message>`, а цикл ішов далі до наступного елемента замість зупинятися.

## Приклад

Програма виводить:

```
processed ok
skipped (bad): boom
processed ok
```
