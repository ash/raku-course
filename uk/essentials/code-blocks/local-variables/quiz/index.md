## 1

Що виведе ця програма?

```raku
my $value = 100;

{
    my $value = 1;
    $value *= 2;
    say $value;
}
```

{:.quiz-select}
2 | Відповідь: (: 1, 2, 100, 200 :) | Використовується та виводиться локальна змінна.

## 2

Що виведе ця програма?

```raku
my $value = 100;

{
    my $value = 1;
    $value *= 2;
}

say $value;
```

{:.quiz-select}
100 | Відповідь: (: 1, 2, 100, 200 :) | Локальна змінна змінюється, але виводиться глобальна змінна.


## 3

Ця програма виглядає майже так само, але всередині блоку немає `my`. Що вона виведе?

```raku
my $value = 100;

{
    $value *= 2;
}

say $value;
```

{:.quiz-select}
200 | Відповідь: (: 1, 2, 100, 200 :) | Без `my` у блоці немає локальної змінної, тож він змінює ту саму глобальну.
