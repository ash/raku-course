Щоб виконати програму на Raku, вам потрібен встановлений компілятор. У цьому курсі використовується Rakudo; інший компілятор, [Raku++](/uk/essentials/the-rakupp-compiler), встановлюється [окремо](/uk/essentials/how-to-install-rakupp). Завітайте на [сайт Rakudo](https://rakudo.org), щоб завантажити версію, яка підходить для вашої операційної системи.

## Джерела

Встановлювач для вашої системи можна завантажити на сторінці [rakudo.org/downloads](https://rakudo.org/downloads). Існують версії для всіх основних операційних систем: Windows, Mac OS та Linux. Є й вихідні коди, які ви можете зібрати самостійно.

## Docker-образи

Rakudo доступний і як docker-образ. Його можна використовувати як для запуску програм, так і для перевірки невеликих скриптів в оболонці REPL. Усі настанови ви знайдете на [github.com/Raku/docker](https://github.com/Raku/docker).

## Номери версій

Система нумерації версій Rakudo складає номер версії з двох частин: року та місяця дати випуску. Так ви одразу бачите, наскільки свіжий ваш компілятор. Виконайте таку команду, щоб побачити номер версії:

```console
$ raku -v
Welcome to 𝐑𝐚𝐤𝐮𝐝𝐨™ v2026.06.
Implementing the 𝐑𝐚𝐤𝐮™ programming language v6.d.
Built on MoarVM version 2026.06.
```

Тут видно три номери версій. Перший — це версія самого Rakudo: `v2026.06`. Далі йде версія мови Raku: `v6.d`. Оновлення наразі отримують наступну літеру як молодшу частину версії, наприклад `v6.e` і так далі. Нарешті, ми бачимо назву віртуальної машини, яку використовує цей компілятор: MoarVM версії `2026.06`.
