Raku++ розповсюджується через свій репозиторій на GitHub, [github.com/ash/rakupp](https://github.com/ash/rakupp). Після встановлення ви отримуєте єдиний виконуваний файл під назвою `rakupp`.

## Бінарні файли

Готові бінарні файли поточного випуску доступні для Windows, macOS і Linux. Завантажте той, що відповідає вашій операційній системі, зі сторінки випусків репозиторію — більше нічого налаштовувати не потрібно, бо в Raku++ немає окремої віртуальної машини, яку треба встановлювати.

## Збирання з вихідного коду

Оскільки Raku++ написано мовою C++, ви можете зібрати його й самостійно з вихідного коду в репозиторії. Репозиторій пояснює, які інструменти для цього потрібні та як його скомпілювати.

## Номери версій

Дізнатися, яка версія у вас, можна за допомогою опції `--version`:

```console
$ rakupp --version
Raku++ (rakupp) 1.5.2 — a Raku interpreter and compiler in C++ (implements Raku 6.d, with 6.e features)
```

Цей рядок повідомляє випуск самого Raku++ (`1.5.2`) і те, на яку версію мови Raku він орієнтується (`6.d` з деякими можливостями `6.e`). Порівняйте це з банером версії Rakudo на [сторінці встановлення Rakudo](/uk/essentials/how-to-install-rakudo), щоб побачити, як два компілятори представляють себе.
