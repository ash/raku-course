Raku++ розповсюджується через свій сайт, [raku.online](https://raku.online), і свій репозиторій на GitHub, [github.com/ash/rakupp](https://github.com/ash/rakupp). Після встановлення ви отримуєте єдиний виконуваний файл під назвою `rakupp` — більше нічого налаштовувати не потрібно, бо в Raku++ немає окремої віртуальної машини, яку треба встановлювати.

## Встановлювач

У macOS, Linux і системах BSD одна команда завантажує збірку для вашого комп'ютера, перевіряє її та додає `rakupp` до вашого `PATH`. Права адміністратора для цього не потрібні:

```console
$ curl -fsSL https://raku.online/install.sh | sh
```

У Windows натомість виконайте цю команду у вікні PowerShell або завантажте майстер встановлення `rakupp-setup-windows-x64.exe` зі сторінки випусків репозиторію:

```console
> irm https://raku.online/install-windows.ps1 | iex
```

Встановлювач запитає, чи хочете ви, щоб Raku++ був доступний ще й під назвою `raku`. Після цього відкрийте новий термінал, щоб новий `PATH` набув чинності. Згодом команда `rakupp upgrade` оновить його до найсвіжішого випуску.

## Інші способи встановлення

* У macOS за допомогою Homebrew: `brew tap ash/rakupp && brew install rakupp`.
* Через Docker, нічого не встановлюючи: `docker run --rm -it ghcr.io/ash/rakupp` запускає інтерактивну оболонку REPL.
* Готові архіви для кожної платформи є на сторінці випусків репозиторію.
* Оскільки Raku++ написано мовою C++, ви можете зібрати його й самостійно з вихідного коду; репозиторій пояснює, які інструменти для цього потрібні.

## Номери версій

Дізнатися, яка версія у вас, можна за допомогою опції `--version`:

```console
$ rakupp --version
Raku++ 5.4.1 (2026-10-13) arm64-darwin
```

Цей рядок повідомляє випуск самого Raku++ (`5.4.1`), дату його збирання та платформу, для якої призначено виконуваний файл. Версія мови Raku — окрема річ, і про неї можна запитати саму мову:

```console
$ rakupp -e 'say $*RAKU.version'
v6.d
```

Порівняйте це з банером версії Rakudo на [сторінці встановлення Rakudo](/uk/essentials/how-to-install-rakudo), щоб побачити, як два компілятори представляють себе.
