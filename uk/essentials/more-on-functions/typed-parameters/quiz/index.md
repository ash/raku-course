## 1

Дано функцію:

```raku
sub f(Rat $x) {
    say 2 * $x;
}
```

Які виклики правильні?

{:.quiz}
0 | f(3); | Навіть якщо `3` вміщується в контейнер `Rat`, виклик хибний, бо `3` — це `Int`, а не `Rat`.
1 | f(3.5);
0 | f(3e0);
0 | f(&apos;3&apos;);
1 | f(<4/5>); | Це число типу `Rat`.


## 2

Дано функцію:

```raku
sub g(Int $a, Str $b) {
    say "Integer $a, string $b";
}
```

Які виклики правильні?

{:.quiz}
0 | g(10, 20);
0 | g(&apos;10&apos;, 20); | Навіть якщо будь-який з аргументів можна перетворити, Raku вимагає точного типу.
1 | g(10, &apos;20&apos;);
0 | g(&apos;10, 20&apos;); | Передано один рядок.
0 | g(&apos;10&apos;, &apos;20&apos;);
