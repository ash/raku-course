## 1

Що повертає ця функція?

```raku
sub f($a, $b) {
    return $a + $b if $a > $b;
    return 42;
}
```

{:.quiz-select}
42 | `f(1, 2)` повертає&nbsp; (: 1, 2, 3, 42 :)
3 | `f(2, 1)` повертає&nbsp; (: 1, 2, 3, 42 :)
42 | `f(2, 2)` повертає&nbsp; (: 1, 2, 3, 42 :)

## 2

Що повертає ця функція?

```raku
sub g() {
    return -1;
    1;
}
```

{:.quiz-select}
−1 | `g()` повертає&nbsp; (: −1, 1 :) | До останнього виразу `1;` виконання ніколи не доходить.
