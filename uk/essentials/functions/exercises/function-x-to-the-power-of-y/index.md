## Завдання

Створіть функцію з двома аргументами, яка повертає значення `$x` у степені `$y`. Напишіть програму, яка виводить значення `5³`, `2¹⁰` та `(−4)⁵`.

## Приклад

Для наведених вище значень програма має вивести:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
